Khayt — पूर्ण परियोजना योजना

स्थानीय-प्रथम प्लेटफ़ॉर्म भरोसेमंद ब्राउज़र एजेंट बनाने और चलाने के लिए, हर चरण पुनरुत्पादित करता है और मनुष्य को निर्णय के केंद्र में रखता है।

डिजिटल परियोजना की योजना: विचार, दर्शक, उत्पाद, राजस्व, विस्तार, जोखिम। परियोजना निर्माणाधीन, लॉन्च नहीं हुई।

1) लक्षित दर्शक

• AI एजेंट डेवलपर: निरीक्षण-योग्य, पुनः चलाने योग्य ब्राउज़र ऑटोमेशन, नाज़ुक स्क्रिप्ट नहीं।

• ऑटोमेशन इंजीनियर/QA: मैनुअल टेस्ट से भरोसेमंद workflows।

• एजेंसियाँ/छोटी टीमें: ग्राहक डेटा संग्रह/प्रविष्टि, बिना ऊँची क्लाउड लागत।

• डेटा-संवेदनशील संगठन: infrastructure पर निजी मॉडल कुंजियों/Ollama के साथ ऑटोमेशन।

• शोधकर्ता/तकनीकी कंटेंट निर्माता: मुफ़्त, दोहराया जा सकने वाला प्रयोग वातावरण।

2) विशिष्टताएँ

• स्थानीय-प्रथम: एक कमांड से स्थानीय वेब UI, डिवाइस/Docker executor, Ollama/OpenAI-संगत प्रदाता; डेटा बाहर नहीं।

• दोहरा संपादक: DAG दृश्य निर्माण, TypeScript/Python नियंत्रण, typed variables, तत्काल validation।

• replay कैप्सूल: screenshots, DOM snapshots, network logs, model calls का रिकॉर्ड; PII स्वतः साफ़; त्रुटि पुनरुत्पादन।

• छिपाव नहीं, governance: fingerprint impersonation/CAPTCHA bypass नहीं; allowlist, rate limits, संवेदनशील क्रियाओं पर मानव स्वीकृति, audit log।

• पोर्टेबल export: workflow को MCP server, REST API, webhook, CLI में बदलें; provider lock-in नहीं।

• evaluation lab: test cases, assertions, regression तुलना, success rate; maintainable engineering asset बनाएँ।

3) पहला संस्करण (अधिकतम 8 कार्य)

1. स्थानीय executor: Docker/npm इंस्टॉल, Playwright Chromium, Ollama/बाहरी API कुंजी।

2. Web studio: visual editor + code panel, typed variables, validation, local save.

3. Editable recorder: clicks, typing, navigation; coordinates से पहले accessibility tree selectors.

4. Replay capsule: screenshots, DOM, network metadata, console, LLM calls; संवेदनशील फ़ील्ड masking.

5. Parallel queue: concurrency, timeouts, retries, token/cost budgets.

6. Policy engine + secrets vault: domain allowlist, संवेदनशील क्रियाओं पर मानव स्वीकृति, rate limits, audit log.

7. Export/automation: MCP server, REST/webhook, scheduling, CLI; वही workflow studio के बाहर।

8. Evaluation lab: test data, assertions, version तुलना, exportable pass/fail report.

4) मूल्य निर्धारण और राजस्व

• Free / Local: self-hosting सदा मुफ़्त; unlimited workflows, 2 parallel sessions, 7 दिन history, local models/उपयोगकर्ता keys, community support.

• Pro: $19/उपयोगकर्ता/माह; cloud sync, 10 parallel sessions, 30 दिन history, scheduled runs, email support.

• Team: $39/उपयोगकर्ता/माह; shared workspace, RBAC/SSO, audit log export, 50 parallel sessions, 90 दिन history, priority support.

• Enterprise: custom pricing; isolated deployment, SLA, compliance review, private connectors, training.

राजस्व: team subscriptions + cloud capacity + deployment/integration services. Model keys पर margin नहीं; मुफ़्त local version गंभीर उपयोग योग्य।

5) मुफ़्त चैनलों से वैश्विक विस्तार

• GitHub पहले: Apache 2.0 open-source core, workflow templates, beginner issues, documented releases.

• SEO/technical content: स्थानीय ब्राउज़र ऑटोमेशन व self-hosted विकल्प, अंग्रेज़ी-अरबी लागत/गोपनीयता तुलना।

• YouTube/blogs: 10-मिनट workflow tutorials, replay debugging, local बनाम cloud benchmark.

• Communities: Show HN, Product Hunt, Ollama/MCP communities, नियमों के अनुसार subreddits, आधिकारिक Discord.

• Integrations: n8n, LangChain, LlamaIndex, Dify templates; MCP server को MCP directories/tool lists में दें।

• Partnerships: automation agencies, university clubs, hackathons, local AI meetups. मुख्य मेट्रिक: पहला run 10 मिनट से कम, साप्ताहिक template reuse.

6) जोखिम (कानूनी/तकनीकी)

कानूनी:

• साइट शर्तों/data-protection कानूनों का उल्लंघन। शमन: usage policy, allowlist, audit logs, robots/आधिकारिक API सम्मान, CAPTCHA bypass/impersonation से इनकार।

• एजेंट actions की ज़िम्मेदारी। शमन: वित्तीय/प्रेषण actions पर मानव स्वीकृति, स्पष्ट सीमाएँ, contractual disclaimer.

• डेटा गोपनीयता/key secrecy. शमन: default local operation, secrets encryption, log sanitization, cloud के लिए DPA.

तकनीकी:

• साइट बदलाव/selectors टूटना। शमन: semantic selectors, pinned browser versions, replay regression detection.

• Anti-bot blocking. शमन: transparent failure, आधिकारिक APIs की सिफ़ारिश, stealth feature नहीं।

• Executor में untrusted code. शमन: container isolation, least privilege, template signing, secrets separation.

• Page content/MCP tools से prompt injection. शमन: content sanitization, limited-scope tokens, संवेदनशील tools से पहले approval.

• Cost/overuse. शमन: concurrency limits, budgets, default timeouts.

नाम: Khayt

टैगलाइन: स्थानीय-प्रथम प्लेटफ़ॉर्म, भरोसेमंद ब्राउज़र एजेंट निर्माण/संचालन, हर चरण पुनरुत्पादनीय और मनुष्य निर्णय-केंद्र में।
