क़िरतास — संपूर्ण परियोजना योजना

हम वेब को एक ही अनुरोध में AI एजेंट्स के लिए साफ़, तैयार डेटा में बदलते हैं।

एक नई डिजिटल परियोजना की पूर्ण कार्यान्वयन योजना: विचार, दर्शक, उत्पाद, राजस्व मॉडल, प्रसार और जोखिम। परियोजना निर्माणाधीन है, अभी लॉन्च नहीं हुई।

उत्पाद योजना: स्मार्ट एजेंट्स के लिए वेब डेटा निष्कर्षण मंच

1) लक्षित दर्शक

• AI एप्लिकेशन डेवलपर्स जो Agents या RAG बनाते हैं और साफ़ वेब सामग्री चाहते हैं।

• छोटे स्टार्टअप जो स्क्रैपिंग/प्रोसेसिंग परत शुरू से नहीं बनाना चाहते।

• डेटा विश्लेषण और शोध टीमें जो कई साइटों से नियमित सामग्री एकत्र करती हैं।

• ऑटोमेशन एजेंसियाँ और no-code समाधान निर्माता (n8n, Make) जो तैयार एकीकरण चाहते हैं।

• शोधकर्ता और शिक्षाविद जिन्हें संरचित रूप में पृष्ठों/संदर्भों का संग्रह चाहिए।

2) विशिष्टताएँ (हमारा उत्पाद क्यों चुनें)

• वास्तविक मुफ़्त शुरुआत: स्थायी मासिक क्रेडिट, बिना कार्ड, परीक्षण/छोटे उत्पादन के लिए पर्याप्त।

• एजेंट-तैयार आउटपुट: साफ़ Markdown, उपयोगकर्ता-निर्धारित Schema-बद्ध JSON, ज़रूरत पर स्क्रीनशॉट।

• एजेंट्स हेतु मूल डिज़ाइन: Async Jobs, Webhooks, MCP सर्वर, आधिकारिक SDK — पारंपरिक स्क्रैपिंग API के बजाय।

• अरबी/बहुभाषी समर्थन: RTL, तश्कील और मिश्रित-भाषा पृष्ठों का प्रसंस्करण।

• लागत पारदर्शिता: प्रति अनुरोध स्पष्ट उपयोग काउंटर; Cache दोहराए कॉल घटाकर बिल कम करता है।

• अंतर्निहित अनुपालन: डिफ़ॉल्ट रूप से robots.txt और साइट नीतियों का सम्मान, प्रति ऑपरेशन ऑडिट लॉग।

• कोई तकनीकी लॉक-इन नहीं: डेटा निर्यात, खुले मानकों वाला इंटरफ़ेस, बाद में Enterprise हेतु self-hosting।

3) पहला संस्करण दायरा (अधिकतम 8 कार्य)

1. extract: एक लिंक को साफ़ Markdown में बदलना; मेन्यू/विज्ञापन/शोर हटाना।

2. extract + कस्टम JSON Schema: विशिष्ट फ़ील्ड (कीमत, शीर्षक, तारीख…) निकालना।

3. JavaScript पृष्ठों हेतु Headless Browser इंजन, स्मार्ट लोड-प्रतीक्षा के साथ।

4. सीमित crawl: निर्धारित गहराई तक साइट खोजना और लिंक मैप लौटाना।

5. search: पृष्ठ खोजना और सर्वोत्तम परिणाम सीधे निकालना।

6. API कुंजी, कोटा/बैलेंस प्रणाली, सरल डैशबोर्ड और उपयोग लॉग।

7. Async Jobs + Webhooks + प्रारंभिक SDK (Python, TypeScript) + MCP सर्वर।

8. Cache, त्रुटि लॉगिंग, स्वचालित पुनःप्रयास, पूर्ण दस्तावेज़ और तैयार उदाहरण।

4) मूल्य निर्धारण और राजस्व मॉडल

• Free: निश्चित मासिक क्रेडिट (जैसे 500 ऑपरेशन), कम दर सीमा, बिना कार्ड।

• Pay-as-you-go: Free के बाद उपयोग-आधारित भुगतान, प्रति ऑपरेशन/हज़ार पृष्ठ।

• Starter / Growth: अधिक क्रेडिट, प्राथमिकता, व्यापक सीमाएँ, कम प्रति-ऑपरेशन दर।

• Enterprise: उपयोग समझौता, कस्टम सीमाएँ, SLA, चालान, self-hosting विकल्प।

• अतिरिक्त राजस्व: तैयार Templates बाज़ार (कमीशन), सशुल्क इंटरफ़ेस (स्क्रीनशॉट, PDF, जटिल तालिका निष्कर्षण)।

• मूल्य सिद्धांत: सरल एकीकृत क्रेडिट, सीमित अवधि तक अप्रयुक्त क्रेडिट स्थानांतरण, वार्षिक भुगतान पर छूट।

5) मुफ़्त चैनलों के साथ वैश्विक प्रसार योजना

• GitHub पर ओपन-सोर्स SDK और CLI, व्यावहारिक उदाहरण और मज़बूत README।

• MCP सर्वर को MCP निर्देशिकाओं और एजेंट टूल स्टोर्स में सूचीबद्ध करना।

• SEO-अनुकूलित दस्तावेज़, तुलना गाइड और प्रत्येक उपयोग-मामले हेतु "कैसे करें"।

• Product Hunt, Hacker News और Reddit (r/LocalLLaMA, r/MachineLearning) पर ईमानदारी से लॉन्च।

• LangChain, LlamaIndex, n8n, Make और Zapier के साथ मुफ़्त एकीकरण।

• YouTube पर छोटे वीडियो; dev.to और Medium पर लिखित ट्यूटोरियल।

• Discord समुदाय और साप्ताहिक न्यूज़लेटर, उपयोग-मामलों/अपडेट के साथ।

• विश्वविद्यालय प्रतियोगिताएँ/हैकाथॉन और ओपन-सोर्स पहलों का प्रायोजन (Good First Issues)।

6) जोखिम (कानूनी और तकनीकी)

कानूनी:

• साइट उपयोग शर्तों/कॉपीराइट के प्रति बदलती अनुपालन आवश्यकताएँ; समाधान: robots.txt का सम्मान, स्वीकार्य उपयोग नीति, डोमेन अपवाद।

• व्यक्तिगत डेटा संरक्षण (GDPR/CCPA) जब सामग्री में व्यक्तियों का डेटा हो; समाधान: न्यूनतम संग्रह, डिफ़ॉल्ट रूप से दीर्घकालिक भंडारण नहीं, हटाने के उपकरण।

• निकाली सामग्री हेतु उपयोगकर्ता की ज़िम्मेदारी; समाधान: स्पष्ट सेवा शर्तें और अनुमत उपयोग की व्याख्या।

• क्षेत्रीय रूप से भिन्न कानूनी जोखिम; समाधान: नियमित समीक्षा, डोमेन प्रतिबंध में लचीलापन।

तकनीकी:

• स्क्रैपिंग-विरोधी प्रणालियाँ, CAPTCHA, IP ब्लॉकिंग; समाधान: नेटवर्क विविधीकरण, पुनःप्रयास, सेवा सीमाओं की सूचना।

• JavaScript रेंडरिंग की उच्च लागत; समाधान: स्मार्ट Cache, जहाँ संभव हो हल्का रेंडरिंग, स्पष्ट सीमाएँ।

• साइट डिज़ाइन बदलने पर निष्कर्षण की नाज़ुकता; समाधान: लचीले Schema, निगरानी परीक्षण, अलर्ट।

• वेब सामग्री से Prompt Injection/डेटा प्रदूषण; समाधान: आउटपुट सफ़ाई, अविश्वसनीय सामग्री को चिह्नित करना।

• इंटरफ़ेस सुरक्षा (SSRF, कोटा दुरुपयोग); समाधान: ब्लॉकलिस्ट डोमेन, दर सीमाएँ, विसंगति निगरानी।

• विश्वसनीयता/स्केलेबिलिटी; समाधान: प्रसंस्करण कतारें, निगरानी, रिकवरी योजना, क्रमिक उपलब्धता।

7) प्रस्तावित नाम और विपणन वाक्य
