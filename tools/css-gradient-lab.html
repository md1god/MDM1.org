مختبر التدرجات اللونية وتوليد CSS

أنشئ تدرجات لونية مع معاينة فورية، اضبط الزاوية والمواضع والألوان، واحصل على CSS جاهز للنسخ والاستخدام في المواقع والتطبيقات دون اتصال بالإنترنت.

نعم، يمكنك تصميم تدرج لوني كامل في ثوانٍ ونسخ شيفرته فورًا من هذه الصفحة. اختر نوع التدرج، ثم حرّك الزاوية ومواضع الألوان حتى تصل إلى الشكل المطلوب. تتغير المعاينة مباشرة مع كل تغيير، لترى النتيجة قبل نسخها إلى مشروعك. يمكنك استخدام التدرج في خلفية موقع، أو زر، أو بطاقة، أو عرض بسيط على شاشة. لا تحتاج إلى ملفات، ولا إلى رفع صور، ولا إلى حساب؛ كل الحسابات تتم داخل المتصفح على جهازك. عند الانتهاء، انسخ CSS من مربع النتيجة وألصقه في ورقة الأنماط أو مكوّن الواجهة.

اضغط إنشاء التدرج لعرض النتيجة.

أسئلة شائعة

ما الذي تفعله هذه الأداة؟

تحوّل اختياراتك للألوان والمواضع إلى تدرج CSS جاهز، مع معاينة فورية ونص يمكن نسخه مباشرة.

هل أحتاج إلى رفع صور أو إنشاء حساب؟

لا. كل شيء يعمل داخل المتصفح، ولا تُرسل الألوان أو الأسماء إلى أي جهة أخرى.

متى أختار التدرج المخروطي؟

استخدمه للعجلات، ومؤشرات النسب، والخلفيات التي تدور حول نقطة مركزية بدل الانتقال في خط واحد.

ماذا تعني نسبة التباين الظاهرة؟

هي تقدير لفرق السطوع بين طرفي التدرج؛ كلما زادت كان الفرق أوضح، وهو مفيد عند وضع نص فوق التدرج.
