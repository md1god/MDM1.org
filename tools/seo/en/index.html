When to use these tools

Use UTM parameters to distinguish campaign traffic in an analytics platform that supports them. Use the metadata preview to review a page title, description, canonical URL, and common social tags before publishing. Use the robots.txt generator to draft crawler guidance, then check it against your actual site configuration and the current documentation of the search engine you care about. Keep a copy of existing settings before changing them.

Good practices to keep in mind

  • Give important pages accurate, distinct titles and descriptions.
  • Verify canonical URLs and sitemap links on the deployed site, not only in a preview.
  • Never use robots.txt as access control; protect private content with authentication and permissions.
  • Treat character counts and previews as estimates: search engines and social platforms may rewrite or truncate text.
