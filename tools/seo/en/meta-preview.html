What does the preview include?
The mockup shows a title, description, and displayed URL. The generated snippet includes title, meta description, canonical link, Open Graph title/description/URL/site name, and common Twitter title/description/card tags. These tags give compatible systems information about the page, but they do not completely control how a platform displays it.
Write for the person who will click
Choose a title that accurately describes the page and reads naturally. Include a brand name when it helps recognition, not as repeated filler. Write a description that explains what a visitor will find and why it is relevant. Give important pages distinct metadata rather than copying the same description across the whole site.
Character counts are estimates
This tool counts characters, not rendered pixel width. Available space varies with device, font, query, and interface. Search engines may shorten a title, rewrite it, or select text from the page itself. The social mockup here previews text only; it does not fetch or validate an Open Graph image. Use the destination platform’s current official preview or debugging tools when image and card behavior matters.
Frequently asked questions
Is this preview guaranteed to match Google?
No. It is a simplified mockup for catching obvious issues. A search engine can choose a different title or excerpt based on the page and query.
Are my page details uploaded?
No. Previewing and generating tags happen in this page in your browser. Remember that published metadata is public.
Do I need both Open Graph and Twitter tags?
Use the tags supported by the sharing platforms that matter to you, and check their current documentation because display behavior can change.
