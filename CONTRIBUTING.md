# Contributing to MDM1.org

Thank you for helping make MDM1 easier to discover and use. Small contributions are welcome: fix a broken link, add a useful tool, improve a translation, test the assistant on a phone, or document a reproducible issue.

## Quick start

```bash
git clone https://github.com/md1god/MDM1.org.git
cd MDM1.org
python3 -m http.server 4174
```

Open `http://127.0.0.1:4174/assistant/` and test the page. Do not add API keys, private credentials or personal data to the repository.

## Good first contributions

- Add or improve a catalog record with a verifiable public URL.
- Improve Arabic or English copy without changing the meaning of pricing or privacy claims.
- Test HTML, JavaScript, Python and SQL generation and report a reproducible issue.
- Check keyboard navigation, mobile layout, alt text and reduced-motion behavior.
- Add a translation only when the translated page contains meaningful content and correct links.

## Pull requests

Explain what changed, why it helps a visitor, and how you tested it. Keep unrelated formatting changes out of the same pull request. For UI changes, include the route and a screenshot when practical. Never claim that a tool is free, safe or open source without checking its current public terms.
