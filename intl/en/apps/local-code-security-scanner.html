No file or text leaves your device during scanning, saving, or exporting; results are stored only in your browser's local storage, and you can download them in structured formats to review later, share with your team, or attach to security review reports. You can also generate a security policy draft and a threat model ready for download and editing according to your project's nature, assets, and various deployment environments.

FAQ

Are the code or results uploaded to an external server during the scan?

No. The tool runs entirely in the browser. Files are read locally, scans are saved only in your device's local storage, and files are downloaded directly from your browser without any network transmission.

What types of issues does the scan detect?

The scan detects embedded secrets such as passwords and access keys, dangerous functions such as dynamic execution and system commands, SQL injection patterns built by concatenating strings, and XSS patterns such as writing directly to HTML.

How do I control severity levels and remove duplicates?

Choose a severity for each category from the drop-down menus, set the minimum severity to show, and enable the remove duplicate results option to hide matching results with the same line, rule, and snippet.

How do I save a scan and export the results?

Select Save current scan locally, then load it later from the list. To export results, choose JSON, CSV, or SARIF; you'll get files ready for review or for other static analysis tools.

What do the Generate SECURITY.md and Generate threat model buttons do?

They generate a draft security disclosure policy and a threat model based on the current scan summary. You can review and edit the text and download it as Markdown for use in your project.
