FAQ

Does this studio work without a server or databases?

Yes, it runs entirely in the browser and saves all data in local storage. You can export and import it as text.

How do I test the billing flow before launch?

Select a plan and billing cycle, then run the simulation. Try a discount code and trial period, then confirm a successful payment or simulate a failure.

Do permissions change based on the current role?

Yes, edit each role's permissions from the dashboard. The current role determines whether you can manage plans, content, and export.

Can I safely try themes and add-ons?

Yes, apply a theme to the studio locally and enable add-ons such as discounts, analytics, and currency conversion, then save or revert them.

What happens when all data is deleted?

The reset button clears local storage and restores default values, so export your settings first if you want to keep them.
