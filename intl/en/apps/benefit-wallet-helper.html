Calculate tax savings and choose the right card with ease

Free web tool that calculates tax savings on everyday transactions and checks eligibility for HSA, FSA, LSA, or employee benefits, and shows the ideal…

The tool automatically calculates tax savings and picks the right card, and lets you log every daily purchase with a note and invoice photo to make reimbursement easier. Everything runs in the browser with no servers or remote storage, so your data stays private and the tool is easy to use on any device. Choose the tax category, enter the amount, add your notes, and attach an invoice photo to see it in the preview, then click Calculate to see the amount saved and the best card to use. You can also export your data as a JSON file or import a previously saved file to restore your information easily.

FAQ

How is tax savings calculated?

The amount is multiplied by the discount rate set for the selected category (for example 15 % for HSA) to show the savings.

Can I save the data to come back to it later?

Yes, use the Export data button to save a JSON file then import it when needed with the Import file button.

What image types can I attach?

The tool supports all browser-supported image formats such as JPEG and PNG, and shows an instant preview on the canvas.

Is any information sent to external servers?

No, all processing happens in the browser and no data is sent to the server.

What should I do if I forget to choose a category?

An alert will ask you to fill in all required fields before calculating.
