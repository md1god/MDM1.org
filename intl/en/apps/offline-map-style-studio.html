Custom map designer for local files

Design custom maps in your browser from local GeoJSON and OSM XML files, with pan and zoom, custom colors for roads, water, buildings, and labels, plus…

Yes, this tool lets you design a fully custom map in your browser without a server, account, or network connection by uploading a local GeoJSON or OSM XML file and previewing it instantly on an interactive canvas that supports drag-to-pan and zooming with the wheel or buttons. You can then customize each layer separately, such as roads, water, buildings, and points, by changing fill or border color, line width, label visibility, label color, size, and font, and you can also set the background color and polygon borders. Multiple styles are saved in your browser's local storage for later use, and you can export the style as a JSON file or an HTML page ready to embed in any site, with live statistics for the number of features in each layer and clear alerts when the file is missing or has a formatting error.

FAQ

Does the tool work completely offline?

Yes, all processing happens in your browser using JavaScript and Canvas, with no server or account. Your local files stay on your device and are never sent anywhere.

What geographic file formats and layers are supported?

The tool supports GeoJSON, JSON, and OSM XML files, and automatically classifies features into roads, water, buildings, points, and other layers based on geometry type and properties like highway, building, and water.

Where are my saved styles stored?

Styles are saved in your browser's localStorage only. You can save, apply, or delete named styles at any time without an account.

How do I use the exported HTML page on my website?

Copy the text shown in the export box after clicking the Export HTML page button, then save it as an HTML file or paste it into an existing page. It includes the map data and style and renders without external libraries.

What should I do if an error appears when uploading a file?

A clear message will appear in the status box explaining the file format issue, while the previous map remains displayed. You can choose another valid GeoJSON or OSM XML file or try the sample data.
