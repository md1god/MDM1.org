FAQ

How do I check for collisions between items?

When you place a new item, the available space is checked automatically. If there is an overlap, the system shows an error and does not add the item.

Can I edit the transfer volume after adding a step?

Yes, you can edit the values in the fields above the list, then click "Add step" to update the list.

What format is the exported file?

The file is exported as JSON containing component and step details, and it can be easily imported again.

Does it support units other than µL?

The app supports µL and mL units, and you can select the unit from the dropdown menu.

Can I run the preview without any visual components?

Yes, even without components, the preview shows the transfer path on the workspace to illustrate timing and order.
