Check phone, email, and IP lists in the browser

Upload a CSV file or paste data to classify phone numbers, email addresses, and IP addresses. Identifies privacy, reserved status, and suspicious…

You can check lists of phone numbers, email addresses, and IP addresses directly in the browser without sending any data to the server. Add a CSV file or paste text into the dedicated field, then choose the check type if you want to guide the analysis, and press the check button to show the results in a detailed table with the classification, status, and any suspicious pattern detected. The app keeps a shared check balance in memory, each check consumes part of it, and you can export the results as a CSV file or import a JSON file to restore the balance. The interface is designed to integrate easily with the current page and responds to programmatic calls from page code without needing a network.

FAQ

How is data processed?

All analysis runs locally in the browser, no information is sent to the server, so your privacy stays protected.

What happens when the check balance runs out?

The check button stops working and the remaining balance shows zero; the balance can be restored either by resetting the app or by importing a JSON file containing a stored balance.

Which file types are supported?

CSV files with one line per item are supported, and data can also be pasted directly into the text field.

Can results be exported?

Yes, there is a "Download CSV" button to generate a CSV file with all the results, and you can also import a JSON file to restore the balance and previous results.
