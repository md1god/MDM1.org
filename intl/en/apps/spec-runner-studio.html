FAQ

How is the entered code validated?

The tool looks for a simple pattern indicating email validation logic, such as the word “email” or the symbol “@”.

Can I modify the test to include other behaviors?

Yes, you can edit the generateReport function in the code to add custom checks as needed.

What format is the downloaded summary in?

The summary is exported as Markdown so you can easily copy it into pull requests or project docs.

Can I share my settings with another team?

Sure, use the “Export Settings” button to get a JSON file that teammates can import directly.

Is the tool affected by the current site theme?

No; it uses the site's global CSS variables (such as --gold, --dark) to match the existing dark/gold look.
