Classic computer emulator running entirely in your browser

A serverless classic computer emulator in your browser: desktop, local files, an interpreter, productivity tools and games, with snapshots and disk import.

This app is a classic computer emulator that runs entirely in your browser with no server. It provides a desktop with draggable windows, a virtual file system saved locally in your browser, a real-time CPU instruction interpreter, and native productivity tools like a text editor, drawing app, calculator, and file manager, plus small games. You can create and save files, draw images and export them, run assembly programs step by step, and play Snake, with snapshot saving and compatible disk import. All data stays on your device and is never sent to any server. You can use a keyboard or game controller.

FAQ

Does the app work offline?

Yes, everything runs in the browser and no data is sent to any server.

Where are my files and snapshots saved?

They are saved in your browser's local storage (localStorage) on your device.

How do I import a disk (disk image)?

From the file manager, choose a JSON file containing a list of files, or a text file to add it as a file.

What instructions does the interpreter support?

It supports MOV, LOAD, STORE, ADD, SUB, MUL, DIV, CMP, JMP, JZ, JNZ, PUSH, POP, PRINT, HALT, and more.

Can I use a game controller?

Yes, in Snake, the game controller (Gamepad API) is read automatically.
