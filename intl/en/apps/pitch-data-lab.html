Browser-Based Soccer Match Analyzer from JSON Files

Analyze soccer match JSON files with no server or account: timeline, xG shot map, passing networks, heatmaps, and team stats.

In short, this app turns a raw JSON file into a complete soccer match analysis without sending any data to a server or creating an account. All processing happens locally in your browser, so your data stays private and the tool works even offline. After uploading a file, pasting its content, or trying the sample data, you'll instantly see team and player summaries and a sorted event timeline showing the minute, team, player, and event type to track the match moment by moment. The shot map displays attempt locations, highlights goals, and scales circles by expected goals (xG), while the passing network connects players with lines representing their passes, and the heatmap reveals the most active areas on the pitch. You can filter by team or event type, click any shot to view its details, save projects locally to load later, or export charts to share with your team.

FAQ

Is my data uploaded to any server during analysis?

No. All processing happens entirely in your browser. Importing files, reading text, and saving projects are all done locally without sending data to any server.

What JSON format is supported?

The tool supports a direct array of events or an object containing an events field, and accepts common fields like minute, type, team, player, location, xg, and outcome with many alternative names.

How do I read the shot map?

Gold circles are goals, light circles are unrecorded attempts, and the larger the circle, the higher the expected goals value. Clicking any point shows its minute, player, and team.

How do I save and share a project?

Enter a project name and click Save project locally. You can load it later from the list or export it as a JSON file. You can also download the shot, pass, and heat maps as images to share.

What happens if the file is invalid or has no events?

A clear error message appears in the results box, and charts and tables remain in an organized empty state instead of breaking. You can fix the JSON or try the sample data.
