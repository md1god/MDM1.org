Analyze diffs and generate an instant risk report

A browser-based tool that analyzes pasted diffs or a manually entered pull request description, assigns a risk score from 0 to 100, and highlights files…

This app gives an instant risk score for pasted or manually entered diffs, analyzing regressions, permissions, data loss, and reversibility. It identifies files that need human review, explains each alert, and lets you adjust policy thresholds and switch diff templates for the current session only. After analysis, you can export a comprehensive report in Markdown or JSON to document the review or integrate it into workflow systems.

FAQ

How is the risk score calculated?

It is calculated based on the number of changes, the presence of sensitive keywords, and the user-defined policy score.

Can policy thresholds be changed after analysis?

Yes, you can change the threshold value and rerun the analysis to update the result immediately.

How do I export the report?

You can export it in either Markdown or JSON using the dedicated buttons, and the file is saved directly to your device.

Does the app support importing previous settings?

Yes, the “Import settings” button lets you load a JSON file containing policy thresholds and the template to apply them immediately.

Which files are shown as risk lines?

It shows any line containing words such as DROP, DELETE, or TRUNCATE with the line number and the reason.
