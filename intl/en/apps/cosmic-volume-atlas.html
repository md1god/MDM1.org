Explore 3D slices of cosmic data right in your browser

Interactive tool for reading local CSV/JSON files and viewing XY/XZ/YZ slices, creating derived fields, plotting radial profiles, browsing time series,…

This lab displays 3D slices of cosmic data in a direct, easy-to-use way. You can upload a CSV or JSON file from your device, choose a slice level, and change display settings in moments. It supports creating derived fields with simple equations, plotting histograms, and showing radial profiles, as well as browsing time series when available. Everything runs inside your browser without sending any data to the server, and you can export the result as a PNG image or save your settings as a JSON file for later use.

Derived field (a·x + b·y + c·z)

FAQ

How do I upload a data file?

Click “Data file” and choose a CSV or JSON file from your device. The data is read directly in the browser.

Can I edit the derived field?

Yes, use the a, b, c fields to set a simple equation of the form a·x + b·y + c·z, then click “Draw slice” to apply it.

What export formats are available?

You can export the scene as a PNG image or save your settings as a JSON file for later use.

Do you support time-series data?

If the file contains a “time” column, you can browse the values by changing the slice position; there is no separate time slider in the current version.

Is any data sent to the server?

No, all processing happens locally in the browser and no information is sent to servers.
