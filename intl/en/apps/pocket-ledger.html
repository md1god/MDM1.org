Track your income and expenses easily in the browser

A ledger app that runs entirely in the browser for manually recording income and expenses, with multiple accounts, categories, monthly budgets, and CSV…

You can easily record income and expenses manually with this in-browser ledger. The app lets you create multiple ledgers and accounts, define subcategories, set monthly budgets, and set up recurring transactions with tags for better categorization. It supports CSV import and export for data exchange, and provides a simple chart showing spending and income trends. All data is stored temporarily in the browser session only and is not sent to any server, making it safe and suitable for quick use.

FAQ

How do I delete an incorrect transaction?

Click the “Delete” button in the transaction's row in the log table to remove it immediately.

Can I edit existing categories or accounts?

Currently you can add new categories and accounts manually via the options menu; editing requires deleting and re-entering the transaction.

What is the import file format?

It should be a JSON file containing an array of objects with the same structure as the transactions exported by the app.

Is data saved after closing the browser?

No, data is saved only in the current browser session; export it before closing the page if you want to keep it.
