      How to use and save

      Add a contact, then drag its card between columns or change the stage in the details. Use search and filters to narrow results, and add notes, interactions, and follow-up tasks. Data stays in page memory only; export a JSON file before leaving and re-import it when you return, or export a CSV file to share with spreadsheet apps.

      FAQ

      Is my data saved after I close the page?

      Data stays in page memory only, so export a JSON file before closing, and you can import it later to pick up where you left off.

      How do I move a card to another stage?

      Drag and drop the card into the desired stage column, or open the details, choose the stage from the dropdown, and save changes.

      Can I search within tags and companies?

      Yes, the search field checks name, company, email, phone, and tag instantly, and you can combine it with stage filtering or clear the filter with one click.

      What's the difference between CSV and JSON?

      CSV works well for spreadsheets and accounting software, while JSON keeps notes, interactions, and tasks intact for re-importing into the board.
