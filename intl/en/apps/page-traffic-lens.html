Visitor classification and page activity dashboard

Estimate visitor type: human, bot, or AI agent, from user agent, referrer, language, and time zone. Record clicks and scrolling in memory, with replay…

Yes, you can estimate the current visitor type on a static page with no server: start by entering or editing the user agent, referrer, language, and time zone signals, then add a company name or domain you know manually, and click Classify visitor. The tool shows a clear result with a confidence score and reviewable reasons, and records clicks, scrolling, and focus changes in page memory only during the session. You can replay the sequence in the widget, copy a text report, or export a JSON file and import it later. Estimates are approximate by nature; a page without a server can't know real companies or see past visits, but it gives you the closest local view of visitors and page activity.

    FAQ

    Does the tool identify the real company?

    No. It relies on signals sent by the browser or a value you enter manually, and it all remains a local estimate within the page.

    What's the difference between a bot and an AI agent here?

    A bot is treated as a crawler or automated testing tool, while an AI agent is treated as an assistant or AI service. Signals can overlap, so a confidence score is shown with the reasons.

    Are events saved after the page is closed?

    No. Clicks, scrolling, and focus changes stay in memory for the session only. You can copy the report or export a JSON file manually before leaving.

    What happens when importing an invalid file?

    A clear error message appears, and current data is not replaced. A valid file reloads the classification and events and shows them immediately in the tables and report.
