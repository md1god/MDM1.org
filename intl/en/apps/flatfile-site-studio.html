Create static sites easily in the browser

An all-in-one tool for designing and editing static pages with Markdown, YAML, and Twig, with live preview, local package management, and complete file…

You can create a complete static site right in your browser without a server. This studio lets you edit Markdown files with a tree structure, adjust YAML settings, tweak simplified Twig templates, and preview the result instantly. You can also add themes or plugins from local packages, then export all files as a publish-ready archive. Everything you need is in one simple interface that matches the current site design.

    FAQ
    Can the project be saved for next time?
    No data is saved in the browser; you can export the project settings as a JSON file and import it later.
    Does the app support adding more than one package?
    Yes, you can select and add multiple packages, and they all appear in the list before export.
    What browser is required to run the tool?
    Any modern browser with JavaScript and DOM support, such as Chrome, Firefox, or Edge.
    Can the template be edited after export?
    Absolutely, you can open the source file in any text editor, edit the template or settings, and import it again.
    Does it generate ready-to-use HTML files?
    The tool merges Markdown content with the template to generate HTML in the preview; when exporting, you can convert it manually to final HTML files.
