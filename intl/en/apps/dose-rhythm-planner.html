    FAQ

    Is data saved after closing the page?

    No, the tool runs only in your browser's memory. You can export a JSON file and import it later when needed; there is no server or account.

    How is the estimated medication level calculated?

    It is calculated by summing the contributions of recorded doses using exponential decay based on the half-life you enter. The peak and final level are shown above the chart.

    How does the planner choose the next injection site?

    It selects the first site not used in the last four times. If all sites have been used, it returns to the least recently used site.

    Can I print the report directly?

    Yes, click Prepare doctor report, then Print report. Your browser's print dialog will open with a neatly formatted report ready to print.
