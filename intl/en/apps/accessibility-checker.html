Tool to check and fix accessibility issues in HTML pages

A complete solution that lets you paste HTML code or upload a web page file to identify errors against EN 301 549 and EAA, with simple explanations,…

This tool scans HTML code for errors related to international accessibility standards, then gives you a simple explanation of each issue and ready-made fixes you can apply. You can paste code directly into the box or upload a web page file; after analysis you'll get a detailed list of errors, with the option to export the results or import a previous report to update it.

FAQ

Does the tool check all international accessibility standards?

The tool covers the main checks related to EN 301 549 and EAA, such as the lang attribute, the presence of headings, associating input elements with labels, and valid alt and role attributes.

Can I save the results for later use?

Yes, the "Export results" button generates a JSON file you can download, and you can import it later using the "Import report" button.

What happens if the code contains unsupported elements?

The code is analyzed as-is; if it contains unknown elements or syntax errors, the browser will display what it can parse and ignore the rest without stopping the program.
