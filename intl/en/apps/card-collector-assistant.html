Upload a card photo and select it to see the latest price and estimated return after grading fees. This in-browser tool lets you load a TCG card image, choose the region containing the card name and details, then match it against a built-in database showing the latest price and estimated return based on PSA, CGC, or TAG fees. FAQ

How is the card price determined?

The app matches the selected image against a built-in database with recent prices, then calculates the return based on the chosen grading company's fees.

Is the match accuracy reliable?

Matching relies on manual region selection and shows an approximate price from the database; results may differ from actual market prices.

How can I save the portfolio between sessions?

You can export the portfolio to a JSON file and import it in a later session; no browser local storage is used.

Which grading fees are included in the estimate?

Returns are calculated using company-specific factors (PSA, CGC, TAG) defined in the built-in database.
