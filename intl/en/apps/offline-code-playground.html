All-in-one web code editor in your browser

A code editor that runs entirely in your browser, with multiple files, live HTML/CSS preview, a simulated terminal, and project export/import as JSON,…

This editor lets you write and run web code directly in your browser, with no connection or account needed. You can create and edit multiple files and preview the result in real time. Everything is saved in the device's cache, and you can export the project as a JSON file or import it later. The interface matches the site's current look and supports dark mode with deep gold colors. Buttons make it easy to add a new file, delete the current file, run the preview, and manage your project content, and the terminal keeps a history of the commands you've run to track changes.


  


FAQ
How can I save my work offline?
The project is saved entirely in your browser's cache, and you can export it as a JSON file to restore it later.
Does the editor run JavaScript?
To avoid security risks, JavaScript isn't executed in the preview; you can only view the code in the editor.
Can I add more than one file to a project?
Yes, you can create multiple files (HTML, CSS, JS) and manage them from the file list at the top.
What are the requirements to run this app?
No server or sign-up needed; it runs directly in any modern browser that supports JavaScript.
Does the app support dark mode?
The app follows the site's existing colors using CSS variables, so it blends automatically with the page's dark mode.
