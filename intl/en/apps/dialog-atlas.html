    FAQ

    How can I import conversations from a file?

    Choose a JSON file using the "JSON file" field, then click "Import". The conversations will appear in the list.

    Where is data saved after the page is closed?

    All data is stored temporarily in browser memory only and is lost when the page is closed; it's best to export it before closing.

    What's the difference between Export MD and Export PDF?

    Export MD produces an editable Markdown text file, while Export PDF creates a file you can print or share as a fixed document.
