Build a smart agent loop in the browser

Create a smart agent loop by setting up tools and guardrails, set the cycle limit and token budget, and run a text model to track decisions and results…

This lab lets you build a smart agent loop in the browser using a set of tools and guardrails that define the agent's behavior. You can set the cycle limit and token budget, then run a text model that simulates decision-making at each step. The app shows a detailed log of every step, and you can edit the log or export it as JSON for later use. It all runs in a simple interface that matches the site's dark and gold theme.

FAQ
How can I change the number of cycles while running?
You can change the value in the "Cycle limit" field, then click "Run loop" to apply the new setting.
Can I save the log for later?
Yes, use the "Export JSON" button to download a file with the settings and log. You can import it again via the file field.
What happens if I exceed the token budget?
The loop stops automatically and a message appears in the log saying the budget ran out at the specified cycle.
Can I run different text models?
Enter the desired text in the "Text model" area. This text is used to shape the agent's decisions in each cycle.
