Scientific Data Package Explorer

A browser-based tool for creating and reading interoperable scientific data packages, with a description tree, array compression, validation schemas, and…

This tool creates a single scientific data package in memory, validates its structure, compresses arrays into binary blocks, and exports it as one interoperable file. Start with a new package or import a file, then add fields, numbers, lists, and numeric arrays, write a schema, validate, and export or copy snippets. Everything runs in the browser with no server, account, connection, or persistent storage, and data stays in memory until exported. Use the graphical preview to review types and shapes, and import the package later to edit or re-export it. You can copy YAML, JSON, or Base64 from any node.

FAQ
How do I start a new package?
Click New package, then add fields, numbers, lists, and arrays.
How do I validate the structure?
Write a JSON Schema in the editor, then click Validate.
Is data stored in the browser?
No, it stays in memory until you export it as a file.
How do I copy a snippet?
Select a node, then click Copy YAML, Copy JSON, or Copy Base64.
