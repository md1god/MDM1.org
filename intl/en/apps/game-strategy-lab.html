Enjoy playing Tic-Tac-Toe, the Prisoner's Dilemma, or a grid maze while adjusting the number of players, play mode, and Minimax, Alpha-Beta, Monte Carlo,…

FAQ

Can the game run offline?

Yes, all algorithms run locally in your browser and do not require any external requests.

What is the difference between "Turn-based" and "Simultaneous" modes?

In "Turn-based" mode, each player takes turns sequentially, while in "Simultaneous" mode, all moves are calculated in the same round.

Can the AI algorithm be modified?

The app provides built-in ready-to-use algorithms, and developers can modify the source code if they want to try other algorithms.
