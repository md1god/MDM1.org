FAQ

Can I change the design after creating the page?

Yes, you can edit the text and change colors using the site's global variables.

How do I add a custom QR code for the event?

Click the "Generate QR code" button and a placeholder code will appear that you can replace manually after downloading.

Does the app support exporting the page as a full image?

The app only lets you download the QR code image; to export the full page as an image, you can use browser tools.

Can I import a guest list from another file?

Yes, use the "Import JSON" button and select the previously saved file.

Is there a limit on the number of guests?

There is no technical limit, but performance may be affected with very large lists.
