Full-featured right-to-left text editor in your browser

Write, run commands, and expand short phrases into ready-to-use text, all in your browser with no server or storage, plus live voice dictation and result…

Quick answer: You can now write and format right-to-left text directly in your browser without needing a server or an internet connection. The app lets you type text, expand short phrases, run special commands to format headings, lists, and quotes, and use local voice dictation if your browser supports it. You can also pick ready-made templates for email, chat, or documents, then easily copy or download the resulting text.

  
  
  

FAQ
Does the app need an internet connection?
No, it runs entirely in the browser with no network requests or local storage.
What happens if the browser does not support voice dictation?
An alert will tell the user the feature is unavailable, and they can continue typing manually.
Can I save the resulting text?
Yes, you can copy the result to the clipboard or download it as a text file using the “Download result” button.
How do I expand shortcuts?
Type the shortcut in the input box, then press the “Expand shortcuts” button to replace it with the predefined full text.
Does the app support headings and lists?
Yes, simple commands like /h1, /ul, and /quote turn a line into the appropriate HTML format in the result.
