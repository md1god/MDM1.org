Create and track CI/CD pipelines directly in the browser

Use this app to design a build, test, and deployment pipeline, set commit triggers and approval policies, then get ready-to-use config files and simulate…

The short answer is that you can build and run a full CI/CD pipeline inside the browser without needing a server. This app lets you create build, test, and deployment stages as interactive diagrams, set commit triggers such as merge or pull request, and assign the required approval policies for each stage. Once you finish designing, you can generate a config file ready to copy or download, and the simulation dashboard shows each task's status, logs, and expected duration, along with a temporary preview of pull requests with deployment rules you can try out.

FAQ

How do I add a new stage to the pipeline?

Enter the stage name in the dedicated field, then press the "Add stage" button. The stage will appear in the diagram.

What type of trigger can I choose?

You can choose "Push code", "Merge request", or "Schedule" depending on your workflow requirements.

How do I get the config file to use in other tools?

After generating the config, press the "Export JSON" button to download the config file to your device.
