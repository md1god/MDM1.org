      FAQ

      Do I need an account or server to use the tool?

      No. The tool works in the page, and you can export the project as a JSON file, then import it later to continue working.

      How do I protect the exported viewer?

      Set an opening password, choose whether to allow viewing, printing, and downloading, and add a watermark with the recipient's name and export time.

      Are files saved in the browser?

      No. Files stay in memory only while you work, and can be saved manually to a project file or inside a standalone HTML viewer.

      What does the viewer log while reading?

      It logs visits to each page, time spent, and unauthorized attempts to open, print, or download, and allows exporting a JSON report.
