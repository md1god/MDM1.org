Single-page invoice management tool

Complete solution for creating clients, items, and invoices, calculating taxes and discounts, choosing a currency and due date, and print preview or PDF…

This app lets you easily create and manage invoices in the browser without a server or permanent storage. You can add clients and items, set taxes and discounts, choose a currency and due date, then preview the invoice for printing or export it as a PDF file. All data stays in the current session, and you can edit it at any time or export it as a JSON file to retrieve it later.

    FAQ

    How can I delete an item from the list?

    Click the “Delete” button next to each item in the items table or next to the client name in the client list.

    Can I save the data to come back to it later?

    Yes, use the “Export as JSON” button to save all the data, then import it later using the “Import JSON” button.

    How are tax and discount calculated?

    Tax is calculated as a percentage of the subtotal, then the discount is subtracted from the total after adding the tax. Values update automatically in the preview.

    Can I print the invoice directly?

    Yes
