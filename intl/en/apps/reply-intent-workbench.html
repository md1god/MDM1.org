FAQ

Can I use the app offline?

Yes, all features work locally in your browser and require no connection.

How can I make sure the reply contains no prohibited phrases?

The app automatically highlights prohibited phrases in the draft with special highlighting so you can edit them before copying.

Is data saved automatically?

No, the app does not use any local storage. You can export data to a JSON file and import it when needed.

What is required to enable the copy button?

You must check the “I confirm the reply is ready to publish” box to enable the button and ensure human approval before copying.

Can I edit the templates or phrases used in the reply?

You can manually edit the draft text in the text box before approval, and you can modify the rules in the code if you want to customize the templates.
