Static Content Manager

A browser-based static content manager: page and folder tree, Markdown editor with live preview, metadata saved locally, media library, and publish-ready…

Yes, this is a complete static content manager that runs entirely in the browser with no server or external connection. It lets you create an organized tree of pages and folders, edit content in Markdown with live preview as you type, and save the title, date, tags, and template locally in your browser using local storage. It also supports a drag-and-drop media library with image previews, instant search across page names, content, and tags, display template and layout style selection, and export of any page or the entire site as ready-to-copy HTML files for publishing on any static hosting provider. All your data stays on your device even after closing or refreshing the page, and a full right-to-left interface makes daily use easier for editors, site owners, bloggers, and small stores.

      FAQ

      Does my data persist when I close the page?

      Yes, the tree, content, metadata, and media are saved in the browser's local storage and restored when you reopen it, with no server.

      How do I add an image to the library?

      Drag and drop an image into the drop area or choose it from the file picker, and its preview will appear in the library immediately.

      Can I export a single page or the entire site?

      Yes, select a page and click Export Page, or click Export Full Site to get ready-to-copy-and-publish HTML for all pages.

      What happens if you search for a word that doesn't exist?

      An empty state message and a result count of zero appear, and you can clear the search to show the full tree again.

      Does the editor support Markdown formatting?

      Yes, it supports headings, bold, italic, code, lists, quotes, and dividers, with live preview and word and character counts.
