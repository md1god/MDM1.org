Speed, Distance and Time Calculator

Enter any two of speed, distance and time to calculate the third instantly, with options for kilometers, miles or meters and hours or minutes, and speed…

The short answer is that distance equals speed multiplied by time, and from this single relationship we can derive any missing value: speed equals distance divided by time, and time equals distance divided by speed. So it's enough to enter two valid values with their units for the third number to appear instantly, without any complex manual steps. This tool runs entirely within the web page, so you don't need to sign up or have an internet connection, and you can change units at any time to read the result in the format that suits you, whether you're planning a road trip, calculating a shipment's arrival time or studying the motion of a moving object.

First choose the value you want to calculate from the list, then type the two known values into their fields and select the unit for each from the adjacent dropdowns. Press Calculate to see the result along with alternative versions in other units, and you can reset at any time to try new numbers.

Result

Results are rounded to six decimal places.

Helpful tip: make sure the time or speed used in the division is greater than zero, because division by zero is undefined. One mile equals 1.609344 kilometers, one meter equals 0.001 kilometers, one hour equals 60 minutes, and every 1 m/s equals 3.6 km/h.

FAQ

How do I calculate speed from distance and time?

Divide distance by time after matching the units. If distance is in kilometers and time is in hours, the result is km/h, and if you want m/s, divide the km/h value by 3.6, while for the reverse multiply m/s by 3.6; or use the tool to convert speed automatically.

What conversions does the tool support?

It supports distance in kilometers, miles and meters, time in hours and minutes, and speed in km/h and m/s. One mile equals 1.609344 kilometers, one hour is 60 minutes, and 1 m/s equals 3.6 km/h.

What happens if I enter zero for time or speed?

The tool shows a warning instead of an incorrect result, because division by zero is mathematically undefined. Change the value to a number greater than zero and press Calculate again.

Do I need an internet connection to use the calculator?

No, all operations run in the browser on your device. You can enter numbers, choose units and get the result without sending any data or creating an account.

How do I read the result if I choose a unit different from the inputs?

The tool converts the values to consistent units before calculating, then returns the final value in the unit you chose and also shows its equivalent in the other units for easy comparison.
