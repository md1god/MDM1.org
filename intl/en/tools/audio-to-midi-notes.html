Upload an audio file and instantly get a sequence of detected musical notes with the option to download them as a MIDI file usable in music composition software. The tool runs entirely in your browser: no file is uploaded to a server, no internet connection is needed, and no software installation is required. Upload monophonic audio such as a single voice or one instrument for the best result, then press the Analyze button to see the notes sorted by time with each note's pitch and standard MIDI number and duration. FAQ

What type of audio gives the best result?

Monophonic audio such as a single instrument or a single voice, because the tool tracks the most prominent frequency at each moment. Not every note may be detected in orchestral or multi-instrument recordings.

Are my files uploaded to a server?

No. The file is read in your browser through the Web Audio API, no data is sent to any third party, and the tool can be used after the page loads even offline.

How do I set the detection sensitivity?

Choose a higher value in the list to capture quiet passages, and a lower one to ignore noise. You can also adjust the minimum note duration to filter out short blips.

What does the resulting MIDI file contain?

It is a Format 0 MIDI file at 120 beats per minute, with note-on and note-off events for each detected note, and it can be opened in most music composition programs.

Why do incorrect notes sometimes appear?

This can happen with instruments that produce strong harmonics or with noisy recordings. Try lowering the sensitivity, or trim the clip to a monophonic section and analyze again.
