FAQ

What does the checker consider valid text?

The checker accepts only strict JSON values: objects, arrays, strings, numbers, booleans, and null, and rejects comments, trailing commas, and unquoted keys.

What appears when there is an error?

The first error is described with line, column and offset, the original text stays in the input box for editing, and no formatted result is shown.

Does the data order change?

No, member and array element order stays the same, only spaces and line breaks change, and duplicate keys are preserved.

Can a document with an error be formatted?

No, formatting runs only after validation succeeds, so you will not get a partial result from an invalid document.

Is the data sent anywhere else?

No, checking and formatting run entirely in your browser, with no uploads or external connections.
