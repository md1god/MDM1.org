Regex Tester — Check regular expressions instantly

Test your regular expressions instantly in your browser: highlight matches, show start and end positions and numbered and named groups, with clear error…

Yes, you can test any regular expression instantly without installing anything or signing up: type the pattern, choose the appropriate flags, then paste the text to test, and the results appear right away. The tool runs entirely in your browser using JavaScript rules, highlighting each match in a clear color, showing the start and end positions of every match, listing the values of numbered and named groups, and alerting you when an optional group did not participate in the match. If the pattern is invalid, you'll see an error message explaining why and where instead of misleading results. If there are no matches, you'll get a neutral message with no highlighting. You can navigate between matches from the list, and note that empty patterns and zero-length matches are displayed safely without repetition. Try the case sensitivity, multiline, dot all, sticky, and Unicode options to see how the results change.

Text is treated as data only, and no code is executed. Large texts or complex patterns may be slow.

FAQ

How are results shown after entering a pattern?

Results update automatically every time you change the pattern, flags, or text, with no need to press a button.

What happens when the pattern doesn't match any part of the text?

A neutral message says there are no matches, no part of the text is highlighted, and the list stays empty.

How are groups that didn't participate in the match displayed?

They appear in the details list as «not participating» instead of being omitted, and named groups are shown alongside their number whenever the name can be linked.

Is the text I test executed?

No, text is treated as data only, and no code is executed; all checking stays inside the browser.
