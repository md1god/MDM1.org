Extract a ZIP archive in your browser

Extract files and folders from a ZIP archive to a folder you choose directly in your browser, preserving the relative structure and names, without…

Quick answer: This tool extracts the contents of a ZIP archive directly in your browser without uploading any file to a server, preserving folders, files, and relative path structure. Choose the archive file and destination folder, then click Extract. It supports stored and deflate-compressed entries, creating intermediate folders, skipping or replacing existing files, and canceling the operation at any time. It also shows extraction progress, completion status, and the number of extracted, skipped, and failed entries, with error messages that identify the entry and the reason. It does not modify the original archive, and rejects unsafe paths.









    FAQ

    Does the tool work without uploading files?

    Yes, all reading and extraction operations take place locally in your browser.

    Which compression formats are supported?

    Stored (stored) and deflate-compressed entries.

    What happens if a file with the same name exists?

    You can choose to skip existing files or replace them.

    Can extraction be canceled?

    Yes, the Cancel button stops writing subsequent entries and shows an incomplete status.

    Is the original archive modified?

    No, the original archive remains unchanged.
