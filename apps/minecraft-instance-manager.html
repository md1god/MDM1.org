مدير إعدادات تثبيتات ماينكرافت

أداة عربية متكاملة لإدارة تثبيتات ماينكرافت داخل المتصفح: أنشئ ملفات تعريف لكل تثبيت، اختر الإصدار والإضافات وواجهة Java وخصائص الأداء، رتبها وصنّفها وصدّرها أو استوردها كملفات JSON دون أي خادم.

الإجابة السريعة: يمكنك الآن إنشاء وإدارة عدة ملفات تعريف لتثبيتات ماينكرافت من المتصفح مباشرة، بدون أي خادم أو تثبيت خارجي. هذا التطبيق يتيح لك حفظ إعدادات كل تثبيت على حدة مثل رقم الإصدار، حزمة الأصول، إضافة Forge أو Fabric أو Quilt أو NeoForge، نسخة Java وواجهة التشغيل، وحجم الذاكرة المخصص للـ JVM، بالإضافة إلى تخصيص ملف properties الكلاسيكي مثل مسافة العرض وألوان الشات والاهتزاز وإشعارات البريد. كل ملف تعريف يخزن محلياً في متصفحك عبر localStorage، ويمكنك ترتيبها بالسحب أو الأزرار، تصنيفها حسب النوع أو الحالة، إنشاء نسخة احتياطية سريعة، وتصدير كل البيانات أو استيرادها كملف JSON في أي وقت. استخدم النموذج أدناه لإضافة أول تثبيت، ثم عدّل أي بروفايل واحفظ التغييرات فوراً، وستجد في الأسفل جدول الملفات المرتبة وصندوق معاينة الحالة وخيارات النسخ الاحتياطي والاستيراد والتصدير.

إنشاء أو تعديل ملف تعريف

لا توجد ملفات تعريف بعد. أضف أول تثبيت من النموذج أعلاه.

أسئلة شائعة

هل يحتاج التطبيق إلى خادم أو حساب مستخدم؟

لا، يعمل التطبيق كاملاً داخل المتصفح ويحفظ جميع ملفات التعريف في localStorage الخاص بمتصفحك فقط، دون أي اتصال بخادم أو إرسال بيانات خارج جهازك.

ما الإصدارات والحمولات التي يدعمها مدير الإعدادات؟

يدعم الإصدارات الكلاسيكية والحديثة من 1.7.10 و1.8.9 حتى 1.21.4، مع اختيار Vanilla أو Forge أو Fabric أو Quilt أو NeoForge ونسخة الحمولة وواجهة Java وحجم الذاكرة المخصص.

كيف أصدّر إعداداتي أو أستوردها على جهاز آخر؟

اضغط زر تصدير JSON لتنزيل ملف يحتوي على كل الملفات، أو صدّر ملفاً واحداً من لوحة المعاينة، ثم استخدم زر استيراد JSON على الجهاز الآخر لاستعادة جميع التثبيتات بضغطة واحدة.

هل يمكنني إنشاء نسخة احتياطية قبل التعديل؟

نعم، زر نسخة احتياطية يحفظ لقطة كاملة محلياً، ويمكنك استرجاعها لاحقاً بزر استرجاع آخر نسخة إذا حدث حذف أو تعديل بالخطأ.

ما الذي يحتويه ملف properties الذي يعرضه التطبيق؟

يعرض مقترحاً نصياً لخصائص الأداء القياسية مثل دقة الشاشة وحد FPS وملء الشاشة واللغة وحزم الموارد، ويمكنك نسخه واستخدامه داخل مجلد التثبيت كما هو أو بتعديلاته.
