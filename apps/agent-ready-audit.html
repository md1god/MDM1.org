مدقق جاهزية الموقع للوكلاء الذكيين

مدقق عربي في المتصفح لجاهزية المواقع للوكلاء: استيراد HTML وrobots.txt وllms.txt وOpenAPI، كشف جدران الحماية والأسعار وغياب llms.txt/MCP/OpenAPI، درجة وإصلاحات.

هذا المدقق يجيب بسرعة: استورد مجلد تصدير أو ملفات HTML مع robots.txt وllms.txt وOpenAPI، وسنفحص جاهزية موقعك للوكلاء الذكيين بالكامل داخل المتصفح بدون أي طلب شبكة أو حسابات. نكتشف جدران الحماية، والصفحات التي لا تكشف أسعارها إلا عبر JavaScript، وغياب llms.txt أو MCP أو OpenAPI، ثم نحسب درجة واضحة من 100 ونعرض إصلاحات قابلة للنسخ بصيغة JSON وMarkdown، مع حفظ كل تدقيق محليًا. لا بيانات تغادر جهازك، والنتائج قابلة للنسخ والمشاركة مع الفريق. أداة عملية للمطورين والمسوقين ومالكي المواقع اليوم.

السجل

أسئلة شائعة

ما الملفات التي يمكن استيرادها؟

يمكنك استيراد مجلد تصدير أو ملفات HTML وrobots.txt وllms.txt وOpenAPI (JSON/YAML) وإعدادات MCP، وكل التدقيق يتم محليًا.

هل تُرسل بياناتي إلى أي خادم؟

لا، كل المعالجة والحفظ (localStorage) تتم داخل المتصفح دون أي طلب شبكة.

كيف أنسخ الإصلاحات؟

بعد التدقيق استخدم أزرار "نسخ JSON" أو "نسخ Markdown" لنسخ التقرير كاملاً.

ماذا تعني الدرجة؟

درجة من 0 إلى 100، تبدأ من 100 وتُطرح منها أوزان المشكلات (جدران حماية، أسعار عبر JS، غياب llms.txt/MCP/OpenAPI، إلخ).

هل يحفظ التدقيقات؟

نعم، يمكنك حفظ التدقيق في السجل (localStorage) وتحميله لاحقًا.
