مدير إعدادات مشغّل Minecraft

تطبيق عربي يعمل في المتصفح لإدارة نسخ Minecraft: إنشاء ملفات نسخ، ربط إصدارات اللعبة ومسارات Java وحصص الذاكرة، ترتيب التعديلات مع التفعيل والتوافق، تسجيل تحديثات الإصدارات، وتصدير/استيراد JSON.

إجابة سريعة: هذا التطبيق يدير إعدادات مشغّل Minecraft بالكامل داخل المتصفح، إذ يمكنك إنشاء ملفات نسخ (Instances) وربطها بإصدارات اللعبة ومسارات Java وحصص الذاكرة، وترتيب قوائم التعديلات (Mods) مع حالات التفعيل والتوافق، وتسجيل آخر تحديثات الإصدارات محليًا. تُحفظ جميع البيانات في localStorage مع إمكانية تصدير واستيراد كامل كملفات JSON، وواجهة عربية مع دعم تعدد اللغات.

كيف أنشئ نسخة Minecraft جديدة؟

اضغط "إضافة نسخة جديدة"، ثم املأ اسم النسخة وإصدار اللعبة ومسار Java والذاكرة، ثم اضغط "حفظ النسخة".

كيف أرتّب التعديلات (Mods)؟

داخل تفاصيل النسخة استخدم أزرار ▲ و ▼ بجانب كل تعديل لتغيير ترتيبه، وأزرار التفعيل/التوافق لتغيير حالته.

كيف أسجّل تحديث إصدار؟

في قسم "سجل تحديثات الإصدارات" اضغط "إضافة تحديث"، اختر الإصدار والتاريخ وأضف ملاحظات، ثم احفظ.

كيف أنقل البيانات إلى جهاز آخر؟

اضغط "تصدير جميع البيانات (JSON)"، انسخ النص من الحقل، ثم في الجهاز الآخر استخدم "استيراد من ملف JSON" بعد حفظ النص كملف JSON.

أين تُحفظ البيانات وما مدى أمانها؟

تُحفظ في localStorage في متصفحك فقط، ولا تُرسل لأي خادم. يمكنك مسحها بزر "مسح جميع البيانات".
