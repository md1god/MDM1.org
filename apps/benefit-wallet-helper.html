احسب ادخار الضرائب واختر البطاقة المناسبة بسهولة

أداة مجانية على الويب تحسب الادخار الضريبي للمعاملات اليومية وتحدد ما إذا كانت مؤهلة لـ HSA أو FSA أو LSA أو مميزات الموظف، وتظهر البطاقة أو المحفظة المثالية مع إمكانية إضافة ملاحظات وإرفاق صورة الفات

الأداة تحسب الادخار الضريبي تلقائيًا وتحدد البطاقة المناسبة، وتسمح لك بإدخال كل عملية شراء يومية مع ملاحظة وصورة الفاتورة لتسهيل الاسترداد. كل شيء يتم داخل المتصفح دون الحاجة إلى خوادم أو تخزين بعيد، مما يضمن خصوصية بياناتك وسهولة الاستخدام على أي جهاز. اختر الفئة الضريبية، أدخل المبلغ، أضف ملاحظاتك، وارفق صورة الفاتورة لتظهر في المعاينة، ثم اضغط حساب لتظهر لك القيمة المدخرة والبطاقة المثلى للاستخدام. يمكنك أيضًا تصدير بياناتك كملف JSON أو استيراد ملف محفوظ مسبقًا لاستعادة المعلومات بسهولة.

أسئلة شائعة

كيف يتم حساب الادخار الضريبي؟

يضرب المبلغ في نسبة الخصم المحددة للفئة المختارة (مثلاً 15 % لـ HSA) لتظهر القيمة المدخرة.

هل يمكن حفظ البيانات للعودة إليها لاحقًا؟

نعم، استخدم زر تصدير البيانات لحفظ ملف JSON ثم استورده عند الحاجة عبر زر استيراد الملف.

ما نوع الصور التي يمكن إرفاقها؟

تدعم الأداة جميع صيغ الصور المدعومة من المتصفح مثل JPEG وPNG، وتظهر معاينة فورية على لوحة القماش.

هل يتم إرسال أي معلومات إلى خوادم خارجية؟

لا، جميع العمليات تتم داخل المتصفح ولا تُرسل أي بيانات إلى الخادم.

ماذا أفعل إذا نسيت اختيار الفئة؟

سيظهر تنبيه يطلب ملء جميع الحقول الضرورية قبل الحساب.
