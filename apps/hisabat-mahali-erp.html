مدير الفواتير والعملاء

تطبيق عربي RTL لإدارة الفواتير وعروض الأسعار والعملاء والمدفوعات وحفظها محليًا في المتصفح مع لوحة إحصائيات وطباعتها وتصديرها احتياطيًا.

نعم، يمكنك إدارة الفواتير والعملاء والمدفوعات مباشرة داخل المتصفح دون خادم أو تسجيل دخول. يقوم هذا التطبيق بحفظ جميع البيانات محليًا في متصفحك عبر localStorage، مما يتيح لك العمل بشكل كامل دون اتصال بالإنترنت مع الحفاظ على خصوصيتك. يوفر التطبيق إنشاء فواتير وعروض أسعار قابلة للطباعة، وتتبع حالة السداد (مدفوع/جزئي/متأخر)، وإدارة قائمة العملاء، ولوحة رئيسية تعرض إجمالي الإيرادات والمبالغ المستحقة وأفضل العملاء برسوم بيانية على canvas. كما يدعم تصدير نسخة JSON احتياطية واستيرادها مرة أخرى عند الحاجة. كل العناصر تفاعلية بوضوح، والواجهة مصممة بتنسيق RTL لتتناسب مع العربية، مع استخدام ألوان الموقع الداكنة والذهبية لضمان تجربة متناسقة وسلسة.

أسئلة شائعة

هل يحفظ التطبيق البيانات محليًا؟

نعم، يحفظ جميع الفواتير والعملاء والمدفوعات في localStorage داخل المتصفح دون أي خادم.

هل يمكن طباعة الفواتير وعروض الأسعار؟

نعم، يمكنك طباعة آخر فاتورة أو آخر عرض سعر مباشرة من أقسام الفواتير وعروض الأسعار.

كيف تعمل حالة السداد؟

تتبع حالات (مدفوع/جزئي/متأخر/غير مدفوع) ويحسب التطبيق المبلغ المدفوع والمستحق تلقائياً.

هل يمكن تصدير واستيراد نسخة احتياطية؟

نعم، يدعم تصدير ملف JSON احتياطي كامل، واستيراد نفس الملف لاستعادة البيانات.

هل يعمل بدون اتصال بالإنترنت؟

نعم، التطبيق يعمل بالكامل داخل المتصفح ولا يستخدم أي شبكة، لذا يعمل دون اتصال تامًا.
