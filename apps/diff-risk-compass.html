تحليل الفروقات وإصدار تقرير المخاطر الفوري

أداة داخل المتصفح تحلل الفروقات المُلصقة أو وصف طلب سحب يدوي، وتُعطي درجة مخاطر من 0 إلى 100 وتُظهر الملفات التي تحتاج مراجعة بشرية مع توصيات قابلة للتصدير.

يُعطي هذا التطبيق درجة مخاطر فورية للفرق التي تُلصق أو تُدخل يدوياً، مع تحليل الانحدار، الصلاحيات، فقدان البيانات، وإمكانية التراجع. يحدد الملفات التي تستلزم تدقيقاً بشرياً، يوضح أسباب كل تنبيه، ويتيح ضبط حدود السياسة وتبديل قوالب الفرق في الجلسة الحالية فقط. بعد التحليل يمكن تصدير تقرير شامل بصيغة Markdown أو JSON لتوثيق عملية المراجعة أو دمجها في أنظمة تدفق العمل.

ما هو مبدأ حساب درجة المخاطر؟

يُحسب بناءً على عدد التغييرات، وجود كلمات مفتاحية حساسة، ودرجة السياسة المحددة من قبل المستخدم.

هل يمكن تعديل حدود السياسة بعد التحليل؟

نعم، يمكن تعديل قيمة الحد وإعادة تشغيل التحليل لتحديث النتيجة فوراً.

كيف يتم تصدير التقرير؟

يمكن تصديره إما بصيغة Markdown أو JSON عبر الأزرار المخصصة، وسيُحفظ الملف على الجهاز مباشرة.

هل يدعم التطبيق استيراد إعدادات سابقة؟

نعم، يتيح زر “استيراد إعدادات” تحميل ملف JSON يحتوي على حدود السياسة والقالب لتطبيقها فوراً.

ما هي الملفات التي تُظهر كخطوط خطر؟

تُظهر أي سطر يحتوي على كلمات مثل DROP أو DELETE أو TRUNCATE مع توضيح رقم السطر والسبب.
