مصمم خريطة وسوم أجهزة التحكم الصناعية

تطبيق ويب محلي لبناء إطارات Modbus RTU/TCP وفكّها، تصميم سجلات الوسوم، محاكاة القراءات، أرشفتها وتصدير الإعدادات بدون شبكة.

هذا التطبيق يتيح للمهندسين إنشاء خريطة وسوم موحّدة لأجهزة التحكم الصناعية، وبناء إطارات Modbus RTU وTCP وفكّها، وتصميم سجلات العناوين والأنواع، وربط الحقول بلوحات عرض مباشرة، مع أرشيف محلي للقراءات وتصدير الإعدادات كملفات JSON وCSV، وتوليد كود جاهز للوصول إلى الوسوم، وعرض سجل أخطاء الإطار لمساعدة المهندسين على التحقق من إعداداتهم قبل توصيل الأجهزة الحقيقية، le tout sans connexion réseau.

هل يعمل التطبيق بدون اتصال شبكي؟

نعم، يعمل بالكامل داخل المتصفح ولا يستخدم أي اتصال شبكي.

هل يمكن تصدير الإعدادات؟

نعم، يمكن تصدير الوسوم والقراءات كملفات JSON وCSV.

هل يدعم Modbus RTU وTCP؟

نعم، يدعم بناء وفك إطارات RTU (مع CRC16) وTCP (مع MBAP).

أين تُحفظ البيانات؟

في التخزين المحلي للمتصفح (localStorage) مع إمكانية المسح.
