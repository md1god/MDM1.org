محلل مباريات كرة القدم من ملفات JSON داخل المتصفح

حلل ملفات JSON لمباريات كرة القدم دون خادم أو حساب: خط زمني، خريطة تسديدات بالأهداف المتوقعة، شبكات تمرير، خرائط حرارية، وإحصاءات الفرق.

باختصار، هذا التطبيق يحوّل ملف JSON خام إلى تحليل كامل لمباراة كرة القدم دون إرسال أي بيانات إلى خادم أو إنشاء حساب، إذ تتم كل المعالجة محليًا داخل متصفحك، فتبقى بياناتك خاصة وتعمل الأداة حتى دون اتصال بالإنترنت. بعد رفع الملف أو لصق محتواه أو تجربة البيانات النموذجية ستظهر فورًا ملخصات الفرق واللاعبين وخط زمني مرتب للأحداث يوضح الدقيقة والفريق واللاعب ونوع الحدث لتتبع تطور المباراة لحظة بلحظة. وتعرض خريطة التسديدات مواقع المحاولات مع تمييز الأهداف وتكبير الدائرة بحسب قيمة الأهداف المتوقعة، بينما تربط شبكة التمرير اللاعبين بخطوط تمثل تمريراتهم، وتكشف الخريطة الحرارية المناطق الأكثر نشاطًا في الملعب. يمكنك التصفية حسب الفريق أو نوع الحدث، والنقر على أي تسديدة لعرض تفاصيلها، وحفظ المشروع محليًا ثم تحميله لاحقًا أو تصدير الرسوم والمخططات للمشاركة مع فريقك.

أسئلة شائعة

هل تُرفع بياناتي إلى أي خادم عند التحليل؟

لا. كل المعالجة تتم داخل المتصفح فقط، واستيراد الملفات وقراءة النص وحفظ المشاريع تتم محليًا دون إرسال البيانات إلى خادم.

ما صيغة JSON المدعومة؟

تدعم الأداة مصفوفة أحداث مباشرة أو كائنًا يحتوي على وسيط events، وتقبل حقولًا شائعة مثل minute وtype وteam وplayer وlocation وxg وoutcome مع أسماء بديلة كثيرة.

كيف أقرأ خريطة التسديدات؟

الدوائر الذهبية أهداف، والدوائر الفاتحة محاولات غير مسجلة، وكلما كبرت الدائرة زادت قيمة الأهداف المتوقعة. النقر على أي نقطة يعرض دقيقتها ولاعبها وفريقها.

كيف أحفظ مشروعًا وأشاركه مع غيري؟

اكتب اسم المشروع ثم اضغط حفظ المشروع محليًا، ويمكنك تحميله لاحقًا من القائمة أو تصديره كملف JSON، كما يمكنك تنزيل خرائط التسديدات والتمرير والحرارة كصور للمشاركة.

ماذا يحدث إذا كان الملف غير صالح أو بلا أحداث؟

تظهر رسالة خطأ واضحة في مربع النتيجة، وتبقى الرسوم والجداول في حالة فارغة منظمة بدل الانهيار، ويمكنك تصحيح JSON أو تجربة البيانات النموذجية.
