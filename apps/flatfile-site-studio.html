إنشاء مواقع ثابتة بسهولة داخل المتصفح

أداة متكاملة لتصميم وتحرير صفحات ثابتة باستخدام Markdown وYAML وTwig، مع معاينة فورية وإدارة حزم محلية وتصدير كامل للملفات كأرشيف جاهز للنشر، كل ذلك داخل المتصفح دون أي خادم أو تخزين دائم.

يمكنك إنشاء موقع ثابت كامل داخل المتصفح دون الحاجة إلى خادم. يتيح لك هذا الاستوديو تحرير ملفات Markdown مع هيكل شجري، ضبط إعدادات YAML، تعديل قوالب Twig مبسطة، ومعاينة النتيجة فوراً. كما يمكنك إضافة سمات أو إضافات من حزم محلية، ثم تصدير جميع الملفات كأرشيف جاهز للنشر. كل ما تحتاجه موجود في واجهة بسيطة تتماشى مع تصميم الموقع الحالي.

    أسئلة شائعة
    هل يمكن حفظ المشروع للمرة القادمة؟
    لا يتم حفظ أي بيانات على المتصفح؛ يمكن تصدير إعدادات المشروع كملف JSON واستيراده لاحقاً.
    هل يدعم التطبيق إضافة أكثر من حزمة؟
    نعم، يمكن اختيار وإضافة عدة حزم، وتظهر جميعها في القائمة قبل التصدير.
    ما المتصفح المطلوب لتشغيل الأداة؟
    أي متصفح حديث يدعم JavaScript وDOM، مثل Chrome أو Firefox أو Edge.
    هل يمكن تعديل القالب بعد التصدير؟
    بالتأكيد، يمكن فتح الملف المصدر في أي محرر نصي وتعديل القالب أو الإعدادات ثم إعادة استيراده.
    هل يتم إنشاء ملفات HTML جاهزة؟
    الأداة تدمج محتوى Markdown مع القالب لتوليد HTML داخل المعاينة؛ عند التصدير يمكن تحويله يدوياً إلى ملفات HTML نهائية.
