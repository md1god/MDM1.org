معمل مرئي لتصميم وتشغيل محاكاة الوكلاء المتعددين عبر مخططات متدفقة

معمل مرئي عربي لتصميم وتشغيل محاكاة وكلاء متعددين عبر مخططات YAML متدفقة، مع نقاط تفتيش وسفر زمني ولوحة تتبع بنمط OpenTelemetry وحفظ محلي كامل.

صمّم وشغّل محاكاة وكلاء متعددين بالكامل داخل متصفحك دون أي اتصال بالشبكة أو نموذج ذكاء اصطناعي. يوفّر هذا المعمل المرئي محرّرًا لتعريف الوكلاء بصيغة YAML، وأربعة أنماط للتدفق: تسلسلي، ومتزامن، وتسليم باليد، وتعاون جماعي. يمكنك تشغيل المحاكاة خطوة بخطوة أو دفعة واحدة، مع نقاط تفتيش تلقائية وزر إرجاع زمني للتراجع عن أي خطوة سابقة. تعرض لوحة التتبع بنمط OpenTelemetry كل مسار تنفيذ مع المدة والحالة والسمات والاستثناءات، بينما تُظهر لوحة الحالة الأوامر الوسيطة والناتج النهائي. كما تدعم خطوات التحكم البشري بالموافقة أو الرفض، وتحفظ المخططات والتجارب في المتصفح مع إمكانية التصدير والاستيراد.

جاهز
الناتج النهائي: —

أسئلة شائعة

هل يتصل المعمل بالإنترنت أو بأي نموذج ذكاء اصطناعي؟

لا. يعمل بالكامل داخل المتصفح دون أي طلبات شبكة؛ التنفيذ محاكاة حتمية، وكل البيانات تُحفظ في localStorage فقط.

كيف أعرّف الوكلاء والمخطط؟

بصيغة YAML بسيطة تضم قائمة agents بحقول id وlabel وrole وemit، وقائمة steps تحدد الوكيل والخطوات البشرية والملاحظات.

ماذا تعني الأنماط الأربعة للتدفق؟

تسلسلي ينفّذ الوكلاء واحدًا تلو الآخر، ومتزامن يشغّل عدة وكلاء في دفعة واحدة، وتسليم باليد يمرّر ناتج كل وكيل إلى التالي، وتعاون جماعي يشغّل جميع الوكلاء في كل جلسة.

كيف يعمل السفر الزمني ونقاط التفتيش؟

تُحفظ نسخة كاملة من الحالة قبل كل خطوة تلقائيًا، ويمكنك زر الإرجاع الزمني لاستعادة آخر نقطة تفتيش والتراجع عن التنفيذ.

أين تُخزَّن مخططاتي وكيف أنقلها؟

تُخزَّن محليًا في localStorage، ويمكن تصديرها كملف JSON أو استيرادها من ملف أو من نص لصقته في المربع.
