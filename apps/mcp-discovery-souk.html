فهرس خوادم MCP العربي مع فحص الأمان وتوليد الإعدادات

تطبيق عربي يعمل محلياً لتصفح خوادم MCP، البحث الدلالي، فحص ملفات الإعداد للصلاحيات الخطرة، وتوليد تهيئة جاهزة لـ Claude وCursor وVS Code بضغطة واحدة.

هذا التطبيق يعمل بالكامل في متصفحك دون أي خادم أو حساب خارجي. يوفر فهرساً محلياً لخوادم MCP مع بحث دلالي يعتمد على المرادفات والجذور اللغوية، ويعرض درجة أمان محسوبة مسبقاً لكل خادم. يمكنك لصق ملف إعداد أو بيان خادم لفحصه محلياً والكشف عن الصلاحيات الخطرة والأوامر المشبوهة، ثم توليد إعداد جاهز للنسخ لأكثر من عميل مثل Claude وCursor وVS Code. المفضلة والمجموعات وسجل التعهدات محفوظة في localStorage مع إمكانية التصدير والاستيراد الكامل.

هل يرسل التطبيق بيانات إلى خوادم خارجية؟

لا، يعمل بالكامل محلياً في المتصفح دون أي اتصال شبكي. جميع البيانات محفوظة في localStorage.

كيف يعمل البحث الدلالي دون خادم؟

يستخدم قاموس مرادفات وجذور لغوية مدمج في الكود يوسع استعلام البحث ليشمل كلمات مرتبطة بالمعنى.

هل يمكن إضافة خوادم مخصصة للفهرس؟

نعم، عبر استيراد ملف JSON للفهرس الكامل أو تعديل الكود مباشرة لإضافة خوادم جديدة.

ماذا تعني درجة الأمان؟

درجة من 0-100 تحسب مسبقاً بناءً على الصلاحيات المعلنة وطبيعة الأوامر. 90+ ممتاز، 70-89 جيد، أقل من 70 يحتاج حذر.

كيف أفحص إعداد خادم غير موجود في الفهرس؟

ألصق ملف JSON الإعداد في مربع التحليل واضغط "تحليل الأمان" للكشف عن الصلاحيات الخطرة والأوامر المشبوهة.
