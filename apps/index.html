تطبيقات مجانية

تطبيقات ويب مجانية بالعربية تعمل داخل متصفحك بدون تسجيل: محررات ومنظمات وأدوات إنتاجية.

🧩
محول صيغ الصور: حوّل PNG وJPG وWebP بجودة مخصّصة
حوّل صورك بين صيغ PNG وJPG وWebP مباشرة في متصفحك، مع اختيار جودة الضغط ومعاينة الحجم قبل وبعد، وتنزيل فردي أو جماعي، دون رفع أي ملف إلى خادم.
🧩
منصة تفسير ومحاكاة سير عمل الوكلاء الافتراضيين عبر سياق مشترك متبادل
منصة عربية تفسير سير عمل وكلاء افتراضيين عبر سياق مشترك متبادل مع اعادة تشغيل تلقائية للأعطال وتتبع التكلفة واستهلاك الموارد لكل مهمة.
🧩
تطبيق حديقة ذكي: تسجيل المحاصيل وتقييم توافق النباتات
تطبيق حديقة ذكي يتيح لمزارعي الأقاليم الصغار تسجيل محاصيلهم وزراعاتهم موسمًا بعد موسم، وتقييم توافق النباتات، وتتبع الحصاد، وتوليد تقارير د periodic locally in the browser.
🧩
تطبيق لياقة بدنية يعمل دون إنترنت
تابع خطط التمارين، وسجلات المجموعات والأوزان، ووزن الجسم، والسعرات والمغذيات اليومية محلياً في المتصفح. دون حسابات، ويعمل كاملاً من دون إنترنت.
🧩
إدارة سجلات المرضى في المتصفح (بدون خادم)
تطبيق ويب عربي يعمل بالكامل في المتصفح لإدارة سجلات المرضى والمواعيد والتشخيصات والأدوية محلياً في localStorage مع طباعة وتصدير واستيراد مشفر.
🧩
دليل النشرات الإخبارية: تطوير الويب وجافا سكريبت وريأكت
دليل مصنف للنشرات الإخبارية في تطوير الويب وجافا سكريبت وريأكت: بحث فوري، تصفية حسب الفئة، حفظ المفضلة محليًا، مع أوصاف وروابط مباشرة.
🧩
مختبر ضغط وتحويل الصور محليًا في المتصفح
حوّل واضغط صور PNG وJPEG وGIF وWebP داخل المتصفح مع شريط جودة ومستويات جهد، واعرض نسبة التوفير وحجم الملف قبل وبعد وزمن فك الضغط، دون خادم.
🧩
مكتبة الصور المحلية: نظّم صورك بألبومات ووسوم وعرض ملء الشاشة
نظّم صورك محليًا في المتصفح: ارفع صورًا، أنشئ ألبومات، أضف وسومًا للبحث السريع، واستعرضها بمعرض مصغرات وعرض ملء الشاشة بشرائح تلقائية، مع حفظ خاص محلي
🧩
محرر الصور الفوتوغرافية غير الإتلافي داخل المتصفح
أداة مجانية لتطوير الصور داخل المتصفح دون خادم أو حساب: اضبط التعريض والألوان ومنحنيات RGB، والاقتصاص والتدوير وتصحيح العدسات، قارن قبل/بعد وصدّر النتيجة.
🧩
تطبيق ويب محلي لإدارة السجلات الطبية
نظام records طبية مصغّر يعمل في المتصفح دون إنترنت، لإدارة المرضى والمواعيد والزيارات والأدوية مع حفظ البيانات محلياً.
🧩
مكتبة أنمي شخصية للاستيراد والمشاهدة محلياً داخل المتصفح
مكتبة أنمي عربية تعمل بالكامل في المتصفح: استورد فيديوهاتك وصورك، تابع التقدم، نظّم السيناريوهات والمدبلج، أدر ملفات متعددة وترجمات خارجية دون خادم.
🧩
حاسبة موقع الشمس وحرارة لون ضوء النهار
احسب ارتفاع الشمس وحرارة لون ضوء النهار (CCT) والسطوع (lx) لحظة بلحظة حسب خط العرض والوقت المحلي مع رسوم بيANYة وتصدير جداول.
🧩
متابعة نوم الرضيع والأطعمة والحفاضات ووقت البطن
تطبيق عربي كامل داخل المتصفح لتسجيل نوم الرضيع وأطعمه وحفاضاته ووقت بطنه مع إحصائيات ورسم زمني وتنبؤ وحفظ محلي وصادرات واستيرادات
🧩
معمل مرئي لتصميم وتشغيل محاكاة الوكلاء المتعددين عبر مخططات متدفقة
معمل مرئي عربي لتصميم وتشغيل محاكاة وكلاء متعددين عبر مخططات YAML متدفقة، مع نقاط تفتيش وسفر زمني ولوحة تتبع بنمط OpenTelemetry وحفظ محلي كامل.
🧩
منتدي روابطي - متصفح شخصي للمقالات التقنية
نظّم روابطك التقنية في منتدى خاص: صوّت بالسهام، علّق تعليقات متداخلة، وسوم برمجة وأمن وذكاء اصطناعي، ترتيب بالشعبية أو التاريخ، بحث وفلترة، حفظ محلي وتصدير JSON.
🧩
محرر واستوديو النماذج والاستبيانات في المتصفح
أنشئ استبيانات واختبارات ونماذج متعددة الخطوات عبر تعريف JSON في متصفحك، مع تحقق ومنطق شرطي وحسابات وحفظ محلي واستيراد وتصدير بلا خادم أو حساب.
🧩
لوحة مراقبة أخطاء المتصفح داخل الصفحة
التقط رسائل الخطأ والاستثناءات في متصفحك واعرضها مجمّعة بتردداتها وسياق المتصفح وسلسلة التتبع، مع فلترة وبحث وتصدير محلي ونافذة زمنية، بلا خادم أو حسابات.
🧩
اختبار مفاهيم Kubernetes محليًا
تعلم واختبار ملفات YAML لمكونات Kubernetes مباشرة في المتصفح مع تصور مرئي وحفظ المشاريع محليًا دون خادم أو تثبيت فعلي
🧩
مصمم خط أنابيب نشر واختبار
ابنِ خط أنابيب بناء واختبار ونشر في YAML، اسحب قوالب إلى المحرر، شاهد المراحل وسجلات لحظية، واحفظ المشاريع في localStorage دون خادم أو حساب.
🧩
لوحة تحليل العلامة التجارية في مساعدات الذكاء الاصطناعي
حلّل ذكر علامتك التجارية في إجابات المساعدات الذكية، قارن مع المنافسين، واكشف التضارب بين الزيارات العضوية والذكاء الاصطناعي محليًا دون خوادم.
🧩
مشغّل صوتيات داخل المتصفح بأسلوب الثمانينيات
مشغّل صوتيات يعمل بالكامل في متصفحك: اسحب ملفاتك MP3 وFLAC وOGG وWAV، واستمتع بقائمة تشغيل ومحلل طيف حيّ ومعادل صوت واختصارات، دون اتصال أو حساب.
🧩
أداة تخطيط وإعداد الفيديوهات الطويلة بدون وجه خطوة بخطوة
أداة عربية تعمل داخل المتصفح بلا خادم: قوالب سيناريو محسّنة للسيو للفيديوهات الطويلة بدون وجه، مخطط زمني على Canvas، محرر ترجمات، حفظ محلي وتصدير JSON.
🧩

🧩
متصفح صناديق الإقراض والادخار الجماعي الصغير

🧩
