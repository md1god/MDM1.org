مصمم الخرائط المخصصة من الملفات المحلية

صمم خرائط مخصصة داخل متصفحك من ملفات GeoJSON وOSM XML المحلية، مع سحب وتكبير وتخصيص ألوان الطرق والمياه والمباني والتسميات، وحفظ الأنماط وتصدير HTML دون خادم.

نعم، هذه الأداة تتيح لك تصميم خريطة مخصصة بالكامل داخل متصفحك دون خادم أو حساب أو اتصال بالشبكة، من خلال رفع ملف GeoJSON أو OSM XML محلي ومعاينته فوراً على لوحة رسم تفاعلية تدعم السحب للتحريك والتكبير بالعجلة أو بالأزرار. يمكنك بعدها تخصيص كل طبقة على حدة، مثل الطرق والمياه والمباني والنقاط، بتغيير لون التعبئة أو الحد وسمك الخط وإظهار التسميات ولونها وحجمها وخطها، كما يمكنك ضبط لون الخلفية وحدود المضلعات. تُحفظ أنماطك المتعددة في التخزين المحلي للمتصفح لتطبيقها لاحقاً، ويمكنك تصدير النمط كملف JSON أو صفحة HTML جاهزة للتضمين في أي موقع، مع عرض إحصاءات فورية لعدد العناصر في كل طبقة وتنبيهات واضحة عند غياب الملف أو وجود خطأ في تنسيقه.

أسئلة شائعة

هل تعمل الأداة دون اتصال بالإنترنت تماماً؟

نعم، كل المعالجة تتم داخل متصفحك باستخدام JavaScript وCanvas دون خادم أو حساب، وتبقى ملفاتك المحلية على جهازك ولا تُرسل إلى أي مكان.

ما صيغ الملفات الجغرافية المدعومة وما طبقاتها؟

تدعم الأداة ملفات GeoJSON وJSON وOSM XML، وتصنف العناصر تلقائياً إلى طرق ومياه ومبانٍ ونقاط وطبقات أخرى حسب نوع الهندسة وخصائصها مثل highway وbuilding وwater.

أين تُحفظ أنماطي المتعددة؟

تُحفظ الأنماط في التخزين المحلي localStorage داخل متصفحك فقط، ويمكنك حفظ اسم النمط وتطبيقه أو حذفه في أي وقت دون الحاجة إلى حساب.

كيف أستخدم صفحة HTML المصدرة على موقعي؟

انسخ النص الظاهر في مربع التصدير بعد الضغط على زر تصدير صفحة HTML، واحفظه كملف HTML أو الصقه في صفحة قائمة، فهو يتضمن بيانات الخريطة والنمط ويرسمها دون أي مكتبات خارجية.

ماذا أفعل إذا ظهر خطأ عند رفع ملف؟

ستظهر رسالة واضحة في مربع الحالة تشرح وجود مشكلة في تنسيق الملف، وتبقى الخريطة السابقة معروضة، فيمكنك اختيار ملف GeoJSON أو OSM XML صالح آخر أو تجربة البيانات التجريبية.
