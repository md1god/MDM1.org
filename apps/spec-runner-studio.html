اختبر كود الواجهة مباشرةً واحصل على تقارير تفصيلية

أداة سريعة تُحوِّل مقاطع HTML/CSS/JS إلى اختبارات تلقائية، تعرض نتائجها على لوحة، وتولِّد ملخَّصًا بصيغة Markdown للتوثيق.

هذه الأداة تسمح لك بتحويل مقاطع الكود إلى اختبارات تلقائية تُظهر النتائج فور تعديلك. يمكنك إدخال أي شريحة من HTML أو CSS أو JavaScript، ثم تشغيل الفحص لتتلقى تقريرًا يوضح ما هو متوقع وما هو فعلي، مع لقطة مرسومة على لوحة canvas لتوثيق الحالة. بالإضافة إلى ذلك، يُمكنك استخراج ملخص بصيغة Markdown لتضمينه في طلبات التغيير أو المراجعات، كما تتوفر خاصية تصدير واستيراد إعداداتك كملف JSON لتسهيل مشاركة العمل بين الفرق.

كيف يتم التحقق من صحة الكود المدخل؟

الأداة تبحث عن نمط بسيط يدل على وجود منطق التحقق من البريد، مثل كلمة “email” أو الرمز “@”.

هل يمكنني تعديل الاختبار ليشمل سلوكيات أخرى؟

نعم، يمكنك تعديل الدالة generateReport داخل الكود لتضيف فحوصات مخصصة بحسب احتياجاتك.

ما هو تنسيق الملخص الذي يتم تنزيله؟

يُصدَّر الملخص بصيغة Markdown لتسهيل نسخه إلى طلبات التغيير أو وثائق المشروع.

هل يمكن مشاركة إعداداتي مع فريق آخر؟

بالتأكيد، استخدم زر “تصدير الإعدادات” لتحصل على ملف JSON يمكن للزملاء استيراده مباشرةً.

هل تتأثر الأداة بموضوع الموقع الحالي؟

لا؛ تعتمد على المتغيرات CSS العامة للموقع (مثل --gold، --dark) لتتناسب مع المظهر الداكن/الذهبي الموجود بالفعل.
