أنشئ عارض مستنداتك الخاص بصلاحيات واضحة

استورد PDF والصور، رتّبها في غرف وفصول، وصدّر عارض HTML مستقل بكلمة مرور للعرض والطباعة والتنزيل وعلامات مائية، مع تقرير زيارات يصدّره المستلم يدويًا.

ابدأ باستيراد ملفاتك الآن، ثم رتّبها داخل غرفة وفصول واضحة، وأنشئ دليل محتويات جاهزًا قبل التصدير. يعمل كل شيء داخل الصفحة الحالية: لا حساب، لا خادم، ولا تخزين في المتصفح. يمكنك حفظ المشروع كملف JSON والعودة إليه لاحقًا، أو تصدير عارض HTML مستقل يحمل كلمة مرور وصلاحيات عرض وطباعة وتنزيل، مع علامات مائية باسم المستلم ووقت الفتح. أثناء القراءة بدون اتصال يسجّل العارض زيارات الصفحات ومدة التوقف ومحاولات الوصول الممنوعة، ثم يعيد تقريرًا جاهزًا تطلبه من المستلم. كل الأزرار أدناه تعمل فورًا، ويمكنك تجربة النتيجة قبل إرسالها.

      الحماية هنا للتحكم في الوصول داخل ملف عرض مستقل، وليست تشفيرًا قويًا. احتفظ بملف المشروع أثناء التحضير، وأرسل العارض النهائي إلى المستلم.

      أسئلة شائعة

      هل أحتاج إلى حساب أو خادم لاستخدام الأداة؟

      لا. تعمل الأداة داخل الصفحة، ويمكنك تصدير ملف المشروع بصيغة JSON ثم استيراده لاحقًا لمتابعة العمل.

      كيف تحمي العارض المُصدّر؟

      تضع كلمة مرور للفتح، وتحدد السماح بالعرض والطباعة والتنزيل، وتضيف علامة مائية باسم المستلم ووقت التصدير.

      هل تُحفظ الملفات في المتصفح؟

      لا. تبقى الملفات في الذاكرة أثناء العمل فقط، ويمكن حفظها يدويًا في ملف مشروع أو داخل عارض HTML مستقل.

      ماذا يسجّل العارض أثناء القراءة؟

      يسجّل زيارات كل صفحة ومدة التوقف ومحاولات الفتح أو الطباعة أو التنزيل غير المسموحة، ويتيح تصدير تقرير JSON.
