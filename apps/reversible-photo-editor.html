محرر الصور غير المتلف بطبقات قابلة للتعطيل والحذف وإعادة الترتيب

حرّر صورك دون فقدان الأصل عبر طبقات مستقلة للسطوع والتباين والتشبع والحدة والقص والدوران، مع معاينة قبل/بعد وتراجع وإعادة وحفظ محلي، ثم تصدير PNG أو JPEG.

الجواب السريع: هذا محرر صور غير متلف يجعل كل تعديل طبقة مستقلة يمكن تعطيلها أو حذفها أو إعادة ترتيبها في أي وقت، فتبقى صورتك الأصلية سليمة تمامًا. يعمل بالكامل داخل متصفحك دون رفع أي صورة إلى خادم، لذا تبقى خصوصيتك محفوظة. أضف طبقات السطوع والتباين والتشبع والحدة والضبابية والفلاتر والقص والدوران، ثم عاين النتيجة قبل التصدير. استخدم معاينة قبل/بعد، والتراجع والإعادة، واحفظ مشروعك محليًا لتفتحه لاحقًا، ثم صدّر النتيجة بصيغة PNG أو JPEG بجودة تحددها بنفسك. لا حاجة إلى تثبيت أي برنامج، وكل شيء يعمل فورًا داخل الصفحة.

أسئلة شائعة

هل تُرفع صوري إلى أي خادم؟

لا؛ تتم كل المعالجة محليًا داخل متصفحك عبر واجهة Canvas، ولا تُرسل أي صورة أو بيانات إلى أي خادم، فتبقى خصوصيتك محفوظة.

كيف أعود إلى الصورة الأصلية؟

الأصل محفوظ دائمًا ولا يتغير. يمكنك تعطيل الطبقات أو حذفها أو استخدام زر «إزالة كل الطبقات»، وستظل النتيجة مطابقة للأصل.

هل يمكنني حفظ المشروع وفتحه لاحقًا؟

نعم، زر «حفظ مشروع محليًا» يخزّن الصورة والطبقات في متصفحك، وزر «فتح مشروع محفوظ» يستعيدها. الحفظ مرتبط بالمتصفح والجهاز نفسه.

هل يمكن إعادة ترتيب الطبقات وتعطيلها؟

نعم، لكل طبقة أزرار تحريك لأعلى وأسفل، ومربع تعطيل، وزر حذف، وزر تعديل يفتح قيمتها في المحرر.

بأي صيغة يمكنني التصدير؟

بصيغة PNG دون فقدان الجودة، أو JPEG مع شريط لتحديد الجودة. اختر الصيغة ثم اضغط زر التصدير لتنزيل الناتج.
