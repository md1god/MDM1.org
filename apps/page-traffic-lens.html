لوحة تصنيف الزائرين وحركة الصفحة

قدّر نوع الزائر: إنسان أو روبوت أو وكيل ذكي، من وكيل المستخدم والمُحيل واللغة والمنطقة الزمنية. سجّل النقرات والتمرير في الذاكرة مع إعادة عرض وتقرير قابل للنسخ.

نعم، يمكنك تقدير نوع الزائر الحالي داخل صفحة ثابتة دون أي خادم: ابدأ بإدخال أو تعديل إشارات وكيل المستخدم والمُحيل واللغة والمنطقة الزمنية، ثم أضف اسم شركة أو نطاقًا تعرفه يدويًا، واضغط تصنيف الزائر. تعرض الأداة نتيجة واضحة مع درجة ثقة وأسباب قابلة للمراجعة، وتسجّل النقرات والتمرير وتغيّر التركيز في ذاكرة الصفحة فقط أثناء الجلسة. يمكنك إعادة عرض التسلسل داخل الوحدة، نسخ تقرير نصي، أو تصدير ملف JSON واستيراده لاحقًا. التقدير تقريبي بطبيعته؛ لا يمكن لصفحة بلا خادم أن تعرف الشركات الحقيقية أو ترى زيارات سابقة، لكنها تمنحك أقرب نسخة محلية لفهم الزوار وحركة الصفحة.

إشارات الزائر

تُملأ القيم تلقائيًا من المتصفح، ويمكن تعديلها لاختبار سيناريوهات أخرى. الإدخال اليدوي للشركة أو النطاق يساعد في السياق فقط ولا يثبت هوية حقيقية.

    أسئلة شائعة

    هل تحدّد الأداة هوية الشركة الحقيقية؟

    لا. تعتمد على إشارات يرسلها المتصفح أو على قيمة تدخلها يدويًا، وكلها تبقى تقديرًا محليًا داخل الصفحة.

    ما الفرق بين روبوت ووكيل ذكي هنا؟

    يُعدّ الروبوت زاحفًا أو أداة اختبار آلية، بينما يُعدّ الوكيل الذكي مساعدًا أو خدمة ذكاء اصطناعي. قد تتداخل الإشارات، لذلك تظهر درجة ثقة مع الأسباب.

    هل تُحفظ الأحداث بعد إغلاق الصفحة؟

    لا. تبقى النقرات والتمرير وتغيّر التركيز في الذاكرة أثناء الجلسة فقط. يمكنك نسخ التقرير أو تصدير ملف JSON يدويًا قبل المغادرة.

    ماذا يحدث عند استيراد ملف غير صالح؟

    تظهر رسالة خطأ واضحة، ولا تُستبدل البيانات الحالية. الملف الصالح يُعيد تحميل التصنيف والأحداث ويعرضها فورًا في الجداول والتقرير.
