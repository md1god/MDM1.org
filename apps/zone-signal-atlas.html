خريطة تفاعلية لمناطق الحظر المؤقت لمراكز البيانات

تطبيق تفاعلي لعرض مناطق الحظر المؤقت، وإجراءات تقسيم المناطق، والاستفتاءات، وقيود الكهرباء والماء، مع تصفية الأحداث وإنشاء قوائم متابعة داخل الجلسة.

هذه الأداة تمنحك رؤية فورية لمناطق الحظر المؤقت لمراكز البيانات وإجراءات تقسيم المناطق والاستفتاءات وقيود الكهرباء والماء في مكان واحد، مع إمكانية تصفية الأحداث بالتاريخ والنوع وحالة القرار، وإنشاء قوائم متابعة داخل الجلسة، واستيراد ملف بيانات محلي لتحديث التغطية، وتصدير بطاقات الأدلة كملفات CSV أو JSON أو نص قابل للمشاركة، دون الحاجة إلى خادم أو اتصال أو تخزين. ابدأ باختيار مرشحات في الأعلى، ثم انقر على منطقة في الخريطة لعرض التفاصيل والأدلة، وأضف عناصر إلى قائمة المتابعة للحصول على تنبيهات محلية عند اقتراب موعد أو قيد.

التفاصيل: انقر على منطقة في الخريطة.
بطاقات الأدلة: حدد حدثاً لعرض الأدلة.

هل يمكن حفظ قوائم المتابعة؟

تُحفظ قوائم المتابعة داخل الجلسة فقط وتُفقد عند إغلاق الصفحة؛ صدّر البيانات للاحتفاظ بها.

كيف أستورد بيانات جديدة؟

اختر ملف JSON بالبنية المطلوبة ثم اضغط استيراد.

كل بطاقة تتضمن المنطقة والنوع والعنوان والتاريخ والحالة والموعد والحد ومصدر قابل للنقر.
