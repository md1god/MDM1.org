أداة توثيق الأكواد دون اتصال

توثيق ملفات المشروع تلقائياً وإنشاء فهرس وREADME ورسم تخطيطي للهيكل مع حفظ محلي دون إنترنت أو حسابات

بإيجاز: يمكنك توثيق مشروعك بالكامل داخل المتصفح دون اتصال بالإنترنت ودون الحاجة إلى أي حسابات. تقوم هذه الأداة بقراءة ملفات مشروعك عند رفعها أو عند لصق محتواها يدوياً، ثم تبني فهرساً للملفات، وتولد وثيقة README مقترحة بناءً على أسماء الملفات وأنواعها، كما ترسم تخطيطاً مرئياً لهيكل المشروع على لوحة رسم، مع إمكانية حفظ كل ما أنجزته في ذاكرة المتصفح واستعادته لاحقاً عند الحاجة. كل ما يتم فعله يحدث محلياً فقط، ولا يخرج أي ملف أو محتوى من جهازك. استخدم الأداة أدناه خطوة بخطوة لبدء توثيق مشروعك بسرعة وبطريقة منظمة.

أسئلة شائعة
هل تعمل هذه الأداة دون اتصال بالإنترنت؟
نعم، جميع العمليات تتم داخل المتصفح ولا توجد اتصالات شبكة، ويمكن استخدامها بالكامل دون اتصال.
هل يتم إرسال ملفات المشروع إلى أي مكان؟
لا، تتم قراءة الملفات ومعالجتها محلياً فقط ولا يتم إرسال أي بيانات خارجيًا.
كيف يتم حفظ العمل؟
يمكنك الضغط على زر حفظ كل شيء محلياً ليتم تخزين الفهرس وREADME وقائمة الملفات في localStorage واستعادتها لاحقاً.
هل يدعم رفع مجلد كامل؟
نعم، يمكنك استخدام خيار رفع مجلد المشروع لقراءة جميع الملفات داخل المجلد دفعة واحدة.
ماذا لو لم أرفع ملفات بل لصقتها؟
يمكنك لصق المحتوى في المساحة المخصصة مع اسم كل ملف ثم نقطتين، وستضيف الأداة الملفات مباشرةً إلى القائمة.
