محرر أكواد ويب متكامل داخل المتصفح

محرر أكواد يعمل بالكامل في المتصفح، يدعم ملفات متعددة، معاينة HTML/CSS، طرفية محاكاة، وتصدير/استيراد المشاريع كملف JSON، كل ذلك دون اتصال أو حساب.

هذا المحرر يتيح لك كتابة وتشغيل أكواد الويب مباشرةً داخل المتصفح دون الحاجة إلى اتصال أو حساب. يمكنك إنشاء ملفات متعددة، تعديلها، ومعاينة النتيجة في الوقت الحقيقي. كل شيء يُحفظ في الذاكرة المؤقتة للجهاز، ويمكنك تصدير المشروع كملف JSON أو استيراده لاحقًا. الواجهة مصممة لتتناسب مع مظهر الموقع الحالي وتدعم الوضع الليلي بألوان الذهب الداكنة. توفر أزرار لإضافة ملف جديد، حذف الملف الحالي، تشغيل المعاينة، وإدارة محتوى المشروع بسهولة، كما يحتوي الطرفية على سجل للأوامر التي نفذتها لتتبع التغييرات.


  


أسئلة شائعة
كيف يمكنني حفظ عملي دون الإنترنت؟
يُحفظ المشروع بالكامل في الذاكرة المؤقتة للمتصفح ويمكنك تصديره كملف JSON لتستعيده لاحقًا.
هل يدعم المحرر تشغيل جافاسكريبت؟
لتجنب مخاطر الأمان، لا يتم تنفيذ كود جافاسكريبت داخل المعاينة؛ يمكنك الاطلاع على الكود في المحرر فقط.
هل يمكنني إضافة أكثر من ملف للموضوع الواحد؟
نعم، يمكنك إنشاء ملفات متعددة (HTML, CSS, JS) وإدارتها عبر قائمة الملفات في الأعلى.
ما هي المتطلبات لتشغيل هذا التطبيق؟
لا يحتاج إلى خادم أو تسجيل؛ يعمل مباشرةً في أي متصفح حديث يدعم JavaScript.
هل يدعم التطبيق الوضع الداكن؟
يتبع التطبيق ألوان الموقع الموجودة باستخدام المتغيرات CSS، لذا يدمج تلقائيًا مع الوضع الداكن للصفحة.
