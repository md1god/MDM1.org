مدير المحتوى الثابت

مدير محتوى ثابت يعمل في المتصفح: شجرة صفحات ومجلدات، محرر Markdown بمعاينة فورية، بيانات وصفية محفوظة محليًا، مكتبة وسائط وتصدير HTML جاهز للنشر.

نعم، هذا التطبيق مدير محتوى ثابت متكامل يعمل بالكامل داخل المتصفح دون أي خادم أو اتصال خارجي، يتيح لك إنشاء شجرة صفحات ومجلدات منظمة وتحرير المحتوى بلغة Markdown مع معاينة فورية أثناء الكتابة، وحفظ العنوان والتاريخ والوسوم والقالب محليًا في متصفحك عبر التخزين المحلي، كما يدعم مكتبة وسائط بالسحب والإفلات مع معاينة الصور، وبحثًا فوريًا في أسماء الصفحات والمحتوى والوسوم، واختيار قوالب العرض وتنسيقات التخطيط المختلفة، ثم تصدير أي صفحة أو الموقع كاملًا كملفات HTML جاهزة للنسخ والنشر على أي استضافة ثابتة، مع الحفاظ على جميع بياناتك في جهازك حتى عند إغلاق الصفحة أو تحديثها، وواجهة عربية كاملة من اليمين إلى اليسار تسهل الاستخدام اليومي للمحررين وأصحاب المواقع والمدونات والمتاجر الصغيرة.

      هل يمكن تصدير صفحة واحدة أو الموقع كاملًا؟

      ماذا يحدث إذا بحثت عن كلمة غير موجودة؟

      تظهر رسالة حالة فارغة وعدد نتائج صفر، ويمكنك مسح البحث لعرض الشجرة كاملة مجددًا.

      نعم، يدعم العناوين والعريض والمائل والكواد والقوائم والاقتباس والفواصل، مع معاينة فورية وعدّاد كلمات وأحرف.
