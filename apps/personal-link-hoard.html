منتدي روابطي - متصفح شخصي للمقالات التقنية

نظّم روابطك التقنية في منتدى خاص: صوّت بالسهام، علّق تعليقات متداخلة، وسوم برمجة وأمن وذكاء اصطناعي، ترتيب بالشعبية أو التاريخ، بحث وفلترة، حفظ محلي وتصدير JSON.

الإجابة السريعة: هذا التطبيق متصفح شخصي يجمع فيه روابط المقالات التقنية وينظّمها كمنتدى خاص يعمل بالكامل داخل متصفحك دون أي خادم، يتيح لك التصويت بالسهام الصاعدة والهابطة، وكتابة تعليقات متداخلة، وتصنيف الروابط بوسوم مثل البرمجة والأمن وذكاء الاصطناعي، وترتيبها بالشعبية أو بالتاريخ، مع بحث وفلترة محلية فورية، وحفظ تلقائي في localStorage، وتصدير واستيراد ملف JSON لنقل بياناتك بسهولة. ابدأ بإضافة رابط، ثم صوّت وعلّق وصنّف، وكل شيء يُحفظ محليًا.

أسئلة شائعة

هل يحتاج التطبيق إلى خادم أو اتصال بالإنترنت؟

لا، يعمل التطبيق بالكامل داخل متصفحك، ويحفظ البيانات في localStorage، ولا يرسل أي شيء إلى الشبكة.

كيف أحفظ بياناتي بعد إغلاق المتصفح؟

يُحفظ كل شيء تلقائيًا في localStorage عند كل إضافة أو تصويت أو تعليق، ويمكنك تصدير نسخة احتياطية كملف JSON.

ما معنى التعليقات المتداخلة؟

يمكنك الرد على أي تعليق لينشأ رد متداخل، مع أزرار تعديل وحذف لكل تعليق ورد على حدة.

كيف أستعيد بياناتي على جهاز آخر؟

صدّر ملف JSON من جهازك الأول، ثم افتح التطبيق على الجهاز الآخر واضغط استيراد ملف JSON واختر الملف.

هل يمكنني التعديل أو حذف مقالة بعد إضافتها؟

نعم، كل مقالة تحتوي أزرار تعديل المقالة وحذف المقالة، وكذلك تصويت صاعد وهابط ووسوم قابلة للتعديل.
