Khayt — خطة مشروع كاملة

منصة محلية أولًا لبناء وتشغيل وكلاء متصفح موثوقين، تعيد إنتاج كل خطوة وتضع الإنسان في مركز القرار.

خطة أصلية مبنية على احتياج حقيقي وتُراجع قبل التنفيذ.

خطة تنفيذ كاملة لمشروع رقمي جديد: الفكرة والجمهور والمنتج والنموذج الربحي وخطة الانتشار والمخاطر. المشروع قيد البناء ولم يُطلق بعد.

1) الجمهور المستهدف

• مطورو وكلاء AI الذين يحتاجون إلى أتمتة متصفح قابلة للفحص وإعادة التشغيل، لا مجرد “سكربتات” هشة.

• مهندسو الأتمتة واختبار الجودة (QA) الذين يريدون تحويل سيناريوهات الاختبار اليدوية إلى workflows موثوقة.

• الوكالات والفرق الصغيرة التي تبني عمليات جمع بيانات أو إدخال بيانات لعملائها دون تكاليف سحابية مرتفعة.

• المؤسسات الحساسة للبيانات التي تريد تشغيل الأتمتة على بنيتها التحتية مع مفاتيح نماذج خاصة أو Ollama.

• الباحثون وصناع المحتوى التقني الذين يحتاجون إلى بيئة تجريب مجانية وقابلة للتكرار.

2) نقاط التميز (لماذا نختار منتجنا)

• محلي أولًا وحقيقي: واجهة ويب محلية تُشغّل بأمر واحد، مع منفّذ خفيف على الجهاز أو داخل Docker، ودعم Ollama وأي مزود متوافق مع OpenAI. لا حاجة لإرسال بيانات التصفح إلى خدمة خارجية.

• محرر مزدوج: بناء مرئي على شكل DAG، وتحكم كامل بالكود عبر TypeScript أو Python، مع متغيرات مُعرّفة الأنواع وتحقق فوري قبل التشغيل.

• كبسولة إعادة تشغيل: تسجيل كل خطوة من screenshots وDOM snapshots وسجلات الشبكة واستدعاءات النموذج، مع تنقية تلقائية للبيانات الشخصية، لإعادة إنتاج الأخطاء بدقة.

• حوكمة بدل التخفي: لا انتحال بصمات أو تجاوز CAPTCHA. بدلًا من ذلك: قائمة نطاقات مسموحة، حدود معدل، موافقة بشرية قبل الإرسال أو الشراء أو الحذف، وسجل تدقيق كامل.

• تصدير محمول: تحويل أي workflow إلى MCP server أو REST API أو webhook أو CLI، دون ربط المنتج بمزوّد واحد.

• مختبر تقييم مدمج: حالات اختبار وassertions ومقارنة انحدارات ونسبة نجاح، لتحويل الأتمتة من تجربة عشوائية إلى أصل هندسي قابل للصيانة.

3) نطاق النسخة الأولى (8 مهام كحد أقصى)

1. منفّذ محلي بأمر واحد: تثبيت عبر Docker أو npm، تشغيل Chromium عبر Playwright، وربط Ollama أو مفتاح API خارجي.

2. استوديو ويب: محرر مرئي + لوحة كود، متغيرات مُعرّفة الأنواع، تحقق من الصحة، وحفظ محلي.

3. مسجّل خطوات قابل للتحرير: تسجيل نقرات وكتابة وتنقل، مع مولّد selectors يعتمد على accessibility tree قبل الإحداثيات.

4. كبسولة replay: screenshots وDOM وnetwork metadata وconsole واستدعاءات LLM، مع إخفاء تلقائي للحقول الحساسة.

5. طابور تشغيل متوازٍ: تحكم في التزامن، timeouts، retries، وحدود ميزانية للتوكنز والتكلفة.

6. محرك سياسات وخزنة أسرار: allowlist للنطاقات، موافقة بشرية للإجراءات الحساسة، حدود معدل، وسجل تدقيق.

7. تصدير وتشغيل آلي: MCP server، REST/webhook، جدولة، وCLI لتشغيل نفس الworkflow خارج الاستوديو.

8. مختبر تقييم: بيانات اختبار، assertions، مقارنة نتائج النسخ، وتقرير نجاح/فشل قابل للتصدير.

4) التسعير ونموذج الربح

• Free / Local: مجاني للأبد للاستضافة الذاتية؛ workflows غير محدودة، جلستان متوازيتان، سجل محلي 7 أيام، نماذج محلية أو مفاتيح المستخدم، دعم مجتمعي.

• Pro: 19 دولارًا/مستخدم/شهر؛ مزامنة سحابية اختيارية، 10 جلسات متوازية، سجل 30 يومًا، تشغيل مجدول، دعم بالبريد.

• Team: 39 دولارًا/مستخدم/شهر؛ مساحة مشتركة، RBAC وSSO، تصدير سجلات التدقيق، 50 جلسة متوازية، سجل 90 يومًا، دعم أولوية.

• Enterprise: تسعير مخصص؛ نشر معزول، SLA، مراجعة امتثال، موصلات خاصة، وتدريب.

الإيرادات: اشتراكات الفرق + سعات تشغيل سحابي اختيارية + خدمات نشر وتكامل. لا هامش على مفاتيح النماذج، وتبقى النسخة المحلية المجانية قابلة للاستخدام الجدي.

5) خطة الانتشار العالمية بقنوات مجانية

• GitHub أولًا: نشر النواة مفتوحة المصدر برخصة Apache 2.0، مع قوالب workflows، issues للمبتدئين، وإصدارات موثقة.

• SEO ومحتوى تقني: صفحات مثل “تشغيل أتمتة المتصفح محليًا”، “بديل مستضاف ذاتيًا لأتمتة الوكلاء”، ومقارنات تكلفة وخصوصية بالإنجليزية والعربية.

• YouTube والمدونات: دروس بناء workflow كامل في 10 دقائق، جلسات debugging باستخدام replay، وbenchmark شفاف بين النماذج المحلية والسحابية.

• المجتمعات: Show HN، Product Hunt، مجتمعات Ollama وMCP، subreddits المتخصصة وفق قواعدها، وDiscord رسمي للدعم.

• التكاملات: قوالب مفتوحة لـ n8n وLangChain وLlamaIndex وDify، ونشر الـMCP server في أدلة MCP وأفضل قوائم الأدوات.

• الشراكات: وكالات أتمتة، أندية جامعية، هاكاثونات، ولقاءات AI محلية. القياس الأساسي: زمن أول تشغيل أقل من 10 دقائق، ثم إعادة استخدام القوالب أسبوعيًا.

6) المخاطر (قانونية وتقنية)

قانونية:

• انتهاك شروط مواقع مستهدفة أو قوانين حماية البيانات. التخفيف: إقرار سياسة الاستخدام، allowlist، سجلات تدقيق، احترام robots وواجهات API الرسمية، ورفض تجاوز CAPTCHA أو انتحال الهوية.

• مسؤولية الإجراءات التي ينفذها الوكيل. التخفيف: موافقة بشرية للإجراءات المالية أو المرسلة، حدود واضحة، وإخلاء مسؤولية تعاقدي.

• خصوصية البيانات وسرية المفاتيح. التخفيف: تشغيل محلي افتراضيًا، تشفير الأسرار، تنقية السجلات، وDPA للنسخة السحابية.

تقنية:

• تغيّر المواقع وانهيار selectors. التخفيف: selectors دلالية، نسخ مثبتة من المتصفح، واكتشاف الانحدار عبر replay.

• حجب الأنظمة المضادة للبوتات. التخفيف: فشل شفاف، توصيات باستخدام APIs الرسمية، وعدم بناء ميزة تخفي.

• تنفيذ كود غير موثوق داخل المنفّذ. التخفيف: عزل الحاويات، صلاحيات أقل، توقيع القوالب، وفصل الأسرار.

• prompt injection عبر محتوى الصفحات وأدوات MCP. التخفيف: تنظيف المحتوى، رموز محدودة الصلاحية، وموافقة قبل الأدوات الحساسة.

• التكلفة والاستهلاك المفرط. التخفيف: حدود تزامن، ميزانيات، وtimeouts افتراضية.
