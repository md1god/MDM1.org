حصين — خطة مشروع كاملة

وكيلك الذكائي يعمل داخل أسوار مؤسستك، وبياناتها لا تغادره أبدًا.

خطة أصلية مبنية على احتياج حقيقي وتُراجع قبل التنفيذ.

خطة تنفيذ كاملة لمشروع رقمي جديد: الفكرة والجمهور والمنتج والنموذج الربحي وخطة الانتشار والمخاطر. المشروع قيد البناء ولم يُطلق بعد.

خطة منتج: بنية وكلاء ذكاء اصطناعي خاصة للقطاعات المنظَّمة

1) الجمهور المستهدف

• المستشفيات ومجموعات الرعاية الصحية التي تتعامل مع بيانات مرضى خاضعة لقواعد حماية صارمة.

• الشركات القانونية ومكاتب المحاماة والفرق العدلية التي ترفض رفع المستندات إلى سحابة خارجية.

• الجهات المالية (بنوك، شركات تمويل، شركات تأمين) المرتبطة بمدققي خارجيين وسجلات تدقيق.

• الجهات الحكومية والسيادية وأجهزة الأمن التي تشترط تشغيل الأنظمة دون اتصال بالإنترنت (Air-gapped).

• فرق الامتثال والحوادث (Compliance / Security) داخل هذه المؤسسات، وشركاء التكليف الحكومي (Government Contractors).

• شريحة القرار: مدير تقنية المعلومات + مسؤول الأمن والمعلوماتية + مسؤول الامتثال.

2) نقاط التميز (لماذا نختار منتجنا)

• تشغيل محلي بالكامل: يُنشأ نموذج الوكيل داخل شبكة المؤسسة، ولا تغادر أي بيانات حدودها.

• وضع معزول اختياري: نشر Air-gapped بوسيلة واحدة، مع نسخة ميزات مطابقة لوضع الاتصال السحابي (Feature parity).

• واجهات خاصة (Private Endpoints): عنوان API داخلي ثابت يمتد إلى الخوادم المحلية أو سحابة العميل الخاصة.

• مسار ترقية موحّد: نفس مكتبات الوكلاء ونفس تعريفات الأدوات تُشغَّل محليًا أو سحابيًا دون إعادة كتابة.

• سجل تدقيق جاهز: سجل غير قابل للتعديل لكل استدعاء، نموذج، ومصدر بيانات، مع تصدير لنظام الحوكمة.

• نموذج مجاني للبدء: طبقة مجانية بعقدة واحدة تسمح بالتجربة داخل المؤسسة قبل أي شراء.

• سعر وقابلية توقّف: لا قفل لملفات العميل، وتصدير كامل للسجلات والإعدادات في أي وقت.

3) نطاق النسخة الأولى (8 مهام كحد أقصى)

1. محرّك تشغيل محلي واحد (نموذج مفتوح المصدر صغير) مع واجهة REST موحّدة.

2. طبقة وكيل واحدة: خطة → تنفيذ أداة → استجابة، مع ذاكرة قصيرة المدى للجلسة.

3. واجهة Endpoint خاصة داخل الشبكة + مفتاح API داخلي وصلاحيات على مستوى المشروع.

4. وضع نشر معزول (Air-gapped) عبر حاوية واحدة مع فهرس نماذج مُجهَّز دون إنترنت.

5. سجل تدقيق + تتبع النداءات (Tracing) مع تصدير JSON/CSV.

6. عامل اتصال واحد لكل قطاع: قوالب وثائق (سياقية/عقدية/مالية) جاهزة.

7. لوحة تحكم ويب خفيفة: مراقبة الاستهلاك، السقف، وحالة العقدة.

8. ترخيص مجاني لعقدة واحدة + نموذج تثبيت ذاتي موجَّه خلال 15 دقيقة.

4) التسعير ونموذج الربح

• مجاني: عقدة واحدة، مشروعان، 10 آلاف استدعاء شهريًا، سجل تدقيق محدود الحجم — للتجربة الداخلية.

• احترافي: 79$ شهريًا لكل عقدة إنتاجية، مستخدمون غير محدودين، سجل تدقيق كامل، تحديثات نماذج.

• مؤسسات: من 999$ شهريًا — نشر Air-gapped، نقاط نهاية خاصة متعددة، تكامل SSO، دعم بمستوى اتفاقية (SLA).

• إضافة اختيارية: تدريب تكييفي على بيانات المؤسسة، وحزمة تقارير جاهزة للتدقيق.

• مصدر الدخل: اشتراك شهري متكرر (SaaS ذاتي التشغيل) + خدمات تكامل للقطاعات المنظَّمة.

5) خطة الانتشار العالمية بقنوات مجانية

• محتوى تعليمي قصير بالعربية والإنجليزية (LinkedIn، X، YouTube) عن: «ما الذي لا يجب أن يغادر مؤسستك».

• مقالات مقارنة تقنية (On-prem مقابل Cloud) تُنشر في مدونة المنتج ونشرات المجتمع.

• حضور في مجتمعات الأمن والامتثال (ISC²، ISACA) ومنتديات مهنيين على Discord وReddit.

• مخزن نموذج مفتوح لواجهة الوكيل لجذب مهندسي الأمن (Contribution على GitHub).

• نشر دراسات حالة قصيرة مع أسماء معتمدة (أو أرقام مجهولة عند تعذّر الاعتماد).

• برنامج مُوجَّه لشركاء (Partners) وفِرق تكليف حكومي مع صفحة تسجيل مجانية.

• نشرات بريدية أسبوعية + ورش تدريبية مجانية شهرية عبر webinar.

6) المخاطر (قانونية وتقنية)

• قانونية: قواعد حماية البيانات الصحية والمالية قد تفرض شهادات إلزامية؛ يجب قصر الادعاءات على «قابلية» لا «ضمان» الامتثال.

• قانونية: مسؤولية المخرجات المولَّدة (اتجار بuprofessional / تشخيص طبي/نصيحة قانونية) تحتاج إخلاء مسؤولية صريحًا وضوابط مراجعة بشرية.

• تقنية: فجوة أداء بين النماذج المحلية والسحابية قد تُضعف الوعد؛ تُعالَج بقوائم نماذج مُختارة لكل حِملة.

• تقنية: سلامة نشر المعزول (Air-gap) وتزويد النماذج دون إنترنت خطوة معقّدة وقد تطيل دورة البيع.

• تقنية: سوء استخدام الوكيل لاستدعاء أدوات وصول لبيانات حسّسة — تُعالج بسياسات وصول صارمة على مستوى الأداة.

• تجارية: دورة بيع طويلة مع الجهات الحكومية؛ تُخفَّف عبر الطبقة المجانية والنموذج الذاتي.
