Ruknly — خطة مشروع كاملة

تطبيقات مصغّرة تُثبّت في دقائق وتعمل معًا من لوحة واحدة لتنمو مع متجرك.

خطة أصلية مبنية على احتياج حقيقي وتُراجع قبل التنفيذ.

خطة تنفيذ كاملة لمشروع رقمي جديد: الفكرة والجمهور والمنتج والنموذج الربحي وخطة الانتشار والمخاطر. المشروع قيد البناء ولم يُطلق بعد.

1) الجمهور المستهدف

• تجار Shopify المستقلون والعلامات الصغيرة والمتوسطة (10–500 طلب شهريًا) الذين يريدون تحسين التحويل دون تركيب 5–10 تطبيقات ثقيلة.

• المتاجر في الأسواق الناشئة (الخليج، مصر، المغرب، جنوب آسيا) حيث الحساسية السعرية عالية والاشتراكات بالدولار عبء.

• وكالات Shopify والمستشارون الذين يديرون عدة متاجر ويحتاجون نشر أدوات موحّدة بسرعة.

• فرق التجارة الإلكترونية التي تحتاج دعمًا أصليًا لـ RTL.

2) نقاط التميز (لماذا نختار منتجنا)

المشكلة: التاجر يحتاج وظائف صغيرة متعددة، لكن السوق يفرض عليه تطبيقات منفصلة واشتراكات متعددة وأداءً ثقيلًا.

• محفظة مترابطة: كل تطبيق يعمل منفردًا، وعند تركيب أكثر من واحد تتشارك الجلسة والفوترة والتحليلات.

• فاتورة واحدة وخطة مجانية دائمة بدل 5–10 اشتراكات.

• أداء أولًا: تحميل كسول للواجهة، دون مكتبات ثقيلة، وقياس Core Web Vitals قبل كل إصدار.

•/RTL أصلية وليست ترجمة لاحقة.

• هوية وتصميم أصليان: نظام تصميم خاص ومكونات مبنية من الصفر، وليس قوالب جاهزة.

• تثبيت وإلغاء بنقرة مع تصدير البيانات أو حذفها فورًا.

• تحليلات متقاطعة تكشف أفضل مزيج أدوات لكل متجر.

• مساحة وكالة لإدارة عدة متاجر بهوية موحدة، وتسعير شفاف بلا رسوم خفية.

3) نطاق النسخة الأولى (8 مهام كحد أقصى)

1. تسجيل موحّد وتركيب بنقرة (Shopify OAuth + App Bridge) مع عزل بيانات كل متجر.

2. لوحة تحكم واحدة + فوترة موحدة + إدارة اشتراكات وتجربة 7 أيام.

3. تطبيق الحزم (Bundles): إنشاء حزم بسيطة ومزامنة المخزون والأسعار.

4. تطبيق البيع الإضافي (Upsell): عروض في صفحة المنتج والسلة.

5. تطبيق خصومات الكمية (Quantity Breaks): قواعد خصم واضحة وقابلة للتعديل.

6. تطبيق شارات الثقة والعد التنازلي لتحسين التحويل.

7. تطبيق مشغل الوسائط (موسيقى/فيديو قصير) بواجهة خفيفة.

8. تحليلات موحدة + cross-sell بين التطبيقات + دعم RTL/.

ملاحظة: يُؤجَّل virtual try-on إلى الإصدار الثاني بسبب التعقيد والكلفة.

4) التسعير ونموذج الربح

• مجاني دائم للبدء: 100 طلب/شهر لكل تطبيق، دون بطاقة.

• Starter: 9$/شهر لكل تطبيق حتى 1000 طلب.

• Growth: 19$/شهر لكل تطبيق حتى 5000 طلب.

• Bundle: 39$/شهر لجميع التطبيقات حتى 5000 طلب.

• Agency: 99$/شهر حتى 10 متاجر + لوحة وكالة.

• استخدام إضافي: 5$ لكل 1000 طلب.

• الدفع عبر Shopify Billing API، تجربة 7 أيام للمدفوع، وإلغاء فوري.

• مصادر الربح: اشتراكات + استخدام + باقات وكالات + تخصيص/دعم مدفوع. لا نبيع بيانات التجار.

5) خطة الانتشار العالمية بقنوات مجانية

• Shopify App Store SEO: صفحة مستقلة لكل تطبيق، كلمات مفتاحية محددة، لقطات شاشة وفيديو قصير، وربط التطبيقات ببعضها.

• أدوات مجانية على الموقع: حاسبة توفير الحزم، حاسبة خصم الكمية، ومولد شارات ثقة لجذب زيارات SEO.

• محتوى تعليمي: مقالات ودروس YouTube بلغتين، وصفحات مقارنة "بدائل".

• مجتمعات: منتدى Shopify، مجموعات التجار على Reddit وFacebook، وDiscord/Slack، بمشاركة قيمة لا إعلانات.

• برنامج وكالات: لوحة مجانية + عمولة 20% على الإحالات.

• إطلاق: Product Hunt، Indie Hackers، BetaList، Show HN.

• إحالات التجار: شهر مجاني لكل طرف.

• صفحات هبوط محلية للخليج ومصر والهند.

6) المخاطر (قانونية وتقنية)

قانونية:

• الالتزام بشروط Shopify Partner وApp Store؛ رفض المراجعة أو تعليق التطبيق.

• GDPR/CCPA/PDPL (السعودية والإمارات): الموافقة، الاحتفاظ بالبيانات، الحق في الحذف والتصدير.

• الفوترة والاسترداد والضرائب وحماية المستهلك.

• الملكية الفكرية: كود وواجهة وهوية أصلية، وفحص تراخيص المكتبات مفتوحة المصدر.

• إمكانية الوصول (WCAG/EAA) ودعم RTL.

تقنية:

• حدود API وموثوقية webhooks وتعطل الخدمة.

• توافق الثيمات (Online Store 2.0/Hydrogen) وقيود checkout extensibility.

• عزل المستأجرين وتشفير التوكنات وإدارة الأسرار.

• حالات حافة الحزم: المخزون، الضرائب، الشحن، وتقريب العملة.

• تدهور الأداء أو تعارض التطبيقات.

• الاعتماد على Shopify: طبقة تكامل مستقلة وتصدير بيانات لتقليل الارتباط.

التخفيف: modular monolith، feature flags، بيئات staging، اختبارات آلية، مراقبة، ومراجعة أمنية.
