1) الجمهور المستهدف

• الشركات الناشئة وفرق SaaS الصغيرة التي تحتاج SOC 2 أو ISO 27001 للبيع للمؤسسات الكبيرة، لكنها لا تستطيع تحمّل تكلفة المستشارين أو الأدوات المؤسسية.

• شركات الذكاء الاصطناعي ومطوّرو النماذج المُلزَمون بـ EU AI Act و ISO 42001، ولا يجدون أدوات تجمع الامتثال الأمني وامتثال الذكاء الاصطناعي في مكان واحد.

• الوكالات ومقدّمو الخدمات المُدارة (MSSPs) الذين يديرون الامتثال لصالح عدة عملاء ويحتاجون مساحات عمل متعددة.

• الشركات في الأسواق الناشئة والشرق الأوسط التي تبحث عن حلّ يفهم لغة السياق المحلي ولوائح حماية البيانات المحلية.

• مجاني للبدء فعليًا: توليد السياسات ولوحة الجاهزية و Trust Center متاحة دون بطاقة ائتمان، والدفع فقط عند الحاجة للتقارير الرسمية والتعاون المتقدم.

• امتثال مزدوج: أول منصة تجمع الأمن السيبراني (SOC 2 / ISO 27001) و امتثال الذكاء الاصطناعي (ISO 42001 / EU AI Act) في محرك تعيين ضوابط واحد.

• جمع الأدلة الآلي من GitHub وAWS وStripe وواجهات OpenAI/Anthropic، بدل جمع الأدلة يدويًا في جداول.

• وصول ذاتي بالكامل دون مكالمات بيع أو عروض أسعار مخفية.

• ثنائي اللغة (عربي/إنجليزي) من اليوم الأول، ميزة لا توفّرها الأدوات المنافسة.

• واجهات API مفتوحة وتصدير كامل للبيانات لتجنّب احتكار المزوّد.

4) التسعير ونموذج الربح

• Free (مدى الحياة): مساحة عمل واحدة، سياسات غير محدودة، لوحة جاهزية، Trust Center أساسي، تكامل واحد — بلا بطاقة ائتمان.

• Starter (مثلًا 99$/شهر): تكاملات كاملة، جمع أدلة آلي، حتى 3 مساحات عمل.

• Growth (مثلًا 399$/شهر): مساحات غير محدودة للوكلاء، SSO، تقارير قابلة للتوقيع، دعم أولوية.

• Enterprise (تسعير مخصّص): استضافة خاصة، ضوابط مخصّصة، مدير نجاح.

• مصادر ربح إضافية: سوق قوالب الأطر والضوابط، وشراكات إحالة مع مدقّقي الحسابات، وواجهة API مدفوعة الاستخدام.

5) خطة الانتشار العالمية بقنوات مجانية

• SEO المحتوى: أدلة مجانية لكل إطار + قوالب سياسات قابلة للتنزيل تجذب الباحثين.

• محرك الأدلة مفتوح المصدر: نشر أدوات التكامل على GitHub لجذب المطوّرين وبناء الثقة.

• Product Hunt و Hacker News: إطلاق «Free forever tier» كرسالة أساسية.

• المجتمعات: Reddit (r/devops, r/cybersecurity)، Slack/Discord للمطوّرين، مجتمعات الشركات الناشئة.

• أسواق التكاملات: إدراج في GitHub Marketplace وAWS Marketplace وSlack App Directory.

• شراكات مجانية مع مسرّعات الأعمال وحاضنات الـ SaaS لإتاحة الخطة المجانية لدفعاتها.

• برنامج سفراء ومحتوى عبر LinkedIn/X يستهدف مسؤولي الأمن والامتثال.

6) المخاطر (قانونية وتقنية)

• قانونية: تجنّب أي ادعاء بأن المنصة «تمنح الشهادة»؛ نحن أداة جاهزية والمدقّق المستقل وحده يمنح الشهادة. صياغة إخلاء مسؤولية واضح.

• الخصوصية والتعاقد: اتفاقية معالجة بيانات (DPA)، امتثال GDPR، ومعالجة بيانات العملاء الحساسة كأدلة.

• مسؤولية الأدلة: تحديد مسؤولية العميل عن صحة الوثائق التي يوقّعها.

• تقنية: أمان تخزين الأدلة وتشفيرها، وموثوقية صلاحيات قراءة فقط (least privilege) للتكاملات.

• دقة التعيين الآلي: ضرورة وجود مراجعة بشرية لمنع «هلوسة» الذكاء الاصطناعي في تعيين الضوابط.

• تغيّر اللوائح: الحاجة لتحديث مستمر للأطر القانونية (EU AI Act خصوصًا).
