2) نقاط التميز (لماذا نختار منتجنا)

1. مصدر مفتوح للبيانات (Data Provenance): كل رقم يعرض أي استعلام، أي محرك، أي تاريخ، وأي لقطة (snapshot) أنتجته — قابل لإعادة التشغيل والتدقيق، على خلاف لوحات封闭式 لا يمكن التحقق منها.

2. مصفوفة الفجوة (Gap Matrix): نقارن إجاباتك بإجابات المنافسين سؤالًا بسؤال، ونُظهر الأسئلة التي تُذكر فيها هم ولا تُذكر فيها أنت — وهي الإشارة الأكثر قابلية للتنفيذ.

3. طابور الإصلاحات (Fix Queue): كل فجوة تُترجم إلى توصية المحدَّد (صفحة/مستند/FAQ/schema.org) مرتّبة حسب الأثر × الجهد، مع تقدير تكلفة استدعاءات LLMFixture منخفض.

4. مركز مصادر الإجابات (Answer Source Map):س أي صفحات يُقتبَس منها عبر كل محرك — يكشف "مواقع Newsrooms والمواقع المقارنة" التي تسيطر على الإجابات، وهو جوهر [مصدر مخفي].

5. مؤشرات تُترجمها لغير التقنيين: "نصيبك من الإجابات" بدل مصطلحات SoV/citation-share المتداخلة.

6. Citable-by-design: تقرير عام قابل للنسخ بالهاش + API للقراءة + تصدير CSV/JSON، مع MCP-compatible endpoint لتغذية وكلاء الذكاء الاصطناعي.

7. مرونةDeployment: SaaS أو self-host (Docker) للوكالات والحوكمة.

8. مركز بحث مجاني بلا تسجيل + فهرس قطاعي عام = محرّك نمو مجاني بلا إنفاق إعلاني.

3) نطاق النسخة الأولى (8 مهام كحد أقصى)

1. إعداد لوحة الاستعلامات: تعريف العلامة (الاسم + المرادفات)، المنافسون (حتى 3)، أسئلة مخصصة ومكتبة أسئلة جاهزة لكل قطاع وسوق/لغة (عربي/إنجليزي)، ومحدد التكرار (أسبوعي افتراضيًا).

2. محرّك الجمع: تشغيل الاستعلامات على ChatGPT وGemini وPerplexity وGoogle AI Overviews وClaude وMicrosoft Copilot عبر APIs رسمية حيثما أمكن + طبقة بديلة محدودة، مع تخزين اللقطة الخام (hash + timestamp + model version).

3. خط الاستخراج: كشف ذكر العلامة (تطابق كيانات + مرادفات + قوائم سلبية)، استخراج الروابط المُقتبَسة مع تطبيع الـ URL وإزالة التتبع، وتصنيف المشاعر (إيجابي/محايد/سلبي) بقواعد ثم LLM عند الحاجة.

4. محرّك المؤشرات: نسبة الظهور لكل استعلام، نصيب الإجابة (Answer Share)، نصيب الاقتباس، اتجاه المشاعر، التجميع حسب المحرك والسوق والقسم، مع عتبات دلالة إحصائية (حد أدنى n واستبعاد الفروق الصغيرة).

5. مصفوفة الفجوة والتنافس: لكل استعلام: من يذكر، من لا يذكر، حجم الفجوة، وتقدير "الأسئلة السهلة السريعة" مرتبة حسب الأثر.

6. طابور التوصيات: توليد توصيات مُولَّدة من الفجوات (تحديث صفحات، FAQ، Schema.org، مراجعات، PR) مع ربط كل توصية بـ URL محدَّد وتقدير أثر.

7. لوحة التحكم + التقرير: رسوم (رسم بياني للظهور عبر الزمن، خريطة مصادر الإجابات، مصفوفة الفجوة، مقارنة المنافسين)، تقرير أسبوعي بالبريد، رابط تقرير عام قابل للقراءة بدون تسجيل، وتصدير CSV/JSON.

8. الفهرس العام + API: صفحة عامة لكل قطاع/مدينة/دولة تعرض ترتيب الظهور مجانًا (بدون كشف بيانات العملاء)، وواجهة API قراءة بمفتاح مجاني + مستند OpenAPI + مثال MCP.

خارج النطاق الآن: كلاء آليون ينفّذون التوصيات على الموقع، تعدد المستأجرين (multi-tenant) للشركات، نماذج تنبؤ، دعم لغات غير العربية/الإنجليزية، منصات محادثة مدمجة (Slack/WhatsApp) — للمرحلة الثانية.

التقنيات المقترحة (مكتوبة من الصفر): Python/FastAPI للواجهة الخلفية + PostgreSQL + Redis/Celery للمهام المجدولة + TypeScript/Next.js للواجهة مع Tailwind RTL، ومحرك كشف ذكر مبني على embeddings + قواعد (spaCy/Nltk + جسر مرادفات) بلا الاعتماد على نموذج خارجي لكل استعلام.

5) خطة الانتشار العالمية بقنوات مجانية

1. الفحص الفوري بلا تسجيل ("اعظِم presence علامتك في 10 أسئلة") — صفحة результа قابلة للمشاركة برابط موقّع + OG image.

2. الفهرس العام للقطاع (مثال: أفضل 100 علامة SaaS عربيًا حسب نصيبها من إجابات AI) — يُحدَّث شهريًا ويُنشر كـ dataset مفتوح على GitHub؛ يجلب SEO و backlinks/PR طبيعيًا.

3. صفحات SEO المولّدة: "ظهور [علامة] في [مدينة/قطاع]" لكل تركيبة — قاعدة تغطية واسعة بتكلفة إنتاج شبه صفرية.

4. أدوات مجانية مدمجة: مولّد أسئلة ChatGPT للقطاع، حاسبة "نصيب الإجابة"، مقياس جاهزية GEO للموقع (تtechnical)، كلّها LEAD magnet.

5. المحتوى: نشرة أسبوعية "تقرير الظهور في الذكاء الاصطناعي" (عربي + إنجليزي)، فيديوهات قصيرة، ورسوم قابلة لإعادة الاستخدام.

6. التوزيع المفتوح: مستودع GitHub للـ SDK وطبقة MCP، документа English + Arabic، أمثلة Notion/Slack/Sheets.

7. المجتمعات: Reddit وX وLinkedIn وDiscord وProduct Hunt وBetaList وIndie Hackers + مجموعات التسويق العربي (Facebook/Telegram/WhatsApp)، · ZenRows.

8. الشراكات: وكالات SEO ومConsultants (عمولة 30% + لوحة عميل)، ومكاتب الاستشارات التي تحتاج تقارير [مصدر مخفي] لكل عميل.

9. الإحالة: "شهر مجاني لكل صديق" + رابط إحالة داخل التقرير.

10. قاعدة بيانات مجانية للباحثين: أكاديمية MIDI → نقاط تصحيح → منشورات ومقالات تستشهد بنا (المصدر المفضّل فيSector).

6) المخاطر (قانونية وتقنية)

قانونية:

• شروط مزوّدي النماذج: إنشاء الحسابات آليًا أو تجاوز الحدود قد يخالف ToS؛ الاعتماد على APIs الرسمية + احترام rate limits + تخزين مؤقت + هوية مشروع واضحة + صفحة "ن-cooperation" معلنة.

• Scraping محرّكات البحث (AI Overviews/منافسوهم): مراجعة robots.txt وToS لكل مزوّد قبل أي زحف؛first approach = APIs + مزوّد بيانات مرخّص (Brave/Serper)، وتحديد النطاق الجغرافي المحظور.

• حقوق الملكية الفكرية: أسماء العلامات في الاستعلامات استخدام nominative Fair Use لأغراض القياس فقط؛ عدم تخزين من monopoly copyrighted content طويل الأجل إلا لزمن قصير لأغراض التحليل (Text & Data Mining exceptions في EU/UK)؛ عرض الاقتباسات كـ "عيّنة" لا كنسخة كاملة.
