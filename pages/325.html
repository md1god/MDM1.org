نَسَق (Nasaq) — خطة منتج أصلي

المشكلة: بناء أنظمة المؤسسات (مخزون، محاسبة، موارد بشرة، مبيعات) يحتاج فرق تطوير مكلفة وشهورًا من العمل، بينما تفشل المنصات التقليدية في دعم العربية وتصبح أنظمة مغلقة يصعب تخصيصها أو نقل بياناتها.

الفكرة: منصة سحابية تحوّل الوصف النصي (بالعربية أو الإنجليزية) إلى تطبيقات مؤسسية كاملة — نماذج بيانات، صلاحيات، سير عمل، تقارير، وواجهات — فوق طبقة نماذج (Metadata) موحّدة قابلة للتوسّع، بنموذج مجاني للبدء.

1) الجمهور المستهدف

• الشركات الصغيرة والمتوسطة في الخليج والمشرق وشمال أفريقيا (5–200 موظف).

• فرق العمليات غير التقنية: المالية، المخزون، الموارد البشرية، المبيعات.

• المستشارون وشركات التنفيذ التي تبني أنظمة عملائها وتريد تسريع التسليم.

• الجمعيات والجهات الحكومية الصغيرة وفرعاتها المحلية.

• الشركات الناشئة التي تحتاج نظامًا ماليًا/تشغيليًا مبكرًا دون تطوير داخلي.

2) نقاط التميز (لماذا نختار منتجنا)

• عربية أولاً: دعم كامل للاتجاه من اليمين لليسار (RTL) في الواجهات والتقارير، وإدخال أوامر بالعربية الطبيعية.

• محرّك توليد موحّد: طبقة Metadata واحدة يولّد تلقائيًا الجداول، العلاقات، قيود التحقق، الصلاحيات، سير العمل، و REST API — لا نظام مجزأ.

• مراجعة قبل النشر: كل توليد يمر بمراجعة المستخدم (human-in-the-loop) لتقليل أخطاء الذكاء الاصطناعي.

• قابلية الهروب: تصدير البيانات والقوالب والـ API في أي لحظة؛ تشغيل ذاتي (self-hosted) متاح، لا احتجاز للبيانات.

• مجانية دائمة للبداية: طبقة مجانية غير محدودة زمنيًا للتجربة والمشاريع الصغيرة.

• قوالب قطاعية جاهزة: تُركَّب وتُعدَّل حواريًا بدل البدء من الصفر.

3) نطاق النسخة الأولى (8 مهام كحد أقصى)

1. محرّك تحويل الوصف النصي (عربي/إنجليزي) إلى نماذج بيانات وعلاقات وقيود تحقق.

2. طبقة Metadata موحّدة مع توليد تلقائي لـ CRUD API ونظام صلاحيات بالدور (RBAC).

3. مولّد واجهات: قوائم، نماذج إدخال، لوحات، وتقارير — بدعم RTL أصلي.

4. محرّك سير العمل: موافقات، إشعارات، ومهام مجدولة بقواعد قابلة للتعديل.

5. محرّر حواري: تعديل الحقول والتقارير والقواعد عبر المحادثة بعد النشر.

6. أربعة قوالب جاهزة: مخزون، فواتير ومبيعات، طلبات شراء، ملفات الموظفين.

7. تكاملات: استيراد/تصدير Excel و CSV، REST API، Webhooks، وربط بريد إلكتروني.

8. استضافة سحابية بطبقة مجانية + حزمة Docker للا التشغيل الذاتي (open-core).

4) التسعير ونموذج الربح

· مجانية · 0 · 3 مستخدمين، تطبيقان، 5,000 سجل، 100 تحويل ذكي/شهر ·

· احترافية · 12$ / مستخدم / شهر · مستخدمون غير محدودين، سير عمل متقدم، تكاملات، مساحة 100GB ·

· مؤسسي · حسب الاستضافة والمتطلبات · SSO، سجلات تدقيق، استضافة خاصة، دعم مخصص ·

مصادر الدخل: الاشتراكات الشهرية/السنوية، حزم ر credits إضافية للذكاء الاصطناعي، سوق القوالب والإضافات (عمولة 20%)، خدمات التنفيذ والتدريب.

5) خطة الانتشار العالمية بقنوات مجانية

• فيديو قصير: YouTube و TikTok و LinkedIn — «اصنع نظام مخزون كامل في 3 دقائق» بالعربية والإنجليزية (3 مقاطع أسبوعيًا).

• GitHub open-core: نشر الطبقة الذاتية الاستضافة لبناء الثقة ونمو عضوي (SEO).

• إطلاقات مجتمعية: Product Hunt، Hacker News، Indie Hackers مع عروض إطلاق.

• مجتمعات: Discord/Telegram، ومنتديات Reddit ذات الصلة (ERP، no-code)، ومجموعات لينكدإن في الخليج.

• برنامج شركاء: تدريب مستشاري ERP والمحاسبين المعتمدين ليصبحوا قناة بيع.

• محتوى مقارنة: مقالات SEO بلغات متعددة مقارنة الأنظمة التقليدية بالتكلفة والوقت.

• أكاديمية: ملتمات جامعية عربية ودورات مجانية معتمدة تُصدر شهادات.

6) المخاطر (قانونية وتقنية)

• خصوصية البيانات: الالتزام بـ PDPL السعودية و GDPR — تشفير أثناء النقل والتخزين، عقود معالجة بيانات، واستضافة إقليمية.

• ملكية المخرجات: توضيح في العقد أن تطبيقات ومخرجات المستخدم ملك له بالكامل.

• ترخيص نماذج اللغة: التحقق من رخص النماذج المفتوحة المستخدمة تجاريًا قبل الإطلاق.

• دقة التوليد: أخطاء النموذج اللغوي — علاجه بمراجعة إلزامية وتثبيت القياسات (human-in-the-loop) وسجل تعديلات.

• الأداء والتوسّع: استعلامات معقدة ومستخدمون متزامنون — عبر فهرسة، تقسيم، واختبارات حِمل مبكرة.

• الاعتماد على المزودين السحابيين: طبقة تجريد تسمح بالانتقال بين المزودين أو التشغيل الذاتي.

• منافسة: منصات low-code عالمية كبيرة — التمايز بالعربية، والمرونة، والسعر، والتشغيل المحلي.
