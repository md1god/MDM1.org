رِواق — خطة مشروع كاملة

كل عقاراتك، تذاكرها وفواتيرها وصيانتها، في منصة عربية واحدة تبدأ معك مجانًا.

خطة أصلية مبنية على احتياج حقيقي وتُراجع قبل التنفيذ.

خطة تنفيذ كاملة لمشروع رقمي جديد: الفكرة والجمهور والمنتج والنموذج الربحي وخطة الانتشار والمخاطر. المشروع قيد البناء ولم يُطلق بعد.

خطة منتج لإدارة العقارات المشتركة

1) الجمهور المستهدف

• شركات إدارة المباني السكنية والمجمعات المشتركة (صغيرة ومتوسطة الحجم).

• مجالس اتحادات الملاك (HOAs) والجمعيات التعاونية السكنية.

• مديرو العقارات المستقلون وشركات الصيانة المتعاقدة معها.

• الملاك الأفراد الذين يؤجرون عدة وحدات ويريدون متابعة المصروفات والتحصيل.

2) نقاط التميز (لماذا نختار منتجنا)

• بداية مجانية فعليًا: نبدأ بالمجان دون الحاجة إلى بطاقة دفع أو استضافة ذاتية معقّدة.

• تجربة عربية أولًا: واجهة RTL أصلية، تقويم ومصطلحات محلية، ودعم لغات متعددة.

• معالجة الديون والعقود كوحدة واحدة: ربط العقد بالوحدة بالفاتورة بالمصروف بتذكرة الصيانة.

• Marketplace للصيانة مدمج مع نظام العروض والمزايدة بدل كونه إضافة منفصلة.

• نظام Plugins خفيف (SDK) لتوسيع الوظائف دون تعديل النواة.

• تقارير مالية جاهزة للتشغيل اليومي، مع تصدير CSV/PDF وإشعارات WhatsApp/Telegram.

3) نطاق النسخة الأولى (8 مهام كحد أقصى)

1. إدارة المباني والوحدات والملاك والمستأجرين.

2. نظام تذاكر موحّد (بلاغات، أولوية، حالات، مرفقات، تتبع SLA).

3. إصدار الفواتير والمطالبات والمتأخرات وتتبع التحصيل.

4. تسجيل المصروفات ضد المباني ومطابقتها بالميزانية.

5. عقود الإيجار ودورة حياتها (تجديد، إنهاء، إشعارات).

6. تتبع المدفوعات والدفعات الجزئية وكشوف الحساب.

7. Marketplace للصيانة: نشر الطلب، عروض المزوّدين، الإسناد والتقييم.

8. Dashboard مع تقارير وتنبيهات + مصادقة وأدوار وصلاحيات.

4) التسعير ونموذج الربح

• خطة مجانية: حتى 2 مبانٍ و20 وحدة، ميزات أساسية، شعار المنصة، مجتمعي فقط.

• خطة Starter: رسم شهري لكل وحدة (مثال: 0.99$ للوحدة/شهر) مع فواتير وتقارير كاملة.

• خطة Pro: رسم أعلى يشمل Marketplace، الـPlugins، التكاملات، نطاق مخصص.

• ربح إضافي: عمولة 5–10% على كل عمليات الإسناد في الـMarketplace، وخطط استضافة مُدارة (Self-hosted Enterprise).

• النموذج: subscription + usage-based + commission، يبدأ مجانًا ويتوسّع مع حجم المحفظة.

5) خطة الانتشار العالمية بقنوات مجانية

• نشر نسخة مفتوحة المصدر على GitHub لجذب المساهمين والثقة.

• محتوى تعليمي مجاني (YouTube، Blog) حول إدارة الأملاك والمحاسبة.

• مجتمعات المنتجات: Product Hunt، Reddit، Hacker News، مجتمعات الملاك المحلية.

• برنامج إحالة: شهر مجاني لكل طرف عند دعوة شركة أخرى.

• شراكات مع شركات الصيانة والنظافة كقناة وصول متبادلة.

• Local SEO بالعربية والإنجليزية + دليل قوالب مجاني للجمعيات السكنية.

• Nasdaq للأعمال: المشاركة في معارض العقارات وبرامج الاحتضان.

6) المخاطر (قانونية وتقنية)

• قانونية: خصوصية بيانات السكان وGDPR/local laws، الامتثال لأنظمة الفوترة والضرائب المحلية، ملكية بيانات الملاك.

• قانونية: مسؤولية المحتوى في الـMarketplace (عقود المزوّدين، سمعة، شكاوى).

• تقنية: هجرة البيانات من أنظمة قديمة، تعدد العملات واللغات، أمن الأدوار.

• تقنية: تكامل متعدد المستأجرين (multi-tenancy) دون تسريب بيانات، واستقرار الـPlugins.

• تشغيلية: مقاومة التغيير لدى الإدارة التقليدية، والحاجة لدعم فني مستمر.
