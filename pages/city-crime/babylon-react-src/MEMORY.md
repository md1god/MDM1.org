# ذاكرة التنفيذ — City Crime

## الاستكشاف الأولي

المستودع الأصلي `MDM1.org/pages/city-crime` يحتوي بوابة HTML ونسخة Godot Web ونسخة Babylon مبنية مسبقاً فقط، من دون مصدر TypeScript أو manifest بناء. لذلك ينشأ مشروع React/Vite قابل للصيانة في `city-crime-next` ثم تنقل مخرجات `dist/public` إلى المسار المنشور داخل المستودع بعد التحقق.

## قيود وتدابير

تعد ملفات الشخصية GLB الحالية كبيرة نسبياً، لذلك لا يعاد استخدامها ضمن أول slice إلا إذا حدد أصلها وترخيصها ومسار ضغطها. نموذج Woman Standing V8 مضغوط بـ Draco إلى 7.1MB لكنه استبعد من النسخة الحالية بطلب المستخدم بسبب عدم الاستقرار. اختار المستخدم لاحقاً منظور كاميرا فقط، لذلك لا تعرض النسخة الحالية أي نموذج أو بديل مرئي للاعب؛ تبقى نقطة التحكم منطقية فقط، وتؤجل أي عودة للشخصية إلى مرحلة لاحقة. لا تستخدم الواجهة أي تقدّم تحميل عشوائي؛ كل نسبة مرتبطة بمرحلة المحرك أو ملف أصل فعلي.

## سياسة الأصول

تعتمد المواد والـ HDRI على Poly Haven؛ وتعتمد كتل المدينة على KayKit/Kenney؛ وتبقى الشخصية والسيارة اختياراً يدوياً في Sketchfab بعد التحقق من CC0 أو CC BY وتسجيل الإسناد؛ وتستخدم Mixamo لحركات idle/walk/run محلياً. تفاصيل الروابط والأحجام في `ASSETS.md`.
