نَبْض — خطة مشروع كاملة

أخبارك كلها في مكان واحد، بذكاءٍ يعمل على خادمك وخصوصية لا تُساوَم.

خطة أصلية مبنية على احتياج حقيقي وتُراجع قبل التنفيذ.

خطة تنفيذ كاملة لمشروع رقمي جديد: الفكرة والجمهور والمنتج والنموذج الربحي وخطة الانتشار والمخاطر. المشروع قيد البناء ولم يُطلق بعد.

خطة منتج: قارئ أخبار ذاتي الاستضافة

1) الجمهور المستهدف

• الأفراد المهتمون بالخصوصية: من يريد متابعة الأخبار دون تتبّع إعلاني أو خوارزميات.

• المطوّرون والفرق التقنية: من يحتاج نشرًا بنقرة واحدة عبر Docker وخادم خاص.

• المؤسسات الصغيرة والمكاتب الإخبارية: فرق تتابع مصادر كثيرة وتريد خلاصات آلية.

• المدونون وصنّاع المحتوى: من يتابعون مصادر منافسين واتجاهات مجالية.

• المستخدمون في مناطق رقابة/شبكات ضعيفة: من يحتاجون مزامنة خفيفة ونسخًا محليًا.

2) نقاط التميز (لماذا نختار منتجنا)

• تلخيص بالذكاء الاصطناعي محليًا مع إمكانية تعطيله كليًا، دون إرسال البيانات لطرف ثالث افتراضيًا.

• نشر بنقرة واحدة: Docker Compose + صورة موحّدة، مع تخزين SQLite افتراضي (بدون إعداد معقّد).

• واجهة حديثة وسريعة تعمل كـ PWA على الجوال، مع دعم RTL/LTR أصلي.

• مزامنة اختيارية متعددة الأجهزة عبر خادم المستخدم نفسه، وليس حسابًا مركزيًا إجباريًا.

• نظام إضافات (Plugins) لواجهات REST آمنة لتمكين التخصيص دون تعديل النواة.

• تصدير/استيراد كامل بصيغة OPML/JSON لتفادي قفل البيانات.

3) نطاق النسخة الأولى (8 مهام كحد أقصى)

1. استيراد ومتابعة خلاصات RSS/Atom/JSON عبر رابط أو OPML.

2. تنظيم المصادر في تصنيفات ووسوم مع بحث فوري.

3. واجهة قراءة نظيفة (قائمة/بطاقات) مع وضع ليلي وRTL.

4. تحديد "غير مقروء" ومزامنة حالة القراءة محليًا.

5. محرّك تلخيص اختياري (محلي أو مفتاح API يضعه المستخدم).

6. حفظ المقالات لقراءتها لاحقًا والبحث داخل النص المخزّن.

7. نشر بنقرة واحدة عبر Docker مع نسخ احتياطي تلقائي مجدول.

8. مصادقة أساسية متعددة المستخدمين وصلاحيات بسيطة.

4) التسعير ونموذج الربح

• مجاني للأبد (Free-to-start): النسخة الذاتية الاستضافة كاملة الميزات الأساسية، بلا حدّ على عدد المصادر.

• خطة سحابية "Pro": اشتراك شهري منخفض (≈ 4–6 دولار) يشمل الاستضافة المُدارة، مزامنة متعددة الأجهزة، وتلخيصًا مدعومًا بالتكلفة.

• خطة "Team": أسعار لكل مقعد مع مشاركة تصنيفات ولوحة إحصاءات.

• مصادر إضافية: دعم مالي طوعي، تراخيص تجارية للشركات التي تريد ميزات مؤسساتية، وإضافات مدفوعة من طرف ثالث.

• المبدأ: النواة مفتوحة المصدر بالكامل؛ الربح من الراحة (الاستضافة) لا من حجز الميزات.

5) خطة الانتشار العالمية بقنوات مجانية

• مجتمعات المصادر المفتوحة: النشر على منصات مشاركة المشاريع التقنية ومنتديات الاستضافة الذاتية.

• مستودع عام للمصادر (OPML Packs) جاهزة حسب المجال واللغة لجذب المستخدمين الجدد.

• محتوى تعليمي: أدلة "ابدأ في 5 دقائق" ومقارنات تقنية على مدوّنة المنتج ومقاطع قصيرة.

• ترجمة جماعية عبر منصة ترجمة مفتوحة لدعم لغات متعددة وعزل عالمي.

• برنامج مساهمين: شارات وميزات مجانية للمساهمين في الكود والإضافات.

• تواجد في مجتمعات font-end/self-hosting مع عروض توضيحية حيّة (demo instance).

6) المخاطر (قانونية وتقنية)

• حقوق النشر: نعرض روابطًا ومقتطفات فقط، دون إعادة نشر المحتوى كاملًا؛ التلخيص يُنسب للمصدر مع احترام robots/شروط الاستخدام.

• الخصوصية والبيانات: لا نجمع بيانات المستخدمين في النسخة الذاتية، وسياسة واضحة للنسخة السحابية مع تشفير عند التخزين.

• الاعتماد على واجهات خارجية: تجنّب الاعتماد على API واحد للتلخيص عبر التجريد والدعم المتعدد.

• الأمان: معالجة مدخلات الخلاصات غير الموثوقة (SSRF، حقن HTML/JS) بتنقية صارمة وعزل تنفيذ الإضافات.

• الاستدامة: منع الإفراط في الطلبات عبر تخزين مؤقت واحترام بروتوكولات التحكم في الزحف.

7) الاسم المقترح والجملة التسويقية

الاسم المقترح: نَبْض (Nabd)
