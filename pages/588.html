Rawi — خطة مشروع كاملة

نحوّل كل محادثة عميل إلى صفقة مكتملة، بذكاء اصطناعي يحترم خصوصيتك ويعمل على بنيتك التحتية.

خطة أصلية مبنية على احتياج حقيقي وتُراجع قبل التنفيذ.

خطة تنفيذ كاملة لمشروع رقمي جديد: الفكرة والجمهور والمنتج والنموذج الربحي وخطة الانتشار والمخاطر. المشروع قيد البناء ولم يُطلق بعد.

1) الجمهور المستهدف

• الشركات الصغيرة والمتوسطة التي تبيع عبر المحادثات، خصوصًا في الشرق الأوسط وأمريكا اللاتينية وجنوب آسيا وأفريقيا، بفريق مبيعات من 3 إلى 50 شخصًا.

• وكالات التسويق ومراكز الخدمة (BPO) التي تدير أرقام واتساب لعملاء متعددين وتحتاج نشرًا واحدًا متعدد المستأجرين وهوية بيضاء.

• القطاعات الحساسة للخصوصية كالصحة والتعليم والتمويل، التي تريد استضافة ذاتية وإقامة بيانات محلية وامتثالًا لـ GDPR وLGPD وPDPL.

• الفرق التقنية والفرق التي تعتمد على API/MCP، وترفض التسعير لكل مقعد أو الارتباط بمزوّد واحد.

2) نقاط التميز (لماذا نختار منتجنا)

• مجاني للبدء فعليًا: النواة مفتوحة المصدر وقابلة للاستضافة الذاتية بلا حدود مقاعد، مع إحضار مفتاح LLM الخاص بك.

• عربي أولًا: واجهة RTL، فهم اللهجات العربية، وقوالب رسائل جاهزة، مع دعم متعدد اللغات.

• قناة مرنة: البدء بـ WhatsApp Cloud API الرسمي، ثم إضافة Instagram وTelegram والبريد وودجت الموقع دون إعادة بناء النظام.

• وكلاء AI موثوقون: إجابات مستندة إلى قاعدة معرفة مع ذكر المصادر، حدود ثقة، سياسات منع، وتحويل بشري تلقائي.

• MCP-native: عرض أدوات CRM كصلاحيات محددة النطاق، مع موافقات وسجلات تدقيق، لربط وكلاء خارجيين بأمان.

• متعدد المستأجرين من اليوم الأول: نشر واحد يخدم الوكالة وعملاءها مع عزل بيانات وصلاحيات.

• خفيف التشغيل: تثبيت بأمر واحد عبر Docker Compose على خادم صغير، دون الحاجة إلى Kubernetes.

• شفافية وملكية بيانات: تصدير كامل، تسعير منشور، وسجلات امتثال وموافقات مدمجة.

3) نطاق النسخة الأولى (ثماني مهام)

1. مساحات عمل متعددة المستأجرين: تسجيل دخول بالبريد وOAuth، أدوار وصلاحيات، دعوات فريق، وسجل تدقيق أساسي.

2. صندوق وارد موحّد: استقبال WhatsApp Cloud API للنصوص والوسائط والقوالب، توزيع المحادثات، وسوم، ملاحظات داخلية، ومؤقتات SLA.

3. نواة CRM: جهات اتصال وشركات، حقول مخصصة، خطوط أنابيب وصفقات ومهام، استيراد/تصدير CSV، ودمج التكرارات.

4. استوديو وكيل AI: قاعدة معرفة مع RAG، نبرة وسياسات، اقتباس المصادر، حد ثقة، تحويل بشري، وبيئة اختبار قبل النشر.

5. بوابة MCP: أدوات مقيدة الصلاحيات، موافقات للعمليات الحساسة، حدود معدل، وسجلات استدعاء قابلة للتدقيق.

6. الأتمتة والمتابعة: مشغلات وإجراءات، تسلسلات متابعة، ساعات عمل، رسائل قوالب، وإدارة إلغاء الاشتراك.

7. التحليلات والامتثال: قمع المبيعات، زمن الاستجابة، نسبة حلّ الوكيل، سجل الموافقات، سياسات الاحتفاظ، وتصدير/حذف البيانات.

8. النشر والتشغيل: تثبيت Docker Compose بأمر واحد، نسخ احتياطي واستعادة، ترقيات، فحوصات صحة، بيانات تجريبية، ووثائق تشغيل.

4) التسعير ونموذج الربح

• النسخة المجتمعية (استضافة ذاتية): مجانية دائمًا، مقاعد غير محدودة، إحضار مفتاح LLM، دعم مجتمعي.

• السحابة — مجاني للبدء: مساحة عمل واحدة، مقعدان، رقم واتساب واحد، و500 رد AI شهريًا.

• Starter — 29 دولارًا/مساحة عمل/شهر: 3 أرقام، 5 مستخدمين، 2,000 رد AI، أتمتة أساسية.

• Growth — 79 دولارًا/شهر: 5 أرقام، 15 مستخدمًا، 8,000 رد AI، تقارير متقدمة وتكاملات.

• Scale — 199 دولارًا/شهر: أرقام ومستخدمون حسب الاستخدام العادل، SSO، سجلات امتثال، وأولوية دعم.

• Agency White-label — 299 دولارًا/شهر: 10 مساحات عملاء، علامة بيضاء، ولوحة فواتير موحدة.

• Enterprise: استضافة ذاتية مدعومة، SLA، تدريب، ومراجعة أمنية — تسعير مخصص.

مصادر الإيراد الإضافية: هامش استخدام AI عند عدم إحضار مفتاح، رسوم تهيئة واتساب المُدارة، دعم ذو SLA، تكاملات مدفوعة، وبرنامج شركاء بالعمولة. خصم 20% للدفع السنوي، وتسعير مرن حسب القوة الشرائية.

5) خطة الانتشار العالمية بقنوات مجانية

• GitHub والمصدر المفتوح: ترخيص AGPLv3 للنواة مع ترخيص تجاري للنسخ المؤسسية، README قوي، فيديو تجريبي، وأزرار نشر بنقرة على Railway وRender وCoolify.

• SEO بلغات متعددة: محتوى عربي وإنجليزي وإسباني وبرتغالي حول «CRM واتساب ذاتي الاستضافة»، ومقارنات، وقوالب، وحاسبات عائد.

• سجلات MCP وقوائم awesome: إدراج الخادم والأدوات، وتكاملات مع n8n وMake وZapier.

• المجتمعات: مجموعات مطوّري Meta، ومنتديات WhatsApp Business، وr/selfhosted وr/sales، وIndie Hackers، وProduct Hunt، وShow HN.

• المحتوى المرئي: دروس قصيرة على YouTube وTikTok، وورش مجانية، وجلسات أسئلة مفتوحة.

• برنامج الوكالات: بيئة تجريبية مجانية بهوية بيضاء وعمولة متكررة، مما يخلق نموًا عبر الشركاء.

• النظام المحلي: حاضنات الأعمال، غرف التجارة، نوادي الجامعات، وندوات بالعربية والإسبانية.

• الحلقة المرجعية: قوالب مجانية كـ lead magnets، برنامج إحالة، وخرائط طريق تصويت عام.

6) المخاطر (قانونية وتقنية)

قانونية

• سياسات Meta/WhatsApp: الاعتماد على Cloud API الرسمي فقط، والموافقة المسبقة، واعتماد القوالب، واحترام حدود الإرسال. أي جسر غير رسمي يحمل خطر الحظر ويجب عزله وتوضيحه.

• الخصوصية: اتفاقيات معالجة بيانات، تشفير أثناء النقل والتخزين، إقامة بيانات حسب المنطقة، وإدارة المزوّدين الفرعيين. عدم استخدام بيانات العملاء لتدريب النماذج.

• مسؤولية مخرجات AI: تحويل بشري للعمليات الحساسة، سياسة استخدام محظور، فلاتر محتوى، وسجلات قابلة للمراجعة.

• الترخيص والملكية الفكرية: توافق AGPL مع الترخيص التجاري، اتفاقية مساهمين، وفحص العلامة التجارية قبل الإطلاق.

• مكافحة الرسائل المزعجة: تحقق من الموافقات، حدود إرسال، وسياسة إيقاف فورية.

تقنية

• عزل المستأجرين: عزل منطقي صارم، مفاتيح تشفير منفصلة، واختبارات تسرب بيانات.

• تكلفة وزمن استجابة LLM: تجريد مزوّد النموذج، تخزين مؤقت، نماذج احتياطية، وحدود استخدام لكل مستأجر.

• أعطال واتساب وتغيّر واجهاته: طبقة تكامل مرنة، إعادة محاولة، ومراقبة جودة الرقم.

• أمان الوكلاء: منع حقن الأوامر، تقييد الأدوات، حماية Webhooks من SSRF، وإدارة أسرار مركزية.

• النشر والترقيات: نسخ احتياطي آلي، تراجع عن الإصدارات، واختبارات ترحيل قواعد البيانات.

• الهجرة من المنافسين: أدوات استيراد، تنظيف بيانات، وتوثيق واضح لتقليل مقاومة الانتقال.
