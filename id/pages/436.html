Nabd — Rencana Proyek Lengkap

Tulis sekali, ingat selamanya.

Rencana pelaksanaan lengkap untuk proyek digital baru: ide, audiens, produk, model bisnis, rencana penyebaran, dan risiko. Proyek ini masih dalam pengembangan dan belum diluncurkan.

Rencana produk: kartu belajar di dalam ruang penulisan

1) Target Audiens

• Pelajar dan mahasiswa yang belajar bahasa atau mempersiapkan sertifikasi (IELTS, ACCA, Kedokteran, dll.) yang menulis catatan dalam format Markdown.

• Peneliti dan profesional yang menyusun pengetahuan referensi besar dan ingin mengaksesnya secara berkala.

• Pengguna aplikasi organisasi pribadi (Obsidian, Logseq, Notion) yang mencari metode pengulangan berjarak tanpa salin-tempel manual.

• Pendidik dan pembuat konten edukatif yang membuat latihan untuk audiens mereka.

2) Keunggulan (Mengapa Memilih Produk Ini)

• Dari catatan ke kartu secara otomatis: menangkap pertanyaan langsung dari file Markdown (daftar, tabel, teks tertentu) tanpa konversi manual.

• Mesin pengulangan berjarak modern (FSRS) alih-alih tabel matematika lama, dengan penyesuaian waktu untuk setiap pengguna.

• Local-first dengan sinkronisasi opsional: file tetap berupa Markdown murni di perangkat Anda; tidak ada penguncian data.

• Pembuatan kartu dengan AI opsional dari teks panjang, dengan tinjauan manusia sebelum disimpan.

• Pengalaman web + desktop ringan yang dapat bekerja offline, alih-alih bergantung pada host eksternal.

• Gratis untuk memulai tanpa batas untuk kartu dasar, dan hanya membayar untuk layanan cloud tingkat lanjut.

3) Lingkup Versi Pertama (Maksimal 8 Tugas)

1. Impor file Markdown tunggal dan folder, serta mengenali format pertanyaan umum.

2. Editor kartu cepat (pertanyaan/jawaban, kartu daftar, kartu benar/salah).

3. Mesin penjadwalan FSRS dengan statistik retensi sederhana.

4. Tampilan ulasan harian: satu kartu per layar, pintasan keyboard.

5. Penyimpanan lokal penuh + ekspor/impor JSON dan CSV.

6. Sinkronisasi opsional melalui akun gratis (enkripsi saat transit dan saat disimpan).

7. Pembuatan kartu awal dari teks yang ditempel (diaktifkan secara manual).

8. Satu aplikasi desktop (Electron/Tauri) + versi web hanya-baca.

4) Harga dan Model Bisnis

• Gratis: kartu tanpa batas secara lokal, penjadwalan penuh, ekspor kapan saja.

• Plus — $5/bulan: sinkronisasi multi-perangkat, cadangan cloud, statistik lanjutan.

• Pro — $9/bulan: pembuatan kartu dengan AI (dengan batas penggunaan wajar), templat akademik, laporan performa.

• Paket institusi/pendidikan: dasbor untuk guru dan sekolah kecil dengan harga per kursi.

• Pendapatan awal berasal dari langganan, dan akan berkembang dengan templat berbayar untuk pembuat konten.

5) Rencana Penyebaran Global Melalui Saluran Gratis

• GitHub sumber terbuka untuk inti (lisensi MIT) untuk membangun kepercayaan dan menarik kontributor.

• SEO dan konten panjang: perbandingan alat pengulangan berjarak, panduan Markdown.

• YouTube/TikTok: klip 30 detik yang menunjukkan proses dari catatan ke kartu.

• Reddit dan Discord: berbagi di komunitas belajar bahasa, pembelajaran, dan organisasi pribadi.

• Product Hunt dan Hacker News saat peluncuran dengan halaman arahan dua bahasa.

• Kemitraan dengan pembuat konten edukatif: tautan rujukan dan akun gratis sebagai imbalan ulasan.

• Webinar gratis bersama universitas dan klub belajar.

6) Risiko (Hukum dan Teknis)

• Hukum: memastikan tidak melanggar merek dagang atau model antarmuka; mematuhi lisensi FSRS dan pustaka enkripsi; kebijakan privasi yang jelas (GDPR) untuk data sinkronisasi, serta tidak melatih model AI dengan data pengguna tanpa izin eksplisit.

• Teknis: akurasi pengenalan berbagai format Markdown (mungkin membutuhkan aturan yang dapat diperluas); sinkronisasi bersamaan tanpa konflik salinan; performa di perangkat rendah; ketergantungan opsional pada API AI yang dapat berubah harganya — harus dapat dinonaktifkan.

• Operasional: persaingan dengan alat gratis yang sudah mapan; solusi: fokus pada alur "catatan → kartu" dengan upaya minimal.
