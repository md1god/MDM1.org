KhaytGrid — Rencana Proyek Lengkap

Kami menenun data energi publik menjadi satu kain siap dianalisis dan diverifikasi.

Rencana lengkap proyek digital baru: ide, audiens, produk, pendapatan, peluncuran, risiko; masih dibangun, belum diluncurkan.

1) Audiens

• Peneliti energi, iklim, ekonomi: data tertaut, terbanding, terkutip.

• Jurnalis investigatif: angka tepercaya cepat, terlacak ke sumber.

• Pembuat kebijakan/regulator: bandingkan utilitas, pasar, harga.

• Nirlaba, think tank, mahasiswa: alternatif gratis atas database komersial mahal.

• Analis investasi/perencana utilitas: API dan keluaran bersih untuk alatnya.

• Masalah: data publik tersebar di ribuan file/PDF/web, nama/ID/format bertentangan; pembersihan, penautan, verifikasi lebih lambat daripada analisis.

2) Keunggulan

• Sumber setiap angka: file sumber, tanggal ambil, kepercayaan, transformasi nilai.

• Pengenal terpadu fasilitas, utilitas, pembangkit lintas sumber; tinjauan kasus ambigu.

• Siap analisis: Parquet/CSV, SQL, API, notebook Python tanpa pembersihan awal.

• Ekstraksi PDF hibrida: aturan deterministik + model bahasa + tinjauan manusia, bukan otomatisasi tak andal.

• Snapshot historis dapat direproduksi: tiap versi punya sidik jari dan nomor versi.

• Gratis mulai, tanpa penguncian: skema/konektor terbuka, data inti gratis; bayar untuk skala/kenyamanan, bukan akses.

• Kode asli, identitas baru: dari nol tanpa salin kode, tampilan, dokumentasi produk ada.

3) Cakupan versi pertama (maks. 8 tugas)

1. Canonical Schema terbuka: fasilitas, pembangkit, utilitas, bahan bakar, kapasitas, produksi, emisi, harga.

2. Konektor EIA-860/923, FERC Form 1, penautan 3 pasar ISO; pembaruan bulanan.

3. Pipeline ekstraksi tabel PDF: validasi, skor kepercayaan, tinjauan manusia.

4. Entity Resolution, pengenal stabil tiap fasilitas/utilitas/pembangkit.

5. Snapshot bertanda tangan (Snapshots): pelacakan penuh tiap bidang/transformasi.

6. Web pencarian/eksplorasi, REST API, SQL endpoint, klien Python, ekspor Parquet/CSV.

7. Dasbor kualitas data dan peringatan otomatis atas perubahan sumber, penyimpangan skema, anomali.

8. Galeri notebook Jupyter, templat analisis jurnalisme, riset, kebijakan.

4) Harga dan model keuntungan

· Paket · Harga · Isi utama ·

· Free · 0 dolar · Data inti, pembaruan bulanan, 10 ribu permintaan API/bulan, ekspor 100MB, notebook dan sumber daya komunitas ·

· Pro · 29 dolar/bulan · Pembaruan harian, 1 juta permintaan API, ekspor 10GB, peringatan, kueri tersimpan, ruang kerja pribadi ·

· Team · 149 dolar/bulan · 10 kursi, SSO, proyek bersama, log audit, 5 juta permintaan API ·

· Enterprise · mulai 12.000 dolar/tahun · Konektor khusus, privat atau on-prem, SLA, pelatihan dan dukungan prioritas ·

Pendapatan lain: riset/analisis khusus, sponsorship data, hibah, kemitraan institusi. Data inti gratis; data pribadi tak dijual.

5) Peluncuran global via kanal gratis

• Tahap 1 (0–6 bulan): AS, Kanada; optimasi pencarian halaman utilitas/fasilitas/laporan harga.

• Tahap 2 (6–18 bulan): Inggris, Uni Eropa, Australia via "paket yurisdiksi" dan skema dapat diperluas.

• Tahap 3 (18 bulan+): Amerika Latin, Asia, Afrika via mitra lokal, dokumentasi terjemahan.

Kanal gratis:

• GitHub terbuka: skema, konektor, dokumentasi, lisensi jelas.

• Data di Hugging Face, Kaggle, Zenodo dengan DOI dapat dikutip.

• Konten edukatif/SEO: panduan, contoh analisis, perbandingan utilitas-harga.

• Kemitraan universitas, sekolah jurnalisme, pusat data nirlaba; workshop gratis.

• Discord, tanya jawab bulanan, duta mahasiswa/peneliti.

• PyData, NICAR, Open Data Day, hackathon energi.

• YouTube, buletin email, terjemahan Arab/Spanyol/Prancis/Portugis.

6) Risiko (hukum dan teknis)

Hukum:

• Patuhi ketentuan sumber, robots.txt, batas laju; pakai API resmi/unduhan agregat.

• Tinjau lisensi tiap sumber; sajikan fakta dengan tautan sumber, bukan salinan dokumen berhak cipta.

• Privasi sesuai GDPR/CCPA; minimalkan data pribadi, jangan dijual.

• Penafian, kebijakan koreksi, log perubahan terbit.

• Cek merek/nama sebelum peluncuran.

Teknis:

• Ekstraksi PDF, halusinasi model bahasa: validasi, skor kepercayaan, tinjauan manusia, uji regresi.

• Perubahan skema sumber: pemantauan otomatis, versi independen tiap konektor.

• Entitas salah gabung: ambang konservatif, antrean tinjauan, rollback.

• Skala/biaya data: penyimpanan kolumnar, pembaruan inkremental, cache.

• Penyalahgunaan API: kunci, kuota, batas laju.

• Reproduksibilitas hilang: snapshot tak berubah, sidik jari verifikasi, cadangan.
