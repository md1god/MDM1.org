MetaLens — Rencana Proyek Lengkap

Baca semua yang disembunyikan foto dan videomu tanpa file keluar dari perangkatmu.

Rencana eksekusi lengkap untuk proyek digital baru: ide, audiens, produk, model pendapatan, rencana peluncuran, dan risiko. Proyek sedang dibangun dan belum diluncurkan.

Rencana produk: Platform ekstraksi dan pemeriksaan data metadata

1) Audiens target

• Investigator digital dan analis forensik digital yang perlu membaca data Exif/IPTC/XMP tanpa mengubah file asli.

• Fotografer dan editor video yang ingin memverifikasi data kamera, lensa, tanggal, dan hak cipta.

• Jurnalis dan pemeriksa fakta untuk mendeteksi foto palsu atau digunakan ulang melalui perbedaan waktu pengambilan.

• Pengembang aplikasi yang mencari API untuk mengekstrak data metadata secara otomatis.

• Petugas kepatuhan dan privasi untuk membersihkan file karyawan sebelum dipublikasikan.

2) Diferensiasi (mengapa memilih produk kami)

• Berjalan sepenuhnya di dalam browser (client-side) tanpa mengunggah file, menarik bagi audiens yang sensitif terhadap privasi, berbeda dari solusi yang mengharuskan pustaka atau unggahan.

• Antarmuka visual sederhana yang menampilkan data dalam kelompok mudah dipahami (kamera, lokasi GPS, stempel waktu, hak) alih-alih daftar field mentah.

• Deteksi kontradiksi otomatis: membandingkan tanggal file, sistem, dan Exif, serta menandai indikasi manipulasi.

• Dukungan format luas (gambar, video, audio) dan ekspor terformat ke JSON/CSV.

• API gratis dengan batas rendah yang mempermudah adopsi cepat di kalangan pengembang.

• Multi bahasa dengan dukungan penuh bahasa Arab dan Inggris sejak versi pertama.

3) Cakupan versi pertama (maksimal 8 tugas)

1. Ekstraksi Exif dan GPS dari format gambar umum (JPEG, PNG, WebP, HEIC).

2. Ekstraksi data dasar video dan audio (durasi, codec, tanggal pembuatan).

3. Panel tampilan terkelompok dengan tampilan peta untuk lokasi GPS jika ada.

4. Pemeriksaan kontradiksi dan penampilan "tingkat kepercayaan" file.

5. Ekspor hasil ke JSON dan CSV dengan penghapusan selektif.

6. Alat pembersihan (strip) untuk menghapus metadata dan mengunduh ulang file bersih.

7. Satu API RESTful untuk ekstraksi dengan kunci gratis.

8. Dukungan antarmuka bahasa Arab dan Inggris dengan penyimpanan preferensi lokal.

4) Harga dan model pendapatan

• Gratis (free-to-start): ekstraksi tanpa batas di browser + 200 permintaan API per bulan + fitur dasar.

• Pro: langganan bulanan rendah yang memberi ekstraksi batch, batas API lebih tinggi, arsip hasil, dan laporan PDF.

• Tim: kursi multi, integrasi langsung, dan dukungan khusus dengan perjanjian tingkat layanan (SLA).

• Pendapatan tambahan: paket "pembersihan berbayar" dan widget tertanam (white-label) untuk lembaga berita.

5) Rencana peluncuran global lewat kanal gratis

• Rilis alat di Product Hunt dan Hacker News dengan kisah "privasi lebih dulu, tanpa unggah file".

• Artikel teknis di dev.to dan Medium serta skrip open source inti di GitHub untuk menarik pengembang.

• Video pendek di YouTube Shorts dan TikTok yang menunjukkan deteksi manipulasi pada satu gambar.

• Menjawab pertanyaan di Stack Overflow dan Reddit (r/photography, r/forensics) serta menautkan alat saat relevan.

• Kemitraan gratis dengan platform pemeriksaan berita dan workshop jurnalis investigatif.

• SEO di sekitar kata kunci seperti "deteksi data gambar" dan "Exif viewer without upload".

6) Risiko (hukum dan teknis)

• Hukum: privasi lokasi GPS dan data identitas personal (GDPR dan CCPA) — solusi: pemrosesan sepenuhnya lokal dan tidak menyimpan file apa pun.

• Hukum: penyalahgunaan alat pembersihan untuk menyembunyikan bukti — solusi: syarat penggunaan jelas dan tanda air opsional khusus log.

• Teknis: banyaknya format file dan perubahan standar — solusi: arsitektur plugin yang dapat diperluas.

• Teknis: akurasi deteksi manipulasi terbatas dan bisa menimbulkan positif palsu — solusi: hasil ditampilkan sebagai indikasi, bukan vonis mutlak.

• Teknis: performa file besar di browser — solusi: pemrosesan streaming dan pemuatan bertahap.
