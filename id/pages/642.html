قِمم — Rencana Proyek Lengkap

Platform SEO terbuka yang bekerja dengan agen AI dan memberi visibilitas penuh situs Anda di pencarian dan AI, mulai gratis.

Rencana eksekusi proyek digital baru: ide, audiens, produk, pendapatan, penyebaran, risiko. Sedang dibangun.

1) Audiens

• Dev/tim engineering: audit SEO ke CI/CD tanpa alat berat.

• Agensi kecil/freelancer: banyak alat mahal, butuh laporan yang bisa dijual ulang.

• Startup/tim konten/growth: riset kata kunci, analisis kompetitor, pemantauan visibilitas AI, anggaran terbatas.

• Pemilik situs/blog/toko kecil: tidak mampu harga enterprise.

• Pengguna agen coding (Cursor, Claude Code, VS Code+MCP): analisis SEO dari IDE.

• Arab-first: pasar kurang terlayani, skalabilitas global.

2) Keunggulan

• Agent-first & MCP-native: tiap fungsi jadi alat standar agen; CLI, API, JSON Schema.

• Local-first & Self-host: inti jalan lokal/server pengguna; BYO keys.

• Visibilitas terpadu: kata kunci, backlink, audit teknis, peringkat, kompetitor.

• Pemantauan visibilitas AI: penyebutan merek & kutipan di ChatGPT, Gemini, Perplexity, Copilot.

• Transparansi terverifikasi: metodologi terbuka, skor kepercayaan, laporan dapat diulang.

• Biaya mulai nol: self-host & cloud gratis, lalu langganan rendah.

• Privasi & kepatuhan: tidak jual data pengguna; opsi residensi regional & penghapusan penuh.

• Identitas/desain berbeda: UI Arab-pertama (RTL), ringan/cepat, mode terminal (TUI).

• Integrasi praktis: GitHub Actions, WordPress, Next.js, Shopify, Ghost, Webhooks.

3) Ruang lingkup v1

1. Crawler & audit teknis: ≤10k hal, tautan rusak, title, desc, canonical, hreflang, sitemap, robots.txt; ekspor CSV/JSON.

2. Penemuan & clustering kata kunci: seed + saran + data publik + SERP opsional; clustering intent/bahasa (Arab/Inggris).

3. Pelacakan peringkat: harian/mingguan, desktop/mobile, geo, riwayat, alert perubahan.

4. Penjelajah backlink: Common Crawl + crawl pengguna + provider opsional; referring domain, anchor, skor risiko, ekspor Disavow.

5. Analisis kesenjangan kompetitif: bandingkan 2+ domain, gap konten, overlap kata kunci, share of voice.

6. Pemantauan visibilitas AI: set pertanyaan, deteksi mention, citation, sumber; sentimen & laporan berkala.

7. MCP Server + CLI: alat terpadu semua modul, auth lokal, contoh siap agen, dok. schema I/O.

8. Laporan & alert: PDF/CSV terjadwal, Email/Slack/Webhook, template white-label untuk agensi.

Di luar cakupan awal: indeks web global privat, app mobile, SSO enterprise, jaminan peringkat.

4) Harga & pendapatan

Self-host: Gratis (inti OSS, kunci sendiri, tanpa batas lokal)

Cloud Free: 0$ (1 proj, 1k hal/bln, 20 kata, 50 cek AI)

Starter: 19$/bln (3 proj, 25k hal, 150 kata, 1k cek AI, 1 kursi)

Growth: 49$/bln (10 proj, 100k hal, 750 kata, 5k cek AI, 3 kursi, API)

Agency: 129$/bln (40 proj, 400k hal, 3k kata, 20k cek AI, 10 kursi, White-label)

Enterprise: kustom (self-host, SSO, audit log, support & SLA)

Model pendapatan:

• Langganan bulanan/tahunan.

• Kredit tambahan untuk crawl & cek AI.

• Dukungan enterprise, deployment & onboarding.

• Marketplace add-on/integrasi berbayar nanti.

• Tanpa jual data, iklan, monopoli kunci API.

5) Penyebaran global (kanal gratis)

• GitHub: repo terbuka, README kuat, rilis jelas, Issues pemula, lisensi menarik.

• Registri MCP: daftar di direktori MCP, awesome-mcp-servers, platform discovery.

• Paket instalasi: npm, PyPI, Docker Hub, Homebrew.

• Peluncuran komunitas: Product Hunt, Show HN, Reddit (r/SEO, r/TechSEO, r/webdev, r/mcp), Indie Hackers.

• Konten edukatif: tutorial YouTube, artikel Dev.to/Hashnode, panduan Arab & Inggris.

• SEO praktis: pakai produk untuk situs sendiri, terbitkan analisis SEO publik gratis.

• Integrasi gratis: GitHub Action, plugin WordPress, app Shopify, template Next.js.

• Komunitas: meetup & grup lokal, universitas, hackathon, newsletter.

• Timur Tengah dulu: konten Arab asli target tim yang diabaikan, lalu global.

• Program referral gratis: reward kredit untuk pengguna & agensi yang bawa proyek.

6) Risiko

Hukum:

• Crawling hasil SERP dapat melanggar ToS; solusi: API resmi/kunci pengguna, hormati robots.txt.

• Privasi data & GDPR/CCPA; solusi: DPA, minimisasi, penghapusan segera, opsi residensi regional.

• Lisensi library & Common Crawl; solusi: audit lisensi, dokumentasi sumber, MIT/Apache + DCO.

• Kemiripan nama/merek; solusi: cek merek dagang sebelum launch.

• Syarat provider AI; solusi: tidak menjual ulang output melanggar, atribusi jelas.

• Tanggung jawab rekomendasi; solusi: disclaimer jelas produk alat pengukur, tidak menjamin ranking.

Teknis:

• Rate limit, blokir, CAPTCHA; solusi: provider dapat ditukar, cache, retry cerdas.
