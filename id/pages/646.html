Rafid Edge — Rencana Proyek Lengkap

Hubungkan perangkat industri apa pun ke satu jaringan dalam hitungan menit, tanpa cloud wajib dan tanpa vendor lock-in.

Rencana lengkap proyek digital baru: ide, audiens, produk, model pendapatan, penyebaran, dan risiko. Proyek sedang dibangun dan belum diluncurkan.

1) Audiens sasaran

• Insinyur otomasi/kontrol (OT) di pabrik kecil-menengah.

• Integrator sistem yang menghubungkan peralatan dari vendor/protokol berbeda.

• Operator utilitas: air, listrik, energi terbarukan, gedung otomasi (BACnet/KNX).

• Produsen mesin (OEM) yang butuh gateway komunikasi terpadu.

• Tim IoT/data yang membangun dasbor Grafana atau platform cloud.

• Pasar berkembang, kota, dan proyek industri beranggaran terbatas.

2) Keunggulan

• Gratis nyata: edisi komunitas lokal tanpa cloud wajib/kartu kredit.

• Deteksi otomatis dan penyiapan terpandu: koneksi perangkat dari hari menjadi menit.

• Mesin plugin terisolasi WebAssembly: protokol baru aman, bertanda tangan, pembaruan instan.

• Model data terpadu: Tag bertipe jelas, kualitas baca, stempel waktu, peta siap integrasi.

• GitOps: konfigurasi terlacak, dapat ditinjau/dikembalikan, bukan pengaturan tersembunyi.

• Store-and-forward: data tidak hilang saat jaringan putus, dengan aturan/peringatan lokal.

• Terbuka: SDK terbuka, integrasi MQTT/Sparkplug B, OPC UA, REST, Kafka, InfluxDB/Timescale, tanpa lock-in vendor.

• Ringan/aman: Raspberry Pi dan ARM/x86, mode baca default, pembaruan bertanda tangan.

• Identitas/desain baru: antarmuka industri sederhana, Arab dan Inggris, kode dari nol.

3) Lingkup versi pertama (maks. 8 tugas)

1. Inti runtime Rust dengan pemuat YAML dan CLI.

2. SDK plugin WebAssembly dengan isolasi, izin, tanda tangan.

3. Empat protokol: Modbus TCP/RTU, Siemens S7, OPC UA Client, EtherNet/IP.

4. Deteksi otomatis awal perangkat dan impor tag.

5. Model data terpadu dengan Store-and-Forward.

6. Northbound: MQTT/Sparkplug B, server OPC UA, REST.

7. Web: wizard koneksi, penjelajah tag langsung, kesehatan koneksi, peringatan.

8. Deployment: Docker, ARM/x86, penginstal satu perintah, dokumentasi, simulator perangkat.

4) Harga dan model pendapatan

• Community: gratis selamanya, self-hosted, satu situs, 25 perangkat/10.000 tag, dukungan komunitas.

• Growth: 79 dolar/situs/bulan, 100 perangkat, cadangan konfigurasi, dukungan email.

• Business: 299 dolar/situs/bulan, perangkat/tag tak terbatas, HA, SSO/RBAC, audit, dukungan 24/7 dan SLA.

• Enterprise: harga khusus: manajemen armada, protokol khusus, audit keamanan, pelatihan.

• Cloud: tier gratis dengan simulator dan dua perangkat nyata, lalu harga konsumsi.

• Toko plugin: paket perangkat bersertifikat, komisi 20%, layanan integrasi/pelatihan.

• Tanpa langganan wajib atau harga per pengguna di edisi komunitas.

5) Penyebaran global lewat kanal gratis

• Inti open source di GitHub, dokumentasi unggul, SEO untuk “Modbus to MQTT” dan “S7 to OPC UA”.

• Image siap pakai di Docker Hub dan GitHub Container Registry, add-on Home Assistant, node Node-RED.

• YouTube: tutorial perangkat nyata, siaran langsung, lab simulasi gratis.

• Komunitas OT/IoT: Reddit, LinkedIn, Discord, Hacker News, grup insinyur otomasi.

• Kemitraan integrasi gratis dengan Grafana, InfluxDB, Timescale, Node-RED.

• Sertifikasi gratis untuk integrator sistem, komisi rujukan untuk kesepakatan berbayar.

• Terjemahan antarmuka/dokumentasi ke Arab, Inggris, Spanyol, Jerman, Portugis, Mandarin.

• Inisiatif universitas, hackathon, proyek akhir dengan simulator gratis.

6) Risiko (hukum dan teknis)

Hukum:

• Nama protokol/merek dagang hanya deskriptif, tanpa logo atau kesan dukungan resmi.

• Pencarian merek dagang nama baru sebelum peluncuran.

• Implementasi protokol clean room tanpa menyalin kode/dokumen terlindungi.

• Patuhi lisensi, terbitkan SBOM, tinjau paten dan kontrol ekspor.

• Penafian jelas untuk sistem kritis/keselamatan, klausul kontrak pembatas tanggung jawab.

• Patuhi GDPR dan kedaulatan data, terutama deployment cloud.

Teknis:

• Banyak versi perangkat dan perilaku protokol aneh; perlu lab uji dan matriks kompatibilitas.

• Keamanan OT: segmentasi jaringan, mode baca default, mTLS, manajemen rahasia, plugin bertanda tangan.

• Keterbatasan resource edge, latensi, keandalan saat jaringan putus.

• Kompleksitas upgrade, rollback, ketersediaan tinggi.

• Keamanan rantai pasok: tanda tangan rilis, pemindaian kerentanan, tinjauan dependensi.

• Beban dukungan/dokumentasi kasus khusus; hindari janji waktu tak realistis.

7) Nama dan slogan

Nama: Rafid Edge

Slogan: Hubungkan perangkat industri apa pun ke satu jaringan dalam hitungan menit, tanpa cloud wajib dan tanpa lock-in vendor.
