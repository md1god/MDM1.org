AnimaForge — Rencana Proyek Lengkap

Dari ide menjadi gerakan: gambar, animasikan, dan ekspor game-mu langsung di browser.

Rencana implementasi lengkap untuk proyek digital baru: ide, audiens, produk, model pendapatan, rencana penyebaran, dan risiko. Proyek sedang dibangun dan belum diluncurkan.

Rencana produk orisinal: editor animasi untuk piksel dan sprite

1) Audiens Sasaran

• Pengembang game independen (Indie) dan pembuat game 2D solo.

• Seniman piksel (Pixel Artists) dan penggambar di sistem lama (Retro).

• Pelajar dan guru desain serta animasi di sekolah dan universitas.

• Kreator konten di media sosial yang membutuhkan animasi kecil (stiker, Emoji, Stickers).

2) Poin Unggulan (Mengapa Memilih Produk Kami)

• Berjalan di browser terlebih dahulu (Web-first) tanpa instalasi apa pun, dengan dukungan kerja offline melalui PWA, dan versi desktop nanti.

• Kolaborasi real-time pada file yang sama dengan catatan perubahan dan versi (Versioning).

• Ekspor terbuka: PNG Sprite Sheet, GIF, WebP animasi, JSON yang kompatibel dengan mesin game populer.

• Asisten cerdas opsional (pengisian frame otomatis / pembuatan warna dan bayangan) yang dibangun berdasarkan aturan, bukan menyalin karya orang lain.

• Ringan dan cepat bahkan di perangkat lemah, dengan dukungan penuh untuk bahasa Arab dan penulisan dari kanan ke kiri.

• Arsitektur plugin (Plugin API) terbuka untuk membangun alat dari komunitas.

3) Cakupan Versi Pertama (maksimal 8 tugas)

1. Editor piksel dasar: layer, sembunyikan/tampilkan, pindahkan, dan alat gambar/hapus/isi.

2. Sistem frame (Frames) dan timeline sederhana untuk membangun gerakan.

3. Menjalankan pratinjau animasi (Play/Stop) dan mengontrol kecepatan frame (FPS).

4. Palet warna (Palettes) yang dapat disimpan dan diimpor/diekspor.

5. Ekspor gambar: PNG, Sprite Sheet, GIF, WebP.

6. Menyimpan proyek di cloud + bekerja offline (PWA).

7. Berbagi file proyek melalui tautan lihat/edit.

8. Antarmuka Arab/Inggris (i18n) dan desain responsif untuk ponsel.

4) Penetapan Harga dan Model Keuntungan

• Gratis untuk memulai: editor lengkap, ekspor PNG, proyek tanpa batas secara lokal.

• Paket Pro (bulanan/tahunan): kolaborasi real-time, versi (Versioning), ekspor Sprite Sheet/GIF, penyimpanan cloud lebih besar, tanpa tanda air.

• Paket Studio (tim): beberapa kursi, izin, pustaka aset bersama.

• Pendapatan tambahan: toko plugin berbayar (70% untuk pengembang), dan lisensi pendidikan untuk sekolah.

5) Rencana Penyebaran Global dengan Kanal Gratis

• Inti open source di GitHub untuk menarik kontributor dan membangun kepercayaan.

• Postingan di Reddit (r/gamedev, r/PixelArt) dan platform seperti itch.io dan Hacker News.

• Konten edukasi di YouTube/TikTok: tutorial "dari ide menjadi sprite".

• Kolaborasi dengan komunitas Godot dan Unity melalui templat ekspor siap pakai.

• Program duta universitas dan beasiswa untuk pelajar.

• SEO melalui blog teknis dan panduan pengguna dalam bahasa Arab dan Inggris.

6) Risiko (Hukum dan Teknis)

• Hukum: kami menulis semua kode dan aset dari awal, dan menghindari nama/logo/kode yang mirip; kami meninjau lisensi pustaka yang disertakan dan mendokumentasikannya.

• Teknis: kinerja potongan besar di web (kami menanganinya dengan Canvas/WebGL dan penyimpanan lokal), perbedaan format browser, dan biaya cloud (kami mulai dengan batas ketat dan rencana penyimpanan bertahap).

• Keamanan komunitas: meninjau plugin untuk mencegah perangkat lunak berbahaya.

7) Nama yang Diusulkan dan Slogan Pemasaran

Nama yang diusulkan: AnimaForge

Slogan pemasaran: Dari ide menjadi gerakan: gambar, animasikan, dan ekspor game-mu langsung di browser.
