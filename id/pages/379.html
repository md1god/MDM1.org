Mishkat — Rencana Proyek Lengkap

Foto dimengerti, tidak diunggah — memori di server Anda sendiri.

Rencana implementasi lengkap untuk proyek digital baru: ide, audiens, produk, model pendapatan, rencana peluncuran, dan risiko. Proyek sedang dibangun dan belum diluncurkan.

Rencana produk: pengelolaan foto rumah dengan kecerdasan buatan

1) Audiens target

• Pemilik koleksi foto besar (puluhan ribu) yang menolak mengunggahnya ke layanan cloud.

• Keluarga dan pengguna aktif fotografi ponsel yang membutuhan pencarian cepat (wajah, tempat, objek, warna).

• Pemilik server rumahan dan penggemar perangkat kecil (seperti Raspberry Pi) serta privasi.

• Fotografer hobi dan pengguna di negara yang memberlakukan pembatasan ekspor data ke luar negeri.

2) Keunggulan (mengapa memilih produk kami)

• Berfungsi sepenuhnya tanpa internet setelah instalasi, foto tidak pernah meninggalkan perangkat Anda.

• Pencarian bahasa alami dalam bahasa Arab dan Inggris seperti: «foto anak-anak di pantai pada malam hari».

• Operasi ringan: model ML miniatur berjalan pada CPU tanpa kartu grafis, dan berfungsi pada perangkat kecil.

• Pengelompokan otomatis cerdas: album «perjalanan», «acara», «wajah serupa» tanpa pengaturan manual.

• Sinkronisasi opsional terenkripsi antar perangkat, dengan salinan asli tetap di server rumah.

• Desain sederhana dan cepat: satu garis waktu, pencarian instan, tanpa iklan dan pelacakan.

3) Cakupan versi pertama (maksimal 8 tugas)

1. Server web sederhana untuk instalasi mandiri (Docker) dengan antarmuka Arab/Inggris.

2. Impor foto dan video dari folder serta perangkat (unggahan opsional terenkripsi).

3. Garis waktu otomatis berdasarkan tanggal dan tempat (dari data EXIF).

4. Pencarian objek, warna, dan waktu menggunakan model kecil lokal.

5. Pengenalan wajah lokal dengan pengelompokan orang otomatis (dengan persetujuan pengguna).

6. Album cerdas otomatis dan pengelompokan visual serupa.

7. Berbagi tautan sementara untuk satu album tanpa membuka seluruh pustaka.

8. Pencadangan dan sinkronisasi dasar antara dua perangkat melalui internet terenkripsi.

4) Harga dan model pendapatan

• Gratis untuk memulai: versi pribadi lengkap untuk penggunaan rumah pada satu perangkat.

• Berbayar opsional: lisensi tahunan untuk fitur lanjutan (pemutaran video, peningkatan pencarian, dukungan prioritas, lisensi komersial kecil).

• Layanan bantuan: paket instalasi siap pakai pada perangkat miniatur, dan konsultasi pengaturan untuk keluarga atau kantor kecil.

• Tanpa iklan dan tanpa penjualan data sama sekali — privasi adalah produknya sendiri.

5) Rencana peluncuran global dengan kanal gratis

• Artikel dan video pendek tentang «cara melindungi foto keluarga di server rumah» di YouTube, TikTok, dan X.

• Berbagi di komunitas privasi dan Self-hosting (forum serta grup Reddit dan Mastodon).

• Uji coba dan lomba «pengaturan pustaka foto terbaik» di media sosial.

• Dokumentasi terbuka dan terjemahan antarmuka untuk pengguna di Timur Tengah, Eropa, dan Amerika Latin.

• Kemitraan dengan kreator teknis Arab dan asing yang fokus pada privasi dan fotografi.

6) Risiko (hukum dan teknis)

• Hukum: regulasi perlindungan data (GDPR dan lainnya) memperketat pengenalan wajah — harus diaktifkan secara manual dan dijelaskan dengan jelas, serta dilarang digunakan tanpa persetujuan.

• Hak privasi saat memotret orang dan membuat album untuk mereka; serta perlunya dokumentasi lisensi open source secara akurat.

• Teknis: konsumsi CPU dan memori untuk ML pada perangkat kecil; kesalahan pencarian melemahkan kepercayaan.

• Kapasitas penyimpanan dan kecepatan pengindeksan dengan pustaka raksasa, serta kompleksitas sinkronisasi melalui jaringan tidak stabil.

7) Nama usulan dan slogan pemasaran

Nama usulan: Mishkat (مشكاة)

Slogan pemasaran: Foto dimengerti, tidak diunggah — memori di server Anda sendiri.
