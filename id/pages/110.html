قرطاس — Rencana Proyek Lengkap

Catatan dan tugas Anda dalam file terbuka milik Anda sendiri, tanpa langganan wajib dan tanpa kunci.

Rencana implementasi lengkap untuk proyek digital baru: ide, audiens, produk, model pendapatan, rencana penyebaran, dan risiko. Proyek masih dalam pembangunan dan belum diluncurkan.

Rencana produk orisinal untuk memecahkan masalah pencatatan dan pengelolaan tugas secara lokal

1) Audiens Target

• Individu yang peduli privasi dan menolak mengunggah catatan mereka ke cloud yang bersifat wajib.

• Penulis, peneliti, dan pelajar yang bekerja dengan format Markdown dan membutuhkan kepemilikan penuh atas file mereka.

• Pengguna todo.txt dan pecinta file teks sederhana yang dapat disalin dan dikendalikan.

• Pengembang dan penggemar self-hosting yang menginginkan sinkronisasi opsional terenkripsi.

• Pengguna yang lelah dengan langganan aplikasi catatan dan mencari alternatif gratis untuk memulai.

2) Keunggulan (mengapa memilih produk kami)

• Local-first: semuanya disimpan sebagai file teks biasa yang dimiliki pengguna, tanpa mengunci data.

• Multi-platform: aplikasi Android + versi web (PWA) + aplikasi desktop, dengan satu editor dan pengalaman yang seragam.

• Sinkronisasi opsional terenkripsi end-to-end, dengan server mandiri gratis bagi yang menginginkan.

• Tugas bawaan yang kuat: tanggal jatuh tempo, pengulangan, pengingat, dan tag — bekerja di atas todo.txt dengan antarmuka modern.

• Editor Markdown unggul: pratinjau langsung, tabel, persamaan matematika via KaTeX, dan dukungan penuh RTL/LTR.

• Pencarian instan lokal via indeks ringan yang bekerja offline dan cepat di perangkat lemah.

• Gratis untuk memulai tanpa iklan dan tanpa akun wajib, dengan transparansi penuh pada kode.

3) Cakupan versi pertama (maksimal 8 tugas)

1. Editor Markdown dengan pratinjau langsung, penyorotan sintaks, dan perintah cepat.

2. Penyimpanan lokal dalam format file teks di folder yang dipilih pengguna, dengan buka/simpan via SAF.

3. Pengelolaan tugas dari todo.txt dengan antarmuka tanggal jatuh tempo, tag, dan pengulangan.

4. Pencarian instan di semua file via indeks lokal.

5. Kunci biometrik dan enkripsi opsional untuk file sensitif.

6. Ekspor/impor dan cadangan lokal dalam format ZIP.

7. Kustomisasi antarmuka: mode gelap, font, ukuran teks, arah teks.

8. Berbagi file dengan aplikasi lain dan pintasan di layar utama.

4) Harga dan model keuntungan

• Tingkat gratis (Free-to-start): semua fungsi dasar terbuka, tanpa iklan dan tanpa akun.

• Paket Pro opsional (langganan tahunan atau pembelian sekali): sinkronisasi terenkripsi, ekspor PDF, tema lanjutan, riwayat versi file.

• Server mandiri gratis (Self-host): bagi yang menginginkan sinkronisasi penuh tanpa bayar, yang membangun kepercayaan dan penyebaran.

• Donasi dan sponsor: melalui platform dukungan terbuka, serta saluran B2B untuk lisensi dan dukungan perusahaan.

• Prinsip: tidak memblokir data, dan tidak membayar untuk mengakses file pengguna.

5) Rencana penyebaran global melalui saluran gratis

• Menerbitkan kode di GitHub dan F-Droid untuk membangun kepercayaan pengguna yang peduli privasi.

• Menghosting versi web sebagai PWA secara gratis di Cloudflare Pages.

• Peluncuran di Show HN, Product Hunt, dan Reddit (r/androidapps, r/selfhosted, r/plaintext, r/todotxt).

• Konten edukatif gratis di YouTube dan menulis artikel teknis tentang local-first dan todo.txt.

• Terjemahan kolaboratif via Crowdin untuk membuka pasar baru dengan biaya minimal.

• Membangun komunitas terbuka untuk kontribusi dan ekstensi guna mempercepat pertumbuhan.

6) Risiko (hukum dan teknis)

Hukum:

• Risiko kontaminasi lisensi atau menyalin kode dari proyek serupa — Solusi: menulis semua kode dari nol dan mendokumentasikan sumber.

• Konflik merek dagang dengan nama serupa — Solusi: memeriksa nama dan merek sebelum peluncuran.

• Kepatuhan terhadap GDPR saat menyediakan sinkronisasi — Solusi: enkripsi end-to-end dan meminimalkan pengumpulan data.

• Lisensi pustaka pihak ketiga seperti KaTeX — Solusi: meninjau lisensi dan menyediakan pemberitahuan yang diperlukan.

Teknis:

• Perbedaan SAF dan versi Android dapat menyebabkan kesalahan akses file — Solusi: pengujian luas dan jalur alternatif.

• Konflik sinkronisasi dan kehilangan data — Solusi: penyelesaian konflik yang jelas dan riwayat versi.

• Performa pada perangkat lemah dan file besar — Solusi: pemuatan parsial dan pengindeksan bertahap.

• Pengingat latar belakang dan konsumsi baterai — Solusi: WorkManager dan optimalisasi penjadwalan.

• Mengelola kunci enkripsi dengan aman — Solusi: mengandalkan keystore sistem dan tidak menyimpan rahasia secara terbuka.
