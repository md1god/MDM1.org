Mizan — rencana proyek lengkap

Mizan membuat agen AI membeli layanan satu sama lain secara otomatis, tanpa kunci API, dengan pembayaran terlindungi dan penilaian terdokumentasi.

Rencana implementasi lengkap untuk proyek digital baru: ide, audiens, produk, model pendapatan, rencana penyebaran, dan risiko. Proyek sedang dibangun dan belum luncur.

1) Audiens target

• Pengembang agen otonom (tim rintisan + independen) yang membutuhkan layanan microservice (pengambilan data, inferensi, validasi, komputasi) tanpa kontrak dan kunci API untuk setiap penyedia.

• Pengembang alat AI dan otomasi yang menjalankan ribuan pemanggilan kecil per bulan dan membutuhkan harga per pemanggilan serta anggaran yang dapat ditentukan.

• Penyedia layanan microservice (independen dan tim kecil) yang ingin menjual layanan mereka secara otomatis tanpa proses penjualan manual.

• Tim data dan riset institusional yang membutuhkan eksekusi yang dapat dibuktikan dan jejak audit untuk setiap operasi.

• Pembangun platform yang menyediakan agen siap pakai (SaaS/B2B) dan ingin memberinya sumber layanan yang tidak terputus.

2) Poin pembeda (mengapa memilih produk kami)

• Penemuan lewat pengujian, bukan deskripsi: setiap penyedia menerbitkan "Kartu Kemampuan" (Capability Card) dalam format JSON + rangkaian uji; agen pembeli menjalankannya secara lokal sehingga memperoleh tingkat keberhasilan terdokumentasi, waktu respons p95, dan harga rata-rata per tugas sebelum membeli.

• Pembayaran terlindungi Atelier dengan hasil: setiap operasi mencadangkan nilai (escrow) dan dicairkan otomatis saat SLA terpenuhi, dengan jendela sengketa 48 jam dan pengembalian otomatis atas pelanggaran — alih-alih "minta lalu bayar".

• Kunci API = nol: identitas agen melalui kunci publik + bukti kepemilikan (Ed25519) + delegasi terbatas (cakupan, plafon belanja, tanggal kedaluwarsa); agen tidak membocorkan rahasia penyedia.

• Penyelesaian multimodal: USDC di L2 + saldo yang dibayar dengan kartu di dalam platform, sehingga pasar menjangkau pengguna non-kripto.

• Inti open source yang dapat di-hosting mandiri: komisi 0% bagi penyedia saat di-hosting sendiri; versi cloud berbayar untuk penemuan, jaminan, dan analitik.

• Simulator biaya sebelum operate: perbandingan biaya yang diharapkan per "hasil sukses" di antara tiga penyedia.

• Identitas visual orisinal: nama, logo, warna, dan nada "buku besar" (timbangan/entri) alih-alih metafora financial-editoria tradisional.

3) Lingkup versi pertama (8 tugas)

1. Registri kemampuan: skema terpadu + REST/Python SDK + pencarian dan penyaringan (jenis layanan, harga, SLA, bahasa).

2. Node open source: gateway lokal yang menerima permintaan pembeli, meneruskannya ke penyedia, dan mencatat biaya serta waktu respons.

3. Dompet credits uji coba + integrasi USDC di Base (testnet dahulu) dengan reserve/release/refund dan jendela sengketa.

4. Delegasi tanpa kunci: challenge-response, penandatanganan, cakupan, plafon belanja, kedaluwarsa, dan pencabutan.

5. Measuring harness: menjalankan rangkaian uji penyedia secara lokal dan menerbitkan "sertifikat pengukuran" (tingkat keberhasilan + p95 + harga) yang diperbarui berkala.

6. CLI untuk agen: search / quote / use / pay / verify / dispute dengan integrasi MCP agar layanan tampil sebagai alat di dalam agen pengguna.

7. Dua dasbor (penyedia/pembeli): pendapatan, pesanan, penyelesaian, pengeluaran, riwayat sengketa.

8. Model penyedia uji coba + 10 penyedia nyata: paket data uji umum (ekstraksi teks, terjemahan, validasi matematis, pengambilan data) untuk mencoba pembelian otomatis sejak awal.

4) Harga dan model pendapatan

• Selalu gratis: inti open source (MIT) dan hosting mandiri = komisi 0% bagi penyedia, tanpa batas jumlah agen.

• Gratis cloud: 1.000 transaksi/bulan, komisi 0%, jaminan USDC 50, log dasar.

• Pro ($29/bulan): komisi 1,5% atas transaksi + dasbor analitik + log verifikasi (receipts) + ruang kerja tim + dukungan.

• Verified Provider ($199/bulan): audit identitas dan perilaku, lencana terdokumentasi, prioritas dalam hasil pencarian.

• Enterprise: biaya kepatuhan, retensi, dan API untuk integrasi (perjanjian tahunan) — tanpa komisi atas transaksi bertanda tangan.

• Tambahan berbayar: template lokakarya desain Economy, dan sertifikat "penyedia terverifikasi" melalui sistem poin.

5) Rencana penyebaran global lewat kanal gratis

• GitHub: quickstart "terbitkan agen Anda dalam 10 menit", halaman profil untuk setiap penyedia (SEO long-tail), dan contrib open.

• MCP: menerbitkan layanan kami sebagai MCP server di komunitas alat (glama, smithery, mcp directories) serta daftar npm/pypi gratis.
