Riwaq — Rencana Proyek Lengkap

Perpustakaan digital — kumpulkan, rapikan, dan baca tanpa koneksi.

Rencana implementasi lengkap untuk proyek digital baru: ide, audiens, produk, model pendapatan, rencana peluncuran, dan risiko. Proyek sedang dibangun dan belum diluncurkan.

Rencana produk: Riwaq

Aplikasi pribadi untuk mengatur dan perpustakaan bacaan manga serta novel digital, mengandalkan file yang diimpor dari perangkat dan sumber legal gratis (domain publik, lisensi Creative Commons, bab resmi gratis melalui OPDS/RSS), dan mengonversinya ke EPUB/CBZ disertai sinkronisasi progres baca.

1) Audiens target

• Pembaca manga dan web novel Arab (terutama usia 18–35) yang mengumpulkan file lokal.

• Pembaca yang tidak selalu terhubung (perjalanan, kuota terbatas).

• Pengumpul perpustakaan digital: menginginkan pengaturan, metadata, dan sampul untuk setiap karya.

• Pengembang dan desainer yang tertarik membaca via OPDS dan sumber terbuka.

2) Poin pembeda (mengapa memilih produk kami)

• Legal sejak desain: tidak ada penyalinan konten berhak cipta — hanya mengandalkan file pengguna + sumber terbuka.

• Mesin metadata otomatis (sampul, judul, penulis, bab) melalui pencocokan lokal serta API Open Library/Gutenberg.

• Pembaca bawaan untuk EPUB dan CBZ/CBR dengan tata letak Arab (RTL) dan daftar bab.

• Konversi massal ke EPUB/ZIP teratur, dengan penghormatan terhadap robots.txt dan batas permintaan.

• Sinkronisasi ringan multi-perangkat (web + desktop) serta alternatif otomatis untuk bekerja tanpa koneksi.

3) Cakupan versi pertama (maksimal 8 tugas)

1) Aplikasi desktop (Tauri) + antarmuka web PWA untuk pengelolaan.

2) Impor file lokal (CBZ/CBR/EPUB/PDF) dengan pemindaian massal.

3) Pencocokan metadata otomatis melalui API Open Library dan Gutenberg.

4) Pembaca CBZ/EPUB dengan RTL, penyimpanan halaman terakhir, mode malam.

5) Pengekspor massal ke EPUB/ZIP teratur dengan nama tunggal.

6) Penemuan sumber terbuka (OPDS/RSS) dengan penelusuran dan unduhan aman.

7) Akun gratis + sinkronisasi progres baca (batas penyimpanan bulanan).

8) Layar penyambutan, kebijakan privasi, dan laporan kesalahan tanpa identitas.

4) Harga dan model pendapatan

• Gratis untuk memulai: perpustakaan lokal tanpa batas, pembaca lengkap, sumber terbuka, sinkronisasi 1 perangkat (100 MB/bulan).

• Pro: $4/bulan atau $39 seumur hidup — sinkronisasi tanpa batas, multi-perangkat, otomasi pemindaian/metadata tingkat lanjut, dan prioritas dukungan.

• Pendapatan tambahan: penjualan tema baca dan templat sampul berbayar, serta kemitraan dengan penerbit bab gratis (komisi rujukan opsional).

5) Rencana peluncuran lewat kanal gratis

• Reddit dan Discord komunitas pembaca serta web novel (menyebar undangan uji coba awal).

• Video pendek (YouTube Shorts/TikTok) yang menjelaskan impor dan konversi dalam 30 detik.

• Product Hunt dan Hacker News (fokus pada aspek legal dan privasi data).

• Blog SEO dua bahasa (Arab/Inggris) tentang perapian perpustakaan dan membaca tanpa koneksi.

• Kanal Telegram untuk perpustakaan digital dan webmaster sumber terbuka.

• Program duta: versi Pro gratis bagi yang membagikan penjelasan bermanfaat.

6) Risiko (hukum dan teknis)

• Hukum: dituduh memfasilitasi bila sumber tak berlisensi diintegrasikan — solusi: kunci sumber ke daftar putih terbuka, peringatan tegas untuk setiap tautan eksternal, dan kebijakan penghapusan DMCA cepat.

• Ketentuan platform: perubahan antarmuka OPDS/RSS — solusi: lapisan adaptif + penggantian sumber + pengguna bertanggung jawab atas file sendiri.

• Teknis: file CBR terkompresi, codec yang didukung sebagian, dan beban server — solusi: batas laju, codec bersama, dan penyimpanan lokal sebagai fondasi.

7) Nama usulan dan slogan

Nama usulan: Riwaq

Slogan: Perpustakaan digital — kumpulkan, rapikan, dan baca tanpa koneksi.
