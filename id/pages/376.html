LensVault — Rencana Proyek Lengkap

Indekskan fotomu di servermu sendiri, temukan foto apa pun dalam kurang dari satu detik.

Rencana pelaksanaan lengkap untuk proyek digital baru: ide, audiens, produk, model pendapatan, rencana peluncuran, dan risiko. Proyek sedang dibangun dan belum diluncurkan.

1) Audiens yang ditargetkan

• Fotografer profesional dan amatir lanjutan yang memiliki arsip mulai dari 50 ribu hingga satu juta foto (pernikahan, perjalanan, studio).

• Studio foto yang membutuhkan pencarian cepat berdasar tag IPTC, nama file, dan nama folder.

• Pengarsip foto, universitas, dan institusi yang mengelola pustaka visual besar secara lokal.

• Siapa pun yang ingin menjalankan arsip di server rumahan (NAS / Raspberry Pi / VPS) tanpa mengunggah foto ke cloud berbayar.

2) Keunggulan

• Indeksasi lokal terlebih dahulu: semua pemrosesan berjalan di perangkat pengguna; foto tidak keluar dari jaringan lokal secara bawaan.

• Pencarian hibrida: menggabungkan IPTC/XMP dengan OCR teks di dalam foto dan penandaan otomatis (tagging) tanpa menghubungkan akun eksternal.

• Antarmuka cepat untuk arsip berukuran sangat besar: pembuatan thumbnail lazy dan indeks parsial pada query, dengan respons di bawah satu detik untuk satu juta item.

• Ringan dijalankan: satu paket dengan .NET atau Docker, berjalan di NAS dan Raspberry Pi tanpa GPU wajib, dengan akselerasi GPU opsional.

• Ekspor dan penggabungan yang aman: menulis tag ke file sidecar atau ke dalam file asli dengan pencadangan otomatis, sehingga data tidak hilang.

• Model data terbuka: versi gratis lengkap untuk penggunaan pribadi, dan file indeks dapat dipindahkan antar perangkat.

3) Cakupan versi pertama (maksimum 8 tugas)

1. Indeksasi folder lokal serta ekstraksi IPTC/XMP dan nama file/folder.

2. Pembuatan thumbnail dan penampil grid cepat dengan pemuatan lazy.

3. Pencarian teks instan (nama file, folder, tag, tanggal, ukuran).

4. Penilaian (scoring) otomatis sederhana untuk foto serupa guna menghapus duplikat.

5. Satu antarmuka web dengan Docker Compose dan panduan pemasangan di NAS.

6. Penulisan tag ke sidecar dengan opsi penulisan ke dalam file, lengkap dengan log perubahan.

7. Server API kecil untuk memungkinkan alat pihak ketiga (GUI desktop menyusul).

8. Pencadangan dan pemulihan basis data indeks, dengan mode yang berfungsi sepenuhnya tanpa internet.

4) Harga dan model pendapatan

• Gratis selamanya: indeksasi dan pencarian untuk penggunaan pribadi hingga 100 ribu foto.

• Pro — 5$ per bulan atau 45$ per tahun: arsip tanpa batas, OCR, deteksi wajah/objek, indeks multi-perangkat.

• Studio — 19$ per bulan: lisensi multi-pengguna, izin akses, pencarian terfokus, dukungan prioritas.

• Pendapatan tambahan: donasi sukarela melalui GitHub Sponsors / Buy Me a Coffee, serta paket aplikasi siap pasang (NAS app) di toko aplikasi.

5) Rencana peluncuran global dengan kanal gratis

1. Repositori publik dengan README berbahasa Inggris yang diterjemahkan ke bahasa Arab, Mandarin, dan Spanyol.

2. Postingan di r/photography, r/selfhosted, dan r/DataHoarder dengan cuplikan performa.

3. Artikel perbandingan teknis di Medium dan dev.to tentang pengarsipan foto berukuran besar.

4. Video pendek di YouTube dan TikTok yang menunjukkan pencarian di satu juta foto.

5. Halaman terjemahan (i18n) dan berkas untuk platform Arab dan Jepang.

6. Newsletter mingguan singkat (gratis) untuk pembaruan rilis.

7. Ikut serta di pameran dan komunitas fotografer serta NAS (Forums, Discord).

8. Permintaan integrasi dengan alat penyuntingan populer untuk usulan gratisan.

6) Risiko (hukum dan teknis)

• Hukum: deteksi wajah dapat melanggar privasi orang di beberapa negara (GDPR di Eropa); harus dibuat opsional dengan pemberitahuan eksplisit dan mode nonaktif bawaan, serta didokumentasikan bahwa pemrosesan berjalan lokal.

• Hukum: penulisan tag ke dalam file dapat menyentuh metadata milik fotografer; pencadangan otomatis diterapkan sebelum penulisan.

• Hukum: hindari lisensi foto contoh yang dimiliki pihak ketiga; gunakan foto sumber terbuka dalam contoh.

• Teknis: konsumsi memori saat mengindeks satu juta foto; diproses dalam batch dan indeks disimpan di SQLite dengan pemecahan indeks.

• Teknis: degradasi basis data atau pemadaman listrik; diterapkan pemulihan atomik dan pemeriksaan integritas saat boot.

• Teknis: perubahan format file RAW kamera; gunakan pustaka stabil (ExifTool/LibRaw) dengan lapisan abstraksi yang dapat diperbarui.

7) Nama yang diusulkan dan slogan pemasaran

Nama yang diusulkan: LensVault

Slogan pemasaran: Indekskan fotomu di servermu sendiri, temukan foto apa pun dalam kurang dari satu detik.
