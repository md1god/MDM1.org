NAQSH — Rencana Proyek Lengkap

Gambar vektor Anda sekali saja, dapatkan file siap cetak, potong, dan bordir, gratis dan open source.

Rencana pelaksanaan lengkap untuk proyek digital baru: ide, audiens, produk, model bisnis, rencana penyebaran, dan risiko. Proyek ini sedang dalam pengembangan dan belum diluncurkan.

Rencana Produk: NAQSH — Studio Gambar Vektor Siap Produksi

Ide: Editor gambar vektor gratis dan open source yang berjalan secara lokal di desktop dan browser, menggabungkan ketelitian editor profesional dengan hasil siap cetak, potong, dan bordir, serta API yang memungkinkan AI mengontrol desain.

1) Target Audiens

• Produsen produk dan percetakan (segmen utama): Mereka yang memproduksi stiker, vinyl, template kaos, sablon, ukiran batu, dan bordir CNC/laser.

• Desainer independen dan pembuat ikon: Membutuhkan gambar vektor bersih, dapat diedit, dan file SVG yang ringan.

• Pembuat konten berbahasa Arab, guru, dan pelajar: Membutuhkan dukungan bahasa Arab yang tepat (tashkil, arah kanan-ke-kiri, spasi huruf) untuk stiker, judul, dan materi cetak pendidikan.

• Studio kecil dan agensi desain: Tim beranggotakan 2–6 orang yang membutuhkan kolaborasi nyata tanpa berlangganan.

• Pengembang agen AI: Menginginkan editor gambar yang dapat diprogram, bukan hanya menghasilkan gambar yang tidak dapat diedit.

2) Keunggulan (Mengapa Memilih Produk Ini)

• Hasil siap produksi, bukan sekadar gambar: Lapisan jalur potong (Cut), kompensasi kerf, tanda potong, spot colors, serta ekspor DXF, DST (bordir), dan PDF untuk cetak — fitur yang jarang ditemukan pada kebanyakan alat gambar.

• Bahasa Arab pertama: Dukungan tashkil, penulisan bidireksional, kashida, dan penggabungan huruf Arab/Latin yang diekspor dengan benar ke SVG dan PDF — masalah umum pada alat lain.

• Dapat diprogram sejak awal: Server MCP, kanal kontrol JSON, dan CLI tanpa antarmuka untuk memungkinkan agen AI menggambar, mengedit, dan mengekspor secara mandiri. Setiap tindakan di antarmuka dapat dipanggil secara programatik.

• Local-first dan kolaborasi gratis: Dokumen tersimpan di perangkat Anda, sinkronisasi bersama opsional melalui CRDT dengan tautan berbagi gratis — tanpa berlangganan atau penguncian proprietary.

• Format file terdokumentasi dan terbuka: JSON untuk segala hal dengan sistem peningkatan versi dan pemulihan penuh untuk lapisan, font, dan efek.

• Performa tinggi: 60 fps untuk 50.000 bentuk, serta versi web yang dimuat dalam hitungan detik (inti yang sama berbasis Rust melalui WASM).

• Satu inti untuk Mac/Windows/Linux dan browser: Dengan antarmuka TypeScript bersama, bukan GUI asli yang berat.

3) Ruang Lingkup Versi Pertama (Maksimal 8 Tugas)

1. Inti dokumen dan geometri: Struktur JSON dokumen, alat Pena dan Bezier dengan pegangan, bentuk, lapisan, operasi boolean (gabung/kurangi/irisan/bagi) yang presisi, isi, garis, gradasi, impor/ekspor SVG tanpa kehilangan data.

2. Antarmuka pengguna: Bilah alat, panel (lapisan/penampilan/warna), pemilihan, pemindahan, pengubahan ukuran, zoom/pan, pintasan lengkap, mode terang dan gelap, serta dukungan bahasa Arab dan Inggris pada menu.

3. Dua aplikasi dari satu inti: Versi desktop (Rust + Tauri) dan versi browser (Rust→WASM + antarmuka TypeScript) dengan kode dan tampilan yang sama.

4. API untuk agen: Server MCP, kanal kontrol JSON, dan CLI untuk eksekusi tanpa antarmuka (membuat, mengedit, mengekspor secara batch).

5. Ekspor untuk produksi dan cetak: PDF siap cetak (bleed, tanda potong, spot colors), SVG dengan lapisan potong, DXF untuk laser/bordir, serta opsi kompensasi pemotongan.

6. Teks Arab bidireksional: Tashkil, penggabungan huruf, paragraf RTL, kashida, penyematan font dan konversi ke path.

7. Kolaborasi local-first: CRDT untuk sinkronisasi, indikator kehadiran, komentar, tautan berbagi dengan batasan pada paket gratis, serta riwayat versi.

8. Jaminan kualitas dan peluncuran: Pengujian geometris berbasis property-based untuk stabilitas operasi dan integritas file, tangkapan layar otomatis, build bertanda untuk Windows/macOS/Linux/WASM, dokumentasi Arab/Inggris, serta penghitung performa di CI.

4) Harga dan Model Bisnis

Model gratis untuk memulai: Inti sepenuhnya open source, pembayaran hanya untuk layanan cloud.

• Community (gratis selamanya): Editor lengkap, file lokal tanpa batas, SVG/PDF, tautan berbagi (3), dukungan komunitas.

• Creator (gratis selama beta, kemudian $0 untuk pelajar): Sinkronisasi cloud tanpa batas, kolaborasi untuk kurang dari 10 orang, ekspor DXF/DST, grup merek.

• Studio ($12/bulan atau $96/tahun): Ruang tim, riwayat versi selama satu tahun, MCP terkelola, pemrosesan batch melalui API, ekstensi kuru
