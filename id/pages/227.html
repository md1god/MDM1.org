Luqmah — Rencana Proyek Lengkap

Rencanakan menu sekali… masak dengan tenang sepanjang minggu.

Rencana implementasi lengkap untuk proyek digital baru: ide, audiens, produk, model pendapatan, peluncuran, dan risiko. Proyek sedang dibangun dan belum diluncurkan.

Rencana produk baru: aplikasi perencanaan menu dan manajemen resep

Ide dan masalah: server perencanaan menu dan manajemen resep self-hosted sangat baik, namun mengandalkan klien tak resmi di banyak platform dan sering kurang mendukung bahasa Arab, mode memasak, daftar belanja cerdas, serta pengalaman konsisten antara ponsel dan desktop. Masalahnya: pengguna menginginkan satu pengalaman yang cepat, elegan, dan lengkap di semua perangkatnya, dengan privasi penuh atas datanya.

1) Audiens target

• Pengguna server perencanaan menu self-hosted (yang peduli privasi dan open source).

• Keluarga dan individu sibuk yang ingin merencanakan menu mingguan dan mengurangi sisa makanan.

• Pengikut diet dan resep (pengelola rumah tangga, mahasiswa, pelancong).

• Penutur bahasa Arab yang mencari dukungan RTL sungguhan.

• Komunitas memasak dan belanja cerdas global (pengguna Android, iOS, dan Desktop).

2) Poin keunggulan

• Aplikasi native dari nol dengan Flutter, berjalan di Android, iOS, dan desktop dengan satu basis kode dan performa tinggi.

• Pengalaman bahasa Arab autentik (RTL, font, kalender Hijri opsional) — kelangkaan jelas di bidang ini.

• Mode memasak: langkah interaktif + beberapa timer + kontrol sentuh/suara.

• Daftar belanja cerdas: menggabungkan bahan otomatis, menghapus duplikat, membagi per bagian toko, dan berbagi via WhatsApp.

• Dukungan offline penuh untuk resep dan rencana tersimpan, sinkronisasi instan saat kembali daring.

• Multi-akun/server, ekspor/impor standar, dan kalender yang bisa dibagikan ke keluarga.

• Privasi lebih dulu: tanpa pelacakan, tanpa iklan, data tetap di sisi pengguna atau terenkripsi lokal.

3) Cakupan versi pertama (maks 8 tugas)

1. Struktur proyek dengan Flutter dan antarmuka Material 3 + dukungan bahasa Arab/Inggris dengan RTL penuh.

2. Lapisan koneksi API ke server self-hosted apa pun + multi-akun dan manajemen kunci.

3. Lihat dan buat resep: foto, bahan, langkah, tag, pencarian, dan filter.

4. Kalender rencana menu (minggu/bulan) dengan seret-lepas dan penyalinan hari.

5. Daftar belanja otomatis cerdas dengan pembagian bagian dan berbagi teks.

6. Mode memasak berbasis langkah + timer + penyimpanan offline.

7. Pengujian otomatis dan CI, lalu rilis Beta ke Google Play dan TestFlight serta rilis desktop.

8. Dokumentasi pengguna + prototipe tertutup dengan 50 pengguna guna mengumpulkan masukan.

4) Harga dan model pendapatan

Gratis untuk memulai: semua fitur inti (resep, rencana, daftar belanja, mode memasak) gratis selamanya, dengan open source untuk membangun kepercayaan.

Sumber pendapatan:

• Langganan Pro opsional (~3,99$/bulan atau 29$/tahun): sinkronisasi cloud terkelola, pencadangan, analisis nutrisi, kustomisasi lanjutan.

• Donasi komunitas (GitHub Sponsors / Buy Me a Coffee).

• Pasar template berbayar: paket rencana resep dan daftar dari koki bersertifikat (komisi 20%).

• Sponsorship komunitas dari perusahaan peralatan dan makanan, tanpa iklan di aplikasi.

5) Rencana peluncuran global lewat kanal gratis

• Artikel blog multi-bahasa (Arab/Inggris) ber-SEO tentang «perencanaan menu» dan «mengurangi pemborosan makanan».

• Konten pendek: TikTok dan YouTube Shorts dan Instagram Reels — resep cepat yang menampilkan aplikasi.

• Posting komunitas: Reddit dan Hacker News (Show HN) dan Mastodon dan LinkedIn.

• Komunitas Discord/Matrix + program penerjemah sukarela (Crowdin).

• Newsletter mingguan «rencana menu siap pakai» untuk membangun audiens yang setia.

• Kemitraan dengan kreator konten kesehatan dan pola makan seimbang dalam banyak bahasa (imbalan penyebutan gratis).

6) Risiko (hukum dan teknis)

• Hukum: nama dan identitas dibuat dari nol untuk menghindari bentrok merek dagang; tidak memakai nama atau kesan pihak ketiga; kepatuhan GDPR/CCPA atas data pengguna; kebijakan Google Play dan App Store; hak cipta foto dan resep unggahan pengguna.

• Teknis: perubahan API pada server (ditangani lapisan kompatibilitas dan pengujian otomatis); batasan iOS soal penyimpanan dan latar belakang; risiko pembayaran dan langganan (melalui penyedia tepercaya); pemeliharaan 3 platform dengan satu basis kode; ketergantungan pada lisensi server yang di-hosting.

7) Nama dan slogan

Nama yang diusulkan: Luqmah
