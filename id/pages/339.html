Mihrab CAD — Rencana Proyek Lengkap

Rancang suku cadang berikutnya langsung dari browser dalam hitungan menit.

Rencana implementasi lengkap untuk proyek digital baru: ide, audiens, produk, model pendapatan, rencana peluncuran, dan risiko. Proyek sedang dibangun dan belum diluncurkan.

1) Audiens target

• Insinyur mesin dan pembuat skala kecil (Prototyping) yang membutuhkan desain cepat tanpa memasang program berat.

• Mahasiswa teknik dan institut teknik di negara berkembang (perangkat lemah + koneksi internet terbatas).

• Komunitas Maker dan hobiis yang mencetak 3D dan ingin mengedit file STL/STEP sederhana.

• Tim produk startup yang membutuhkan prototipe kolaboratif berbasis cloud.

2) Keunggulan (mengapa memilih produk kami)

• Berjalan sepenuhnya di dalam browser tanpa instalasi, dengan dukungan mode offline via Service Worker dan penyimpanan lokal di IndexedDB.

• Mesin editing Parametric ringan ditulis dalam bahasa Rust yang dikompilasi ke WebAssembly untuk performa mendekati desktop.

• Mode Collaborative Editing real-time antar beberapa editor (seperti dokumen bersama) menggunakan CRDT.

• Alur kerja terarah untuk impor/ekspor: STEP, STL, OBJ, SVG dengan pratinjau instan.

• Antarmuka Arab lengkap (RTL) dengan dukungan bahasa lain, yaitu celah yang jelas di pasar.

• Versi gratis sungguhan tanpa batas waktu, bukan uji coba terbatas.

3) Cakupan versi pertama (maksimal 8 tugas)

1. Penampil 3D dasar (rotasi, zoom, potong, ukur) di browser.

2. Alat gambar 2D: garis, lingkaran, persegi, potong untuk membentuk profil Revolve dan tarik (Extrude).

3. Mesin Rust → WebAssembly untuk perhitungan geometri dasar.

4. Impor dan ekspor STL dan OBJ dengan konversi awal ke STEP.

5. Penyimpanan proyek secara lokal dan pemulihan, serta ekspor sebagai satu file proyek.

6. Antarmuka Arab RTL + Inggris dengan pengganti bahasa.

7. Berbagi pratinjau read-only melalui tautan (URL + WebRTC).

8. Halaman landing + perbandingan prototipe siap diunduh.

4) Harga dan model pendapatan

• Gratis untuk memulai: dua proyek tanpa batas pada fitur dasar, penggabungan (Merge) hingga 5 bagian, ekspor hingga 10 kali per bulan.

• Pro — 12$/bulan: proyek tanpa batas, editing kolaboratif real-time, impor/ekspor STEP, Loft (penggabungan Loft), riwayat versi.

• Tim — 8$/pengguna/bulan: ruang kerja bersama, izin, integrasi API.

• Pendapatan tambahan: toko template dan pustaka komponen berbayar (komisi 20%), serta lisensi pendidikan universitas dengan harga diskon.

5) Rencana peluncuran global dengan kanal gratis

1. YouTube / Bilibili: tutorial singkat «Desain suku cadang dalam 5 menit» dengan teks Arab dan Inggris.

2. X (Twitter) dan Threads: seri Build in Public dan klip GIF sebelum/sesudah desain.

3. Forum dan komunitas r/CAD, r/3Dprinting: versi uji gratis + survei umpan balik.

4. Komunitas Maker berbahasa Arab: grup Telegram dan Discord (progres, grup Arab untuk publikasi, dan tantangan bulanan dengan hadiah simbolis).

5. GitHub Pages / pustaka terbuka: merilis sebagian SDK terbuka untuk menarik pengembang.

6. SEO: artikel perbandingan alternatif berbasis browser untuk kueri seperti «program CAD online gratis».

7. Kemitraan pendidikan: alat gratis untuk akademi pelatihan teknis dengan imbalan logo rujukan.

6) Risiko (hukum dan teknik)

• Hukum: menghindari pelanggaran paten algoritma CAD standar; menilai lisensi pustaka terbuka sebelum adopsi, serta menjelaskan kepemilikan file yang digunakan untuk melatih model. Ketergantungan pada file pengguna mungkin mengharuskan kebijakan privasi yang sesuai dengan GDPR.

• Teknis: batas memori browser pada model besar → pemotongan (Chunking) dan pemuatan malas. Stabilitas WebAssembly di berbagai browser → matriks pengujian. Kehilangan pekerjaan jika penyimpanan lokal gagal → sinkronisasi opsional ke cloud.

• Lainnya: persaingan dari perusahaan dengan perlengkapan lengkap; kami meredamnya dengan fokus pada kecepatan, harga, dan bahasa Arab.
