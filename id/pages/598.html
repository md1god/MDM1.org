قِرطاس — rencana proyek lengkap

Kami mengubah web menjadi data bersih yang siap untuk agen AI dalam satu permintaan.

Rencana proyek digital: ide, audiens, produk, pendapatan, distribusi, risiko. Belum diluncurkan.

Produk: platform ekstraksi web untuk agen cerdas

1) Target audiens

• Pengembang AI yang membangun agen (Agents) atau RAG dan membutuhkan konten web bersih.

• Startup kecil yang enggan membangun scraping dan pemrosesan dari nol.

• Tim analisis data dan riset yang mengumpulkan konten berkala dari banyak situs.

• Agensi otomasi dan pembuat no-code (seperti n8n dan Make) yang mencari integrasi siap pakai.

• Peneliti dan akademisi yang membutuhkan arsip halaman dan referensi terstruktur.

2) Keunggulan

• Gratis: kuota bulanan permanen tanpa kartu kredit, cukup untuk uji coba dan produksi kecil.

• Output siap agen: Markdown bersih, JSON sesuai skema pengguna, dan tangkapan layar bila perlu.

• Dirancang untuk agen: Async Jobs, Webhooks, server MCP, dan SDK resmi, bukan scraping tradisional.

• Dukungan Arab dan multibahasa: RTL, diakritik, dan halaman campuran bahasa.

• Biaya transparan: penghitung pemakaian per permintaan; cache menekan panggilan berulang dan tagihan.

• Kepatuhan bawaan: patuhi robots.txt dan kebijakan situs secara default, dengan log audit tiap operasi.

• Tanpa ketergantungan teknis: ekspor data, antarmuka berstandar terbuka, dan opsi self-hosting enterprise.

3) Cakupan versi pertama (8 tugas)

1. extract: satu tautan menjadi Markdown bersih tanpa menu, iklan, dan noise.

2. extract dengan skema JSON khusus untuk bidang tertentu (harga, judul, tanggal…).

3. Render JavaScript via browser headless dengan penantian pemuatan cerdas.

4. crawl terbatas: jelajahi situs hingga kedalaman tertentu dan kembalikan peta tautan.

5. search: cari halaman lalu ekstrak hasil terbaik langsung.

6. Kunci API, kuota, dan saldo, dengan dasbor sederhana dan riwayat pemakaian.

7. Async Jobs + Webhooks + SDK awal (Python dan TypeScript) + server MCP.

8. Cache, pencatatan error, dan percobaan ulang otomatis, dengan dokumentasi dan contoh siap pakai.

4) Harga dan pendapatan

• Free: kuota bulanan tetap (misalnya 500 operasi) dan batas laju rendah, tanpa kartu.

• Pay-as-you-go: bayar sesuai pemakaian setelah kuota gratis habis, per operasi atau per seribu halaman.

• Starter / Growth: kuota lebih besar, prioritas pemrosesan, cakupan lebih luas, harga per operasi lebih rendah.

• Enterprise: perjanjian penggunaan, batas khusus, SLA, faktur, dan opsi self-hosting.

• Tambahan: pasar template ekstraksi (Templates) dengan komisi, serta antarmuka berbayar (tangkapan layar, PDF, tabel kompleks).

• Prinsip: saldo terpadu yang mudah dipahami, pemindahan saldo tak terpakai untuk periode terbatas, dan diskon tahunan.

5) Distribusi global via kanal gratis

• SDK dan CLI open source di GitHub dengan contoh praktis dan README kuat.

• Server MCP terdaftar di direktori MCP dan toko alat agen.

• Dokumentasi SEO, panduan perbandingan, dan "how to" untuk tiap kasus penggunaan.

• Peluncuran di Product Hunt, Hacker News, dan Reddit (r/LocalLLaMA, r/MachineLearning) secara jujur.

• Integrasi gratis dengan LangChain, LlamaIndex, n8n, Make, dan Zapier.

• Video singkat di YouTube serta artikel di dev.to dan Medium.

• Komunitas Discord dan buletin mingguan berisi kasus penggunaan dan pembaruan.

• Kompetisi, hackathon universitas, dan sponsor open source (Good First Issues).

6) Risiko hukum dan teknis

Hukum:

• Ketentuan situs dan hak cipta berubah; solusi: patuhi robots.txt, kebijakan penggunaan wajar, dan pengecualian domain.

• Data pribadi (GDPR/CCPA) dalam konten; solusi: minimalkan pengumpulan, tanpa penyimpanan jangka panjang default, dan alat hapus.

• Tanggung jawab pengguna atas konten; solusi: syarat layanan dan batas penggunaan jelas.

• Risiko hukum regional; solusi: tinjauan berkala dan fleksibilitas pemblokiran domain.

Teknis:

• Anti-scraping, CAPTCHA, blokir IP; solusi: diversifikasi jaringan, percobaan ulang, dan komunikasi batas layanan.

• Render JavaScript mahal; solusi: cache cerdas, render ringan bila bisa, dan batas jelas.

• Ekstraksi rapuh saat desain situs berubah; solusi: skema fleksibel, uji pemantauan, dan peringatan.

• Prompt Injection dan pencemaran data; solusi: sanitasi output dan penandaan konten tak tepercaya.

• Keamanan (SSRF, penyalahgunaan kuota); solusi: daftar domain terlarang, batas laju, pemantauan anomali.

• Keandalan dan skala; solusi: antrean, pemantauan, rencana pemulihan, dan ketersediaan bertahap.
