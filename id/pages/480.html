Khayt — Rencana Proyek Lengkap

Platform local-first untuk membangun dan menjalankan agen peramban tepercaya, mereproduksi setiap langkah, dan menempatkan manusia di pusat keputusan.

Rencana implementasi proyek digital baru: ide, audiens, produk, model bisnis, distribusi, risiko. Masih dibangun, belum diluncurkan.

1) Audiens

• Pengembang agen AI yang butuh otomasi peramban yang dapat diperiksa/diputar ulang, bukan skrip rapuh.

• Engineer otomasi/QA yang mengubah skenario uji manual jadi workflow andal.

• Agensi/tim kecil yang membangun pengumpulan/entri data klien tanpa biaya cloud tinggi.

• Organisasi sensitif data yang menjalankan otomasi di infrastruktur sendiri dengan model privat/Ollama.

• Peneliti/kreator konten teknis yang butuh lingkungan uji gratis, reproducible.

2) Keunggulan

• Local-first: UI web lokal satu perintah, executor ringan di perangkat/Docker, dukungan Ollama dan penyedia kompatibel OpenAI; data tidak keluar.

• Editor ganda: builder visual DAG dan kode TypeScript/Python, variabel bertipe, validasi instan.

• Kapsul replay: rekam screenshot, DOM, log jaringan, panggilan model; PII disaring otomatis untuk reproduksi bug.

• Tata kelola, bukan stealth: tanpa spoof fingerprint/CAPTCHA; allowlist domain, rate limit, persetujuan manusia untuk kirim/beli/hapus, audit log.

• Ekspor: workflow ke MCP server, REST API, webhook, CLI; tanpa lock-in.

• Lab evaluasi: kasus uji, assertion, regresi, success rate; otomasi jadi aset engineering.

3) Lingkup versi pertama (maks 8 tugas)

1. Executor lokal satu perintah: Docker/npm, Chromium via Playwright, Ollama/API key eksternal.

2. Studio web: editor visual + panel kode, variabel bertipe, validasi, simpan lokal.

3. Perekam langkah: klik, ketik, navigasi; selector via accessibility tree sebelum koordinat.

4. Kapsul replay: screenshot, DOM, metadata jaringan, console, panggilan LLM; kolom sensitif disamarkan.

5. Antrean paralel: konkurensi, timeout, retry, batas token/biaya.

6. Kebijakan + vault rahasia: allowlist domain, persetujuan manusia untuk aksi sensitif, rate limit, audit log.

7. Ekspor/otomasi: MCP server, REST/webhook, penjadwalan, CLI di luar studio.

8. Lab evaluasi: data uji, assertion, bandingkan versi, laporan lulus/gagal.

4) Harga dan model keuntungan

• Free/Local: gratis selamanya untuk self-hosted; workflow tak terbatas, 2 sesi paralel, riwayat 7 hari, model lokal/kunci pengguna, dukungan komunitas.

• Pro: US$19/pengguna/bulan; sinkron cloud opsional, 10 sesi paralel, riwayat 30 hari, eksekusi terjadwal, dukungan email.

• Team: US$39/pengguna/bulan; ruang kerja bersama, RBAC/SSO, ekspor audit log, 50 sesi paralel, riwayat 90 hari, dukungan prioritas.

• Enterprise: harga khusus; deployment terisolasi, SLA, tinjauan kepatuhan, konektor privat, pelatihan.

Pendapatan: langganan tim, eksekusi cloud opsional, deployment/integrasi. Tanpa margin kunci model; versi lokal gratis tetap kuat.

5) Kanal distribusi gratis

• GitHub dulu: core open-source Apache 2.0, template workflow, issue pemula, rilis terdokumentasi.

• SEO/konten: halaman “jalankan otomasi peramban lokal”, “alternatif self-hosted untuk otomasi agen”, bandingkan biaya/privasi Inggris/Arab.

• YouTube/blog: tutorial workflow 10 menit, debugging via replay, benchmark lokal vs cloud.

• Komunitas: Show HN, Product Hunt, Ollama/MCP, subreddit sesuai aturan, Discord resmi.

• Integrasi: template n8n, LangChain, LlamaIndex, Dify; MCP server di direktori MCP dan daftar alat.

• Kemitraan: agensi otomasi, klub kampus, hackathon, meetup AI lokal. Metrik: first run <10 menit, reuse template mingguan.

6) Risiko hukum dan teknis

Hukum:

• Melanggar ketentuan situs/hukum data. Mitigasi: kebijakan penggunaan, allowlist, audit log, patuhi robots/API resmi, tolak bypass CAPTCHA/penyamaran.

• Tanggung jawab aksi agen. Mitigasi: persetujuan manusia untuk aksi finansial/pengiriman, batas jelas, disclaimer kontrak.

• Privasi data/kunci. Mitigasi: lokal default, enkripsi secret, redaksi log, DPA cloud.

Teknis:

• Situs berubah/selector rusak. Mitigasi: selector semantik, versi browser dipin, deteksi regresi via replay.

• Anti-bot memblokir. Mitigasi: gagal transparan, rekomendasi API resmi, tanpa stealth.

• Kode tak tepercaya di executor. Mitigasi: isolasi container, least privilege, signing template, pisahkan secret.

• Prompt injection via halaman/MCP. Mitigasi: sanitasi konten, token scope terbatas, persetujuan sebelum tool sensitif.

• Biaya berlebih. Mitigasi: batas konkurensi, budget, timeout default.
