Михраб Инженерия — полный план проекта

Спроектируйте свою следующую деталь прямо в браузере за несколько минут.

Полный план реализации нового цифрового проекта: идея, целевая аудитория, продукт, бизнес-модель, стратегия распространения и риски. Проект находится в стадии разработки и ещё не запущен.

1) Целевая аудитория

• Инженеры-механики и небольшие производственные компании (Prototyping), которым необходим быстрый дизайн без установки тяжеловесного ПО.

• Студенты инженерных специальностей и техникумов в развивающихся странах (слабые устройства и ограниченный интернет).

• Сообщества Maker и любители, занимающиеся 3D-печатью и желающие редактировать простые файлы STL/STEP.

• Стартап-команды, которым необходимы общие облачные прототипы.

2) Ключевые преимущества (почему выбираем наш продукт)

• Полностью работает в браузере без установки, с поддержкой офлайн-работы через Service Worker и локальным сохранением в IndexedDB.

• Лёгкий движок для параметрического моделирования (Parametric), написанный на Rust и скомпилированный в WebAssembly, что обеспечивает производительность, близкую к десктопной.

• Режим Collaborative Editing в реальном времени для нескольких редакторов одновременно (аналог общего документа) с использованием CRDT.

• Направленный рабочий процесс импорта и экспорта: STEP, STL, OBJ, SVG с мгновенным предпросмотром.

• Полностью русскоязычный интерфейс с поддержкой RTL и другими языками — явный пробел на рынке.

• Настоящая бесплатная версия без ограничений по времени, без пробного периода с лимитами.

3) Объём первой версии (не более 8 задач)

1. Базовый 3D-просмотр (вращение, масштабирование, обрезка, измерение) в браузере.

2. Инструменты 2D-проектирования: линия, окружность, прямоугольник, вырез для создания тела вращения (Revolve) и выдавливания (Extrude).

3. Движок Rust → WebAssembly для базовых инженерных расчётов.

4. Импорт и экспорт STL и OBJ с первичной конвертацией в STEP.

5. Локальное сохранение и загрузка проектов, а также экспорт в виде единого файла проекта.

6. Интерфейс на русском языке с RTL + английский язык с переключателем языков.

7. Общий предпросмотр только для чтения по ссылке (URL + WebRTC).

8. Целевая страница + готовые примеры прототипов для загрузки.

4) Ценообразование и бизнес-модель

• Бесплатно для старта: два проекта без ограничений по основным функциям, Merge до 5 деталей, экспорт до 10 раз в месяц.

• Pro — 12$/мес.: неограниченное количество проектов, совместное редактирование в реальном времени, импорт/экспорт STEP, функция Loft, история версий.

• Team — 8$/пользователь/мес.: общие рабочие пространства, права доступа, интеграция API.

• Дополнительный доход: магазин платных шаблонов и библиотек деталей (комиссия 20%), а также льготные лицензии для университетов и учебных заведений.

5) Глобальный план распространения через бесплатные каналы

1. YouTube / короткие ролики: уроки «Спроектируй деталь за 5 минут» на русском и английском языках.

2. X (Twitter) и Threads: серия Build in Public и GIF с демонстрацией до/после проектирования.

3. Reddit и форумы r/CAD, r/3Dprinting: бесплатная пробная версия + опросы для сбора обратной связи.

4. Русскоязычные сообщества Maker: группы в Telegram и Discord (обзоры, русскоязычная группа для публикаций и ежемесячный конкурс с символическим призом).

5. GitHub Pages / открытые библиотеки: выпуск части SDK в открытом доступе для привлечения разработчиков.

6. SEO: статьи-сравнения браузерных альтернатив для запросов типа «бесплатная онлайн CAD-программа».

7. Образовательные партнёрства: бесплатное использование инструмента для технических учебных заведений в обмен на упоминание в качестве партнёра.

6) Риски (юридические и технические)

• Юридические: избегать нарушения патентов на алгоритмы параметрического моделирования; оценивать лицензии открытых библиотек перед их внедрением, а также чётко обозначать право собственности на файлы, используемые при обучении моделей. Использование пользовательских файлов может потребовать политики конфиденциальности, соответствующей требованиям GDPR.

• Технические: ограничения памяти браузера при работе с большими моделями → реализация Chunking и отложенной загрузки (lazy loading). Стабильность работы WebAssembly в разных браузерах → матрица тестирования. Потеря работы в случае сбоя локального хранилища → опциональная синхронизация с облаком.

• Прочие: конкуренция со зрелыми продуктами; смягчаем её за счёт акцента на скорость, цену и поддержку русского языка.
