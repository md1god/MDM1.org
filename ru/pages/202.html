خزينة — полный план проекта

Зашифрованное резервное копирование по принципу нулевого знания: полный контроль и бесплатный старт.

Полный план реализации нового цифрового проекта: идея, аудитория, продукт, модель монетизации, план продвижения и риски. Проект находится в разработке и ещё не запущен.

План оригинального продукта: зашифрованное облачное резервное копирование

1) Целевая аудитория

• Частные пользователи, заботящиеся о приватности, и владельцы конфиденциальных данных на личных компьютерах.

• Малые и средние команды (SMEs), которым нужно надёжное резервное копирование без выделенной технической команды.

• Разработчики и продвинутые пользователи (self-hosters), которые хотят полностью контролировать свои ключи и хранилище.

• Пользователи нескольких систем (Windows / macOS / Linux), ищущие единый инструмент.

2) Ключевые преимущества (почему стоит выбрать наш продукт)

• Шифрование на стороне клиента по принципу нулевого знания (zero-knowledge): ключи никогда не покидают устройство пользователя.

• Настройка в один клик через простой интерфейс для нетехнических пользователей, при этом полная мощность остаётся доступной через командную строку.

• Поддержка нескольких провайдеров и отсутствие привязки: S3-compatible, Backblaze B2, Google Drive и любое собственное хранилище.

• Эффективность хранения за счёт дедупликации (deduplication) и инкрементного копирования (incremental), что снижает затраты.

• Бесплатный старт без обманчивых ограничений, с прозрачной моделью open-core, проверяемой на безопасность.

• Быстрое восстановление с системой точек во времени (point-in-time) и удобный поиск по версиям.

3) Объём первой версии (не более 8 задач)

1. Кроссплатформенный агент (Windows / macOS / Linux) с простой командной строкой.

2. Движок инкрементного копирования с дедупликацией на уровне блоков (chunk-level).

3. Шифрование на стороне клиента (AES-256) с безопасным выводом ключей и генерацией фразы восстановления.

4. Базовые коннекторы хранилищ: S3-compatible и Backblaze B2.

5. Планирование автоматического копирования и фоновый мониторинг (system tray / service).

6. Простой интерфейс управления для создания задач копирования и просмотра версий.

7. Полное или частичное восстановление с выбором точки во времени.

8. Проверка целостности данных (integrity check) и уведомления об ошибках.

4) Ценообразование и модель прибыли

• Бесплатный старт: все базовые функции для частных лиц и самостоятельного использования с собственным хранилищем (bring-your-own-storage).

• Платная личная подписка: облачное хранилище, размещённое на нашей стороне, по низким месячным ценам + приоритетная поддержка.

• План для бизнеса/команд: централизованное управление политиками, журналы аудита, SSO и индивидуальная поддержка.

• Дополнительный доход: корпоративные лицензии, услуги миграции и управляемой поддержки, а также индивидуальные услуги интеграции.

• Прозрачное ценообразование без обязательной привязки, с возможностью отмены в любое время.

5) План глобального продвижения через бесплатные каналы

• Публикация открытого репозитория на GitHub и построение сообщества контрибьюторов.

• Публикации на платформах пользователей и разработчиков: Hacker News, Product Hunt, Reddit (r/selfhosted, r/DataHoarder, r/homelab).

• Наличие в менеджерах пакетов: Homebrew, Winget, APT/DNF и пакеты Docker Hub.

• SEO-контент и обучающие видео на YouTube о защите данных и резервном копировании.

• Сообщество Discord/Matrix для взаимной поддержки, программа амбассадоров и вознаграждения ранним контрибьюторам.

• Интеграция с платформами самостоятельного хостинга (NAS, TrueNAS, Unraid) через готовые шаблоны.

6) Риски (юридические и технические)

• Юридические: соблюдение GDPR и законов о защите данных, ответственность за утрату ключей, правила экспортного контроля шифрования, выбор лицензии, совместимой с моделью open-core (избегать конфликта GPL с проприетарным компонентом).

• Технические: обеспечение целостности данных и защиты от повреждения, безопасное восстановление при утрате секретной фразы, изменения API провайдеров хранилищ, масштабирование при больших объёмах данных, противодействие атакам на истощение ресурсов и производительность (performance).

7) Предлагаемое название и маркетинговый слоган

Предлагаемое название: خزينة (Khazina)

Маркетинговый слоган: Зашифрованное резервное копирование по принципу нулевого знания, полностью под вашим контролем, начать можно бесплатно.
