MetaLens — полный план проекта

Прочитайте всё, что скрывают ваши фото и видео, не покидая ваше устройство.

Полный план реализации нового цифрового проекта: идея, аудитория, продукт, модель монетизации, план продвижения и риски. Проект в разработке и ещё не запущен.

План продукта: платформа извлечения и проверки метаданных

1) Целевая аудитория

• Цифровые следователи и судебные эксперты, которым нужно читать данные Exif/IPTC/XMP без изменения исходного файла.

• Фотографы и видеоредакторы, желающие проверять данные камеры, объектива, даты и авторских прав.

• Журналисты и фактчекеры для выявления подделанных или переиспользованных фотографий по расхождению даты съёмки.

• Разработчики, которым нужен API для автоматического извлечения метаданных.

• Специалисты по комплаенсу и приватности для очистки файлов сотрудников перед публикацией.

2) Отличия (почему выбирают нас)

• Полная работа в браузере (Client-side) без загрузки файлов — привлекает аудиторию, ценящую приватность, в отличие от решений, требующих установки библиотеки или загрузки файла.

• Простой интерфейс: данные сгруппированы (камера, GPS-местоположение, отметка времени, права) вместо сырого списка полей.

• Автоматическая проверка противоречий: сравнение дат файла, системы и Exif, отметка признаков вмешательства.

• Широкая поддержка форматов (фото, видео, аудио) и экспорт в JSON/CSV.

• Бесплатный API с низкими лимитами для быстрого внедрения разработчиками.

• Многоязычность с полной поддержкой арабского и английского с первой версии.

3) Объём первой версии (не более 8 задач)

1. Извлечение Exif и GPS для распространённых форматов изображений (JPEG, PNG, WebP, HEIC).

2. Извлечение основных данных видео и аудио (длительность, кодек, дата создания).

3. Сгруппированная панель просмотра с картой при наличии GPS.

4. Проверка противоречий и отображение «индекса достоверности» файла.

5. Экспорт результатов в JSON и CSV с выборочным удалением.

6. Инструмент очистки (Strip) для удаления метаданных и повторной загрузки чистого файла.

7. Один REST API для извлечения с бесплатным ключом.

8. Интерфейс на арабском и английском с локальным хранением настроек.

4) Тарифы и модель доходов

• Бесплатно (Free-to-start): неограниченное извлечение в браузере + 200 запросов API в месяц + базовые функции.

• Про (Pro): недорогая ежемесячная подписка — пакетная обработка, более высокие лимиты API, архивация результатов, PDF-отчёты.

• Команда (Team): несколько мест, прямые интеграции, выделенная поддержка и SLA.

• Дополнительный доход: платный пакет «очистка» и встраиваемые решения (White-label) для новостных организаций.

5) Глобальный вывод на рынок через бесплатные каналы

• Публикация инструмента на Product Hunt и Hacker News с историей «приватность прежде всего, без загрузки файлов».

• Технические статьи на dev.to и Medium и открытый исходный код ядра на GitHub для привлечения разработчиков.

• Короткие видео на YouTube Shorts и TikTok, демонстрирующие обнаружение вмешательства на одном изображении.

• Полезные ответы на Stack Overflow и Reddit (r/photography, r/forensics) со ссылкой на инструмент при необходимости.

• Бесплатные партнёрства с платформами проверки новостей и редакциями расследований.

• Поисковая оптимизация по запросам вроде «проверка метаданных фото» и «Exif viewer without upload».

6) Риски (юридические и технические)

• Юридические: приватность GPS-данных и персональных данных (GDPR и CCPA) — решение: полная локальная обработка без хранения файлов.

• Юридические: злоупотребление инструментом очистки для сокрытия улик — решение: чёткие условия использования и необязательный водяной знак только для журнала.

• Технические: разнообразие форматов и изменение стандартов — решение: расширяемая архитектура на плагинах.

• Технические: точность выявления вмешательства ограничена, возможны ложные срабатывания — решение: показывать результат как индикатор, а не как окончательный вердикт.

• Технические: производительность больших файлов в браузере — решение: потоковая обработка и поэтапная загрузка.
