Рифад — полный план проекта

Открытый и нейтральный реестр расширений, работающий с любым редактором, с надёжными источниками и безопасностью прежде всего.

Полный план реализации нового цифрового проекта: идея, аудитория, продукт, модель монетизации, план распространения и риски. Проект находится в разработке и ещё не запущен.

План продукта: открытый мультиредакторный реестр расширений

1) Целевая аудитория

• Независимые разработчики расширений, которые хотят публиковать бесплатно, без посредников и комиссий.

• Пользователи редакторов, совместимых с VS Code (VSCodium, Cursor, Windsurf, Theia, Code-OSS), лишённые нейтрального централизованного маркетплейса.

• Команды безопасности и комплаенса в компаниях, которым нужна проверка источника и безопасности расширений.

• Организации, желающие иметь собственный внутренний приватный реестр для своих корпоративных расширений.

2) Отличительные преимущества (почему стоит выбрать наш продукт)

• Полностью нейтральный и с открытым исходным кодом: никакой монополии одного редактора, протокол документирован и открыт.

• Безопасность цепочки поставок прежде всего: обязательная подпись, данные о происхождении (Provenance), автоматическая проверка на вредоносное ПО перед публикацией.

• Мультиредакторность: один клиент обслуживает все совместимые форки через единую конечную точку.

• Продвижение за счёт солидарности, а не рекламы: никакого отслеживания пользователей и продажи данных.

• Мгновенная замена в один клик: автоматический импорт расширений из стандартного формата без переписывания кода.

3) Объём первой версии (не более 8 задач)

1. Центральный API-реестр, совместимый со стандартным форматом файла описания расширения (package.json).

2. Загрузка и публикация расширений одной командой в командной строке (CLI) с проверкой подписи.

3. Веб-интерфейс для поиска, фильтрации и скачивания со страницей для каждого расширения.

4. Микросервис (proxy), обслуживающий клиент редактора для установки и обновления расширений.

5. Базовая автоматическая проверка безопасности (статический анализ + обнаружение подозрительных пакетов) перед публикацией.

6. Аутентификация разработчиков через открытый провайдер идентификации (OAuth/OpenID).

7. Панель управления разработчика: версии, анонимная статистика, жалобы.

8. Открытый воспроизводимый индекс (Mirror) для создания доверенных подписок.

4) Ценообразование и модель монетизации

• Бесплатно для старта: публикация, установка и поиск без ограничений для публичных проектов.

• Уровень «проверенный издатель» (опционально): значок верификации, корпоративные страницы, расширенная статистика — по низкой ежемесячной подписке.

• Приватный реестр для организаций: внутренняя публикация, политики безопасности, интеграция SSO — цена за место.

• Сообщественное спонсорство и опциональная корпоративная поддержка вместо рекламы.

• Бесплатно навсегда для проектов с открытым исходным кодом и образовательных.

5) План глобального распространения через бесплатные каналы

• Запуск на бесплатных площадках технических обсуждений (сообщества редакторов, Reddit, Hacker News).

• Автоматическая миграция в один клик, привлекающая текущих издателей через инструмент импорта.

• Добавление «кнопки публикации» в популярные шаблоны проектов с открытым исходным кодом.

• Открытый образовательный контент и статьи о безопасности цепочки поставок.

• Партнёрства с дистрибутивами открытых редакторов для включения клиента по умолчанию.

• Программа послов и бесплатные награды для первых издателей.

6) Риски (юридические и технические)

• Юридические: вероятность претензий по товарным знакам с названиями редакторов → использование общих терминов и описаний и обезличивание.

• Юридические: ответственность за содержимое расширений → чёткая политика жалоб и удаления и строгие ограничения ответственности в условиях.

• Технические: уязвимости вредоносного ПО → обязательная подпись, многоуровневая проверка и возможность мгновенного отзыва.

• Технические: медленное принятие на фоне существующего рынка → постепенное привлечение, автоматическая миграция и полная совместимость со стандартным форматом.

• Технические: стоимость хостинга и хранения при большом масштабе → CDN, распределённое хранилище и сообщественное финансирование.

7) Предлагаемое название и маркетинговый слоган

Предлагаемое название: Рифад (Rifad)

Маркетинговый слоган: Открытый и нейтральный реестр расширений, работающий с любым редактором, с надёжными источниками и безопасностью прежде всего.
