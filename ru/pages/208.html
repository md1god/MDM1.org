نَبْض (Nabd) — полный план проекта

Все ваши новости в одном месте, с интеллектом на вашем сервере и непримиримой конфиденциальностью.

Полный план реализации нового цифрового проекта: идея, аудитория, продукт, модель монетизации, план продвижения и риски. Проект находится в разработке и ещё не запущен.

План продукта: новостной ридер с самохостингом

1) Целевая аудитория

• Люди, заботящиеся о конфиденциальности: те, кто хочет следить за новостями без рекламного отслеживания и алгоритмов.

• Разработчики и технические команды: те, кому нужен деплой в один клик через Docker на собственном сервере.

• Малые организации и новостные редакции: команды, которые следят за множеством источников и хотят автоматические дайджесты.

• Блогеры и создатели контента: те, кто следит за источниками конкурентов и отраслевыми трендами.

• Пользователи в регионах с цензурой/слабыми сетями: те, кому нужна лёгкая синхронизация и локальные копии.

2) Конкурентные преимущества (почему выбирают наш продукт)

• Локальное ИИ-суммирование с возможностью полностью его отключить, без отправки данных третьим лицам по умолчанию.

• Деплой в один клик: Docker Compose + единый образ, с хранилищем SQLite по умолчанию (без сложной настройки).

• Современный и быстрый интерфейс, работающий как PWA на мобильных, с нативной поддержкой RTL/LTR.

• Опциональная синхронизация между устройствами через собственный сервер пользователя, а не обязательный централизованный аккаунт.

• Система плагинов (Plugins) для безопасных REST-интерфейсов, позволяющая кастомизацию без изменения ядра.

• Полный экспорт/импорт в формате OPML/JSON во избежание привязки к платформе.

3) Объём первой версии (не более 8 задач)

1. Импорт и отслеживание лент RSS/Atom/JSON по ссылке или OPML.

2. Организация источников по категориям и тегам с мгновенным поиском.

3. Чистый интерфейс чтения (список/карточки) с ночным режимом и RTL.

4. Пометка «непрочитано» и локальная синхронизация статуса чтения.

5. Опциональный движок суммирования (локальный или API-ключ, задаваемый пользователем).

6. Сохранение статей для чтения позже и поиск по сохранённому тексту.

7. Деплой в один клик через Docker с автоматическим резервным копированием по расписанию.

8. Базовая многопользовательская аутентификация и простые права доступа.

4) Ценообразование и модель монетизации

• Бесплатно навсегда (Free-to-start): самохостинговая версия с полным набором базовых функций, без ограничения числа источников.

• Облачный план «Pro»: недорогая месячная подписка (≈ 4–6 долларов), включающая управляемый хостинг, синхронизацию между устройствами и суммирование с покрытием затрат.

• План «Team»: цена за место с общим доступом к категориям и панелью статистики.

• Дополнительные источники дохода: добровольная финансовая поддержка, коммерческие лицензии для компаний, которым нужны корпоративные функции, и платные сторонние плагины.

• Принцип: ядро полностью открыто; заработок на удобстве (хостинге), а не на удержании функций.

5) План глобального продвижения через бесплатные каналы

• Сообщества открытого исходного кода: публикация на платформах обмена техническими проектами и форумах самохостинга.

• Публичный репозиторий источников (OPML Packs), готовых по отраслям и языкам, для привлечения новых пользователей.

• Обучающий контент: руководства «Начни за 5 минут» и технические сравнения в блоге продукта и короткие видео.

• Коллективный перевод через открытую платформу перевода для поддержки множества языков и глобального охвата.

• Программа для контрибьюторов: бейджи и бесплатные функции для тех, кто вносит вклад в код и плагины.

• Присутствие в сообществах font-end/self-hosting с живыми демонстрациями (demo instance).

6) Риски (юридические и технические)

• Авторские права: показываем только ссылки и фрагменты, не перепубликуем контент целиком; суммирование сопровождается указанием источника с соблюдением robots/условий использования.

• Конфиденциальность и данные: не собираем данные пользователей в самохостинговой версии, чёткая политика для облачной версии с шифрованием при хранении.

• Зависимость от внешних интерфейсов: избегаем зависимости от одного API для суммирования через абстракцию и мультиподдержку.

• Безопасность: обработка недоверенных входных данных лент (SSRF, инъекции HTML/JS) со строгой очисткой и изоляцией выполнения плагинов.

• Устойчивость: предотвращение чрезмерных запросов через кэширование и соблюдение протоколов управления сканированием.

7) Предлагаемое название и слоган

Предлагаемое название: نَبْض (Nabd)

Слоган: Все ваши новости в одном месте, с интеллектом на вашем сервере и непримиримой конфиденциальностью.
