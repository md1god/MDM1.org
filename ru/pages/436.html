План продукта: карточки для обучения внутри пространства для письма

1) Целевая аудитория

• Студенты и изучающие языки и сертификаты (IELTS, ACCA, медицина…), которые ведут заметки в формате Markdown.

• Исследователи и профессионалы, создающие большую справочную базу знаний и регулярно обращающиеся к ней.

• Пользователи приложений личной организации (Obsidian, Logseq, Notion), ищущие интервальное повторение без ручного копирования и вставки.

• Преподаватели и создатели образовательного контента, готовящие упражнения для своей аудитории.

2) Преимущества (почему выбирают нас)

• Из заметки в карточку автоматически: извлекает вопросы из файлов Markdown напрямую (списки, таблицы, выделенный текст) без ручного преобразования.

• Современный алгоритм интервального повторения (FSRS) вместо старых математических расписаний, с индивидуальной подстройкой под каждого пользователя.

• Local-first и необязательная синхронизация: файлы остаются чистым Markdown на вашем устройстве; нет привязки данных.

• Необязательная генерация карточек ИИ из длинного текста, с проверкой человеком перед сохранением.

• Лёгкое веб- и десктоп-приложение, работающие офлайн, вместо зависимости от внешнего хостинга.

• Бесплатно на старте без лимита базовых карточек; оплата только за продвинутые облачные сервисы.

3) Объём первой версии (максимум 8 задач)

1. Импорт отдельных файлов и папок Markdown, распознавание распространённых форматов вопросов.

2. Быстрый редактор карточек (вопрос/ответ, карточки со списками, верно/неверно).

3. Планировщик FSRS со статистикой запоминаемости.

4. Ежедневный режим повторения: одна карточка на экране, горячие клавиши.

5. Полное локальное хранение + экспорт/импорт JSON и CSV.

6. Необязательная синхронизация через бесплатный аккаунт (шифрование при передаче и хранении).

7. Предварительная генерация карточек из вставленного текста (включается вручную).

8. Одно десктоп-приложение (Electron/Tauri) + веб-версия только для чтения.

4) Ценообразование и модель дохода

• Бесплатно: неограниченное число карточек локально, полное планирование, экспорт в любое время.

• Plus — 5 долларов в месяц: синхронизация на нескольких устройствах, облачное резервное копирование, расширенная статистика.

• Pro — 9 долларов в месяц: генерация карточек ИИ (с честным лимитом использования), академические шаблоны, отчёты эффективности.

• Корпоративный/образовательный тариф: панели управления для учителей и небольших школ, цена за место.

• Первый доход — от подписок; далее расширение за счёт платных шаблонов для авторов контента.

5) План глобального продвижения бесплатными каналами

• Открытый исходный код ядра на GitHub (лицензия MIT) для доверия и привлечения участников.

• SEO и длинные статьи: сравнения инструментов интервального повторения, гайды по Markdown.

• YouTube/TikTok: ролики по 30 секунд, показывающие превращение заметки в карточку.

• Reddit и Discord: участие в сообществах обучения, языков и личной организации.

• Product Hunt и Hacker News на запуске с двуязычной посадочной страницой.

• Партнёрства с авторами образовательного контента: реферальные ссылки и бесплатные аккаунты в обмен на обзоры.

• Бесплатные вебинары с университетами и учебными клубами.

6) Риски (юридические и технические)

• Юридические: соблюдение товарных знаков и паттернов интерфейсов; соблюдение лицензий FSRS и криптографических библиотек; явная политика конфиденциальности (GDPR) для данных синхронизации и запрет обучения ИИ-моделей на данных пользователей без явного разрешения.

• Технические: точность распознавания различных форматов Markdown (может потребоваться расширяемые правила); синхронизация без конфликтов версий; производительность на слабых устройствах; необязательная зависимость от ИИ-интерфейсов, чьи цены могут меняться — должна быть отключаемой.

• Операционные: конкуренция с устоявшимися бесплатными инструментами; решение: фокус на потоке «заметка → карточка» без лишних усилий.
