Qirtas — полный план проекта

Превращаем веб в чистые данные, готовые для AI-агентов, за один запрос.

Полный план нового цифрового проекта: идея, аудитория, продукт, монетизация, продвижение, риски. Проект в разработке, ещё не запущен.

Продуктовый план: платформа извлечения веб-данных для умных агентов

1) Аудитория

• Разработчики AI-приложений и агентов (Agents) и систем RAG, которым нужен чистый веб-контент.

• Небольшие стартапы без желания строить скрапинг и обработку с нуля.

• Команды аналитики и исследований, регулярно собирающие контент с разных сайтов.

• Агентства автоматизации и создатели no-code решений (n8n, Make), ищущие готовую интеграцию.

• Исследователи и академики, которым нужна архивация страниц и источников в структурированном виде.

2) Преимущества (почему выбирают нас)

• Настоящий бесплатный старт: постоянный месячный баланс без карты, хватает для тестов и малого продакшена.

• Результаты для агента: чистый Markdown, JSON по заданной пользователем схеме (Schema), скриншоты при необходимости.

• Дизайн для агентов: асинхронные задачи (Async Jobs), Webhooks, сервер MCP, официальный SDK вместо классического скрапинга.

• Сильная поддержка арабского и языков: направление текста (RTL), диакритика, смешанные языки.

• Прозрачные затраты: счётчик потребления на запрос и кэш (Cache), снижающий повторы и счёт.

• Встроенный комплаенс: robots.txt и политики сайтов по умолчанию, журнал аудита операций.

• Без технологической зависимости: экспорт данных, интерфейс по открытым стандартам, позже — self-hosted для Enterprise.

3) Первая версия (до 8 задач)

1. extract: одна ссылка → чистый Markdown без меню, рекламы и шума.

2. extract с пользовательской JSON-схемой для полей (цена, заголовок, дата…).

3. Рендеринг JavaScript через headless-браузер (Headless Browser) с умным ожиданием загрузки.

4. crawl с ограниченным охватом: обход сайта до заданной глубины и карта ссылок.

5. search: поиск страниц и прямой экстракт лучших результатов.

6. API-ключи, квоты и баланс; простая панель и журнал потребления.

7. Async Jobs + Webhooks + начальный SDK (Python, TypeScript) + сервер MCP.

8. Cache, логи ошибок, авто-повторы, полная документация и примеры.

4) Цены и модель прибыли

• Free: фиксированный месячный баланс (например, 500 операций), низкий rate limit, без карты.

• Pay-as-you-go: оплата по потреблению после Free, за операцию или 1000 страниц.

• Starter / Growth: больше баланса, приоритет обработки, шире лимиты, ниже цена операции.

• Enterprise: договор, индивидуальные лимиты, SLA, счета, опция self-hosted.

• Дополнительно: маркетплейс шаблонов (Templates) с комиссией; платные скриншоты, PDF, сложные таблицы.

• Принципы: понятный единый баланс, перенос остатка на ограниченный срок, скидка за год.

5) Глобальное продвижение бесплатными каналами

• Open-source SDK и CLI на GitHub с примерами и сильным README.

• Сервер MCP в каталогах MCP и магазинах инструментов для агентов.

• SEO-документация, сравнения и руководства «как сделать» для каждого сценария.

• Запуск на Product Hunt, Hacker News, Reddit (r/LocalLLaMA, r/MachineLearning) честно и прозрачно.

• Бесплатные интеграции с LangChain, LlamaIndex, n8n, Make, Zapier.

• Короткие видео на YouTube; уроки на dev.to и Medium.

• Discord и еженедельная рассылка с кейсами и обновлениями.

• Конкурсы, вузовские хакатоны, поддержка open-source (Good First Issues).

6) Риски

Юридические:

• Меняющиеся условия сайтов и авторские права → соблюдение robots.txt, допустимая политика использования, исключения доменов.

• Персональные данные (GDPR/CCPA) → минимизация сбора, отсутствие долгого хранения по умолчанию, инструменты удаления.

• Ответственность пользователя за контент → чёткие условия сервиса и разъяснение допустимого использования.

• Региональные различия → регулярный пересмотр и гибкая блокировка доменов.

Технические:

• Антискрапинг, CAPTCHA, блокировка IP → диверсификация сети, повторы, информирование о лимитах сервиса.

• Дорогой рендеринг JavaScript → умный кэш, облегчённый рендеринг где можно, чёткие лимиты.

• Изменение дизайна сайтов ломает извлечение → гибкие схемы, мониторинговые тесты, оповещения.

• Prompt Injection через веб-контент и загрязнение данных → очистка результатов, маркировка недоверенного контента.

• Уязвимости (SSRF, злоупотребление квотами) → список запрещённых доменов, rate limit, мониторинг аномалий.

• Надёжность и масштабирование → очереди, мониторинг, план восстановления, постепенный рост доступности.
