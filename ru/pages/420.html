LingoLayer — Полный план проекта

Читайте любой сайт на своём языке, сохраняя оригинал поверх.

Полный план реализации нового цифрового проекта: идея, аудитория, продукт, модель монетизации, план продвижения и риски. Проект в разработке и ещё не запущен.

План продукта: расширение для двуязычного перевода и перевода на странице

1) Целевая аудитория

• Читатели, ежедневно следящие за иностранными сайтами (новости, технологии, документация) и желающие читать текст в переводе, не покидая страницу.

• Ученики и изучающие языки, сравнивающие оригинал с переводом, чтобы улучшить язык.

• Пользователи в арабском мире, Китае и Европе, сталкивающиеся со страницами на языке, которым не владеют.

• Авторы контента и исследователи, копирующие фрагменты перевода для работы.

2) Преимущества (почему выбирают нас)

• Перевод на уровне предложений и абзацев с сохранением вёрстки страницы (заголовки, ссылки, таблицы) вместо разрушения макета.

• Возможность скрывать/показывать перевод одним нажатием и режим параллельного сравнения для длительного чтения.

• Свободный выбор переводческого движка (бесплатные облачные движки + локальная модель для приватности).

• Автосохранение вашего собственного глоссария (личный словарь), применяемого на всех страницах.

• Низкое потребление памяти и более быстрая загрузка по сравнению с тяжёлыми решениями; работа без сети с локальными движками.

• Поддержка всех современных браузеров через единый унифицированный интерфейс.

3) Объём первой версии (максимум 8 задач)

1. Разработка расширения на TypeScript + WXT (или напрямую Manifest V3) с поддержкой Chrome, Firefox и Edge.

2. Извлечение текста со страницы (DOM traversal) с выделением абзацев и заголовков и игнорированием скриптов и рекламы.

3. Встраивание перевода под/рядом с оригинальным текстом с настраиваемым CSS.

4. Подключение нескольких переводческих движков (DeepL/Google/LibreTranslate) через единый слой абстракции с управлением API-ключами.

5. Закреплённая панель инструментов: вкл/выкл, смена направления, скрытие перевода, тумблер автоматического перевода.

6. Контекстное меню для ручного перевода выделенного фрагмента страницы.

7. Страница настроек: исходный/целевой язык, режим отображения, локальное хранение терминов (localStorage/IndexedDB).

8. Публикация как бесплатного расширения в официальных магазинах + файл userscript через Greasy Fork + простая посадочная страница.

4) Ценообразование и модель монетизации

• Полностью бесплатно для старта: все базовые функции и локальный движок LibreTranslate без ограничений.

• Необязательная платная подписка (Freemium): тариф Pro за небольшую ежемесячную плату для профессиональных API-ключей через наш proxy, перевода PDF-файлов и синхронизации личного словаря между устройствами.

• Умеренная и чистая реклама (ненавязчивый блок в одном месте) в бесплатной версии по выбору пользователя.

• Открытый исходный код базовой версии для доверия, при сохранении продвинутых функций как коммерческих.

5) Глобальный план распространения через бесплатные каналы

1. Официальные магазины расширений (Chrome Web Store, Firefox AMO, Edge Add-ons) и Greasy Fork — крупнейший источник органических загрузок.

2. Reddit, Hacker News, V2EX: обзорный пост с коротким видео, показывающим перевод на сложной странице.

3. Каналы X, Telegram и YouTube: 60-секундные обзоры на целевых языках (арабский, английский, китайский).

4. Открытая документация и сравнение на GitHub Pages для захвата длинных поисковых запросов (SEO).

5. Партнёрства с создателями языкового образовательного контента и техническими каналами (бартер, без оплаты).

6. Сообщества Discourse и Discord для пользователей, программа Early Explorers с бесплатными бонусами.

6) Риски (юридические и технические)

• Юридические: условия использования коммерческих переводческих API могут запрещать proxy — решение: пользователь вводит ключ локально, по умолчанию используются открытые движки.

• Юридические: загрузка страниц, защищённых авторским правом — оставляем перевод локальным и не храним тексты пользователей на наших серверах.

• Технические: постоянные изменения вёрстки сайтов ломают извлечение текста — решение: распределённые шаблоны разбора для каждого сайта + быстрые обновления.

• Технические: лимиты запросов (Rate Limits) бесплатных движков — слой кэширования и автоматическая маршрутизация между движками.

• Магазинные: отклонение публикации из-за политик рекламы или контента — соблюдение правил магазинов с первого дня.

• Конкурентные: быстрые клонирования конкурентами — сохранение скорости, приватности и личного словаря как защитного барьера.

7) Предлагаемое название и слоган
