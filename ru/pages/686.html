DeepPulse — Полный план проекта

Перезапустите фокус за 25 минут — без интернета, без отслеживания, с умным тренером, подстраивающимся под вас.

Полный план цифрового проекта: идея, аудитория, продукт, бизнес-модель, распространение, риски. Проект в разработке.

1) Целевая аудитория

• Студенты (15-25) в 40+ странах (ES/EN/AR), дистанционно (Coursera/Udemy), отвлечения TikTok/Instagram.

• Удалённые (25-40) в SaaS (Stripe/Notion), теряют 40% дня на context switching по Nielsen Norman Group.

• Фрилансеры по часовой ставке, нужен журнал продуктивности (12-15 счетов/мес).

• Родители (30-45) с детьми (6-12), «часы фокуса» (25-50 мин).

• ADHD (8-10%), нужны внешние опоры (external scaffolding).

• Малые компании (1-20), team focus ≤3$/сотр/мес.

2) Отличия

• Focus OS: таймер + задачи + привычки + blocker + заметки вместо Toggl+Todoist+Freedom+Notion.

• AI Coach: анализ паттернов и расписание (например, «9-11, 50/10 вместо 25/5»).

• Offline-First: 100% локально (SQLite+CRDT), в отличие от Forest/Focus@Will.

• Privacy-First: без telemetry/аккаунта, данные на устройстве; «мы ничего не видим» для GDPR/CCPA.

• Team Focus Rooms: WebRTC + общий таймер + лидерборд (геймификация).

• Cross-Platform Native: KMP+Compose, Android/iOS/Desktop/Web, поддержка на 60% дешевле.

3) Объём первой версии (максимум 8 задач)

1. Timer Engine: Pomodoro (25/5, 50/10, 90/20) + звуки + уведомления.

2. Task List: CRUD + привязка к сессии + «completed today».

3. Habit Tracker: streak, цель «3 сессии/день».

4. Site Blocker: Android (UsageStatsManager + AccessibilityService); iOS Screen Time API.

5. Local Storage + Sync: SQLite + Firebase Auth + cloud sync.

6. Statistics Dashboard: heatmap + «лучший час» + «средний focus/day».

7. Onboarding + Paywall: 3 экрана + trial 7 дней.

8. Landing Page + SEO: Next.js + блог (3 статьи) + Product Hunt.

4) Цены и модель дохода

• Free: 3 сессии/день, timer+tasks+habit (streak≤7) — free-to-start (без карты).

• Pro: 6.99$/мес или 49$/год: неограниченные сессии + blocker + stats + sync + AI Coach (beta).

• Team: 3$/пользователь/мес, мин 3: Focus Rooms + leaderboard + admin + SSO.

• Lifetime: 149$ (первые 1000) — runway.

• Add-ons: sounds 2.99$, themes 1.99$ — импульсные.

• Цель: 1000 платящих к 6 мес → MRR 7k$; безубыточность при 2000 (серверы ~1.5k$/мес).

• Каналы: 60% app stores, 30% web/Stripe, 10% аффилиаты (20%).

5) Глобальный план распространения бесплатными каналами

• Product Hunt (день 1): цель Top 5; 500 upvotes → 5k installs.

• Reddit: 3 поста (кейс «I tracked 1000 hours») + AMA.

• Shorts/TikTok: 30-сек «до/после» (1/день 30 дней) #DeepWork.

• SEO: 2 статьи/нед, цель 10k орг. визитов/мес к 6 мес.

• Open-source: «focus-timer-core» на GitHub → goodwill + backlinks.

• Партнёрства: Notion/Obsidian экспорт → co-marketing.

• Локализация: 7 локалей к 3 мес → 40% не-англ.

6) Риски (правовые и технические)

• Правовые: API screen time Apple/Google (iOS Family Controls 2-4 нед.), GDPR (Plausible + DPA), trademark (USPTO/EUIPO).

• Технические: KMP Compose на iOS (риск) — fallback; Android blocker (AccessibilityService, Play policy).

• Бизнес: «Pomodoro» generic, «Forest» trademark; возвраты 14 дней → chargeback ≤2%.

• Конкуренция: Forest (10M+), Focus@Will; отличие AI Coach + Team Rooms + offline.

• Удержание: D30 25% (индустрия 15%); streak-уведомления + recap email.

• Производительность: батарея blocker (polling) → event-driven (UsageStats) + WorkManager.

7) Предложенное название и маркетинговая фраза

Название: DeepPulse

Маркетинговая фраза: Перезапустите фокус за 25 минут — без интернета, без отслеживания, с умным тренером, подстраивающимся под вас.
