План продукта: Wasla (Васла)

1) Целевая аудитория

· Приоритет · Сегмент · Размер/Потребность ·

· Первый · Малый и средний бизнес доставки (5–50 водителей) на Ближнем Востоке и в Северной Африке · Управляют маршрутами в Excel или на бумаге ·

· Первый · Интернет-магазины, аптеки и рестораны с ежедневной городской доставкой · Заказы меняются в течение дня ·

· Второй · Сервисные и домашние компании (кондиционеры, сантехника, электрика) · Мобильные бригады с фиксированными окнами ·

· Третий · Учебные заведения, благотворительные организации и стартапы в логистике · Ограниченный бюджет ·

Принимающее решение: руководитель операций / владелец компании. Конечный пользователь: водитель.

2) Преимущества (почему выбирают наш продукт)

1. Полный интерфейс с первого дня: клиенту не нужно писать код или подключать серверы — загружает CSV-файл и получает маршрут за две минуты.

2. Мгновенная переоптимизация: новый заказ или задержка водителя → немедленное автоматическое перестроение только оставшихся маршрутов.

3. Контроль человека над решением: диспетчер закрепляет или перетаскивает остановку между водителями, а Solver оптимизирует заново с учётом его ограничений (human-in-the-loop).

4. Реально замкнутый цикл: панель распределения + водительское приложение (PWA работает без интернета) + уведомления, а не просто библиотека алгоритмов.

5. Мощный Solver с открытым ядром: современные алгоритмы (HGS, улучшенный Clarke–Wright) с публикацией части Solver на GitHub для доверия технического сообщества.

6. Ваши данные принадлежат вам: бесплатная Self-Hosted-версия и управляемое облачное решение для тех, кто ценит удобство.

7. Готов к арабскому языку: двуязычный интерфейс и карты, лучше покрывающие улицы арабских городов, чем глобальные альтернативы.

8. Готовые интеграции: Shopify, WooCommerce, Odoo, а также REST API + Webhooks.

3) Объём первой версии (максимум 8 задач)

1. Система пользователей, команд и тарификации (Freemium).

2. Импорт заказов из CSV/Excel с проверкой адресов (Geocoding).

3. Интерфейс оптимизации маршрутов: вместимость, временные окна, максимум времени вождения, один депо.

4. Интерактивная карта (Leaflet + OpenStreetMap) с ручным изменением перетаскиванием.

5. Панель распределения: закрепление остановок, перетаскивание между водителями, быстрая переоптимизация.

6. Водительское PWA-приложение: список остановок, переход в Google/Apple Maps, доставка с подписью, работа Offline с последующей синхронизацией.

7. Открытый REST API + Webhooks (новый заказ, задержка, завершение).

8. Базовая отчётность: время выполнения, эффективность маршрута, ориентировочная стоимость.

Отложено во вторую версию: мультидепо (Multi-depot), транспорт разных типов, прогноз загрузки, интеграция с POS.

5) План глобального запуска через бесплатные каналы

1. Двуязычное SEO: статьи на арабском и английском о «маршрутизации доставки» и «стоимости последней мили» — таргетинг на длинные поисковые запросы.

2. Публикация вычислительного ядра с открытым исходным кодом на GitHub: привлекает разработчиков и конвертирует их в платных пользователей облачной версии.

3. YouTube/TikTok: короткие уроки «из Excel-файла в готовый маршрут за две минуты» на арабском, английском и испанском.

4. Бесплатные запуски: Product Hunt, Hacker News Show HN, Reddit (r/logistics, r/opensource) в один день.

5. Отраслевые сообщества: группы Facebook и LinkedIn для логистических менеджеров в Саудовской Аравии, Египте, ОАЭ, Инд
