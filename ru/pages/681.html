Pro Path — полный план проекта

Создавайте более дешёвые и быстрые потоки ИИ прямо в редакторе за минуты.

Полный план реализации нового цифрового проекта: идея, аудитория, продукт, модель монетизации, план продвижения и риски. Проект находится в разработке и ещё не запущен.

1) Целевая аудитория

• Разработчики начинающих продуктов: небольшие команды из 2–15 разработчиков, которым нужно запустить интеллектуального ассистента или внутреннюю автоматизацию за 4–6 недель и у которых нет специализированной команды по инфраструктуре ИИ.

• Разработчики бэкенда и платформ: создающие SaaS-продукты, такие как поддержка клиентов, семантический поиск и суммирование документов, которым нужно связывать несколько API без переписывания логики при каждом изменении модели.

• Агентства по разработке и консалтингу: обслуживающие 10–30 клиентов в год и нуждающиеся в переиспользуемых шаблонах, отчётах о расходах и единой рабочей среде, чтобы сократить время поставки с дней до часов.

• Команды данных и исследований: тестирующие потоки поиска информации и агентов на частных наборах данных и нуждающиеся в локальном запуске экспериментов перед переносом в облако.

• Разработчики в арабоговорящих и англоговорящих регионах: ищущие понятную документацию и практические примеры на обоих языках и близкий регион размещения, снижающий время отклика до менее 150 миллисекунд в Европе и на Ближнем Востоке.

2) Отличительные преимущества (почему мы выбираем наш продукт)

• Запуск за минуту: одна команда, например pip install flowkit && flowkit init, создаёт готовый проект с 5 шаблонами на арабском и английском вместо ручной настройки десятков библиотек и переменных окружения.

• Умная маршрутизация для снижения стоимости: система автоматически выбирает самую дешёвую и быструю модель для каждой задачи, например использует малую модель для классификации и мощную только для формулирования, что снижает счёт за API на 35–60% во внутренних тестах.

• Визуальная отладка внутри редактора: показывает каждый шаг потока со временем выполнения, количеством токенов и оценочной стоимостью и позволяет перезапустить один шаг без повторного выполнения всего потока.

• Локальный запуск в первую очередь: работает на персональном компьютере или небольшом сервере с 8 ГБ памяти, с возможностью отделения конфиденциальных данных от облачных сервисов, что важно для здравоохранения, юридических и финансовых компаний.

• Фиксированный контракт между узлами: каждый узел имеет задокументированные входы и выходы в формате JSON Schema, что снижает число ошибок интеграции, обычно возникающих из-за разных имён полей у провайдеров.

• Готовые шаблоны вместо пустой страницы: предоставляется 20 шаблонов для таких задач, как ответы на тикеты, поиск по документам, перевод контента и заполнение форм, каждый шаблон можно изменить и экспортировать.

3) Объём первой версии (не более 8 задач)

• Расширение для VS Code и интерфейс командной строки: для создания, запуска, отладки и тестирования потоков из среды разработки, с поддержкой Windows, macOS и Linux.

• Лёгкое исполнительное ядро, написанное с нуля: на Python с интерфейсом TypeScript, поддерживает параллельное выполнение, тайм-ауты и повторные попытки — максимум 3 попытки на шаг.

• Только 25 основных узлов: включая вызовы, условия, циклы, извлечение текста, таблицы, файлы, запросы HTTP, электронную почту и реляционные базы данных.

• 8 провайдеров языковых моделей: с единым слоем перевода между их интерфейсами, поддержкой нескольких ключей API для каждой команды и скрытием конфиденциальных значений в логах.

• 4 векторные базы данных: PostgreSQL с pgvector, Qdrant, Chroma и FAISS локально, с единым интерфейсом поиска, возвращающим результаты в отсортированном виде с указанием источников.

• Отслеживание, анализ и развёртывание: запись каждого запуска с затратами, временем и ошибками, экспорт в один файл и развёртывание через Docker Compose в один шаг, при этом мультиагенты и полный графический интерфейс откладываются до второй версии.

4) Ценообразование и модель монетизации

• Бесплатный план: для индивидуальных разработчиков, включает 3 проекта, 10 000 выполнений в месяц и все базовые шаблоны, работает локально без ограничения по времени, с целью создания широкой базы пользователей.

• План «Профессиональный»: 19 долларов в месяц за разработчика, включает безлимитные проекты, 100 000 выполнений, умную маршрутизацию затрат, ежемесячные отчёты и поддержку в течение 24 часов.

• План «Команда»: 49 долларов за пользователя в месяц при годовой оплате, включает общие рабочие пространства, роли и права, журнал аудита, интеграцию с платёжными шлюзами и системам
