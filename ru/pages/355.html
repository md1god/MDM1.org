Накы — полный план проекта

Простое управление контентом для статических сайтов прямо из репозитория.

Полный план реализации нового цифрового проекта: идея, аудитория, продукт, модель монетизации, план продвижения и риски. Проект в разработке и ещё не запущен.

1) Целевая аудитория

• Разработчики статических сайтов: те, кто использует Git как источник контента и хочет упростить его редактирование.

• Контент-команды: например, команды маркетинга или редакторы, которые хотят обновлять контент без глубоких знаний программирования.

• Малые проекты: некоммерческие организации, школы и молодые продукты, которым нужно недорогое и быстрое управление контентом.

2) Преимущества (почему выбирают наш продукт)

• Очень простой: понятный интерфейс, созданный специально для не-разработчиков, с минимальным количеством шагов.

• Безопасный и построенный на Git: каждое изменение сразу сохраняется в репозитории, а любую правку легко проверить.

• Работает отовсюду: поддержка Self-hosted-развёртывания наряду с лёгкой версией SaaS, с акцентом на свободу пользователя.

• Широкая совместимость: поддержка самых популярных генераторов статических сайтов и простое добавление новых.

• Лёгкий и быстрый: упрощённая архитектура, ориентированная на высокую скорость даже с большими репозиториями.

3) Объём первой версии (максимум 8 задач)

1. Аутентификация: безопасное подключение к популярным провайдерам Git.

2. Просмотр контента: навигация по файлам сайта и структура по папкам.

3. Умный редактор: простой редактор Markdown с поддержкой пользовательских полей и предпросмотром.

4. Управление медиа: загрузка изображений и файлов с организацией внутри репозитория.

5. Безопасное сохранение: автоматическое создание pull request на каждое изменение ради сохранения процесса ревью.

6. Простые права доступа: понятные уровни доступа (администратор, редактор, читатель).

7. Базовая поддержка: три самых популярных генератора статических сайтов.

8. Готовность к развёртыванию: единый конфигурационный файл и Docker-образ для простого запуска.

4) Ценообразование и модель монетизации

• Бесплатный старт: self-hosted-версия полностью бесплатна, а ограниченная по использованию SaaS-версия тоже бесплатна.

• Freemium-модель: ежемесячные подписки на SaaS-версию для команд, которым нужно больше места хранения, больше пользователей или дополнительные функции совместной работы.

• Ориентация на ценность: доход только от hosted-сервиса, при этом self-hosted-версия остаётся полностью свободной.

5) План глобального продвижения через бесплатные каналы

• Подробная документация: создание руководства на арабском и английском языках и бесплатная публикация.

• Образовательный контент: короткие статьи о том, как управлять контентом статического сайта без технического бэкграунда.

• Сообщества разработчиков: участие в сообществах генераторов статических сайтов, а также на Reddit и Dev.to.

• Короткие соцсети: публикация коротких обучающих видео на YouTube Shorts, TikTok и LinkedIn.

• Шаблоны с открытым исходным кодом: сотрудничество с разработчиками ради публикации шаблонов, использующих продукт, для органического роста видимости.

6) Риски (юридические и технические)

• Юридические: полное соблюдение лицензий используемых библиотек, уважение конфиденциальности пользователей, гарантия сбора только необходимых данных.

• Технические: защита ключей доступа, безопасность загрузки файлов, обработка конфликтов правок, совместимость с изменениями провайдеров Git и поддержание хорошей производительности с большими репозиториями.

7) Предлагаемое название и слоган

Предлагаемое название: Накы

Слоган: Простое управление контентом для статических сайтов прямо из репозитория.
