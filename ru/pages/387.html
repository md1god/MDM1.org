Равак — полный план проекта

Вся ваша библиотека в одном месте — с вашего сервера на любой экран.

Полный план реализации нового цифрового проекта: идея, аудитория, продукт, модель монетизации, план распространения и риски. Проект находится в разработке и ещё не запущен.

1) Целевая аудитория

• Отдельные организованные пользователи: те, у кого на устройствах тысячи файлов (PDF, CBZ/CBR, EPUB, изображения) и кто хочет иметь быструю и упорядоченную библиотеку.

• Семьи и небольшие группы: 2–10 человек, желающие безопасно и бесплатно делиться своей личной библиотекой.

• Создатели и поставщики легального контента: небольшие издательства, писатели, преподаватели, желающие представить свои работы ограниченной аудитории.

• Образовательные сообщества и клубы по чтению: небольшие цифровые библиотеки в школах и книжных клубах.

• Недостаточно охваченная арабоязычная аудитория: читатели, нуждающиеся в полноценном арабском интерфейсе (RTL), с возможностью текстового поиска по отсканированным файлам.

2) Ключевые преимущества (почему стоит выбрать наш продукт)

1. Сначала арабский язык: полноценный RTL-интерфейс, нумерация страниц справа налево, полная поддержка арабских обложек и метаданных — не просто постперевод.

2. Локальный интеллект без облака: рекомендации, классификация по жанрам и генерация обложек выполняются полностью на устройстве пользователя (on-device), без передачи данных наружу.

3. Поиск по изображениям: опциональный OCR для арабского/английского языков в отсканированных файлах с лёгким текстовым индексированием.

4. В первую очередь — чтение: ночной режим, разделение страниц, горизонтальный/вертикальный скролл, оффлайн-чтение с автоматической синхронизацией прогресса.

5. Всё в одном: один Docker-контейнер или встроенное десктопное приложение, которое одновременно работает как сервер и интерфейс — без сложной сетевой настройки.

6. Конфиденциальность в основе: обмен через временные и отменяемые пригласительные ссылки, тонкие права для каждого пользователя.

7. Действительно лёгкий: время открытия менее секунды даже для библиотек свыше 100 000 элементов (фоновая поэтапная индексация).

8. Цена: настоящая бесплатная версия с полным набором для личного и семейного использования, а не временный пробный период.

3) Объём первой версии (максимум 8 задач)

1. Импорт библиотеки из единой папки с поддержкой PDF, CBZ/CBR, EPUB, PNG/JPG.

2. Автоматическая индексация с извлечением названия, автора и количества страниц прямо из файла (без подключения к интернету).

3. Встроенный ридер: горизонтальный/вертикальный скролл, ночной режим, режим двух страниц, сохранение позиции чтения.

4. Совместный доступ к библиотеке по пригласительной ссылке с правами (только чтение / чтение + управление).

5. Синхронизация прогресса чтения между несколькими устройствами через прямую дифференциальную синхронизацию.

6. Развёртывание одним Docker-контейнером + единым десктоп-приложением (Windows/macOS/Linux).

7. Полностью арабский интерфейс (RTL) с поддержкой английского, мобильная верстка в приоритете.

8. Текстовый поиск внутри файлов с опциональным включением OCR для построения индекса.

4) Ценообразование и модель монетизации

• Бесплатно навсегда (Free-to-start): один сервер, до 3 пользователей, до 5 000 элементов, все базовые функции чтения.

• Pro — 4$/мес. или 36$/год: неограниченный совместный доступ, OCR, облачное резервное копирование, кастомные интерфейсы.

• Home Lab — разовая оплата 79$: бессрочная лицензия на одно устройство со всеми возможностями Pro.

• Команда/Организация — 12$/пользователь/мес.: расширенные права, журналы активности, собственный домен.

• Дополнительные источники дохода: опциональный управляемый хостинг для тех, кто не хочет запускать свой сервер, + пожертвования через GitHub Sponsors.

• Принцип: базовый функционал никогда не блокируется — оплата покупает удобство и объём, а не право на чтение.
