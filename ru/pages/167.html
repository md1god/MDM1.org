Mnemos — полный план проекта

Ваш умный помощник на вашем устройстве: приватная память, мощные инструменты и ноль данных без вашего разрешения.

Полный план реализации нового цифрового проекта: идея, аудитория, продукт, модель монетизации, план продвижения и риски. Проект находится в разработке и ещё не запущен.

Оригинальная продуктовая идея: локальный умный помощник «Mnemos»

1) Целевая аудитория

• Люди, заботящиеся о приватности: разработчики, исследователи, журналисты, врачи, юристы, работающие с чувствительными данными, которые нельзя отправлять в чужое облако.

• Нетехнические пользователи, которым нужен умный помощник, работающий локально, без опыта запуска серверов или настройки Ollama.

• Небольшие команды и компании с регуляторными ограничениями, политика которых запрещает вывод данных за пределы устройства (здоровье, право, финансы).

2) Ключевые преимущества (почему выбирают нас)

• Установка в один клик: десктопное приложение автоматически готовит модель и память без ручной настройки.

• Проверяемая приватность: сетевой выключатель (kill switch) по умолчанию блокирует любое внешнее соединение без явного согласия, с видимым журналом.

• Зашифрованное хранилище памяти + граф знаний: быстрый гибридный семантический поиск и сквозное шифрование при синхронизации.

• Нейтральный провайдер: работает с любой локальной или облачной моделью, с авто-переключением при недоступности.

• Безопасное выполнение: песочница для команд и браузинга, права для каждого инструмента и полный журнал аудита.

• Нативная поддержка арабского: интерфейс RTL, понимание диалектов и точное арабское резюмирование.

3) Объём первой версии (не более 8 задач)

1. Локальный чат с переключением между провайдерами (локальными или облачными).

2. Зашифрованное личное хранилище памяти + граф знаний и семантический поиск.

3. Импорт источников (ссылки, PDF, заметки) с документированными цитатами.

4. Голосовые команды и простое зрение (OCR и описание изображения) локально.

5. Планирование повторяющихся задач (напоминания, ежедневная сводка).

6. Автоматизация браузера и терминала внутри песочницы с правами и журналом аудита.

7. Каналы связи (Telegram/Signal) для безопасного удалённого доступа.

8. Краткая панель здоровья (сон/вода/активность), интегрируемая в память без медицинской диагностики.

4) Ценообразование и модель монетизации

• Бесплатно навсегда локально: все базовые функции, без аккаунта и без лимита использования.

• Pro: зашифрованная синхронизация между устройствами + мобильные приложения + резервное копирование — 6$/месяц или 60$/год.

• Команда: общий доступ к хранилищу знаний с правами + SSO и администратор — 12$/пользователь/месяц.

• Дополнительная выручка: магазин плагинов с комиссией и опциональный облачный хостинг по модели bring-your-own-key.

• Незыблемые принципы: не продаём данные, не показываем рекламу, не обучаем на данных пользователя.

5) План глобального продвижения через бесплатные каналы

• Open-source базовой версии на GitHub для завоевания доверия разработчиков и привлечения вкладов.

• Многоязычное SEO/AEO: страница для каждого сценария использования (приватность, журналистика, исследования, здоровье) на арабском и английском.

• Технические сообщества: r/LocalLLaMA, r/selfhosted, запуск «Show HN» и Product Hunt.

• Короткое видео: YouTube/Shorts/TikTok «Установи своего помощника за минуту».

• Сообщество Discord/Telegram + двуязычная документация + включение в Awesome self-hosted и списки приватности.

• Реферальная программа: месяц Pro бесплатно за успешное приглашение.

6) Риски (юридические и технические)

Технические:

• Слабая производительность моделей на скромном железе → рекомендации по железу + облачный режим.

• Разброс между провайдерами моделей → единый слой абстракции для чата и инструментов.

• Инъекция команд (prompt injection) через браузинг/файлы → песочница, подтверждения и журнал аудита.

• Конфликты синхронизации в зашифрованном хранилище → CRDT со сквозным шифрованием.

Юридические:

• Соблюдение GDPR/CCPA: управление согласиями, право на удаление и экспорт.

• Лицензии моделей, импортируемых данных и авторские права.

• Функции здоровья: явный медицинский отказ от ответственности, запрет диагностики и назначения лекарств, соблюдение локальных норм.

• Ответственность за автоматизированные команды и злоупотребление → границы прав и безопасные настройки.

7) Предлагаемое название и маркетинговый слоган

Предлагаемое название: Mnemos

Маркетинговый слоган: Ваш умный помощник, живущий на вашем устройстве: приватная память, мощные инструменты и ноль данных, покидающих устройство без вашего разрешения.
