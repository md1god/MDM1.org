ContextDock — полный план проекта

Создавайте, тестируйте и разворачивайте серверы MCP за минуты — безопасно и без сложной инфраструктуры.

Полный план нового цифрового проекта: идея, аудитория, продукт, модель монетизации, продвижение и риски. Проект в разработке, ещё не запущен.

План продукта: платформа для создания, тестирования и развертывания серверов MCP

1) Целевая аудитория

• AI-инженеры, создающие серверы Model Context Protocol для связи моделей с базами данных и внутренними системами.

• Компании SaaS, открывающие свои продукты умным моделям через MCP без большой команды Infra.

• Независимые разработчики и сообщества Open Source, публикующие инструменты MCP и желающие быстро их тестировать и делиться.

• Команды DevOps и Security, которым нужны мониторинг и документирование внутренних серверов MCP.

2) Преимущества (почему выбирают нас)

• Среда симуляции: эмуляция Claude, ChatGPT и локального клиента без внешних API-ключей, с логом каждого вызова (prompt/tool call) для диагностики.

• Автопроверка безопасности: чрезмерные полномочия, утечки данных в tool description и недоверенные input scopes.

• Auth Kit: OAuth 2.1 и OIDC, готовые переносимые ключи, генерируемые в один клик.

• Развёртывание в один клик: Docker image или управляемое размещение в глобальной сети с HTTPS и журналами.

• Визуальные Workflows: связывание инструментов в логический маршрут (orchestration) без кода, экспорт маршрута в код TypeScript/Python.

• Максимальная гибкость: полностью бесплатный Self-host наравне с управляемым облаком, в отличие от тех, кто навязывает только облако.

3) Объём первой версии (до 8 задач)

1. Генератор проектов (scaffold) серверов MCP на TypeScript и Python из готовых шаблонов.

2. Локальная среда запуска и симуляции с веб-интерфейсом для проверки инструментов.

3. Живой журнал вызовов (request/response logs) с фильтрами и поиском.

4. Автоматические тесты: запуск набора тестов (test suite) на инструментах и проверка схем (JSON Schema).

5. Базовая проверка безопасности + экспортируемый отчёт.

6. Auth Kit: генерация конфигураций OAuth/API-ключей в один клик.

7. Развёртывание в один клик (публичный Docker + простое управляемое размещение) с бесплатным поддоменом.

8. Публикация проекта по публичной ссылке: документация и статусы тестов (галерея развёртываний).

4) Тарифы и модель монетизации

• Бесплатно для старта: неограниченные локальные проекты, полностью открытый Self-host и размещение на общем поддомене.

• Pro — 19$/мес. для разработчика: собственный домен, более длительные журналы, расширенная проверка безопасности и управляемое размещение с разумными лимитами.

• Team — 49$/участник/мес.: общие рабочие пространства, роли и права доступа, ревью Pull Request для документации и настроек.

• Enterprise: Self-host внутри сети клиента, SSO, соглашения об уровне сервиса и выделенная поддержка.

• Доп. источники дохода: профессиональные шаблоны сообщества (Marketplace с комиссией 20%) и аудит безопасности.

5) План глобального продвижения через бесплатные каналы

• GitHub: лёгкий open source шаблон MCP, связанный с платформой, с вкладами сообщества.

• GitHub Topics и Awesome-MCP: включение шаблонов в известные списки MCP.

• X и LinkedIn: серия коротких роликов «Создайте сервер MCP за 5 минут».

• Reddit и Hacker News: публикация Show HN и обмен опытом DevOps.

• YouTube и Twitch: прямые трансляции по созданию, тестированию и развёртыванию сервера MCP.

• Открытый Discord: сообщество разработчиков с каналами поддержки и обмена шаблонами.

• Dev.to, Medium и внутренний блог: кейсы и сравнения (типичные ошибки в серверах MCP).

• Митапы и конференции DevOps и AI: бесплатные доклады о безопасности умных инструментов (MCP Security).

• Партнёрская программа: вознаграждения за привлечение клиентов.

6) Риски (юридические и технические)

• Юридические: соблюдение условий использования платформ умных моделей при предоставлении совместимых шаблонов; соблюдение норм защиты данных (GDPR) в журналах вызовов; ограничение ответственности при публикации списков инструментов с чувствительным контентом.

• Технические: быстрые изменения протокола MCP — решение через слой совместимости (compatibility layer) и закреплённые версии шаблонов; надёжная изоляция (sandboxing) клиентского кода инструментов; uptime управляемых серверов с планом миграции на Self-host.

• Конкурентные: выход крупных облачных платформ с похожими версиями — наше преимущество: опыт тестирования/безопасности и открытое сообщество.
