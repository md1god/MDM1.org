Miqyas — plan de proyecto completo

Una única métrica fiable que llega a cada panel y a cada agente de IA.

Plan completo de ejecución de un nuevo proyecto digital: idea, público, producto, modelo de ingresos, difusión y riesgos. El proyecto está en construcción y aún no se ha lanzado.

1) Público objetivo

• Equipos de datos y analítica de startups y empresas medianas con uno o más almacenes de datos.

• Ingenieros de datos y analistas de BI que sufren definiciones duplicadas de métricas y cifras inconsistentes entre paneles e informes.

• Equipos de producto e IA que construyen agentes LLM o analítica integrada y necesitan una capa semántica fiable.

• Desarrolladores que quieren integrar analítica sin duplicar lógica de negocio.

2) Puntos diferenciales (por qué elegir nuestro producto)

• AI-first: capa semántica para agentes vía MCP y API, no solo una capa BI tradicional.

• Inicio rápido: métricas definidas en minutos con YAML o interfaz visual, sin reconstruir modelos.

• Fuente única de verdad: una definición de métrica para paneles, informes y agentes de IA, con versiones y trazabilidad.

• Gobernanza práctica: permisos granulares, auditoría y linaje de datos claro.

• Independiente del almacén: funciona sobre PostgreSQL, BigQuery, Snowflake y DuckDB sin dependencia de proveedor.

• Gratis para empezar: núcleo de código abierto y autoalojamiento, con capa de nube opcional.

3) Alcance de la primera versión (máximo 8 tareas)

1. Motor de definición de métricas y dimensiones en YAML con versiones y cambios seguros.

2. Conectores de lectura iniciales: PostgreSQL, BigQuery, Snowflake, DuckDB.

3. Interfaz de consulta unificada: REST + GraphQL + endpoint SQL + servidor MCP para agentes.

4. Catálogo de búsqueda y documentación automática de métricas con linaje.

5. Permisos por métrica y columna, y auditoría.

6. Generador de SQL seguro con caché y agregaciones previas simples.

7. Integración ligera de paneles y SDK JavaScript.

8. Demo gratuita con datos de ejemplo y configuración guiada paso a paso.

4) Precios y modelo de ingresos

• Gratis permanente: núcleo de código abierto para autoalojamiento, sin límite de métricas.

• Cloud Free: un proyecto, 3 usuarios y generoso límite mensual de consultas, para probar y adoptar.

• Pro: suscripción mensual por usuario con permisos avanzados, copias de seguridad y soporte.

• Scale: precio por uso de consultas y analítica embebida, con SLA y despliegue privado opcional.

• Enterprise: contratos anuales con SSO, auditoría avanzada, aislamiento de red y soporte dedicado.

• El ingreso principal viene de suscripciones en la nube y del uso, no de vender datos.

5) Plan de difusión global con canales gratuitos

• Publicar el núcleo en GitHub con documentación abierta, licencia clara y comunidad de colaboradores.

• Posicionamiento en buscadores con guías técnicas, comparativas y casos de uso.

• Incluir el servidor MCP en directorios abiertos de herramientas de IA y comunidades técnicas.

• Vídeos breves en YouTube y plataformas para desarrolladores sobre cómo resolver la inconsistencia de métricas.

• Participar en comunidades especializadas de dbt, Slack y Reddit con respuestas útiles, no anuncios.

• Programa de embajadores y recompensas para colaboradores, y hackatones virtuales gratuitos.

• Contenido paralelo en árabe e inglés para atraer al mercado de MENA y luego expandirse globalmente.

6) Riesgos (legales y técnicos)

• Legales: respetar licencias de código abierto, no copiar código ni marcas registradas y revisar la propiedad intelectual antes de lanzar.

• Legales: cumplir GDPR y CCPA, acuerdos de procesamiento de datos y gestión de secretos de conexión a almacenes.

• Legales: condiciones de proveedores de nube y plataformas de IA, y aclarar que las salidas de IA no son asesoramiento financiero ni jurídico.

• Técnicos: diferencias de dialectos SQL entre almacenes, resueltas con una capa de conversión y pruebas de contrato.

• Técnicos: rendimiento de consultas grandes, con caché, agregaciones previas y límites claros.

• Técnicos: desviación de definiciones de métricas, con versiones, revisión y alertas.

• Técnicos: seguridad de agentes y prevención de inyección de instrucciones, con permisos de solo lectura, filtrado de consultas y auditoría completa.

7) Nombre propuesto y eslogan

Nombre propuesto: Miqyas

Eslogan: Una única métrica fiable que llega a cada panel y a cada agente de IA.
