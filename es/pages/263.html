معيار — Plan de proyecto completo

Respuestas contables documentadas con fuentes en segundos, gratis para todo profesional.

Plan de ejecución completo para un nuevo proyecto digital: idea, público objetivo, producto, modelo de negocio, plan de difusión y riesgos. El proyecto está en construcción y aún no ha sido lanzado.

1) Público objetivo

• Contadores públicos autorizados y auditores con licencia (usuario principal).

• Asesores fiscales y responsables de cumplimiento financiero en empresas.

• Estudiantes de contabilidad y auditoría que se preparan para certificaciones profesionales (CPA / ACCA / CMA).

• Firmas de contabilidad y auditoría (como clientes empresariales futuros), que serán quienes paguen.

2) Puntos diferenciadores (por qué elegimos este producto)

• Respuestas documentadas con fuentes primero: cada respuesta incluye el texto de la norma, el número del artículo, la fuente oficial y un enlace para verificarla, sin una caja negra.

• Gratis para el profesional con licencia: no cobramos al usuario final, lo que permite una rápida difusión dentro de la profesión.

• Diseñado para una sola profesión: terminología contable, estados financieros y revelaciones, no un asistente genérico superficial.

• Cobertura normativa regional: integra las leyes fiscales locales con las normas internacionales, algo que las herramientas generales no logran.

• Neutralidad declarada: los anuncios no influyen en las respuestas, con una separación explícita entre el contenido pagado y el resultado.

• Listo para la integración: API para empresas y para programas de gestión de despachos.

3) Alcance de la primera versión (máximo 8 tareas)

1. Plantear una pregunta y obtener una respuesta con citas verificables (texto de la norma + número del artículo).

2. Búsqueda semántica en normas y legislación (IFRS, normas de auditoría ISA, normativas locales).

3. Resumen de documentos profesionales (contratos, estados financieros, informes) y extracción de obligaciones.

4. Comparación entre dos normas o dos tratamientos, con una tabla de diferencias.

5. Ayuda para preparar revelaciones, estados financieros y borradores de notas.

6. Alertas sobre actualizaciones normativas y cambios en las normas.

7. Cuentas de usuario y verificación de la licencia profesional.

8. Panel interno para analizar las preguntas más frecuentes y mejorar la cobertura.

4) Precios y modelo de ingresos

• Gratis para siempre para profesionales y técnicos con licencia.

• Publicidad contextual premium: de proveedores de software contable y empresas de formación, sin distorsionar las respuestas.

• Formación continua (CPE) patrocinada: los cursos patrocinados pagan por acceder a un público profesional cualificado.

• Contratos empresariales y API para firmas y auditorías (suscripción anual, mayor margen).
