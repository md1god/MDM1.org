MDM1 · Plan de projet

Nabih — plan de projet complet

Un agent vocal qui comprend votre dialecte, répond à vos appels et transforme chaque appel manqué en rendez-vous ou prospect.

Projet numérique en construction, non lancé : idée, public, produit, modèle économique, diffusion, risques.

Produit : agent d'accueil vocal pour petites entreprises

1) Public cible

• Cœur : PME de services (1–20 salariés) dépendant des rendez-vous : dentaires, dermatologie, salons, dépannage, vétérinaires, avocats, immobilier.

• Douleur : 20–40 % d'appels manqués hors horaires ou en occupation → rendez-vous et clients perdus.

• Marchés : Golfe, Égypte, Levant (arabe), puis Espagne/Amérique latine, Asie du Sud-Est, États-Unis/Canada (services locaux).

• Acheteur : propriétaire/directeur, sans informatique, budget ni équipe technique.

• Achat : recherche directe, recommandation sectorielle ou consultant marketing/Twilio.

2) Différenciation

• 5 min : import URL/PDF, test chat/voix avant publication.

• Essai gratuit : numéro test, simulateur complet, sans carte ni engagement.

• Arabe natif : dialectes Golfe, égyptien, levantin, bascule arabe-anglais ; pas de traduction littérale.

• Modèles verticaux : dentaire, salon, dépannage ; pas d'agent à créer.

• Résultat : rendez-vous confirmé ou prospect enregistré, relance SMS/WhatsApp.

• Bring Your Own Twilio : numéro et compte utilisateur ; coût marginal réduit, démarrage quasi gratuit.

• Transparence : transcription, résumé, journal, consentement à l'enregistrement, humain immédiat.

• Prix à l'usage, sans siège, frais d'installation ni engagement.

3) Première version (8 tâches maximum)

1. Agent depuis modèle vertical : formulaire 4 étapes (secteur, horaires, ton, transfert), modifiable.

2. Import : URL, FAQ, PDF/texte, sources visibles, citations corrigées.

3. Twilio : SID/Token, achat/connexion d'un numéro, essai gratuit limité.

4. Simulateur : chat/voix, scénarios prêts (prix, réservation, réclamation, transfert).

5. Réception/prospects : réponses issues de la base, collecte nom, téléphone, motif, consentement, résumé.

6. Google Calendar (lecture/écriture) : anti-conflit, confirmation et rappel SMS/WhatsApp.

7. Transfert humain si demande/incompréhension ; enregistrement/transcription consentis.

8. Dashboard : appels, transcription, résumé, statut, export CSV, Webhook/e-mail immédiat.

Lancement : 20 appels réels, >90 % capturés, 30 % en rendez-vous/prospect.

4) Tarification et revenus

• Free : 0 $, 30 min/mois, numéro test, Twilio utilisateur, logo — essai.

• Starter : 19 $/mois, 120 min, numéro géré, 1 calendrier, SMS — indépendant.

• Growth : 49 $/mois, 400 min, 3 comptes, Webhook, rapports, transfert — cabinet.

• Agency : 149 $/mois, 1 200 min, 10 clients, White-label, API — agences.

• Au-delà : 0,12–0,15 $/min, transparent.

• Revenus : abonnements, marge (Twilio/STT/TTS/LLM), numéros, modèles, installation/migration.

• Free-to-start : sans carte ni installation ; coût marginal quasi nul (Twilio utilisateur).

• -20 % annuel ; crédit parrainage/client payant.

5) Diffusion mondiale gratuite

• SEO programmatique : pages secteur × ville/langue (ex. dentistes à Dubaï), comparatifs, guides, hreflang.

• Outils gratuits : calculateur d'appels manqués, générateur de scénario, testeur de numéro ; e-mails/backlinks.

• Lancements : Product Hunt, AlternativeTo, G2/Capterra, GitHub, Indie Hackers.

• Communautés : Reddit, Facebook local, forums immobiliers ; valeur, pas publicité.

• Vidéos : YouTube Shorts, TikTok/Instagram, « appel réel avant/après » en arabe, anglais, espagnol.

• Partenariats : consultants Twilio, indépendants, chambres de commerce ; parrainage 20 % plutôt que publicités.

• Interne : modèles, parrainage, « mois gratuit contre témoignage », rapport trimestriel presse locale.

6) Risques juridiques et techniques

Juridiques :

• Enregistrement : double consentement si requis ; GDPR : base légale et transparence. → avis vocal, désactivé par défaut sur marchés sensibles, conservation courte.

• IA : divulgation des bots (Californie), AI Act européen. → annonce automatisée dès 5 secondes.

• Données : GDPR, CCPA, lois du Golfe, patients (HIPAA/BAA). → pas de santé américaine sans BAA ; stockage UE/région.

• Sortants : TCPA, STIR/SHAKEN, anti-fraude. → pas de marketing sortant en première version ; numéros vérifiés.

• Paiements : pas de carte par téléphone dans le MVP (PCI).

• Twilio : conditions et prix ; couche d'abstraction pour fournisseur alternatif.

Techniques :

• Latence/coupures audio → streaming/STT-TTS rapide, timeouts, transfert immédiat.

• Dialectes/bruit → modèles multiples, tests, escalade humaine si confiance faible.
