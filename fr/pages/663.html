Namq — plan de projet complet

Faites construire par les agents de codage des interfaces qui ressemblent à des humains, pas à des modèles.

Plan complet d'un nouveau projet numérique en construction, non lancé : idée, public, produit, revenus, diffusion, risques.

1) Public cible

• Développeurs front-end générant vite des pages d'atterrissage avec Claude Code, Cursor ou Codex, et voulant un contrôle qualité design automatique.

• Petites équipes/startups à identité visuelle distinctive, sans équipe design complète.

• Agences design/développement livrant des sites clients, sans rendu « généré par l'IA ».

• Ingénieurs qualité/DevOps voulant vérifier le design en CI avant déploiement.

• Enseignants et créateurs techniques intéressés par la qualité des interfaces web.

2) Différenciation

• Évaluation déterministe et explicable : chaque infraction a une règle claire et une preuve visuelle, pas une opinion.

• Lié à l'identité, pas au goût général : « contrat de design » par marque (couleurs, polices, espacements, ton).

• Compatible avec tout agent de codage : pack de compétences + CLI autonome, sans fournisseur imposé.

• Vérifie le rendu réel : DOM, CSS et captures d'écran, pas seulement le code source.

• Corrige, ne critique pas : suggestions applicables avec exemples de code alternatifs.

• Gratuit et open source : adoption et confiance communautaire rapides.

• Sans « empreinte de générateur » : règles de zéro, identité produit et langage design indépendants.

3) Périmètre v1 (8 tâches max.)

1. CLI open source au nom du produit, via npx, avec compétences installables dans Claude Code, Cursor et Codex.

2. Moteur YAML/JSON déterministe : 60 règles en 6 catégories — mise en page, typographie, couleur, espacements, composants, animation.

3. Détecteur de clichés : dégradés violets par défaut, angles excessifs, ombres gonflées, icônes surexploitées, textes génériques.

4. Analyseur Playwright : contraste, hiérarchie visuelle, grille, polices, espacements réels.

5. Score de 0 à 100, preuves visuelles (capture + coordonnées de l'élément) et corrections copiables.

6. Intégration CI/GitHub Action : échec du build sous un seuil qualité, rapport concis dans la PR.

7. Contrat de design par projet : Design Tokens, exceptions autorisées, un seul fichier de configuration.

8. Comparaison avant/après et aperçu navigateur pour montrer l'effet des corrections.

4) Tarification

• Gratuit (Free forever) : CLI, compétence, 60 règles, usage local illimité. Open source Apache 2.0.

• Pro — 12 $/mois : rapports cloud, comparaisons historiques, packs de règles personnalisés, analyse multi-projets.

• Team — 29 $/siège/mois : contrats de design partagés, historique CI, autorisations, Slack.

• Enterprise — sur mesure : on-prem, SSO, audit, support prioritaire.

• Revenus additionnels : marketplace de règles payantes, minutes CI supplémentaires, conseil en audit design.

5) Diffusion mondiale gratuite

• GitHub + npm : dépôt open source, versions régulières, README avant/après.

• Marketplaces de compétences : publication dans annuaires et communautés Claude Code, Cursor, Codex.

• Product Hunt et Hacker News : comparaison visuelle forte entre page « AI slop » et page soignée.

• YouTube, X, TikTok : vidéos de 30 s « avant/après » avec le score.

• Articles SEO : « Comment empêcher les interfaces d'IA de paraître génériques » et guides pratiques.

• Discord, Reddit, dev.to : communautés dev/design, copies gratuites pour équipes open source.

• Partenariats modèles/UI : règles par framework, badge « vérifié ».

6) Risques

Juridiques :

• Nom ou marque : vérifier la marque, réserver domaine et comptes avant lancement.

• Copie de règles/textes existants : taxonomie et formulation de zéro, sources documentées.

• Licences bibliothèques, polices, images : se limiter aux composants autorisés commercialement.

• Captures : pas d'envoi cloud par défaut, consentement explicite.

• Agents de codage : respecter les politiques, ne pas usurper une qualité officielle.

Techniques :

• Faux positifs : calibrer, autoriser exceptions et explication.

• Rendu variable (navigateurs, polices) : figer l'environnement, documenter la précision.

• Motifs « AI slop » : mises à jour régulières via communauté ouverte.

• Grands projets : analyse sélective, cache.

• Contournement : analyse visuelle + règles structurelles, pas le code seul.

• Agents externes : CLI autonome sans agent.

7) Nom et slogan

Nom proposé : Namq (نمق)

Slogan : Faites construire par les agents de codage des interfaces qui ressemblent à des humains, pas à des modèles.
