MDM1 · Plan de projet

Qimam — plan de projet complet

Plateforme SEO ouverte pour agents IA, offrant une vision complète de votre site dans la recherche et l’IA, dès gratuitement.

Plan d’exécution : idée, audience, produit, revenus, diffusion, risques. Projet non lancé.

1) Public cible

• Développeurs/ingénierie : audit SEO dans le développement et le CI/CD, sans outils lourds.

• Agences/indépendants : plusieurs outils coûteux, rapports revendables.

• Startups/contenu/croissance : mots-clés, concurrence, visibilité IA, budget limité.

• Petits sites, blogs, boutiques exclus des tarifs entreprise ; agents Cursor, Claude Code, VS Code avec MCP pour le SEO local.

• Marché arabe prioritaire, moins desservi, extension mondiale.

2) Points forts

Problème : SEO payant cher, fermé, orienté GUI, sans vraie visibilité IA, données/méthodologie monopolisées.

• Agent-first/MCP-native : chaque fonction est un outil agent standard, avec CLI, API et JSON Schema clair.

• Local-first/self-host : local ou serveur utilisateur, clés API personnelles (BYO keys).

• Unifié : mots-clés, backlinks, audit technique, positions, concurrence.

• IA : mentions et citations dans ChatGPT, Gemini, Perplexity, Copilot.

• Transparence : méthodologie ouverte, scores de confiance, rapports reproductibles.

• Coût dès zéro : auto-hébergement/cloud gratuits, puis abonnements réduits.

• Confidentialité : aucune revente, rétention régionale, suppression totale.

• Design : interface arabe (RTL), légère, terminal (TUI), rapports soignés.

• Intégrations : GitHub Actions, WordPress, Next.js, Shopify, Ghost, Webhooks.

3) Périmètre V1 (8 tâches max)

1. Crawler/audit : 10 000 pages ; liens brisés, titres, descriptions, canonical, hreflang, sitemap, robots.txt ; export CSV/JSON.

2. Mots-clés : requêtes, suggestions, données publiques, SERP optionnel ; intention et langue (ar/en).

3. Positions : quotidien/hebdo, desktop/mobile, zone géographique, historique, alertes.

4. Backlinks : Common Crawl, crawl utilisateur, fournisseur optionnel ; domaines, ancres, risque, export Disavow.

5. Concurrence : domaines, contenus, mots-clés, Share of Voice.

6. IA : questions, mentions, citations, sources, sentiment, rapport périodique.

7. MCP Server + CLI : outils unifiés, auth locale, exemples agents, schémas documentés.

8. Rapports/alertes : PDF/CSV planifiés, Email/Slack/Webhook, white-label agences.

Hors V1 : index web propriétaire, app mobile, SSO, garanties SEO.

4) Tarification et revenus

· Self-host · Gratuit · open source, clés personnelles, sans limites locales ·

· Cloud Free · 0 $ · 1 projet, 1 000 pages/mois, 20 mots-clés, 50 analyses IA ·

· Starter · 19 $/mois · 3 projets, 25 000 pages, 150 mots-clés, 1 000 analyses IA, 1 siège ·

· Growth · 49 $/mois · 10 projets, 100 000 pages, 750 mots-clés, 5 000 analyses IA, 3 sièges, API ·

· Agency · 129 $/mois · 40 projets, 400 000 pages, 3 000 mots-clés, 20 000 analyses IA, 10 sièges, White-label ·

· Enterprise · Sur mesure · auto-hébergement, SSO, audit, support, SLA ·

• Abonnements mensuels/annuels ; crédits crawl/analyses IA.

• Support entreprise, déploiement ; extensions/intégrations payantes.

• Ni vente de données, ni publicité, ni monopole des clés API.

5) Diffusion mondiale gratuite

• GitHub : dépôt ouvert, README solide, versions claires, Issues débutants, licence attractive.

• Registres MCP : annuaires MCP, awesome-mcp-servers, découverte d’outils agents.

• Installation : npm, PyPI, Docker Hub, Homebrew.

• Lancement : Product Hunt, Show HN, Reddit (r/SEO, r/TechSEO, r/webdev, r/mcp), Indie Hackers.

• Contenu : YouTube court, Dev.to/Hashnode, guides arabe/anglais ; SEO via son site et analyses publiques.

• Intégrations : GitHub Action, WordPress, Shopify, Next.js.

• Communautés : meetups, groupes locaux, universités, hackathons, newsletters.

• Moyen-Orient d’abord : contenu arabe authentique, puis expansion mondiale.

• Parrainage : crédits aux utilisateurs/agences apportant des projets.

6) Risques juridiques et techniques

• Crawl de résultats : risque de violation ; API officielles ou clés utilisateur, robots.txt respecté, pas de contournement.

• Données et GDPR/CCPA : accords de traitement, collecte minimale, suppression immédiate, hébergement régional.

• Licences bibliothèques et Common Crawl : audit, sources documentées, MIT/Apache pour le noyau, DCO contributeurs.

• Nom/marque similaire : vérification avant lancement.

• Fournisseurs d’IA : pas de revente non conforme des sorties, attribution claire.

• Responsabilité : le produit mesure sans garantir les positions.

• Limites de débit, blocages et CAPTCHA : fournisseurs interchangeables, cache, nouvelle tentative intelligente.
