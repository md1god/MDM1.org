# MD1usd AI Office (`/office/`)

مكتب الشركة الذكي: تطبيق ويب ثابت (PWA) بيشتغل في المتصفح. الملفات هنا بتتنشر زي ما هي على GitHub Pages.

## ⚠️ الخصوصية: الصفحة دي مش "خاصة" فعلاً
- بوابة الدخول (`office-auth.js` والخزنة) بتحمي **بيانات المتصفح** بس. **كل الملفات** (JS/CSS/`data.json`) عامة ومقروءة لأي حد، و`noindex` بيمنع محركات البحث بس، مش الزوّار.
- **ممنوع** وضع أي سر في المستودع: مفاتيح API، توكنات، كلمات سر. المفاتيح بيدخلها المستخدم في المتصفح وتتخزن في الخزنة المشفّرة.
- لو محتاج خصوصية حقيقية: حط `/office/` خلف Cloudflare Access أو تحقق على السيرفر (Supabase) قبل ما تتقدّم الملفات.
- الصفحة عليها `Content-Security-Policy` (meta) بتمنع تحميل سكربتات/إطارات من أي موقع غير المسموح بهم. لو ضفت خدمة خارجية جديدة (مزوّد نماذج مثلاً)، شوف إنها بتتصل عبر `https:`، ولو بتحمّل سكربت من نطاق جديد ضيفه في `script-src` في `index.html`.

## النسخ الاحتياطي
بيانات المكتب (المهام، العملاء، الذاكرة…) **محفوظة في المتصفح**. لو اتمسحت بيانات الموقع تضيع.
- تبويب **النسخ الاحتياطي** بيعمل نسخة مشفّرة (AES-256-GCM) تقدر تنزّلها وتستعيدها.
- بيظهر تذكير أعلى الصفحة لو مفيش نسخة، أو آخر نسخة أقدم من **7 أيام** (وتقدر تأجّله 3 أيام).
- جرّب الاستعادة على متصفح تاني مرة واحدة على الأقل عشان تتأكد إن النسخة سليمة.

## قبل ما تعدّل (لتفادي الكتابة فوق شغل غيرك)
`office/` بيتعدّل من أكتر من مكان (نشرات `pwaNN`، أدوات، تعديلات يدوية). عشان ما تضيعش تعديلات:
1. اعمل `git pull` قبل ما تبدأ.
2. اشتغل في فرع واعمل Pull Request بدل الرفع المباشر على `main`.
3. ما تستبدلش `styles.css` أو `index.html` بنسخة قديمة عندك.

## رقم النسخة (cache busting)
رقم النسخة (مثلاً `20261128pwa42`) متكرر في 8 ملفات. مصدره الوحيد هو `office/VERSION`:
```bash
node scripts/office-version.js check          # يتأكد إن كل الملفات متطابقة
node scripts/office-version.js bump           # pwa42 -> pwa43 بتاريخ اليوم
node scripts/office-version.js set 20261129pwa50
```
غيّر الرقم عند أي تعديل على ملفات مخزّنة مؤقتاً (JS/CSS/HTML) عشان المتصفحات تسحب الجديد. الـ CI بيفشل لو الأرقام مش متطابقة.

## الاختبارات
```bash
npm i --no-save playwright && npx playwright install chromium
node tests/office-ui-smoke.js                 # الواجهة (Chromium بدون واجهة + API مُحاكى)
node --test tests/decision-policy.test.js tests/conversation-intelligence.test.js
```
اختبار الواجهة (`.github/workflows/office-ui-smoke.yml` على كل PR يلمس `office/`) بيتأكد من: رسم الأرضية بدون إمالة أو تداخل، إن أسماء الموظفين الخبيثة تظهر كنص (بدون XSS)، فتح كل التبويبات بدون أخطاء أو overflow أفقي على سطح المكتب والموبايل، البحث، التذكير بالنسخ الاحتياطي، وعدم وجود انتهاكات للـ CSP. للحصول على لقطات: `SMOKE_SHOTS=./shots node tests/office-ui-smoke.js`.

## اختصارات
`Alt` + رقم/حرف يبدّل التبويب (راجع `TAB_HOTKEYS` في `app.js`). تنبيه الموافقات الجديدة: عنوان التبويب + إشعار + نغمة اختيارية (خانة في القائمة الجانبية).
