هذه الحزمة تجهز صفحة الإطلاق، لكنها لا تنشر أي شيء باسم صاحب المشروع تلقائياً. قبل النشر يجب مراجعة الحساب والاسم والصور والروابط، ثم تأكيد الإرسال داخل Product Hunt.

## Product Hunt submission

**Name**

`MDM1 Personal Assistant`

**Tagline — under 60 characters**

`Discover tools and generate code privately in your browser`

**Description — under 500 characters**

`MDM1 Personal Assistant helps people turn a goal into a practical first step. Search a multilingual catalog of tools, apps and projects, then generate starter code for HTML/CSS, JavaScript, Python or SQL. The fast mode works without an account or paid API. Compatible browsers can optionally run a small language model locally with WebGPU, keeping the conversation on the device.`

Free. Do not describe the optional browser model as a hosted API or promise unlimited performance; the visitor's device and browser determine local inference speed.

## First comment draft

> We built MDM1 for the moment when you know the outcome you want but do not know which tool or first step to choose. The assistant works without registration, the catalog points to practical resources, and Code Lab creates editable starter files. Local AI is opt-in and runs in the browser on compatible WebGPU devices. We would love feedback on the recommendations, generated code and languages that should be prioritized next.

## Gallery plan

Product Hunt requires a square thumbnail and recommends at least two gallery images. Prepare these assets before submitting:

1. **Hero:** the assistant landing view with the phrase “From goal to first step”.
2. **Workflow:** three panels showing goal → recommendation → code output.
3. **Privacy:** a simple diagram showing the optional local model running in the browser, with no hosted API claim.

Use readable screenshots, no fake user counts and no unverified ranking claims. Keep the thumbnail square and the gallery images wide enough for Product Hunt's recommended layout.

## Launch-day runbook

- Schedule the launch only after the live URL, repository and screenshots have been checked.
- Post the maker's first comment immediately and answer questions with concrete examples.
- Invite genuine early users and developers to test the assistant; do not buy votes or coordinate misleading engagement.
- Share the launch URL with the tagged UTM parameters above.
- Record visits, assistant starts, code generations, repository clicks and feedback themes.
- After 24 hours, publish a short changelog based on real feedback.

## Approval gate

Do not submit until the owner confirms the final name, tagline, description, launch date and gallery images. Product Hunt's current launch requirements are documented at https://www.producthunt.com/launch/preparing-for-launch.
