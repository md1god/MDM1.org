# MDM1 Hub — Grants & Market Launch Draft

## Product

MDM1 Hub is a public-facing directory and service layer for open-source digital tools. The first release offers a searchable service directory, partner pages, optional featured placements, and a catalogue of deployable tools for support, forms, bookings, analytics, and automation.

The open-source core remains free. Revenue comes from clearly disclosed implementation, hosting, customization, maintenance, sponsorship, and featured-placement services. The project does not promise investment returns, manipulate token markets, or present sponsorship as a security or quality rating.

## First 90 days

1. Publish the landing page and add 20 free listings from projects with compatible licenses.
2. Publish two practical guides and one monthly ecosystem report.
3. Contact open-source maintainers and small businesses with a free listing invitation and a paid setup option.
4. Convert the first three setup requests into case studies, with permission.
5. Apply for public-goods funding using measurable deliverables: listings, page views, deployments, API/widget usage, and documented improvements.

## Grant positioning

The project should be presented as reusable public infrastructure, not as a request to promote a single token. MD1USD and MDM1 can be initial examples, while the platform must support other projects and disclose data sources and sponsorships.

Potential programs to monitor:

- Ethereum Ecosystem Support Program — open-source infrastructure and public goods.
- Gitcoin Grants — community-funded public goods rounds.
- Giveth and Octant — public-goods and impact funding.
- Arbitrum grants — only for a clearly scoped Arbitrum tool/integration.
- Circle Developer Grants — only if a real Circle/USDC/Arc integration is added.

## Customer acquisition, lawful and permission-based

- Publish free listings and invite maintainers through their public contact channels.
- Offer a free 30-day pilot to three small businesses in exchange for feedback, not investment.
- Publish tutorials and short demonstrations on the existing MDM1 channels.
- Use referral links only where the provider allows them and label them as referrals.
- Never use unsolicited bulk messages, fake reviews, paid trading, price manipulation, or claims of guaranteed returns.

## Commercial packages

| Package | Deliverable | Revenue source |
|---|---|---|
| Free listing | Name, link, category, license, public description | Public-good reach |
| Featured listing | Clearly labelled placement and analytics | Sponsorship fee |
| Setup | Deploy and configure an open-source tool | One-time implementation fee |
| Managed | Hosting, updates, backups, monitoring | Monthly service fee |
| Custom | Branding, integrations, reports, training | Project fee |

## Important legal note

Before accepting money, custodying customer funds, facilitating exchange, or operating in a regulated market, obtain local legal advice. The Hub should start as an information and software-service site, not as a broker, exchange, custodian, or investment product.
