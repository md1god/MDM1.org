Midad — Plan de projet complet

Espace de connaissances hors ligne qui garde les données de votre équipe sous votre contrôle.

Plan complet projet numérique : idée, public, produit, économie, déploiement, risques. En construction, non lancé.

Plan produit : espace de connaissances local d'abord pour équipes

1) Public cible

• Équipes produit/ingénierie (5–50) : wiki, specs, docs de décisions sans abonnement mensuel élevé.

• Agences/studios : doc par client, espaces isolés, permissions précises sans serveurs complexes.

• Universités, labos, ONG à budget limité : auto-hébergement local ou cloud local.

• Équipes terrain (humanitaire, fermes, chantiers) : travail hors ligne puis sync.

• Organisations conformité (santé, droit, public) : données dans leurs frontières, audit, sauvegardes locales.

• Particuliers et rédacteurs techniques : alternative légère notes/docs Markdown portable.

2) Différenciation

• Hors ligne d'abord : modifs locales, fusion au retour via CRDT ; aucune perte, historique par page.

• Déploiement une commande : Docker Compose exécute app, base, stockage ; setup <10 min VPS 2 Go.

• Gratuit au départ : édition communauté complète auto-hébergée, sans limite pages/durée.

• Multi-tenant jour 1 : espace isolé par équipe/client, rôles (propriétaire, éditeur, commentateur, lecteur), isolation requête.

• RTL/arabe fondamental : alignement, direction, recherche arabe correcte.

• Propriété données : export Markdown+JSON, sauvegarde programmée S3, chiffrement transit/repos.

• Identité : OIDC/SAML optionnel payant, invitations courriel, permissions précises.

3) Périmètre v1 (max 8 tâches)

1. Éditeur Markdown riche : titres, listes, tableaux, tâches, code coloré, aperçu, RTL/arabe.

2. Espaces : création équipe, espace client, pages imbriquées, étiquettes, liens internes.

3. Permissions/rôles : propriétaire/éditeur/commentateur/lecteur, invitations courriel, liens partage révocables.

4. Sync local : stockage local navigateur/bureau, fusion auto, résolution conflits.

5. Recherche instantanée : plein texte, filtres étiquette, auteur, date.

6. Import/export : Markdown et ZIP, import par lots sans perte de liens.

7. Sauvegarde programmée : tâche quotidienne S3/MinIO, restauration un clic, test documenté.

8. Déploiement : Docker Compose + config, admin de base.

4) Tarification et économie

• Communauté : gratuit auto-hébergement, 50 utilisateurs, fonctions de base ; but base utilisateurs et confiance.

• Cloud gratuit : 3 utilisateurs, 1 Go, essai réel, barrière d'entrée réduite.

• Pro : 6 $/utilisateur/mois (60/an), 20 Go, historique versions complet, recherche avancée.

• Business : 12 $/utilisateur/mois, SSO/OIDC, journaux audit, rétention longue, support prioritaire.

• Revenus extra : support entreprise, migration données (500–3000 $/projet), sauvegarde gérée, hébergement régional.

• Remises : 50 % universités/ONG, essai 14 jours plans payants sans carte.

5) Déploiement mondial (canaux gratuits)

• Open source GitHub, licence claire, versions régulières, liste « awesome self-hosted », guide déploiement arabe/anglais.

• Lancement Show HN, Product Hunt, Reddit (r/selfhosted, r/opensource, r/ObsidianMD) angle « alternative légère hors ligne ».

• Contenu éducatif : 12 articles et 6 vidéos courtes comparant scénarios réels (agence, université, ingénierie) sans attaquer concurrents.

• SEO longue traîne arabe/anglais : « wiki équipe hors ligne », « alternative auto-hébergée », pages comparaison neutres.

• Distribution communautés locales : rencontres universitaires, groupes devs arabes, ambassadeurs étudiants.

• Conversion vers payants via limites souples (stockage, SSO, audit) sans bloquer base.

6) Risques (juridiques et techniques)

• Confidentialité/conformité : GDPR, CCPA, données santé/juridiques ; hébergement UE, accord traitement, chiffrement, rétention claire.

• PI/licence : licence open source compatible hébergement commercial, marque examinée, propriété contenu.

• Perte données sync : conflits CRDT, mauvais usage restauration ; tests restauration périodiques, sauvegardes immuables, audit.

• Sécurité app : fuite sessions, upload malveillant, vulnérabilités SSO ; revue code, analyse dépendances, limitation débit, chiffrement secrets.

• Coût exploitation/concurrence : pression tarifaire grands outils ; marché local, petites équipes, auto-hébergement, coût stockage.

• Dépendance IdP/courriel : panne OIDC ou rejet courriels ; connexion secours propriétaire, envoi via plusieurs fournisseurs.

7) Nom et slogan

Nom proposé : Midad

Slogan marketing : Espace de connaissances hors ligne qui garde les données de votre équipe sous votre contrôle.
