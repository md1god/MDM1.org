MDM1 · Plan de projet

Rawi — plan de projet complet

Transformons chaque conversation client en vente conclue grâce à une IA qui respecte votre vie privée et fonctionne sur votre infrastructure.

Plan d’un nouveau projet numérique : idée, public, produit, revenus, diffusion, risques. En construction, non lancé.

1) Public

• PME de la messagerie (Moyen-Orient, Amérique latine, Asie du Sud, Afrique), 3-50 commerciaux.

• Agences/BPO gérant plusieurs numéros WhatsApp : multi-tenant, marque blanche.

• Santé, éducation, finance : auto-hébergement, données locales, conformité RGPD, LGPD, PDPL.

• Équipes API/MCP refusant le prix par siège ou un fournisseur unique.

2) Atouts

• Gratuit : open source auto-hébergé, sièges illimités, clé LLM.

• Arabe d’abord : RTL, dialectes, modèles de messages, multilingue.

• Canaux : WhatsApp Cloud API officiel, Instagram, Telegram, e-mail, widget.

• Agents IA fiables : sources citées, seuil de confiance, blocages, transfert humain.

• MCP-native : outils CRM à permissions limitées, approbations, audit.

• Multi-tenant : agence et clients, données et permissions isolées.

• Léger : Docker Compose en une commande, sans Kubernetes.

• Transparence : export complet, tarifs publiés, conformité, approbations.

3) Version 1 (8 tâches)

1. Espaces multi-tenant : e-mail/OAuth, rôles, invitations, audit.

2. Boîte unifiée : WhatsApp Cloud API (textes, médias, modèles), répartition, étiquettes, notes, SLA.

3. CRM : contacts, entreprises, champs personnalisés, pipelines, opportunités, tâches, CSV, doublons.

4. Studio IA : RAG, ton, politiques, sources, confiance, transfert humain, test.

5. Portail MCP : outils restreints, approbations, débit limité, audit.

6. Automatisation : déclencheurs, actions, séquences, heures ouvrées, modèles, désabonnement.

7. Analyses/conformité : entonnoir, délais, résolution, approbations, conservation, export/suppression.

8. Déploiement : Docker Compose, sauvegarde, mises à niveau, santé, démo.

4) Tarification et revenus

• Communauté auto-hébergée : gratuite, sièges illimités, clé LLM, support.

• Cloud gratuit : 1 espace, 2 sièges, 1 numéro WhatsApp, 500 réponses IA/mois.

• Starter 29 $/espace/mois : 3 numéros, 5 utilisateurs, 2 000 réponses IA, automatisation.

• Growth 79 $/mois : 5 numéros, 15 utilisateurs, 8 000 réponses IA, rapports, intégrations.

• Scale 199 $/mois : usage équitable, SSO, conformité, support prioritaire.

• Agency White-label 299 $/mois : 10 clients, marque blanche, facturation unifiée.

• Enterprise : auto-hébergement assisté, SLA, formation, audit, tarif sur mesure.

Revenus additionnels : marge IA sans clé, installation WhatsApp gérée, support SLA, intégrations payantes, partenaires. -20 % annuel, prix selon pouvoir d’achat.

5) Diffusion gratuite

• GitHub/open source : AGPLv3, licence commerciale, README, démo, déploiement Railway, Render, Coolify.

• SEO multilingue : arabe, anglais, espagnol, portugais sur « CRM WhatsApp auto-hébergé », comparatifs, modèles, calculateurs de ROI.

• Répertoires MCP/listes awesome : serveur, outils, intégrations n8n, Make, Zapier.

• Communautés : développeurs Meta, forums WhatsApp Business, r/selfhosted, r/sales, Indie Hackers, Product Hunt, Show HN.

• Vidéo : YouTube/TikTok, ateliers, questions.

• Agences : essai marque blanche, commission récurrente, croissance via partenaires.

• Local : incubateurs, chambres de commerce, clubs universitaires, séminaires arabe/espagnol.

• Référencement : lead magnets, parrainage, feuilles de route avec vote public.

6) Risques

Juridiques

• Meta/WhatsApp : Cloud API officiel, consentement préalable, validation des modèles, limites d’envoi ; un pont non officiel risque le bannissement et doit être isolé.

• Confidentialité : accords de traitement, chiffrement, résidence régionale, sous-traitants ; pas d’entraînement sur les données clients.

• Sorties IA : transfert humain, usage interdit, filtres, journaux vérifiables.

• Licence/PI : compatibilité AGPL/commercial, accord des contributeurs, vérification de marque.

• Anti-spam : consentements vérifiés, limites d’envoi, arrêt immédiat.

Techniques

• Tenants : isolation logique stricte, clés séparées, tests de fuite.

• LLM : abstraction du fournisseur, cache, secours, limites par tenant.

• WhatsApp : intégration flexible, nouvelles tentatives, surveillance du numéro.

• Agents : anti-injection, outils restreints, Webhooks anti-SSRF, secrets centralisés.

• Déploiement : sauvegarde automatique, retour arrière, tests de migration.

• Migration : import, nettoyage, documentation claire.

Nom : Rawi
