CritterDock — plan de projet complet

Apportez un compagnon pixel vivant sur votre bureau en un clic.

Plan d'exécution complète pour un nouveau projet numérique : idée, audience, produit, modèle économique, plan de diffusion et risques. Le projet est en cours de construction et n'est pas encore lancé.

1) Public cible

• Développeurs logiciels (18–35 ans) utilisant des assistants IA quotidiennement : environ 60 % recherchent des « retours périphériques » pendant le build/test, ex. : un développeur Node.js veut que le compagnon saute quand les tests réussissent et dorme quand ils échouent.

• Créateurs de contenu (10k–100k abonnés) : streamers/YouTubers ayant besoin d'une overlay d'animal de bureau qui réagit aux dons du chat et aux jalons d'abonnés.

• Collectionneurs d'art pixel : utilisateurs ayant collecté 50+ compagnons sur d'autres plateformes et voulant importer/exporter dans un format unifié.

• Travailleurs à distance et étudiants : besoin de signaux de concentration (Pomodoro, rappels d'hydratation) depuis un compagnon non intrusif.

• Enseignants de programmation : mascottes de classe qui réagissent aux résultats de compilation pour encourager les élèves.

• Utilisateurs non techniques : membres de la famille voulant une installation en un clic sans Terminal ni Node.

2) Points de différenciation (pourquoi choisir notre produit)

• Aperçus de mouvement générés par IA (GIF 3–5 s) avant installation, réduisant le « regret d'installation » d'environ 40 %.

• Installation isolée (sandbox) : chaque compagnon dans un processus séparé avec manifeste de permissions ; pas de code arbitraire.

• Support multiplateforme : Windows/macOS/Linux + VS Code + Terminal (CLI).

• Supervision communautaire : vote + scan de sécurité automatique (heuristiques + VirusTotal optionnel) + revue humaine pour le Top 100.

• Mode hors ligne (offline-first) : les compagnons fonctionnent localement, aucun compte requis pour le niveau gratuit.

• Désinstallation/rollback en un clic : aucune trace dans le Registry ni les LaunchAgents.

3) Périmètre de la première version (8 tâches max)

1. Enveloppe de bureau (Tauri 2) avec system tray et fenêtre transparente always-on-top.

2. Moteur d'exécution du compagnon : animation spritesheet + machine à états (idle/walk/sleep/react).

3. Galerie web + API : parcourir, rechercher, filtrer par tags.

4. Installation/désinstallation en un clic avec versioning et cache.

5. Générateur d'aperçus (clip 4 s) depuis spritesheet via FFmpeg.

6. Scanner de sécurité des soumissions (analyse statique + exécution sandbox timeout 5 s).

7. Comptes utilisateurs + favoris + évaluations (1–5).

8. Paiements (Stripe) pour les compagnons premium + partage créateurs 70/30.

4) Tarification et modèle de revenus

• Free-to-start : 20 compagnons gratuits, sans compte, sans publicité.

• Pack Premium $4.99 une fois : 100+ compagnons exclusifs + thèmes + son.

• Marché créateurs : vente de compagnons $1.99–$9.99, partage 70/30 (créateur/plateforme).

• Tip jar (Stripe Connect) pour soutenir les créateurs (0 % de frais les 3 premiers mois).

• Abonnement Pro $2.99/mois : sync cloud, créateur de compagnon personnalisé, analytics.

• Licence écoles/classes $49/an (jusqu'à 30 appareils, support).

5) Plan de diffusion mondial par canaux gratuits

• Lancement Product Hunt + vote « Pet of the Week » (objectif : Top 5 du jour).

• Reddit : r/programming, r/PixelArt, r/vscode, r/DesktopToys (3 publications/semaine, value-first).

• GitHub : runtime open source (MIT) pour attirer les développeurs ; repo compagnons séparé (CC-BY pour l'art).

• TikTok/YouTube Shorts : démos de 15 s des réactions du compagnon, 3/semaine, défi hashtag.

• Dev.to/Hashnode : « Build your own desktop pet in 10 min » (tutoriel + lien repo).

• Communauté Discord + showcase hebdomadaire + primes pour nouveaux compagnons ($50).

• Show HN sur Hacker News + publications de jalons IndieHackers.

6) Risques (légaux et techniques)

• Légal : droits d'art pixel ; procédure DMCA ; marques ; ToS des soumissions (originalité + licence).

• Technique : consommation CPU/RAM dans Electron/Tauri ; évasion de sandbox ; payloads malveillants ; compatibilité OS/GPU.

• Confidentialité : telemetry opt-in uniquement ; pas d'enregistrement de frappes ; conformité GDPR/CCPA.

• Supervision : spam/NSFW ; revue automatique + humaine ; processus d'appel.

• Chaîne d'approvisionnement : CVEs dans les dépendances ; SBOM + Dependabot ; versions épinglées.

7) Nom proposé et slogan marketing

Nom proposé : CritterDock

Slogan marketing : Bring a living pixel companion to your desktop in one click.
