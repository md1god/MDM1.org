Khanah — Plan de projet complet

Faites rayonner votre patrimoine dans le monde, sans limites ni complexité.

Plan complet d'un projet numérique : idée, public, produit, modèle économique, déploiement et risques. Projet en construction, non lancé.

1) Public cible

1. Photographes amateurs/professionnels du patrimoine bâti/naturel : envoyer vite des centaines de photos originales avec métadonnées riches (GPS, date, catégories).

2. Bénévoles de la connaissance libre : lots quotidiens de « Wiki Loves Monuments » et concours locaux, envoi programmé dès qu'un Wi-Fi est disponible.

3. Chercheurs collectant des images de terrain (plantes, roches, vestiges) : lier chaque image à un DOI/ORCID et une taxonomie avant publication.

4. Journalistes citoyens en zone à connexion instable : hors ligne d'abord, synchronisation au retour du réseau, envoi en arrière-plan sans écran allumé.

5. Enseignants/élèves documentant l'environnement scolaire : interface simplifiée multilingue (arabe, français, swahili, espagnol), modèles CC-BY-SA 4.0.

6. Développeurs tiers (voyage, guides, science citoyenne) : intégrer l'envoi via un SDK léger (<200 Ko).

2) Points forts

1. Envoi reprenable : fichiers >100 Mo en parties de 4 Mo, reprise après coupure, 35 % de batterie économisée face à l'envoi séquentiel.

2. Éditeur visuel : glisser-déposer depuis un arbre taxonomique vivant (Wikidata), tags suggérés par IA (TensorFlow Lite local, 92 % pour monuments célèbres).

3. Mode « mission de terrain » : photos regroupées, licence et lieu appliqués au lot, export CSV pour rapports institutionnels.

4. Synchronisation bidirectionnelle avec le cloud personnel (Nextcloud, Google Drive, S3) avant l'envoi au dépôt public, AES-256 côté client.

5. Comptes et identités multiples (personnel, organisation, machine), clés OAuth distinctes, bascule sans déconnexion.

6. SDK ouvert (MIT) : bouton « Envoyer aux communs » en deux lignes dans Android/iOS/Flutter, erreurs et codes unifiés.

3) Périmètre V1 (8 tâches max)

1. Clean Architecture + Kotlin Multiplatform, 70 % du code partagé Android/iOS ; modules core-upload, core-metadata, core-auth, ui-components.

2. OAuth 2.0 (PKCE), jetons chiffrés via Android Keystore / iOS Keychain, renouvellement silencieux.

3. File d'envoi : priorités (haute/normale/basse), parties regroupées, pause/reprise, notifications système, 5 envois parallèles configurables.

4. Métadonnées : titre, description Markdown, lieu sur carte hors ligne (MapLibre + MBTiles), catégories Wikidata SPARQL, licence SPDX.

5. Hors ligne d'abord : Room/SQLite pour vignettes 512 px et métadonnées, synchronisation au retour du réseau, export ZIP chiffré.

6. Vision locale : MobileNetV3 entraîné sur 10 000 monuments, sans Internet, 5 suggestions à confiance >0,7, mises à jour Firebase Remote Config.

7. SDK public + application de référence Material 3 / Cupertino, tests UI (Espresso/XCUITest) sur 85 % des parcours critiques.

8. CI/CD (GitHub Actions + Fastlane) : AAB/IPA signés, versions internes quotidiennes, notes issues des Conventional Commits.

4) Tarification

1. Gratuit pour les utilisateurs finaux (sans publicité, suivi ni achats intégrés), open source Apache 2.0.

2. SDK B2B : 499 dollars/an par application propriétaire, envois illimités, support e-mail SLA 48 h.

3. Hébergement géré Kubernetes : 0,02 dollar/image (CDN, WebP, sauvegarde 30 jours), minimum 100 dollars/mois.

4. « Power Contributors » : >10 000 images/an, badge, support prioritaire, -50 % sur l'hébergement géré.

5. Subventions (Wikimedia Foundation, Mozilla, NLnet) pour langues autochtones ou WCAG 2.1 AA, transparence via OpenCollective.

6. Community Add-ons Market : 15 % sur modèles payants, filtres pro et packs de classification, audit de sécurité automatisé.

5) Déploiement mondial

1. Ambassadeurs dans 20 pays (Inde, Brésil, Nigeria, Indonésie, Égypte, Mexique…), ateliers mensuels « Faites rayonner votre patrimoine », t-shirts et autocollants, budget nul.

2. Vidéos de 3 minutes (YouTube, PeerTube, Bilibili) en 12 langues via Crowdin : premier envoi en 60 secondes, hors ligne dans le désert, automatisation des concours.

3. Partenariats « Wiki Loves Monuments » et « Wiki Loves Earth » : outil intégré aux concours, modèles JSON importables en un clic.

4. ASO organique : mots-clés longue traîne (« upload photos to commons offline », « bulk image uploader wikidata »), captures traduites, vidéo de 30 s, description revue toutes les 6 semaines via AppTweak gratuit.

5. Parrainage : 5 contributeurs actifs invités (>50 images/mois) donnent un badge « Catalyseur » et un code de suivi, classement public.
