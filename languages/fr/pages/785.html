نُوقى — Plan de projet complet

نُوقى transforme vos données de recherche et de mesure en réponses prêtes pour votre agent intelligent en 3 minutes, gratuitement pour commencer.

Plan complet : idée, public, produit, modèle économique, diffusion, risques. En chantier, non lancé.

1) Public cible

• Agences SEO (3-15 pers., 5-40 sites) : 6-10 h/sem. à recopier entre dashboards ; pas d'ingé. intégration ; données prêtes pour l'agent.

• Développeurs d'agents marketing internes : interface unique appelable depuis le code, sans OAuth, renouvellement jetons ni quotas Google à zéro.

• Startup growth : 1 responsable suit site/ads/contenu ; réponse immédiate à « Quelle page a perdu 30 % de trafic en 14 j ? » sans 5 dashboards.

• Consultants/freelances arabes et asiatiques : multilingues, rapports bilingues, format client local, départ gratuit avant décision d'achat.

• Sites à faibles ressources : boutiques/blogs, suivi hebdo mots-clés, backlinks, Core Web Vitals ; sans gros abonnement ni analyste.

2) Points forts (pourquoi nous choisir)

• Gratuit réel : 3 sites, 1 000 appels/mois, 7 j d'hist., sans carte ni essai qui expire ; test données réelles avant paiement.

• Sécurité défaut : lecture seule ; écriture = activation explicite + validation par opération sensible ; journal : agent, heure, ID.

• Données unifiées : 1 champ requête, 1 champ page, 1 unité de temps ; « confirmé source » / « estimé » pour limiter l'invention de l'agent.

• Économe jetons : appels groupés, 25 lignes/page, mode « résumé » = 5 lignes au lieu de 500 ; moins de coût modèle, pas de dépassement mémoire.

• Hébergé sans install. : 1 URL MCP, 1 clé, OAuth < 3 min, docs copiables ; ni serveur local, ni Python/Docker.

• Transparence : pas d'entraînement sur données clients, export JSON/CSV, compteur évitant l'arrêt aux limites.

3) Périmètre v1 (8 tâches maximum)

1. OAuth : jetons chiffrés, renouvellement 24 h avant fin, isolation clients, déconnexion immédiate.

2. Search Console unifié : requêtes, pages, pays, appareils, positions, CTR ; 2 périodes, détection baisses.

3. GA4/Ads lecture : visites, conversions, campagnes, support ; devise + ID page unifiés.

4. Signaux externes : SERP, backlinks, suggestions mots-clés, Core Web Vitals ; fournisseurs agréés, cache 6-24 h.

5. Politiques : lecture/écriture séparées, listes blanches, limites/agent, validation sensible, journal exportable.

6. Point MCP hébergé, 3 modèles, docs ar/ang, tableau usage : conso, limites, facture.

4) Tarification et modèle économique

• Gratuit : 3 sites, 1 000 appels, 7 j, outils lecture seule ; but : 1re réponse utile en 1 séance, pas paiement anticipé.

• Pro 19 $/mois : 10 sites, 20 000 appels, 90 j, export, support 24 h ; freelance, growth.

• Équipe 79 $/mois : 30 sites, 100 000 appels, 5 sièges, écritures validées, alertes ; petite agence.

• Agence 249 $/mois : 150 sites, 500 000 appels, espaces clients, rapport dédié, DPA ; -20 %/an, excédent ~0,002 $/appel.

• Revenus : coût fournisseurs payants visible, offres entreprise support prioritaire, ateliers payants ; ni vente de données ni pub.

5) Diffusion mondiale, canaux gratuits

• Contenu : 30 articles pratiques ar/ang/hindi en 90 j ; chacun = question précise + appel réel + résultat attendu.

• Dépôt public cas d'usage : agent rapport hebdo, alerte baisse qualité, rapport client arabe ; licence ouverte = contributions + liens naturels.

• Annuaires/communautés : interface dans annuaires MCP, réponses techniques forums programmation/marketing, Q&A hebdo sans promo directe.

• Partenariats : 5 agences/5 marchés, 6 mois gratuits contre étude de cas publiée, puis conversion partielle payante.

• Utilitaires : calculateur temps gagné sur rapports + vérificateur Search Console ; trafic organique vers abonnement, sans pub.

6) Risques (juridiques et techniques)

• Plateformes : interfaces officielles seules, quotas respectés, pas de revente de données brutes, politiques revues /3 mois.

• Confidentialité : requêtes sensibles ; jetons chiffrés, données effacées après délai choisi, DPA + suppression immédiate sur demande.

• Fournisseurs : sources agréées au lieu du scraping ; source/date de récup. par chiffre ; arrêt immédiat du contrevenant pour protéger les clients.

• Écritures : lecture par défaut, double confirmation, copie avant changement, bouton annuler si dispo.

• Technique : renouvellement jetons, schémas modifiés, latence, pression appels ; tests quotidiens, compatibilité, files, alerte 80 %.
