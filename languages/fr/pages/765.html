دَفّة (Daffa) — Plan de projet complet

Construisez un agent intelligent, contrôlez-le étape par étape et exécutez-le avec n'importe quel modèle et n'importe quel cloud en quelques minutes.

Plan complet : idée, public, produit, modèle économique, diffusion, risques. Projet en construction, non lancé.

« دَفّة (Daffa) » : noyau de contrôle pour agents intelligents

1) Public cible

• Startups (2–10 ing.) : service client/automatisation ; 500 tickets/jour, réponses sans réinventer la boucle de contrôle.

• Ing. IA indépendants : 3–5 projets/an, 2 semaines perdues sur outils, mémoire, journaux.

• Plateforme interne (50–500 salariés) : 5 agents dispersés ; une norme pour construire, surveiller, gérer les droits.

• Secteurs réglementés (banque, santé, gouvernement) : 70 % des demandes = audit, traçabilité des autorisations, reprise d'étape.

• Chercheurs/étudiants : ~100 000 devs en local, sans carte ni cloud payant ; installation en 1 min.

• Éditeurs SaaS : « assistant intelligent » intégré en 5 jours sans équipe IA.

2) Pourquoi ce produit

• Noyau lisible : <12 000 lignes, sans dépendances cachées, local avant tout cloud ; compris en 1 jour.

• Interface unifiée, 12 fournisseurs (OpenAI, Anthropic, Gemini, Ollama) : changement en 1 ligne, logique inchangée ; 200 cas testés.

• Carte visuelle : étapes datées, entrées/sorties/motif, export JSON/JSONL vers dashboard ou SIEM.

• Sécurité : droits lecture/écriture/exécution, mode « simulation », validation humaine avant suppression ou envoi.

• Coût prévisible : budget jetons, arrêt à 80 %, rapport par exécution (100 000 → 80 000 + alerte).

• Python/TypeScript depuis des types communs : même comportement serveur/navigateur, 90 % de tests partagés.

3) Périmètre v1 (6 tâches)

• T1 : noyau Python — boucle de raisonnement, registre outils, mémoire locale, interface extensible, 30 tests.

• T2 : paquet TypeScript identique, générateur de types commun contre la dérive API.

• T3 : 4 fournisseurs ; retry intelligent et bascule après 3 échecs.

• T4 : journal exportable, numéro par étape, reprise en 1 clic en débogage.

• T5 : droits, simulation, outils isolés hors d'atteinte des clés d'environnement.

• T6 : CLI : projet en 60 s, 10 exemples, guide de 5 min.

4) Tarification

• Noyau MIT gratuit à jamais, 0 $ en local, sans compte ni carte.

• Studio gratuit : jusqu'à 3 agents, 1 000 exécutions/mois, 7 jours de journaux ; pour un dev ou un étudiant.

• Pro 29 $/mois/dév : 50 000 exécutions, 30 jours de journaux, dashboard, alertes coût/échecs.

• Team 99 $/mois/10 membres : SSO, 90 jours de journaux, rôles, support 24 h.

• Enterprise annuel : autohébergement, 99,9 %, audit, support dédié ; prix selon contrats.

• Marché de modèles : 0 % commission 12 mois, puis 10 % sur les payants ; le gratuit reste gratuit.

5) Diffusion gratuite

• Dépôt : 30 exemples, docs en 5 langues (arabe, anglais, français, allemand, japonais), 20 issues « good first issue ».

• Lancement hebdo : article technique, démo 90 s, questions ouvertes ; 500 étoiles en 90 jours.

• Forums : 5 réponses utiles/semaine, lien de l'exemple pertinent seulement.

• 5 Hackathons et associations : noyau gratuit, 3 prix par événement contre un exemple documenté.

• 12 articles, 8 vidéos, cours de 6 leçons sur 3 plateformes ouvertes.

• 20 ambassadeurs/10 pays : traduction des docs, 1 rencontre locale/mois, badge officiel et accès anticipé.

6) Risques juridiques et techniques

• Juridique : revente/stockage selon les fournisseurs ; API publiques, aucun poids ni clé, revue tous les 6 mois.

• Juridique : conflit de marque ; vérifier 5 registres, domaine et comptes sous un nom unique.

• Technique : appels d'outils variables ; 200 cas, 4 fournisseurs avant chaque version.

• Technique : fuites de clés ; variables d'environnement, masquage, scanneur dans le pipeline.

• Technique : dépassement ; plafond jetons, arrêt 80 %, alerte à 100 opérations simultanées.

• Technique : outil dangereux ; isolement du processus, liste blanche de chemins, validation humaine avant suppression ou virement.

7) Nom et slogan

Nom : دَفّة (Daffa)

Slogan : Construisez un agent intelligent, contrôlez-le étape par étape et exécutez-le avec n'importe quel modèle et n'importe quel cloud en quelques minutes.
