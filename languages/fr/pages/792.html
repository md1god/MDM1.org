Siraj — Plan de projet complet

Faites tourner un agent de programmation intelligent sur votre téléphone, sans root ni terminal complexe, sorties instantanées et données conservées.

Plan complet d’un nouveau projet numérique : idée, public, produit, revenus, diffusion, risques. Projet en construction, non lancé.

1) Public cible

• Dev sans PC : étudiant/employé, Android 4 Go, 11+, 3 tâches/jour (fonction, bug, test) en mobilité ; 1er lancement en 60 s.

• Support/techniciens : lire logs USB, 10 commandes de diagnostic, capture sans root ; tout dans un tableau de bord.

• Petites entreprises : e-commerçant, 10 descriptions ou fichiers boutique modifiés en 20 min depuis le téléphone, sans abonnement desktop cher.

• Enseignants/étudiants : prof explique 15 exemples/séance ; environnement mémorise la dernière ligne même après fermeture brutale.

• Confidentialité : équipe sur code client, refuse serveurs inconnus ; local par défaut, seul le choix utilisateur part vers un fournisseur.

2) Atouts (pourquoi notre produit)

• APK classique : sans déverrouillage du bootloader, ni root, ni terminal ; 4 taps entre download et 1re tâche.

• Isolation user-space de zéro : redirection chemins/appels sans ptrace ; <3 % CPU, <150 Mo RAM au repos.

• Flux instantané : texte token par token, <200 ms ; diffs avant tout changement de fichier.

• Pont intégré : USB/Wi-Fi, 5 commandes (install, logs, capture, copie, reboot) + audit.

• Persistance : base chiffrée locale, capture/30 s ; reprise 100 % en tests internes.

• Vrai gratuit : 20 tâches/j, 3 sessions, sans CB ; votre clé : vous payez les tokens.

3) Périmètre v1

• T1 — Paquet d’installation : APK signé Android 11–15, assistant installe Ubuntu 90 Mo dans un dossier dédié en 45 s.

• T2 — Isolation : /home, /tmp, /proc en user-space ; compatibilité 12 appareils, 4 niveaux de RAM.

• T3 — Agent : instructions découpées en 5 étapes, sortie token par token, stop à tout moment.

• T4 — UI : arabe RTL/anglais en direct, éditeur à onglets, état CPU/RAM/session.

• T5-6 — Pont/sauvegarde : détection + 5 commandes, confirmation avant install/suppression, SQLite chiffrée, capture/30 s, export compressé.

• T7-8 — Compte/métriques : e-mail optionnel, 20 tâches/j, écran de mise à niveau, métriques anonymes désactivables (démarrage, succès), rapport d’erreurs optionnel. Hors périmètre : iOS, entraînement de modèles, synchronisation multi-appareils.

4) Prix et revenus

• Gratuit (0 $) : 20 tâches/j, 3 sessions, projet 50 Mo, modèle local illimité, sans CB.

• Voyageur (4,99 $/mois ou 39 $/an) : 600 tâches/mois, 10 sessions, 500 Mo, sauvegarde chiffrée optionnelle.

• Équipe (12 $/utilisateur/mois) : bibliothèque partagée, 20 sessions, audit + CSV ; min 5 utilisateurs.

• À l’usage : recharge 10 $ pour tokens cloud, +10 % sur prix fournisseur, facture par tâche.

• Règles : 0 pub, 0 vente de données, résiliation en 2 taps ; BYOK supprime les frais de tokens.

5) Diffusion mondiale, canaux gratuits

• Dépôt ouvert : cœur Apache-2.0, README arabe, anglais, indonésien, guide « 1er lancement en 5 min » ; 50 contributeurs/6 mois.

• Communauté : Show HN, Product Hunt, vidéo 90 s install+1re tâche, essai sans inscription.

• Courts : 30 YouTube Shorts/TikTok en arabe, anglais, hindi, portugais ; 25 s, fin sur « essayez le gratuit ».

• Ateliers : 12 lives avec groupes de développeurs Google et clubs étudiants au T1, 20 min + fichier prêt.

• Stores/parrainage : Google Play et F-Droid, pages traduites « sans root », « données restent sur votre appareil » ; 7 jours de mise à niveau pour 3 amis ; 30 % parrainage au M6, 0 pub payante.

6) Risques (juridiques, techniques)

• Juridique — Licences : revue de chaque paquet groupé, attribution complète, contrôle de similarité du code écrit de zéro avant chaque release.

• Juridique — Fournisseurs : certains interdisent l’automatisation ; conditions in-app, clés pas dans le cloud, suppression en 1 clic.

• Technique — OS : Android durcit le user-space ; tests 12 appareils/3 versions, mode compat 20 % plus lent si échec rapide.

• Technique/sécurité : 3 Go RAM peut couper ; plafond 150 Mo, flux stop >42 °C ; instructions peuvent supprimer : écriture au dossier projet + confirmation par commande dangereuse.

• Données : coupure pendant écriture ; journal + captures/30 s, 100 % du dernier état validé sur 10 tests de stress.

7) Nom proposé et phrase marketing

Nom proposé : Siraj

Phrase marketing : agent de programmation intelligent sur téléphone, sans root ni terminal complexe, sortie instantanée, données conservées.
