Knotiva — Plan de projet complet

Tissez vos idées dans un réseau de nœuds vivants et transformez un seul chiffre en modèle 3D en quelques secondes dans Blender.

Plan complet pour un projet numérique : idée, public, produit, revenus, diffusion, risques. En cours, non lancé.

1) Public cible

• Designers paramétriques en petits studios (2 à 15) : mobilier, façades, produits ; 40 colonnes = ~45 min de reconstruction manuelle ; cible 90 s.

• Architectes et urbanistes : 20 variantes d'ombrage ; relier angle du soleil et densité du maillage à un résultat 3D immédiat, sans code complexe.

• Artistes techniques et animateurs : formes pilotées par le temps ou l'audio ; 3 à 6 h/jour dans Blender, outils sans quitter la fenêtre.

• Enseignants et étudiants : profs de design dans ~40 universités (géométrie computationnelle) ; un exemple visuel explique nœuds, entrées, sorties en 60 min.

• Indépendants à budget limité : marchés émergents, PC 16GB, pas de CAD coûteux ; gratuit puis passage au payant après la 1re vente.

2) Arguments clés (pourquoi notre produit)

• Nœuds lisibles comme des phrases, pas des câbles : titre arabe/anglais, couleur par fonction, aperçu intégré ; compris au 1er regard.

• Modification directe : 1 chiffre met à jour le réseau en <200 ms pour 50 000 faces ; annuler/rétablir comme dans Blender.

• Versions partageables : petit JSON révisable dans Git ; le client commente « épaisseur = 12 mm » au lieu d'une capture floue.

• Bibliothèque de modèles : 100 modèles (garde-corps, carrelage, toiture, vague, corde, treillis) ; 1 clic puis ajustements, pas de page blanche.

• Performance locale d'abord : aucun cloud, base hors ligne, indicateur du nœud consommant 70 % du temps.

3) Périmètre v1 (8 tâches max)

• Tâche 1 : noyau, 30 nœuds : point, courbe, surface, transformation, répétition, fusion, découpe, étiquetage ; Python/NumPy dans Blender 4.3+.

• Tâche 2 : éditeur intégré à Blender, panneau latéral masquable, raccourcis personnalisables, aucune fenêtre externe.

• Tâche 3 : types stricts : pas de sortie texte → entrée géométrique ; erreur arabe indiquant le côté à corriger.

• Tâche 4 : aperçu instantané pendant le glissement, limité à 30 im/s pour préserver les PC moyens.

• Tâche 5 : enregistrement/import JSON, export mesh dans Blender, 3 exemples complets actifs après installation.

• Tâche 6 : tarifs et docs arabe/anglais, canal Discord, installateur ≤8MB.

4) Tarification et revenus

• Gratuit à vie : noyau, 30 nœuds, 10 modèles, docs, sans carte de crédit ; 5 000 actifs en 6 mois.

• Pro 9 $/mois ou 79 $/an : 120 nœuds avancés, sauvegarde cloud, historique illimité.

• Studio 24 $/poste/mois : 10 postes max, modèles privés, support 24 h, min. 3 postes.

• Licences éducatives gratuites sur e-mail institutionnel ; nom de l'établissement sur le certificat.

• Marketplace 80/20 : les designers vendent 5-25 $ ; 20 % après 1 000 $ de ventes du nouveau vendeur.

• Support payant 149 $ : session de configuration personnalisée de 90 min.

5) Diffusion mondiale, canaux gratuits

• Blender add-on store : version gratuite d'abord, images animées : 1 chiffre → forme.

• YouTube/Bilibili : 3 vidéos de 45 s/semaine, « Du chiffre à la courbe en 20 s », sous-titres arabe, anglais, chinois.

• Reddit/Discord : 5 réponses/jour dans la 3D, sans promotion ; lien des docs en signature seule.

• Défi hebdo : « Une chaise en 7 nœuds » ; meilleurs dans newsletter 2 000 abonnés au mois 4.

• Écoles de design : atelier 60 min par université l'utilisant dans un cours, contre mention sur la page partenaires.

• Traduction via Git : fichiers français, espagnol, coréen relus par bénévoles, badge « traducteur ».

6) Risques (juridiques et techniques)

• Licences : extension dans Blender ⇒ code compatible GPL ; contrôle fichier par fichier, sources dans un dépôt séparé.

• Marques : « pour Blender » descriptif, sans logo ni nom proche ; vérification sur 5 marchés.

• API Blender : une mise à jour majeure peut casser l'interface ; tests sous 72 h sur Windows, macOS, Linux, branche 6 mois.

• PC moyens : 200 nœuds = 6GB ; alerte à 80 % et calcul par lots de 5 000 faces.

• Dérive numérique : 0,01 mm d'écart peut gâcher une impression ; 25 tests dorés, précision figée dans le fichier.

• Peu de modèles gratuits ⇒ conversion difficile ; 2 modèles gratuits/semaine pendant 3 mois.

7) Nom proposé et phrase marketing

Nom proposé : Knotiva

Phrase marketing : Tissez vos idées dans un réseau de nœuds vivants, et transformez un seul chiffre en modèle 3D en quelques secondes dans Blender.
