Fennec — Plan de projet complet

Fennec : testez, documentez et partagez des APIs sans cloud, à vitesse fulgurante.

Plan d'exécution complet d'un nouveau projet numérique : idée, audience, produit, modèle économique, plan de diffusion et risques. Le projet est en construction et n'a pas encore été lancé.

1) Audience cible

• Développeurs indépendants et petites équipes (2–10 personnes) construisant des APIs REST/GraphQL/gRPC, dont 70 % utilisent Git quotidiennement et ont besoin d'un outil qui ne les force pas à créer un compte cloud ni à souscrire un abonnement.

• Ingénieurs QA/automatisation dans des startups (50–500 employés) cherchant une alternative après des changements de tarification des outils incumbents ; équipe moyenne de 4 testeurs nécessitant un runner batch pour la CI.

• Étudiants et enseignants dans des universités (≈2M étudiants CS dans le monde) nécessitant un outil offline pour des travaux pratiques sans Internet.

• Contributeurs OSS maintainers souhaitant des collections stockées comme du code dans le dépôt, révisables via PR.

• DevOps/SRE pour des smoke tests dans les pipelines, nécessitant un CLI headless runner avec codes de sortie et rapport JUnit.

2) Points forts (pourquoi choisir notre produit)

• Offline-first : fonctionne entièrement sans compte ; données dans un dossier local, pas de sync obligatoire.

• Collections basées sur des fichiers : chaque requête = fichier .http/.yaml, diff-friendly, git-native ; pas de format binary propriétaire.

• Binary unique <80MB, startup <2s (contre ~8s pour les outils incumbents), mémoire <200MB.

• Mock server intégré avec injection de latency/errors pour le contract testing.

• IA optionnelle (bring your own key) qui génère des tests à partir d'un spec OpenAPI ; pas d'envoi de données sans consentement.

• Plugin SDK (JS) pour des custom auth flows + marketplace gratuit.

3) Périmètre de la première version (8 tâches max)

1. Moteur HTTP client (methods, headers, body types, SSL, proxy) + visionneuse de réponse.

2. Modèle workspace/collection stocké sous forme de fichiers + variables d'environnement avec masquage des secrets.

3. Scripting pre/post en JS sandbox (QuickJS) + assertions (expect).

4. CLI headless runner pour CI (exit codes, rapport JUnit).

5. Import depuis OpenAPI 3.x et Postman collection v2.1.

6. Mode mock server servant des exemples de collections.

7. UI Git-aware (badges de statut, vue diff) + résolution de conflits.

8. Empaquetage multiplateforme (Windows/macOS/Linux) + auto-update signé.

4) Tarification et modèle de revenus

• Gratuit à vie : collections illimitées, usage local, CLI, mock server, imports.

• Pro 8 $/utilisateur/mois : sync géré optionnel, environnements partagés, accès basé sur les rôles.

• Enterprise 29 $/utilisateur/mois (annuel) : SSO/SAML, export de conformité, support dédié.

• Objectifs : 100k utilisateurs gratuits en an 1, conversion 3 % → 3000 payants → 288k $ ARR, plus sponsorships.

5) Plan de diffusion mondial par canaux gratuits

• GitHub releases + Homebrew/winget/scoop/apt ; landing page optimisée SEO.

• Contenu : tutoriels sur Dev.to/Hashnode/YouTube Shorts ; études de cas.

• Communauté : Discord, Reddit (r/programming, r/webdev), Hacker News Show HN.

• Intégrations : extension VS Code, marketplace GitHub Actions.

• Localisation : i18n pour 8 langues ; traduction des docs par la communauté.

• Programme universités : Pro gratuit pour les étudiants.

6) Risques (légaux et techniques)

• Légal : recherche de trademark avant le nommage ; ne pas copier de code d'une source ; conformité des licences (Apache/MIT) des bibliothèques ; conditions des fonctionnalités IA.

• Technique : sécurité du sandbox QuickJS ; gestion des grandes réponses (streaming) ; trousseau OS pour les secrets ; signature de l'auto-update ; performance avec 10k+ requêtes.

• Marché : lock-in des incumbents ; besoin d'outils de migration ; charge de support.

• Conformité : GDPR pour le sync cloud optionnel ; résidence des données.

7) Nom proposé et slogan marketing

Nom proposé : Fennec

Slogan marketing : Fennec : testez, documentez et partagez des APIs sans cloud, à vitesse fulgurante.
