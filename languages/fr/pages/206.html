وِشَاح — Plan de projet complet

Synchronisez vos favoris chiffrés entre tous vos appareils, en les stockant uniquement dans votre espace personnel.

Plan d'exécution complet d'un nouveau projet numérique : l'idée, le public cible, le produit, le modèle économique, le plan de diffusion et les risques. Le projet est en cours de développement et n'a pas encore été lancé.

Plan produit : Synchronisation des signets (Bookmarks) avec une confidentialité totale

Idée : Un outil open source qui synchronise les signets entre tous les navigateurs et tous les appareils, en les stockant chiffrés dans le cloud personnel de l'utilisateur, avec un nettoyage automatique par intelligence artificielle. Nous ne copions aucun produit existant ; nous construisons une solution originale à partir de zéro.

1) Public cible

• Les utilisateurs soucieux de leur vie privée et refusant de lier leurs données à un compte de navigateur.

• Les utilisateurs pratiquant l'auto-hébergement (Self-hosting) et les utilisateurs de Nextcloud/WebDAV.

• Les professionnels travaillant sur 3 appareils ou plus (travail/domicile/téléphone).

• Les petites équipes et les agences partageant une bibliothèque de liens commune.

2) Points forts (pourquoi choisir notre produit)

• Chiffrement de bout en bout par défaut : le fournisseur ne voit aucun lien.

• Liberté de stockage : WebDAV / Nextcloud / Google Drive / Dropbox / dossier local, sans restriction.

• Organisation intelligente automatique : classification, tags et suggestion de dossiers via une IA désactivable.

• Recherche instantanée unifiée sur tous les appareils, avec les textes des pages enregistrées localement.

• Modèle gratuit dès le départ et code source ouvert vérifiable.

• Pas de verrouillage fournisseur (No vendor lock-in) : exportation complète toujours disponible.

3) Portée de la première version (8 tâches maximum)

1. Extension de navigateur pour Chrome et Firefox et Edge avec synchronisation bidirectionnelle de base.

2. Connexion au stockage personnel (WebDAV et Nextcloud en premier, puis Google Drive).

3. Chiffrement E2E avec une clé locale dérivée d'une phrase de récupération.

4. Résolution des conflits avec une stratégie claire (le plus récent / fusion / conserver une copie).

5. Organisation automatique par IA (tags et dossiers suggérés, à valider).

6. Interface web/application légère pour afficher et rechercher les liens.

7. Import/export aux formats HTML, JSON et CSV + sauvegarde.

8. Panneau de configuration simple et tests de synchronisation fonctionnelle.

4) Tarification et modèle économique

• Gratuit à vie (Free) : synchronisation illimitée via le stockage de l'utilisateur, 2 appareils, organisation IA limitée mensuellement.

• Pro (abonnement mensuel/annuel) : appareils illimités, organisation IA illimitée, historique des conflits, support prioritaire.

• Équipes (Teams) : bibliothèques partagées, rôles et permissions, tableau de bord d'administration.

• Soutien open source (Sponsorships) : parrainages GitHub et licence commerciale supplémentaire pour les entreprises.

5) Plan de diffusion mondial via des canaux gratuits

• Publication du code source ouvert sur GitHub et référencement dans awesome-privacy et awesome-selfhosted.

• Magasins d'extensions officiels : Chrome Web Store et Mozilla Add-ons et Edge Add-ons.

• Plateformes communautaires : Reddit (r/privacy, r/selfhosted, r/firefox), Hacker News, Product Hunt.

• Sites d'alternatives : AlternativeTo et Slant.

• Contenu SEO : tutoriels « Comment synchroniser vos favoris sans vendre vos données », comparaisons neutres.

• YouTube et technologies ouvertes : tutoriels d'installation avec Nextcloud.

• Intégrations et communautés Nextcloud et Home Assistant.

6) Risques (juridiques et techniques)

• Juridiques : conformité au RGPD lors du traitement des données utilisateur, politiques des magasins de navigateurs, conditions d'utilisation des fournisseurs de stockage, droits de marque sur le nom.

• Techniques : changements des interfaces de navigateurs (Manifest), précision de la résolution des conflits avec chiffrement, limites de débit des fournisseurs cloud, sécurité des clés et de la synchronisation, coûts d'exécution de l'IA.

7) Nom proposé et slogan

Nom proposé : وِشَاح

Slogan : Synchronisez vos favoris chiffrés entre tous vos appareils, en les stockant uniquement dans votre espace personnel.
