Spreadly — Plan de projet complet

Lisez des mangas comme un vrai livre—deux pages à la fois, n'importe où, hors ligne.

Plan d'exécution complet pour un nouveau projet numérique : idée, audience, produit, modèle économique, plan de diffusion et risques. Le projet est en construction, pas encore lancé.

1) Audience cible

• Lecteurs de manga et comics sur le web (16–35 ans), dont 60 % sur mobile, frustrés par le défilement page par page.

• Amateurs du mode « double page » (spread) voulant une expérience proche du livre papier sur les sites d'agrégation.

• Équipes de traduction (scanlation) qui ont besoin d'une revue visuelle rapide avant publication.

• Utilisateurs de tablettes (iPad/Android tablets) lisant en mode paysage.

• Lecteurs de contenu RTL/LTR (japonais, coréen, chinois, anglais) qui ont besoin d'un changement de direction fluide.

• Utilisateurs de l'accessibilité (zoom, contraste élevé, navigation au clavier).

2) Points forts (pourquoi choisir notre produit)

• Détection intelligente de la « double page » (gutter detection) with auto-crop removes empty margins and aligns panels.

• Mode hors ligne d'abord (PWA + IndexedDB) qui stocke 200–500 pages (~150MB) for offline reading.

• Couche d'adaptateurs (adapters) générique + plugins par site : works on 5+ major sites without per-site forks.

• Performance : changement de page <100ms, préchargement des deux pages suivantes, virtualized list for long chapters.

• Vie privée : pas de suivi, progression de lecture exportée/importée as encrypted file (no server required).

• Accessibilité : repères ARIA, focus clavier, contraste élevé, support des lecteurs d'écran.

3) Périmètre de la première version (8 tâches max)

1. Moteur de lecteur (spread/single toggle, RTL/LTR, zoom, navigation clavier/gestes).

2. Couche d'adaptateurs for 5 sites (heuristics + per-site selectors).

3. Stockage hors ligne (Service Worker + IndexedDB) with quota handling.

4. Préchargement et cache (prefetch next 2 pages, virtualization).

5. Export/import de la progression de lecture (encrypted JSON file).

6. Panneau de paramètres + onboarding (3 étapes, <60s pour la première lecture).

7. Passe accessibilité (WCAG AA) + tests clavier.

8. Bêta fermée (200 utilisateurs) + correctifs + publication dans les stores d'extensions.

4) Tarification et modèle économique

• Free-to-start : lecteur de base (spread/single, offline 50 pages, 3 sites) gratuit pour toujours, sans pub.

• Premium $3/mois ou $24/an : offline 500 pages, sync across devices, themes, unlimited sites, priority support.

• Lifetime $49 one-time pour les early adopters (premiers 1 000 utilisateurs).

• Dons (GitHub Sponsors/Patreon) pour les traducteurs communautaires.

• Objectif : 5 % de conversion depuis 50k MAU → ~$7.5k MRR à $3 de moyenne ; point mort à ~$1.2k/mois d'infra.

5) Plan de diffusion mondiale par canaux gratuits

• Versions GitHub + stores Chrome/Firefox/Edge (ASO keywords : manga reader, two-page).

• Publications à valeur (not spam) in r/manga, r/manhwa, r/ComicBook (case studies with screenshots).

• Discord : prise de contact avec 20 groupes de scanlation pour tests bêta + témoignages.

• Lancement Product Hunt avec GIF de démo + post « Show HN ».

• YouTube/TikTok : démos de 60s par des créateurs (barter : premium gratuit contre avis).

• Traduction de l'interface en 6 langues via la communauté (Crowdin free for OSS).

6) Risques (juridiques et techniques)

• Juridique : we don't host images; client-side enhancement only. Risque : retraits des stores d'extensions. Atténuation : contact DMCA, no hotlinking changes, respect de robots.txt, ToS clairs.

• Technique : les changements du DOM cassent les adaptateurs. Atténuation : heuristic fallback, weekly automated smoke tests on 5 sites, community plugin updates within 48h.

• Stores : rejets de politique MV3. Atténuation : permissions minimales, no remote code, documented privacy policy.

• Vie privée : données de sync. Atténuation : chiffrement E2E, opt-in, local-first default.

• Performance : appareils bas de gamme. Atténuation : paliers de qualité, option de désactivation des animations.

• Concurrence : applications natives. Atténuation : web-first zero-install, works on any site.

7) Nom proposé et slogan marketing

Nom proposé : Spreadly

Slogan marketing : Read manga like a real book—two pages at a time, anywhere, offline.
