Nasaq Code — plan de projet complet

Votre assistant de codage intelligent dans votre éditeur : il comprend votre projet et préserve votre vie privée.

Plan d’un projet numérique : idée, public, produit, revenus, diffusion et risques. En construction, non lancé.

1) Public cible

• Freelancers : livrer vite les tâches clients en réduisant les abonnements, p. ex. corriger 5–10 bugs/jour ou prototyper en 24–48 h.

• Petites équipes/start-up (3–15 devs) : outil unique dans l’éditeur pour accélérer revue de code et tests, sans configuration complexe ni coût élevé.

• Étudiants et autodidactes : explications interactives dans le projet, exemples concrets et exercices courts sur recursion, API design.

• Entreprises sensibles aux données : modèles locaux (Local LLMs) pour garder le code source sur le réseau interne, surtout finance et santé.

• Contributeurs open source : comprendre vite de grands dépôts (100 000+ lignes) et proposer des changements conformes au style.

2) Différenciation

• Confidentialité flexible : cloud pour modèles hébergés ou 100 % local via Ollama/llama.cpp, avec bascule instantanée bloquant sa sortie.

• Contexte approfondi : Semantic Indexing, recherche par sens et index actualisé en moins de 30 s après sauvegarde.

• Agents contrôlables : étapes multiples (lecture, modification, commandes), approbation avant action sensible et journal de revue/annulation.

• Intégration ouverte : MCP pour bases de données, tickets ou API internes via un fichier JSON.

• Expérience légère : chat latéral, faible mémoire, raccourcis personnalisables et streaming lancé en moins de 2 s.

3) Périmètre V1 (8 tâches max.)

1. Extension VS Code : chat latéral avec Markdown et coloration du code.

2. Fournisseurs multiples : OpenAI-compatible APIs, Ollama et llama.cpp via config unifiée.

3. Clés/paramètres : stockage chiffré local des clés API, option de désactiver l’envoi cloud.

4. Indexation sémantique initiale : index local avec embeddings et recherche des extraits pertinents (jusqu’à 50 000 fichiers texte).

5. Édition avec accord : Diff et boutons accepter/refuser par fichier avant sauvegarde.

6. Terminal contrôlé : commandes proposées (tests, build) exécutées après accord explicite, sortie dans le panneau.

7. Historique/contexte : sessions locales, reprise et accès aux 20 dernières conversations.

8. MCP initial : connexion à au moins un serveur, affichage des outils et appel depuis le chat.

4) Prix et revenus

• Free : chat, édition avec accord, modèles personnels ou locaux, sans plafond strict (usage équitable).

• Pro à 8 $/mois : indexation rapide des grands projets, synchro chiffrée facultative, support e-mail prioritaire sous 48 h.

• Team à 12 $/utilisateur/mois : règles de confidentialité communes, modèles de commandes d’équipe, rapports mensuels (sans contenu du code).

• Entreprise : contrat annuel dès 2 000 $/an pour 20 utilisateurs, déploiement interne assisté et support dédié aux heures ouvrées.

• Principe : monétiser l’organisationnel et le support, en gardant l’essentiel gratuit pour l’adoption et la confiance.

5) Diffusion gratuite mondiale

• Marché des extensions VS Code : page optimisée (mots-clés, visuels, vidéo de 60–90 s d’un cas réel).

• GitHub open source : licence claire, guide de contribution, modèles d’Issues ; objectif : 500 étoiles en 3 mois.

• Contenu pratique : 8 articles/tutoriels (arabe/anglais) sur « corriger un bug en 10 min » ou « comprendre un dépôt en 15 min ».

• Communautés : mises à jour hebdo sur Reddit, Hacker News et Discord, axées sur transparence et confidentialité, avec retours précoces.

• Ambassadeurs étudiants : 10 clubs techniques universitaires, ateliers gratuits, kit prêt ; objectif : 1 000 utilisateurs actifs/mois en 6 mois.

6) Risques

• Fuite de données : envoyer du code à des fournisseurs externes menace la confidentialité ; solution : mode local par défaut pour projets sensibles et alertes avant requête cloud.

• Suggestions erronées : modifications incorrectes possibles ; solution : approbation obligatoire de chaque Diff et tests auto après édition.

• Licences tierces : risque de conflits ; solution : revue automatique en CI et bibliothèques sous licences compatibles (MIT/Apache-2.0).

• Appareils limités : indexation et modèles locaux gourmands ; solution : taille d’index personnalisable et modèles légers (7B ou moins).

• Évolution des APIs/MCP : risque de rupture ; solution : couche d’abstraction et tests d’intégration hebdo avec versions expérimentales.

7) Nom et slogan

Nom proposé : Nasaq Code (نسق كود)

Slogan : votre assistant de codage intelligent dans votre éditeur : il comprend votre projet et préserve votre vie privée.
