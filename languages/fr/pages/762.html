Revilo — Plan de projet complet

Un lien d'aperçu pour chaque modification en une minute, qui s'arrête automatiquement avant que vous ne payiez.

Nouveau projet numérique : idée, public, produit, revenu, diffusion, risques. En construction, non lancé.

1) Public cible

• Startups produit (5–20 devs) : mises à jour/jour ; designer et chef de produit voient la feature sur un lien réel avant fusion, sans long cycle ni ops.

• Plateformes internes (3–8 ingénieurs) : 1–3 clusters Kubernetes ; uniformiser build/déploiement sur 10–40 dépôts, sans configs répétées.

• ETI (50–300 salariés) : audit ; historique clair par déploiement : demande, contrôles, approbation, mise en production.

• Open source : petits projets, 20–200 fusions/mois ; aperçu auto par demande, moins de commentaires aléatoires, débat sur version réelle.

• Formation : bootcamps pour 30–120 apprenants ; environnement sûr, vite créé/supprimé, sans facture surprise.

• Indépendants : 1 dev, 2–5 apps, pas le temps d'un CI/CD complet ; mêmes fonctions, gratuit sans carte.

2) Atouts (pourquoi nous)

• Aperçu décisionnel, sans config : connecter le dépôt suffit ; lien unique par demande en ~90 s, dans un commentaire : état du build, lien, résumé des contrôles.

• Coût maîtrisé : 30 min par défaut + plafond 2 h, extinction à la clôture ; coût horaire estimé affiché avant création, pas après.

• Modèles sans code : 12 modèles (interface React, Vue, Django, Node.js ; service Go ; tâche Python...) en liste déroulante ; pipeline en fichier relu, pas en boîte noire.

• Conditions simples : règles lisibles, logique non éparpillée : « front seul → pas de rebuild serveur », « branche dependabot → contrôles légers ».

• Neutre : tout cluster Kubernetes compatible ; local avec Kind ou k3d ; moteur d'exécution remplaçable derrière l'interface, usages inchangés.

• Dev first : commandes courtes, aucune config ; un seul CLI pour lister, ouvrir, prolonger, supprimer ; notifications Slack et Teams au besoin, pas par défaut.

3) Périmètre v1 (8 tâches max.)

1. Dépôt : login GitHub ou GitLab, 1 dépôt, webhook auto, autorisations vues avant accord.

2. Modification : lire la demande, classer les fichiers, choisir le modèle, ID unique visible dans tous les journaux.

3. Image : image conteneur, cache partagé, tag commit, envoi au registre de l'utilisateur ou registre intégré gratuit.

4. Qualité : contrôles statiques, tests unitaires, dépendances connues ; résultat en un commentaire, pas de messages épars.

5. Aperçu : namespace isolé, valeurs de la demande, sous-domaine, expiration en base légère.

6. Cycle de vie : commentaire à chaque changement, suppression à la clôture/expiration ; bouton « Déployer en production », accord écrit optionnel, journal exportable.

4) Tarifs et revenu

• Départ (0 $) : 1 dépôt, 20 aperçus/mois, 2 h max/env., journaux 7 jours, 12 modèles ; sans carte ni limite de durée.

• Équipe (19 $/mois/dev actif, min. 3) : 10 dépôts, 300 aperçus, durée jusqu'à 6 h, journaux 30 jours, Slack, support e-mail sous 1 jour ouvré.

• Croissance (79 $/mois) : dépôts illimités, environnements parallèles par demande, approbations, tableau de coûts avancé, sauvegarde du journal, chat.

• Entreprise (selon taille, dès 400 $/mois) : cluster client, LDAP/SSO, audit centralisé, SLA 99,9 %, support annuel.

• Règles équitables : ni pub, ni revente de données, ni frais surprises ; dépassement → avertissement puis arrêt sauf confirmation ; export total à la résiliation.

• Revenu : abonnements des équipes ; appoint limité : pack de modèles sur mesure à 199 $ (une fois) pour un modèle interne conforme.

5) Diffusion mondiale, canaux gratuits

• Dépôts : extension légère sur GitHub et GitLab, installation en 1 étape, config locale prête, étiquette changeant par version.

• Contenu : 12 articles courts arabe/anglais « Ajouter un aperçu à une demande de fusion en 5 minutes », 6 vidéos de 90 s, exemples copiables.

• Communautés : solutions dans les canaux Kubernetes et CNCF locaux, 4 sessions hebdo en direct sur plateformes gratuites, 8 semaines, enregistrements consultables.

• Ambassadeurs : 50 devs, badge et accès anticipé contre article, vidéo ou correctif ; tableau d'honneur mensuel plutôt que primes.

• Intégrations : commande de canal Slack et Microsoft Teams, recherche VS Code et JetBrains montrant les env. actifs ; gratuites, révisables.

• Objectifs : 1 000 utilisateurs actifs en 6 mois, 200 installations/mois, 35 % de rétention à 30 jours ; événements anonymes, collecte hebdo, publication transparente.
