MDM1 · Plan de projet

Khayt — plan de projet complet

Plateforme locale-first pour créer et exécuter des agents de navigateur fiables, reproductibles à chaque étape, l’humain au centre des décisions.

Plan complet : idée, public, produit, revenus, diffusion, risques ; en construction, non lancé.

1) Public cible

• Développeurs d’agents AI : automatisation de navigateur inspectable et rejouable, pas de scripts fragiles.

• Ingénieurs automatisation/QA : tests manuels convertis en workflows fiables.

• Agences et petites équipes : collecte/saisie de données sans gros coûts cloud.

• Organisations sensibles : automatisation sur leur infrastructure, clés privées ou Ollama.

• Chercheurs et créateurs techniques : expérimentation gratuite et reproductible.

2) Points de différenciation

• Local-first : interface web locale en une commande, exécuteur léger local ou Docker, Ollama/OpenAI ; aucune donnée de navigation envoyée à l’extérieur.

• Éditeur double : DAG visuel et code TypeScript/Python, variables typées, validation instantanée.

• Capsule de replay : screenshots, snapshots DOM, réseau et appels au modèle ; données personnelles assainies, erreurs reproduites.

• Gouvernance, pas dissimulation : ni usurpation ni contournement de CAPTCHA ; allowlist, débit limité, approbation humaine avant envoi/achat/suppression, audit.

• Export portable : MCP server, API REST, webhook ou CLI, sans dépendance fournisseur.

• Lab d’évaluation : tests, assertions, régressions, taux de réussite ; automatisation maintenable.

3) Première version (8 tâches maximum)

1. Exécuteur local : Docker/npm, Chromium via Playwright, Ollama ou clé API.

2. Studio web : éditeur visuel/code, variables typées, validation, sauvegarde locale.

3. Enregistreur modifiable : clics, saisie, navigation ; selectors d’accessibilité avant coordonnées.

4. Capsule de replay : screenshots, DOM, réseau, console, appels LLM ; masquage des champs sensibles.

5. File parallèle : concurrence, timeouts, retries, budgets tokens/coût.

6. Politiques et secrets : allowlist, approbation humaine, débit limité, audit.

7. Export/automatisation : MCP server, REST/webhook, planification, CLI hors studio.

8. Évaluation : données de test, assertions, comparaison de versions, rapport succès/échec exportable.

4) Tarification et revenus

• Free / Local : gratuit à vie, auto-hébergé ; workflows illimités, 2 sessions, historique 7 jours, modèles locaux ou clés, support communautaire.

• Pro : 19 $/utilisateur/mois ; cloud facultatif, 10 sessions, historique 30 jours, exécution planifiée, support e-mail.

• Team : 39 $/utilisateur/mois ; espace partagé, RBAC/SSO, export d’audit, 50 sessions, historique 90 jours, support prioritaire.

• Enterprise : tarif personnalisé ; déploiement isolé, SLA, conformité, connecteurs privés, formation.

Revenus : abonnements d’équipes + exécution cloud facultative + déploiement/intégration ; aucune marge sur les clés, version locale gratuite sérieuse.

5) Diffusion mondiale par canaux gratuits

• GitHub : cœur open source Apache 2.0, modèles de workflows, issues débutants.

• SEO/contenu : « automatisation de navigateur en local », « alternative auto-hébergée pour agents », comparaisons coût/confidentialité anglais-arabe.

• YouTube/blogs : workflow en 10 minutes, debugging avec replay, benchmark local/cloud.

• Communautés : Show HN, Product Hunt, Ollama/MCP, subreddits selon règles, Discord.

• Intégrations : modèles n8n, LangChain, LlamaIndex, Dify ; MCP server dans annuaires MCP et listes d’outils.

• Partenariats : agences, clubs universitaires, hackathons, meetups AI. Mesure : premier lancement < 10 min, réutilisation hebdomadaire.

6) Risques juridiques et techniques

Juridiques :

• Sites/lois sur les données ; charte, allowlist, audit, robots et API officielles, refus de contourner CAPTCHA ou usurper une identité.

• Actions de l’agent ; approbation humaine des actions financières/envoi, limites claires, clause de non-responsabilité.

• Données/clés ; local par défaut, chiffrement, logs nettoyés, DPA cloud.

Techniques :

• Sites changeants, selectors cassés ; selectors sémantiques, navigateur épinglé, régressions via replay.

• Anti-bots ; échec transparent, API officielles, aucune dissimulation.

• Code non fiable ; conteneurs isolés, moindres privilèges, modèles signés, secrets séparés.

• Prompt injection via pages et outils MCP ; contenu nettoyé, jetons limités, approbation des outils sensibles.

• Coût excessif ; concurrence limitée, budgets, timeouts par défaut.

7) Nom proposé et slogan

Nom proposé : Khayt

Slogan : plateforme locale-first pour créer et exécuter des agents de navigateur fiables, reproductibles à chaque étape, l’humain au centre des décisions.
