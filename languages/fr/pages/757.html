سِجيل — Plan de projet complet

Enregistrez vos dépenses en cinq secondes et gardez vos données à vous, où que vous alliez.

Plan complet : idée, public, produit, modèle économique, diffusion, risques. En construction, non lancé.

1) Public cible

• Petits entrepreneurs/indépendants : 30-50 factures/mois, registre simple sans comptabilité.

• Sensibles confidentialité : employés, médecins, journalistes ; données sur appareil, export CSV/JSON.

• Zones faible connectivité : Internet coupé quotidiennement ; saisie hors ligne puis sync sans perte.

• Avancés/développeurs : automatisation et MCP (assistant, scripts).

• Familles/multi-devises : transferts étranger, suivi devise locale+dollar, conversion quotidienne, rapports partageables.

2) Points de différenciation

• Appareil d'abord, cloud optionnel : enregistrement local, hors ligne instantané, données propriété utilisateur.

• Liberté lieu sync : iCloud, WebDAV, S3, serveur auto-hébergé ; NAS ou fournisseur en un clic.

• Saisie intelligente : caméra capture reçu, lit texte/montant/date, propose catégorie ; confirmation d'une touche, <5 s.

• Automatisation ouverte via MCP : assistants lisent résumés et ajoutent écritures, autorisations révocables, journal.

• Expérience arabe native et design propre : interface arabe complète, équivalent iOS/Android/Web.

• Départ gratuit sans promesses trompeuses : pas de pub ni vente données, base gratuite à vie, export disponible.

3) Portée v1 (8 tâches max)

1. Base locale (SQLite) pour enregistrer revenu/dépense en <5 s et catégoriser auto.

2. Interface saisie arabe pour ajouter, modifier, supprimer, rechercher par nom/montant/date.

3. Écran résumé mensuel : revenus, dépenses, profit net, graphique circulaire catégories.

4. Moteur sync arrière-plan iCloud/WebDAV/S3 ; conflits résolus en interrogeant utilisateur.

5. Capture reçu caméra et extraction IA, confirmation obligatoire avant enregistrement.

6. Export complet CSV/JSON et sauvegarde chiffrée par mot de passe.

7. Version web navigateur + apps iOS/Android, interface unifiée et stockage local indépendant.

8. Serveur auto-hébergé avec fichier config (Docker) et interface MCP lecture/ajout.

4) Tarification et modèle économique

• Gratuit à vie (Free) : jusqu'à 100 opérations/mois, catégories de base, sync un serveur, export complet, accès sans carte.

• Pro : ~39 $/an ou 5 $/mois, opérations illimitées, rapports avancés, plusieurs serveurs sync, sauvegardes auto ; 10 000 abonnés ≈ 390 000 $/an.

• Crédits IA optionnels : 50 captures gratuites/mois, puis lot 500 pour 4 $.

• Support/hébergement payants : serveur auto-hébergé gratuit, contrat maintenance/support 99 $/an pour petites entreprises.

• Règles confiance : pas de pub ni vente/partage données financières, page tarification expliquant montant.

5) Plan de diffusion mondiale par canaux gratuits

• Open source GitHub : code sous licence claire, README pratique, tags recherche arabe/anglais.

• Boutiques apps : publication App Store et Google Play, description gratuite, réponse aux avis sous 24 h, ciblage mots-clés.

• Communautés/forums : partage guides réels dans communautés confidentialité et auto-hébergement, Reddit/Hacker News, 30 publications utiles en deux mois.

• Contenu/éducation : 12 articles et vidéos 90 s montrant saisie caméra hors ligne.

• Localisation progressive : arabe et anglais jour 1, puis français, espagnol, turc sous six mois via bénévoles.

• Partenariats confidentialité : collaboration avec petits hébergeurs pour guide installation prêt à l'emploi.

6) Risques (juridiques/techniques)

• Réglementation financière/fiscale : pas de conseil fiscal, avertissement clair, éviter promesses « prêt pour impôts », examiner règles UE avant abonnement.

• Protection données (RGPD etc.) : sync cloud soumise règles confidentialité ; politique claire, suppression définitive, consentement explicite, zone stockage.

• Complexité sync : modification simultanée peut perdre données ; atténuation par journaux numérotés, sauvegardes, écran choix conflit.

• Précision IA : montant peut être erroné ; enregistrement par utilisateur, source des champs, mesure hebdomadaire, refus images floues.

• Sécurité/confiance : clés chiffrement hors serveurs ; chiffrement bout en bout et audit indépendant avant annonce.

• Durabilité/concurrence : alternatives gratuites font pression ; diversifier revenus (Pro, crédits IA, support), écouter utilisateurs.

7) Nom proposé et slogan

Nom proposé : سِجيل

Slogan : Enregistrez vos dépenses en cinq secondes et gardez vos données à vous, où que vous alliez.
