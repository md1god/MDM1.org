Rukn UI — plano de projeto completo

Uma única interface .NET escrita uma vez que funciona de forma fluida no desktop, no celular e na web.

Plano de implementação completo para um novo projeto digital: a ideia, o público, o produto, o modelo de lucro, o plano de divulgação e os riscos. O projeto está em construção e ainda não foi lançado.

Plano de produto: um framework de interfaces unificado para a plataforma .NET

A ideia e o problema: os desenvolvedores .NET sofrem com a dispersão das interfaces entre ferramentas de desktop, celular e web, com ciclos de build lentos, vazamento de detalhes técnicos e dificuldade de transportar o mesmo código entre plataformas. Apresentamos um novo framework que permite escrever uma única interface em uma linguagem de descrição moderna e renderizá-la de forma nativa em cada plataforma, com uma experiência de desenvolvimento instantânea.

1) Público-alvo

• Desenvolvedores C#/.NET que criam aplicativos de desktop ou de negócios.

• Equipes que querem uma única interface para desktop, celular e WebAssembly sem reescrever.

• Empresas que precisam de aplicativos internos rápidos e fáceis de publicar no Windows, Linux e macOS.

• Desenvolvedores independentes e startups que buscam um modelo gratuito para começar.

2) Diferenciais (por que escolher nosso produto)

• Um novo motor de renderização escrito do zero com design independente, que não depende de nenhum código anterior.

• Uma linguagem de descrição moderna, mais limpa e mais curta que as alternativas, com verificação de erros durante a escrita.

• Recarregamento instantâneo (Hot Reload) para todas as plataformas, incluindo a web.

• Interface unificada para dispositivos: entradas, notificações, armazenamento e permissões por meio de uma única camada de abstração.

• Suporte a Native AOT para tamanhos de execução pequenos e velocidade de inicialização alta.

• Sistema de plugins isolado que permite à comunidade expandi-lo sem afetar o núcleo.

• Totalmente gratuito para começar, sem restrições a projetos pessoais ou educacionais.

3) Escopo da primeira versão (no máximo 8 tarefas)

1. Núcleo do motor de renderização e camada de desenho vetorial.

2. Analisador e compilador da nova linguagem de descrição.

3. Sistema de layout (Layout), estilos e aparência.

4. Modelo de vinculação de dados e interação (Reactive).

5. Conjunto de 20 componentes básicos prontos.

6. Sistema de build e execução para quatro plataformas: Windows, Linux, macOS e WebAssembly.

7. Ferramenta de recarregamento instantâneo e linha de comando de desenvolvimento.

8. Documentação de início rápido e exemplos prontos.

4) Preços e modelo de lucro

• Gratuito: o núcleo, os componentes básicos e as ferramentas de desenvolvimento, com licença aberta para começar a usar.

• Pro (assinatura mensal): componentes avançados, designer visual e relatórios de desempenho.

• Enterprise (anual): suporte técnico prioritário, treinamento para equipes e hospedagem de registro de pacotes privado.

• Serviços pagos: consultoria de migração e criação de interfaces personalizadas.

5) Plano de divulgação global com canais gratuitos

• Publicar o repositório em uma plataforma de hospedagem de código aberto e construir reputação inicial.

• Escrever artigos técnicos em plataformas para desenvolvedores e documentar exemplos práticos.

• Publicar vídeos curtos e workshops ao vivo por meio de plataformas de vídeo.

• Lançar um template inicial pronto e projetos de código aberto construídos sobre ele.

• Participar de comunidades .NET e de perguntas técnicas, oferecendo respostas práticas.

• Inscrever-se em conferências gratuitas para desenvolvedores e hackathons.

6) Riscos (legais e técnicos)

• Legais: evitar qualquer cópia literal de código, ativos ou marcas; adotar uma licença clara e auditar a propriedade intelectual antes da publicação.

• Legais: garantir a compatibilidade das licenças das bibliotecas externas utilizadas.

• Técnicos: o desafio da compatibilidade entre as quatro plataformas e as várias versões do .NET.

• Técnicos: a concorrência de frameworks maduros, o que exige diferenciação clara e qualidade de documentação.

• Técnicos: manter o desempenho com Native AOT e gerenciar com segurança o ciclo de vida dos plugins.

7) Nome sugerido e slogan de marketing

Nome sugerido: Rukn UI

Slogan de marketing: uma única interface .NET escrita uma vez que funciona de forma fluida no desktop, no celular e na web.
