Mihak — Rencana Proyek Lengkap

Mihak: Periksa setiap server MCP, ketahui risikonya, dan buktikan keamanannya sebelum Anda memberikannya kepercayaan.

Rencana pelaksanaan lengkap untuk proyek digital baru: ide, audiens, produk, model bisnis, rencana penyebaran, dan risiko. Proyek ini masih dalam pengembangan dan belum diluncurkan.

1) Audiens Target

Kesenjangan: server MCP menyebar dengan cepat dan diberikan akses ke file, perintah, dan data produksi sebelum keamanan mereka diverifikasi. Produk ini menyediakan pemeriksaan dan evaluasi yang jelas sebelum memberikan kepercayaan.

• Pengembang dan agen AI serta tim yang menghubungkan server MCP dengan alat mereka.

• Insinyur keamanan, DevSecOps, dan AppSec.

• Tim platform dan kepatuhan yang membutuhkan log audit dan bukti.

• Pengelola proyek open source dan penyedia server MCP.

• Usaha kecil dan menengah yang mengadopsi MCP tanpa tim keamanan khusus.

• Penyedia layanan terkelola dan konsultan keamanan.

2) Keunggulan (Mengapa Memilih Produk Kami)

• Pemeriksaan ganda: analisis statis terhadap file definisi dan skema, serta eksekusi dinamis di lingkungan terisolasi yang secara default tidak mengizinkan koneksi eksternal.

• Evaluasi yang dapat dijelaskan: skor kepercayaan disertai bukti untuk setiap hasil, bukan angka yang tidak jelas.

• Daftar komponen MCP: catatan mengenai apa saja yang dapat diakses server seperti alat, file, jaringan, dan rahasia.

• Deteksi risiko rantai pasokan: tool poisoning, perubahan perilaku setelah persetujuan, prompt injection, izin luas, kebocoran rahasia, serta akses ke shell atau data produksi.

• Gerbang CI/CD: kebijakan sebagai kode yang menghentikan penggabungan jika risiko melebihi batas yang diizinkan.

• Pemantauan berkelanjutan: pemeriksaan ulang saat versi atau pengaturan berubah, disertai peringatan drift.

• Privasi terlebih dahulu: pemeriksaan lokal adalah default, dan rahasia tidak diunggah ke server.

• Transparansi: aturan dasar bersifat terbuka, dan kami tidak menjual peringkat keamanan yang lebih tinggi.

3) Lingkup Versi Pertama (Maksimal 8 Tugas)

1. Penemuan dan Inventarisasi: mengimpor pengaturan klien MCP umum dan membuat inventaris server serta alat.

2. Analisis Statis: memeriksa skema alat, izin, alamat jaringan, rahasia yang terlihat, dan instruksi tersembunyi.

3. Pemeriksaan Dinamis Terisolasi: menjalankan server di container sementara dengan canary secrets dan lingkungan tanpa jaringan, serta memantau akses ke file, perintah, dan jaringan.

4. Mesin Kepercayaan: aturan transparan + skor A-F + klasifikasi tingkat bahaya + panduan perbaikan.

5. Integrasi CI/CD: GitHub Action, keluaran SARIF/JSON, dan gerbang kebijakan yang mencegah penggabungan saat berisiko.

6. Pemantauan Berkelanjutan: pemeriksaan ulang saat versi atau pengaturan berubah, membandingkan hasil, dan menampilkan perbedaan.

7. Laporan dan Berbagi: laporan bertanda tangan yang dapat dibagikan, lencana untuk server aman, serta ekspor PDF/JSON.

8. Platform SaaS Gratis: akun, log pemeriksaan publik dengan persetujuan pemilik, dan batas penggunaan untuk paket gratis.

4) Harga dan Model Bisnis

Prinsip: gratis untuk memulai, pembayaran untuk perluasan dan operasi perusahaan, bukan untuk menaikkan peringkat keamanan.

· Paket · Harga · Isi ·

· Gratis · 0$ · 3 server, pemeriksaan manual, laporan publik, aturan komunitas ·

· Pro · 12$/pengembang/bulan atau 99$/tahun · 25 server, pemeriksaan berkelanjutan, gerbang CI, laporan pribadi ·

· Business · 29$/pengembang/bulan · Server tak terbatas, SSO/SAML, log audit, kebijakan, dukungan prioritas ·

· Enterprise · Harga khusus · Penerapan mandiri/on-prem, SLA, integrasi, audit kepatuhan ·

Sumber tambahan: lisensi penerapan mandiri, layanan audit keamanan manual, dan tinjauan perbaikan. Hasil pemeriksaan tidak dapat dibeli dan tidak dipengaruhi oleh langganan.

5) Rencana Penyebaran Global melalui Saluran Gratis

• Open Source: menerbitkan CLI dan mesin aturan dengan lisensi Apache-2.0 untuk membangun kepercayaan dan adopsi.

• GitHub: GitHub Action gratis dan pemeriksaan publik untuk repositori open source, dengan kehadiran di Marketplace.

• Konten: panduan praktis, analisis insiden MCP, dan \"10 Risiko Teratas\" dalam bahasa Arab dan Inggris.

• Komunitas: Discord, Reddit, Hacker News, komunitas MCP, dan komunitas alat agen.

• Kemitraan: penyedia server MCP, kerangka kerja agen, dan komunitas keamanan cloud.

• Peluncuran: Product Hunt, demo teknis, dan kompetisi CTF ringan seputar pengamanan server.

• Insentif: lencana gratis untuk server aman, dan program hadiah untuk menemukan aturan yang salah.
