سِجيل — Rencana Proyek Lengkap

Catat pengeluaranmu dalam lima detik, dan milikilah datamu sendiri ke mana pun kamu pergi.

Proyek digital baru: ide, audiens, produk, model pendapatan, distribusi, risiko. Masih dibangun, belum diluncurkan.

1) Audiens Target

• UMKM dan pekerja mandiri: toko, tukang cukur, desainer lepas; 30–50 faktur/bulan, buku kas sederhana tanpa ilmu akuntansi.

• Peduli privasi: karyawan, dokter, jurnalis; data tetap di perangkat, ekspor penuh ke CSV atau JSON kapan saja.

• Koneksi lemah: catat offline, sinkron saat sinyal kembali, tanpa hilang atau dobel.

• Pengguna lanjutan dan pengembang: otomasi dan MCP; tanya "pengeluaran bulan ini" ke asisten atau tambah entri lewat skrip.

• Keluarga multi-mata uang: transfer luar negeri, lokal dan dolar sekaligus, konversi harian, laporan bisa dibagikan.

2) Keunggulan (Mengapa Produk Kami)

• Perangkat dulu, cloud opsional: data tersimpan lokal, kerja offline instan, tanpa wajib akun cloud.

• Bebas server: iCloud, WebDAV, S3, atau self-hosted; NAS rumah atau penyedia satu klik.

• Input cepat: kamera membaca struk, jumlah, tanggal, menyarankan kategori; pengguna mengonfirmasi, target <5 detik.

• MCP: asisten membaca ringkasan dan menambah entri, izin bisa dicabut, ada catatan tiap transaksi.

• Arab asli, desain baru: penuh di iOS, Android, dan web, tanpa kesan terjemahan.

• Gratis tanpa janji palsu: tanpa iklan atau jual data, tanpa uji coba mendadak; versi dasar gratis selamanya, ekspor selalu ada.

3) Versi Pertama (maksimal 8 tugas)

1. Database lokal (mis. SQLite): catat pendapatan/pengeluaran di bawah 5 detik, kategori otomatis.

2. Input Arab: tambah, ubah, hapus, cari berdasarkan nama, jumlah, atau tanggal.

3. Ringkasan bulanan: pendapatan, pengeluaran, laba bersih, diagram lingkaran kategori.

4. Sinkronisasi latar dengan iCloud, WebDAV, S3; konflik ditanyakan ke pengguna.

5. Kamera menangkap struk, AI mengekstrak data, konfirmasi wajib sebelum menyimpan.

6. Ekspor penuh ke CSV dan JSON, cadangan terenkripsi kata sandi pengguna.

7. Web di browser plus aplikasi iOS dan Android, antarmuka terpadu, penyimpanan lokal mandiri.

8. Server self-hosted satu file konfigurasi (Docker) dan antarmuka MCP untuk baca dan tambah.

4) Harga dan Model Pendapatan

• Free selamanya: 100 transaksi/bulan, kategori dasar, satu server, ekspor penuh, tanpa kartu kredit.

• Pro: sekitar $39/tahun atau $5/bulan; transaksi tanpa batas, laporan lanjutan, banyak server, cadangan otomatis. 10.000 pelanggan ≈ $390.000/tahun.

• Kredit AI opsional: 50 tangkapan gratis/bulan, paket 500 seharga $4 untuk pemakai kamera intensif.

• Dukungan berbayar: server self-hosted tetap gratis, kontrak perawatan $99/tahun untuk UMKM, tanpa monopoli data.

• Aturan kepercayaan: tanpa iklan, tanpa jual atau bagikan data keuangan, halaman harga yang jelas.

5) Distribusi Global Gratis

• GitHub: kode berlisensi jelas, README praktis, tag Arab dan Inggris, menarik pengembang yang meninjau alat keuangan.

• Toko aplikasi: rilis di App Store dan Google Play, balas ulasan dalam 24 jam, kata kunci "pembukuan offline" dan "akuntansi self-hosted".

• Komunitas: panduan nyata di komunitas privasi dan self-hosting, Reddit, Hacker News; 30 kontribusi bermanfaat dalam dua bulan.

• Konten: 12 artikel memecahkan masalah seperti sinkron ponsel–server rumah, video 90 detik input kamera offline.

• Lokalisasi: Arab dan Inggris hari pertama, Prancis, Spanyol, Turki dalam enam bulan oleh relawan, format tanggal dan mata uang lokal dihormati.

• Kemitraan privasi: panduan pemasangan untuk server kecil sebagai ganti penyebutan alat dalam daftar mereka.

6) Risiko (Hukum dan Teknis)

• Keuangan dan pajak: tanpa konsultasi pajak, penafian jelas, hindari janji "siap pajak", tinjau aturan konsumen Uni Eropa.

• Data (GDPR dll): sinkron cloud tetap tunduk privasi; kebijakan jelas, hapus permanen, izin unggah tegas, wilayah penyimpanan ditetapkan.

• Sinkronisasi: edit entri sama dari ponsel dan server bisa hilang data; catatan perubahan bernomor, cadangan, pilihan saat konflik.

• Akurasi AI: jumlah bisa salah; simpan tetap di tangan pengguna, tampilkan sumber tiap kolom, ukur kesalahan mingguan, tolak gambar buram.

• Keamanan: kunci enkripsi jangan sampai ke server kami; enkripsi end-to-end dan audit independen sebelum peluncuran.

• Persaingan: banyak alternatif gratis; pendapatan terdiversifikasi antara Pro, kredit AI, dan dukungan, dengarkan pengguna.

7) Nama dan Kalimat Pemasaran

Nama yang diusulkan: سِجيل
