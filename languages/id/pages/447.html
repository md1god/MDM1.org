Jawb — Rencana Proyek Lengkap

Ketahui di mana merek Anda muncul dan di mana pesaing Anda unggul dalam jawaban AI — dengan angka, bukan intuisi.

Rencana eksekusi lengkap untuk proyek digital baru: ide, audiens, produk, model keuntungan, rencana distribusi, dan risiko. Proyek dalam pengembangan dan belum diluncurkan.

2) Poin Unik (Mengapa Memilih Produk Kami)

1. Sumber Data Terbuka (Data Provenance): Setiap angka menunjukkan kueri mana, mesin mana, tanggal mana, dan snapshot mana yang menghasilkan angka tersebut — bisa dijalankan ulang dan diaudit, tidak seperti dashboard tertutup yang tidak bisa diverifikasi.

2. Matriks Kesenjangan (Gap Matrix): Kami bandingkan jawaban Anda dengan jawaban pesaing pertanyaan per pertanyaan, dan tunjukkan pertanyaan di mana mereka disebut tapi Anda tidak — sinyal paling actionable.

3. Antrian Perbaikan (Fix Queue): Setiap kesenjangan diterjemahkan ke rekomendasi spesifik (halaman/dokumen/FAQ/schema.org) diurutkan berdasarkan dampak × usaha, dengan estimasi biaya pemanggilan LLMFixture rendah.

4. Peta Sumber Jawaban (Answer Source Map): Halaman apa yang dikutip di setiap mesin — mengungkap "Newsroom dan situs perbandingan" yang mendominasi jawaban, inti dari [sumber tersembunyi].

5. Indikator yang Diterjemahkan untuk Non-teknis: "Bagian Anda dari jawaban" bukan istilah SoV/citation-share yang membingungkan.

6. Citable-by-design: Laporan publik bisa disalin dengan hash + API read-only + ekspor CSV/JSON, endpoint kompatibel MCP untuk mengumpan agen AI.

7. Fleksibilitas Deployment: SaaS atau self-host (Docker) untuk agen dan governance.

8. Pusat Riset Gratis Tanpa Registrasi + Indeks Sektor Publik = Mesin Pertumbuhan Gratis Tanpa Pengeluaran Iklan.

3) Ruang Lingkup Versi Pertama (Maks 8 Tugas)

1. Setup Dashboard Kueri: Definisi merek (nama + sinonim), pesaing (maks 3), pertanyaan kustom dan perpustakaan pertanyaan siap pakai per sektor dan pasar/bahasa (Arab/Inggris), dan pengatur frekuensi (mingguan default).

2. Mesin Pengumpulan: Menjalankan kueri di ChatGPT, Gemini, Perplexity, Google AI Overviews, Claude, Microsoft Copilot via API resmi jika memungkinkan + lapisan fallback terbatas, dengan penyimpanan snapshot mentah (hash + timestamp + versi model).

3. Pipeline Ekstraksi: Deteksi sebutan merek (pencocokan entitas + sinonim + daftar negatif), ekstraksi link yang dikutip dengan normalisasi URL dan penghapusan tracking, dan klasifikasi sentimen (positif/netral/negatif) dengan aturan lalu LLM jika perlu.

4. Mesin Indikator: Rasio muncul per kueri, Answer Share, Citation Share, tren sentimen, agregasi per mesin/pasar/bagian, dengan ambang signifikansi statistik (minimal n dan pengecualian perbedaan kecil).

5. Matriks Kesenjangan & Kompetisi: Per kueri: siapa yang menyebut, siapa yang tidak, ukuran kesenjangan, dan estimasi "pertanyaan mudah cepat" diurutkan berdasarkan dampak.

6. Antrian Rekomendasi: Menghasilkan rekomendasi dari kesenjangan (update halaman, FAQ, Schema.org, review, PR) dengan menghubungkan setiap rekomendasi ke URL spesifik dan estimasi dampak.

7. Dashboard + Laporan: Grafik (visi muncul seiring waktu, peta sumber jawaban, matriks kesenjangan, perbandingan pesaing), laporan mingguan email, link laporan publik read-only tanpa registrasi, dan ekspor CSV/JSON.

8. Indeks Publik + API: Halaman publik per sektor/kota/negara menampilkan peringkat visibility gratis (tanpa mengekspos data klien), dan interface API read-only dengan kunci gratis + dokumen OpenAPI + contoh MCP.

Di Luar Ruang Lingkup Sekarang: Agen otomatis yang mengeksekusi rekomendasi di situs, multi-tenant untuk perusahaan, model prediksi, dukungan bahasa non-Arab/Inggris, platform chat terintegrasi (Slack/WhatsApp) — untuk fase kedua.
