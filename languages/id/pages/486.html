I'tidal — Rencana Proyek Lengkap

Iklim rumah Anda menyesuaikan sendiri dan menghemat energi, tanpa menyentuh katup.

Rencana lengkap proyek digital baru: ide, audiens, produk, pendapatan, peluncuran, risiko. Masih dibangun, belum diluncurkan.

1) Audiens sasaran

• Pemilik rumah dengan katup pemanas pintar (TRV) dan suhu tidak akurat dekat radiator.

• Pengguna Home Assistant ingin kontrol lokal tanpa cloud atau langganan wajib.

• Penyewa dan pemilik kecil ingin menurunkan tagihan tanpa mengganti sistem pemanas.

• Keluarga dengan suhu ruang tidak merata, sering buka jendela, atau sering pergi.

• Teknisi pemanas dan instalasi kecil butuh alat kalibrasi serta diagnostik berskala.

• Pasar Eropa dan Amerika Utara dulu, dukungan Arab penuh, antarmuka RTL.

2) Keunggulan (alasan memilih produk kami)

• Lokal: berjalan penuh di jaringan rumah, tanpa akun cloud wajib, tanpa menjual data.

• Multi-sensor: sensor ruangan, luar, jendela/pintu, keberadaan, dan prakiraan cuaca dalam satu keputusan.

• Kalibrasi adaptif: mempelajari dan mengoreksi penyimpangan tiap katup otomatis, bukan mengandalkan radiator.

• Transparan: alasan pemanasan/penghentian lewat log dapat diaudit, bukan kotak hitam.

• Kompatibel: Zigbee, Matter/Thread, Wi-Fi via Home Assistant, deteksi otomatis perilaku katup.

• Aman: batas bawah/atas, perlindungan antibeku, perilaku cadangan saat sensor hilang.

• Gratis untuk mulai: inti lokal selalu gratis; bayar hanya layanan opsional.

• Antarmuka Arab asli, bukan terjemahan susulan, dengan laporan hemat energi dan istilah mudah.

3) Lingkup versi pertama (maks. 8 tugas)

1. Inti kontrol lokal (Add-on/Container) dan penyiapan integrasi Home Assistant.

2. Model ruangan/zona, integrasi beberapa sensor (median/rata-rata berbobot), penolakan pembacaan menyimpang.

3. Kalibrasi katup adaptif dan pembelajaran offset, dengan batas suhu dan perilaku aman saat gagal.

4. Deteksi jendela/pintu dan keberadaan; pemanasan berhenti sementara lalu dilanjutkan.

5. Prakiraan cuaca, pemanasan awal, pemanfaatan matahari dan beban panas.

6. Jadwal mingguan, penggantian manual, mode penguatan sementara.

7. Dasbor visual dengan penjelasan keputusan, diagnostik, dan log dapat diekspor.

8. Wizard penyiapan awal, dokumentasi Arab/Inggris, uji kompatibilitas katup umum.

4) Harga dan model keuntungan

• Gratis (Free-to-start): inti lokal, ruangan tak terbatas, dasbor dasar, pembaruan keamanan. Tanpa kartu kredit.

• Pro: sekitar 3,99 euro/bulan atau 34,99 euro/tahun: cadangan cloud opsional, akses jauh tanpa VPN, analitik energi lanjutan, dukungan prioritas.

• Lifetime: ±89 euro (pribadi).

• Installer/Partner: sekitar 199 euro/tahun per fasilitas: pengelolaan banyak lokasi, laporan white-label.

• Perangkat opsional: sensor dan paket pemasangan harga pokok + margin kecil, tanpa kewajiban.

• Prinsip: tidak menjual data, tanpa biaya per katup, API terbuka untuk versi lokal.

5) Peluncuran global via kanal gratis

• Menerbitkan inti open source di GitHub dan mendaftarkannya ke HACS.

• Aktif di forum Home Assistant, Reddit, Discord/Matrix dengan jawaban teknis, bukan iklan.

• Tutorial YouTube: kalibrasi katup, hemat 20% tagihan, menghubungkan sensor jendela.

• SEO multibahasa untuk “kalibrasi TRV” dan “pemanas pintar hemat”.

• Perbandingan transparan dan studi kasus rumah dengan angka nyata.

• Peluncuran Show HN dan Product Hunt, partisipasi di pertemuan Home Assistant dan FOSDEM.

• Terjemahan komunitas via Weblate, program rujukan berhadiah bulan Pro gratis.

• Kemitraan gratis dengan teknisi pemanas dan asosiasi energi lokal via kalkulator hemat bersama.

6) Risiko (hukum dan teknis)

Hukum:

• Patuh GDPR, minimalisasi data, transparansi kebijakan privasi.

• Verifikasi merek dagang dan kebebasan penggunaan sebelum peluncuran.

• Lisensi open source kompatibel; hindari kode dan aset produk lain.

• Penafian jelas bila pemanas gagal atau pipa membeku.

• Jika menjual perangkat: patuh CE/UKCA, RED, RoHS, WEEE, jaminan konsumen.

Teknis:

• Protokol/perilaku katup berbeda; atasi dengan lapisan kompatibilitas dan pengujian komunitas.

• Perubahan mendadak Home Assistant; atasi dengan versi tersemat dan pengujian otomatis.

• Sensor hilang atau terlambat; atasi dengan data cadangan dan batas keamanan.

• Embun beku dan kegagalan katup; atasi dengan perlindungan independen offline.

• Keamanan siber; atasi dengan pembaruan bertanda tangan dan izin terbatas.

• Biaya cloud dan dukungan; atasi dengan fitur cloud opsional dan terbatas.

7) Nama dan slogan

Nama yang diusulkan: I'tidal (اعتدال)

Slogan: Iklim rumah Anda menyesuaikan sendiri dan menghemat energi, tanpa menyentuh katup.
