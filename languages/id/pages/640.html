سَرَيان — Rencana Proyek Lengkap

Simulasi fluida cepat dan andal di perangkat apa pun, dari laptop hingga klaster komputasi Anda.

Rencana lengkap proyek digital baru: ide, audiens, produk, model pendapatan, penyebaran, dan risiko. Proyek masih dibangun, belum diluncurkan.

Rencana produk: simulasi fluida cepat di perangkat keras apa pun

1) Audiens sasaran

• Insinyur fluida/aerodinamika di UKM butuh simulasi cepat tanpa lisensi mahal.

• Peneliti dan mahasiswa pascasarjana fisika, teknik mesin, teknik lingkungan.

• Pengembang simulasi/game ilmiah yang ingin pustaka cepat tersemat.

• Tim desain industri butuh penilaian visual instan aliran udara/air.

• Institusi pendidikan mencari alat untuk komputer laboratorium lama/baru.

2) Keunggulan (mengapa memilih produk kami)

• Lokal pertama: tanpa cloud/perangkat tertentu, dengan percepatan otomatis via WebGPU, Vulkan/Metal, CUDA, dan fallback CPU.

• Penyiapan 10x lebih cepat: impor geometri, pilih fluida, jalankan simulasi <2 menit.

• Antarmuka visual modern dengan editor parameter dan tampilan aliran langsung, bukan konfigurasi rumit.

• Transparansi performa: panel metrik membandingkan akurasi/kecepatan pada perangkat pengguna, dengan paket validasi terpublikasi.

• Skalabilitas tanpa ubah kode: dari laptop ke klaster via antarmuka baris perintah dan Python API.

• Gratis sejak awal untuk penggunaan lokal individual penuh, tanpa batas waktu/tanda air.

• Privasi data: simulasi dan geometri tetap di perangkat pengguna secara default.

3) Cakupan versi pertama (maksimal 8 tugas)

1. Mesin LBM dasar 2D/3D (D2Q9, D3Q19) untuk aliran tak termampatkan, batas sederhana.

2. Eksekusi multi-perangkat keras: WebGPU untuk web; Vulkan/Metal/CUDA untuk desktop; CPU SIMD cadangan.

3. Impor geometri STL/OBJ, pembuat adegan siap pakai, pengaturan kondisi batas.

4. Antarmuka visual untuk kecepatan, viskositas, jaringan, waktu, dengan pratinjau aliran langsung.

5. Paket validasi 10 kasus referensi dengan laporan akurasi/performa yang dapat direproduksi.

6. Ekspor hasil ke VTK, CSV, gambar, video singkat.

7. Antarmuka baris perintah dan Python API untuk batch/otomatisasi eksperimen.

8. Berbagi hasil via tautan ringan atau berkas proyek lokal, tanpa unggah data secara default.

4) Harga dan model keuntungan

• Gratis selamanya: penggunaan lokal individual, semua fitur simulasi dasar, ekspor tanpa batas.

• Pro individu: 9 dolar/bulan atau 79 dolar/tahun, dengan kolaborasi, perbandingan lanjutan, dukungan prioritas.

• Team: 29 dolar/pengguna/bulan, dengan ruang bersama, riwayat versi.

• Enterprise: lisensi tahunan on-premise, dukungan integrasi khusus, tanpa unggah data.

• Cloud opsional berbasis konsumsi: menghitung menit eksekusi saat kapasitas lokal terlampaui.

• Keuntungan tambahan: templat siap pakai, kursus pelatihan, lisensi komersial pustaka penyematan.

5) Rencana penyebaran global via kanal gratis

• GitHub: contoh, templat, paket validasi, rilis gratis rutin.

• YouTube: seri singkat "dari geometri ke hasil dalam dua menit" multibahasa.

• Papan peringkat publik: perbandingan performa transparan pada perangkat pengguna, mendorong partisipasi organik.

• Komunitas ilmiah: Reddit, Discord, LinkedIn, komunitas CFD, dengan konten edukatif, bukan iklan.

• Universitas: lisensi pendidikan gratis dan lokakarya praktik untuk adopsi awal.

• SEO dan konten teknis: artikel tentang validasi hasil dan pengurangan konsumsi memori.

• Paket pengembang: pustaka Python di PyPI, contoh di Hugging Face dan Colab.

• Hackathon dan kompetisi berhadiah kecil untuk menarik kontribusi/contoh baru.

6) Risiko (hukum dan teknis)

• Hukum: klaim mungkin atas algoritma LBM terpublikasi atau paten lama; ditangani via tinjauan hukum, penelitian terbuka terdokumentasi, dan menghindari kode/aset produk lain.

• Lisensi: risiko lisensi tidak kompatibel; ditangani via kebijakan persetujuan dependensi, pemeriksaan otomatis.

• Ekspor/data: pembatasan simulasi di sektor sensitif; ditangani via syarat penggunaan, klasifikasi jelas.

• Teknis: perbedaan presisi desimal antarperangkat; ditangani via pengujian validasi wajib, dokumentasi batas setiap backend.

• Performa tak terduga: variasi definisi GPU; ditangani via cadangan otomatis, panel metrik bawaan.

• Kualitas hasil: risiko kepercayaan pengguna; ditangani via kasus referensi terpublikasi, perbandingan dengan solusi analitis.
