Reflow — Rencana Proyek Lengkap

Tautan pratinjau untuk setiap perubahan dalam satu menit, berhenti otomatis sebelum Anda membayarnya.

Rencana proyek digital baru: ide, audiens, produk, model bisnis, distribusi, risiko. Sedang dibangun, belum diluncurkan.

1) Audiens Target

• Produk rintisan (5–20 pengembang): update harian berkali-kali; desainer dan PM ingin lihat fitur di tautan nyata sebelum merge, tanpa deploy panjang/engineer operasi.

• Platform internal (3–8 engineer): 1–3 klaster Kubernetes; satukan build/deploy di 10–40 repositori tanpa konfigurasi berulang per tim.

• Perusahaan menengah (50–300 karyawan): butuh audit; catatan per deploy: perubahan → cek → setuju → tayang di produksi.

• Sumber terbuka: tim kecil, 20–200 merge request/bulan; tautan pratinjau otomatis per request agar komentar acak turun, diskusi berbasis versi nyata.

• Pendidikan: bootcamp continuous delivery, 30–120 peserta; lingkungan aman cepat dibuat/dihapus, tanpa tagihan mendadak.

• Freelancer: 1 pengembang, 2–5 aplikasi; tak punya waktu CI/CD lengkap, ingin fitur sama, gratis tanpa kartu kredit.

2) Keunggulan (Mengapa Produk Kami Dipilih)

• Pratinjau lewat keputusan: cukup hubungkan repositori; tautan unik per request ~90 detik, di komentar berisi status build, tautan, ringkasan cek.

• Kesadaran biaya: tiap lingkungan default 30 menit + maks 2 jam, mati saat request ditutup; dasbor biaya/jam tampil sebelum buat, bukan sesudah.

• Template tanpa kode: 12 template (React, Vue, Django, Node.js, layanan Go, tugas Python...), dipilih dari drop-down; pipeline jadi file tinjauan, bukan kotak hitam.

• Mesin kondisi: aturan terbaca, bukan logika tersebar: «ubah file antarmuka saja → jangan build ulang server»; «cabang dependabot → cek ringan».

• Netral teknologi: klaster Kubernetes kompatibel apa pun; lokal via Kind atau k3d; mesin eksekusi bisa diganti tanpa ubah cara pakai.

• Utamakan pengembang: perintah singkat, tanpa pengetahuan awal; satu CLI lihat/buka/perpanjang/hapus lingkungan; notifikasi Slack dan Teams sesuai kebutuhan, bukan default.

3) Lingkup V1 (Maks 8 Tugas)

1. Hubungkan repositori: login GitHub/GitLab, pilih 1 repo, webhook otomatis, pratinjau izin sebelum setuju.

2. Ekstrak perubahan: baca merge request, klasifikasi file, pilih template, ID unik lingkungan di semua log.

3. Bangun image: image kontainer dengan cache bersama, tag ID commit, push ke registry pengguna atau gratis bawaan.

4. Cek kualitas: cek statis, tes unit, cek dependensi; hasil jadi 1 komentar, bukan pesan tersebar.

5. Lingkungan pratinjau: namespace sendiri, nilai khusus request, subdomain, masa kedaluwarsa di database ringan.

6. Siklus hidup & deploy: komentar update tiap perubahan; hapus saat tutup/timeout; tombol «Deploy ke produksi» + persetujuan tertulis opsional, log bisa diekspor.

4) Harga dan Model Pendapatan

• Awal (0 dolar): 1 repo, 20 lingkungan/bulan, maks 2 jam, log 7 hari, 12 template; tanpa kartu kredit, tanpa batas waktu.

• Tim (19 dolar/bulan per pengembang aktif, min. 3): 10 repo, 300 lingkungan, maks 6 jam, log 30 hari, notifikasi Slack, email 1 hari kerja.

• Pertumbuhan (79 dolar/bulan): repo tak terbatas, lingkungan paralel per request, kebijakan setuju, dasbor biaya lanjutan, cadangan log deploy, chat langsung.

• Perusahaan (mulai 400 dolar/bulan): di klaster pelanggan, LDAP/SSO, audit terpusat, perjanjian tingkat layanan 99,9%, kontrak tahunan.

• Adil: tanpa iklan/jual data/biaya mendadak; lewat batas → peringatan dulu, pembuatan berhenti kecuali dikonfirmasi; ekspor data saat batal.

• Pendapatan: langganan tim; sekunder dari paket template khusus 199 dolar (sekali bayar) untuk template internal sesuai standar.

5) Rencana Distribusi Global via Kanal Gratis

• Repositori: ekstensi ringan di pasar GitHub dan GitLab, pasang 1 langkah, file konfigurasi lokal, tag berubah tiap rilis.

• Konten: 12 artikel Arab–Inggris «Tambahkan tautan pratinjau ke merge request dalam 5 menit», 6 rekaman layar 90 detik, contoh siap salin.

• Komunitas: kanal Kubernetes dan CNCF lokal, 4 sesi mingguan via streaming gratis 8 minggu pertama, rekaman tetap dicari.

• Duta: 50 pengembang dapat lencana + versi awal untuk artikel/video/perbaikan template; papan kehormatan bulanan, bukan uang.

• Integrasi: perintah di Slack dan Microsoft Teams, pencarian di VS Code dan JetBrains untuk lingkungan aktif; gratis, terbuka ditinjau.

• Pengukuran: 1.000 pengguna aktif/6 bulan, 200 instalasi/bulan, retensi 35% di hari ke-30, dari peristiwa anonim mingguan transparan.
