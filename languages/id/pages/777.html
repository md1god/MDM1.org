Mehwar — Rencana Proyek Lengkap

Ubah model mobil apa pun menjadi enam denah ortografis akurat siap cetak dalam kurang dari dua puluh detik, tanpa instalasi atau unggah berkas.

Rencana proyek digital baru: ide, audiens, produk, model pendapatan, distribusi, risiko. Sedang dibangun, belum diluncurkan.

1) Audiens Target

• Pemodel simulasi (55%): bangun ulang mobil dari model ada untuk game balap. Model GT butuh tampilan atas/samping/depan sesuai dimensi; kini atur 6 kamera, sembunyikan roda+kaca, 15–25 menit/mobil.

• Desainer/reverse engineering (20%): desain ulang mobil klasik; denah 1:10 di A3 di samping model tanah liat di meja.

• Developer game indie (10%): studio 2–5 orang ingin satu "lembar referensi" proporsi/sudut, bukan gambar forum.

• Mahasiswa/pemula (10%): belajar hard-surface, butuh silhouette bersih tanpa set pencahayaan dan kamera.

• Kreator konten/bengkel cetak (5%): rekam tutorial atau rangka mobil remote control 1:8; butuh denah cetak dengan grid ukur.

2) Keunggulan

• Nol instalasi/unggah: semua di browser via WebAssembly dan WebGL2; tarik berkas, hasil ±20 detik. Tak disimpan di server—aman untuk model belum rilis.

• Isolasi bodi cerdas: cek nama+posisi, deteksi 4 roda, kaca, kabin; tombol "Bodi Saja"; sembunyikan 4 roda + 12 interior sekaligus, lalu pulihkan.

• Akurasi terukur: baca unit, hitung bounding box; 4.512 mm pada 1:20 → cetak "225,6 mm" + bar ukur; koreksi unit cegah salah 100× cm/mm.

• Output siap kerja: PNG transparan ≤4096×4096, SVG vektor cetak tanpa rugi kualitas, PDF A4/A3 enam halaman bernomor, gratis tanpa watermark.

• Template dibagikan: sudut, margin, garis, warna latar di JSON/tautan; pakai ulang untuk puluhan mobil tanpa set ulang.

3) Versi Pertama (Maksimal 8 Tugas)

• 1 — Impor lokal: modul WASM dari awal baca OBJ, FBX, GLB/GLTF; batas 150 MB + pesan error jelas.

• 2 — Penampil 3D: ortografis enam arah (atas, bawah, depan, belakang, kanan, kiri) + verifikasi 15°.

• 3 — Deteksi komponen: roda, kaca, kabin menurut nama/posisi, checkbox per grup.

• 4 — Panel: unit (mm/cm/inci), skala (1:1, 1:10, 1:20, 1:43), warna latar, grid 10 mm, garis 1–4 px.

• 5 — Ekspor: "Ekspor Semua" PNG/SVG/PDF, nama otomatis mehwarside1-20.png.

• 6 — Template/UX: simpan localStorage, impor JSON, landing Arab/Inggris tanpa daftar, feedback kirim deskripsi saja tanpa berkas model.

4) Harga dan Model Pendapatan

• Gratis selamanya: impor, 6 tampilan, PNG ≤2048, SVG; tanpa daftar/watermark; mesin pertumbuhan, coba 1 menit.

• Pro $19 sekali bayar: PNG 4096, PDF beranotasi (panjang/lebar/tinggi), batch 20 model, sinkron template; via Lemon Squeezy hindari PPN.

• Seumur hidup $39: sama + update terus, untuk anti-langganan; target 30% pembeli.

• Tim studio $49/bulan: 5 kursi, template bersama, respons 24 jam, API input model otomatis.

• Ekonomi: ±$40/bulan (domain+CDN+analitik); 300 Pro × $19=$5.700, impas 3 lisensi, margin >90%, refund 14 hari.

5) Distribusi Global via Kanal Gratis

• Komunitas (Minggu 1–4): bantu r/3Dmodeling, r/Blender, mod balap Reddit/Discord; sebelum/sesudah 18 menit vs 20 detik; 10 pertanyaan/minggu.

• Video pendek (Minggu 2–8): 30 klip YouTube Shorts/TikTok/Reels, judul "Dari berkas ke denah dalam 15 detik", subtitel Inggris/Turki/Spanyol; target 100 ribu tayangan bulan ke-3.

• Peluncuran (Minggu 6): Show HN/Product Hunt/Indie Hackers sehari, coba tanpa daftar; target 500 pengunjung + 30 email/72 jam.

• Open source: CLI MIT untuk batch lokal, tarik developer, masuk daftar GitHub, kode dari awal.

• SEO/lokalisasi: 12 halaman "tampilan ortografis model mobil" dan "denah 1:20"; target 800–1.500 organik/bulan akhir bulan ke-6; terjemahan Arab/Inggris, lalu Turki/Italia/Portugis.

6) Risiko (Hukum dan Teknis)

• Hak model: berkas mungkin bukan hak pengguna; syarat: pengguna bertanggung jawab, kami tak terima berkas, header PDF "penggunaan pribadi/pendidikan".

• Merek dagang: tanpa logo/nama merek di template, tanpa halaman nama perusahaan; deskripsi umum "mobil sport dua pintu" cegah klaim.

• Lisensi pustaka: kode dari awal, UI pakai pustaka open source; LICENSE + atribusi, cek MIT/BSD untuk komersial.

• Privasi: tanpa akun kurangi GDPR; analitik anonim tanpa cookie iklan; kebijakan 1 halaman: berkas tak keluar perangkat.

• Performa: FBX besar >500 MB; batas 150 MB, baca bertahap+batal, bounding box sebelum ekspor cegah salah unit, panduan 30 detik ke GLB, fallback WebGL2 tanpa WebGPU.
