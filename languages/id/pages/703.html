Chattyard — Rencana Proyek Lengkap

Ubah dokumen Anda menjadi dukungan instan yang bekerja saat Anda tidur.

Rencana eksekusi lengkap untuk proyek digital baru: ide, audiens, produk, model pendapatan, rencana penyebaran, dan risiko. Proyek sedang dibangun dan belum diluncurkan.

1) Audiens Sasaran

1. Pemilik toko kecil di Shopify/WooCommerce (10–500 pesanan/bulan) yang tidak memiliki tim dukungan dedicated, dan membutuhkan jawaban instan tentang pengiriman dan pengembalian tanpa merekrut karyawan.

2. Agen layanan digital (desain, SEO, iklan) yang mengelola 5–20 klien dan menginginkan saluran terpadu untuk menerima pertanyaan dan meneruskannya ke Slack atau Email tanpa kehilangan konteks percakapan.

3. Pembuat konten dan pelatih yang menjual kursus di Gumroad/Tej dan kesulitan dengan pertanyaan berulang tentang kurikulum, serta membutuhkan jawaban otomatis dari basis pengetahuan yang diperbarui harian.

4. Startup pra-Series A (tim 3–10 orang) yang menggunakan Notion/GitBook untuk dokumentasi dan menginginkan widget yang mengambil jawaban langsung dari sana tanpa salin/tempel manual.

5. Organisasi nirlaba dan inisiatif komunitas yang bergantung pada relawan terdistribusi waktu, dan menginginkan kotak masuk tunggal di Telegram yang mengumpulkan pertanyaan dari situs dan halaman "Hubungi Kami".

6. Pengembang independen yang membangun produk SaaS sampingan dan membutuhkan solusi gratis sepenuhnya untuk 1.000 percakapan/bulan pertama dengan kemampuan upgrade sekali klik.

2) Poin Keunikan (Mengapa Memilih Produk Kami)

1. Sumber Pengetahuan Hibrida: Menghubungkan Notion, GitBook, Google Docs, dan PDF lokal sekaligus, dengan sinkronisasi otomatis setiap 15 menit melalui webhook, menghapus kebutuhan migrasi konten manual.

2. Mode "Asisten Pengembang": Mendeteksi kode error (stack traces) dalam pesan pengunjung dan menulis ulangnya dalam bahasa alami serta menyarankan solusi dari repositori GitHub tim.

3. Routing Cerdas Multi-Saluran: Mendistribusikan percakapan ke Telegram, Slack, Discord, dan Email berdasarkan aturan waktu (mis.: 09:00–18:00 → Slack, waktu lain → Telegram) dengan notifikasi cadangan via SMS setelah 5 menit tanpa balasan.

4. Antarmuka Percakapan yang Dapat Diperluas: Komponen React/Vue/Svelte siap pakai, mendukung kolom kustom (nomor pesan, paket langganan) yang muncul dinamis berdasarkan variabel halaman, meningkatkan konversi 22 % berdasarkan uji A/B awal.

5. Privasi Default: Tidak menyimpan pesan apa pun di server; meneruskan teks terenkripsi ke model LLM lokal (Ollama) atau API yang dipilih klien, dan membersihkan memori sementara setelah 30 detik.

6. Model Harga "Bayar Sesuai Pemakaian": 2.000 pesan/bulan pertama gratis, lalu hanya $0,0015/pesan saat melebihi batas, tanpa biaya tetap atau per-kursi, sehingga biaya sebanding dengan pertumbuhan nyata.

3) Ruang Lingkup Versi Pertama (Maksimal 8 Tugas)

1. Membangun Inti Mesin Obrolan (Core Chat Engine): Layanan Node.js/TypeScript yang menerima event via WebSocket, mengelola state sesi, dan menerapkan logika routing, dengan unit test mencakup 90 % jalur kritis.

2. Adapter Sumber Pengetahuan (Knowledge Adapters): Empat adapter awal (Notion API, GitBook API, Google Drive API, unggah file lokal) dengan logika re-indeks otomatis setiap 900 detik dan penanganan error < 0,5 %.

3. Elemen Widget Web (Web Widget): Paket NPM mandiri (@ourbrand/chat-widget), ukuran < 35 KB gzipped, mendukung SSR dan CSR, dapat dikustomisasi via CSS Variables dan data-attributes.

4. Gerbang Integrasi (Integration Gateway): Antarmuka terpadu untuk mengirim pesan ke Telegram Bot API, Slack Incoming Webhooks, Discord Webhooks, SMTP (SendGrid/Postmark), dengan exponential backoff dan audit log immutable.

5. Dashboard Admin Sederhana: Aplikasi Next.js 14 (App Router) menampilkan statistik real-time (percakapan aktif, rata-rata waktu balas, tingkat penyelesaian AI), pengaturan routing, API keys, dengan RBAC sederhana (Owner / Agent).

6. Sistem Penagihan & Kuota (Billing & Quotas): Integrasi Stripe Billing untuk mengukur pemakaian per pesan, membuat invoice bulanan, dan mematikan layanan lembut saat melebihi kuota gratis dengan notifikasi 48 jam sebelumnya.

7. Pipeline Evaluasi Otomatis (Eval Pipeline): Skrip Python dijalankan malam hari via GitHub Actions, membandingkan jawaban model dengan set emas 500 pasangan pertanyaan/jawaban, dan mempublikasikan laporan akurasi (Target ≥ 88 % F1) ke dashboard.

8. Dokumentasi Pengembang & SDK: Situs Docusaurus multi-bahasa (EN/AR) berisi contoh integrasi untuk React, Vue, Svelte, HTML biasa, dan halaman "Quick Start" yang membawa pengembang dari nol ke Widge
