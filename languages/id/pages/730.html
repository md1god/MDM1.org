Mirqab — Rencana Proyek Lengkap

Pengelola berkas terminal ringan yang memberikan visi penuh dan kecepatan instan dalam satu jalur.

Rencana implementasi lengkap untuk proyek digital baru: ide, audiens, produk, model bisnis, rencana peluncuran, dan risiko. Proyek sedang dibangun dan belum diluncurkan.

Rencana produk: pengelola berkas terminal native

1) Audiens target

• Dev dan DevOps yang bekerja harian lewat SSH di server remote, butuh navigasi cepat antar proyek >10k berkas tanpa keluar terminal.

• Insinyur/ilmuwan data yang menangani folder log/CSV/JSON besar, ingin pratinjau cepat sebelum salin/pindah.

• Sysadmin dan support engineer yang kelola beberapa server, butuh log audit dan undo operasi salah.

• Peneliti dan penulis yang rapihkan pustaka ribuan berkas, hargai pencarian fuzzy dan tag, bukan hafal path.

• Pengguna perangkat lemah dan terminal Arab: RAM 1GB, UI RTL, nama berkas Arab perlu normalisasi pencarian.

2) Keunggulan (mengapa memilih produk kami)

• Startup terukur: <40ms, <25MB RAM saat buka folder 100k berkas, vs detik pada pengelola grafis.

• Pratinjau instan >20 format: teks/gambar Sixel/Kitty, PDF, ZIP, grafik Git, max 200ms.

• Operasi aman: tempat sampah internal, undo 50 operasi terakhir, salinan atomik anti berkas setengah jadi saat putus.

• Dukungan Arab native: normalisasi alif/hamzah/ta marbuta, UI RTL opsional, tampil benar nama campuran.

• Dapat diperluas: plugin terisolasi WASM, CLI integrasi skrip seperti mirqab --pick mengembalikan path terpilih.

• Remote-first: jelajah SSH/SFTP/S3 langsung, kredensial di keychain bukan teks, kode ditulis dari awal.

3) Ruang lingkup versi pertama (maksimal 8 tugas)

1. Tampilan 3 kolom (induk/saat ini/pratinjau), navigasi penuh keyboard, respons <16ms per tombol.

2. Pratinjau teks/gambar dasar (Sixel/Kitty), max 5MB, fallback teks jika terminal tak dukung.

3. Operasi berkas: salin, pindah, rename massal regex + pratinjau, hapus ke tempat sampah internal.

4. Pencarian fuzzy instan folder saat ini/subfolder sampai depth 5, normalisasi Arab.

5. Tab, bookmark, simpan sesi pulih setelah restart.

6. Log operasi, undo/redo 50 operasi terakhir, log audit teks opsional.

7. Enam plugin bawaan: Git, arsip, CSV, gambar, PDF, buka editor eksternal.

8. Paket instalasi Linux/macOS via Homebrew, AUR, deb; satu berkas konfigurasi shareable; uji performa otomatis di CI.

4) Harga dan model pendapatan

• Versi dasar gratis selamanya, open source MIT, semua fitur manajemen lokal, pratinjau, tab.

• Pro $5/bulan atau $39/tahun: sinkron pengaturan/bookmark antar perangkat, log cloud 90 hari, dukungan email 24 jam.

• Team $9/pengguna/bulan: kebijakan terpusat, manajemen plugin, log audit ekspor, dukungan prioritas.

• Lisensi seumur hidup $99/individu, diskon 25% pelajar/sekolah.

• Pasar plugin gratis publikasi, komisi 15% plugin berbayar, review keamanan wajib.

• Tanpa iklan/penjualan data; pendapatan tambahan kustomisasi enterprise mulai $2.000/deployment + dukungan teknis tahunan.

5) Rencana peluncuran global melalui kanal gratis

• GitHub repo publik, rilis v0.1.0 dalam 90 hari, README animasi 5 operasi dalam 20 detik.

• Distribusi pengelola paket: Homebrew, AUR, Flathub, apt via PPA, target 10k instalasi 6 bulan pertama.

• Presentasi teknis di HN, Lobsters, Reddit (r/commandline, r/rust), jawaban jujur bukan iklan berulang.

• 12 tutorial Inggris/Arab alur kerja nyata seperti "bersihkan 50.000 log dalam 3 menit", SEO frasa terminal file manager.

• Video pendek YouTube/TikTok kecepatan vs pengelola grafis, kolaborasi 20 kreator teknis kecil.

• Masuk daftar awesome-, ajukan ke maintainer distro Linux, kompetisi plugin hadiah fisik tarik kontributor.

6) Risiko (legal dan teknis)

• Legal: nama mirip merek terdaftar; solusi cek merek di 3 yurisdiksi (US/EU/JP) sebelum launch, ganti nama bila perlu.

• Legal: dependensi lisensi bertentangan GPL/AGPL; solusi cek lisensi otomatis cargo-deny sebelum merge.

• Legal: cegah salin kode/aset/teks produk sebelumnya; setiap berkas baru log commit dokumentasi kepengarangan dan review orisinalitas.

• Teknis: dukungan gambar beda terminal (Sixel/Kitty/iTerm2); solusi deteksi otomatis dan fallback teks aman tanpa crash.

• Teknis: data hilang saat transfer putus; solusi salinan atomik ke berkas sementara lalu rename, cek integritas sebelum hapus.

• Teknis: lambat jutaan berkas dan celah plugin; solusi indeks malas, baca paralel, uji beban 1 juta berkas, isolasi WASM tanpa akses jaringan default.
