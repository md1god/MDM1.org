Zaytoon — Rencana Proyek Lengkap

Satu panel untuk Windows: buka aplikasi, file, atau paket kerja apa pun dengan satu klik, tanpa hsurf aplikasi Windows.

Rencana eksekusi lengkap untuk proyek digital baru: ide, audiens, produk, model keuntungan, rencana penyebaran, dan risiko. Proyek sedang dibangun dan belum diluncurkan.

1) Audiens Sasaran

• Pengguna Windows intensif: pengembang, administrator sistem, pengguna multi-jendela (Multi‑Monitor) yang mencari alternatif lebih ringan dari shell Existing shells.

• Pekerja jarak jauh dan siswa: membutuhkan "paket kerja" tetap (aplikasi + file + folder + tautan) yang dibuka dengan satu klik sebagai gantinya menyiapkan sesi secara manual.

• Pecinta kustomisasi dan kemewahan: mengikuti Keyboards, Wallpapers, dan Dotfiles serta suka memodifikasi antarmuka dan mengimpor ekstensi.

• Pengembang dan pembuat ekstensi: segmen kedua yang membuat konten, memperluas sistem, dan menjangkau audiens baru.

• Pasar non-Inggris: pengguna bahasa Arab, Turki, Spanyol, Portugis, dan Indonesia yang menderita dari antarmuka tanpa RTL asli.

2) Poin Unik (Mengapa Memilih Produk Kami)

• Asli dan ringan: inti ditulis dari nol (Rust + DirectWrite) dengan waktu boot < 120ms dan konsumsi < 60MB, tanpa Electron dan tanpa WebView2.

• Satu panel menggantikan Taskbar dan Menu Start: aplikasi + file + pengaturan + kalkulator + pencarian web + cuplikan + riwayat clipboard di satu tempat, dengan tetap memungkinkan sistem Windows asli dipulihkan dengan satu tekanan.

• "Topics" (Topik): setiap paket kerja (aplikasi/file/tautan/alur kerja) disimpan dan dijalankan dengan satu perintah, dan dibagikan sebagai satu file — poros keunikan versus peluncur aplikasi tradisional apa pun.

• Sistem ekstensi dengan sandbox aman: Sandbox (WASM/JS terbatas hak) + SDK terbuka + galeri tema dan ekstensi, dengan skrip penerbitan dan penandatanganan.

• Lokal terlebih dahulu dan tanpa pelacakan: indeks dan pencarian di perangkat, nol analitik, berfungsi penuh offline.

• Dukungan RTL dan Arab asli: tata letak, font, input IME, dan terjemahan antarmuka lengkap sejak hari pertama.

• Sumber terbuka (MIT) untuk inti: membangun kepercayaan, menarik kontribusi dan pembuat, serta memperluas penyebaran secara gratis.

3) Ruang Lingkup Versi Pertama (Maksimal 8 Tugas)

1. Peluncur cepat: Hotkey global + pencarian fuzzy instan di aplikasi, file, folder, dan pengaturan + kalkulator/pencarian web/konversi cepat.

2. Panel yang dapat dikustomisasi: tata letak, anchors, dan panel samping, editor tema dengan pratinjau langsung, dan dukungan RTL penuh.

3. Mode penggantian antarmuka: pengganti Menu Start dan Taskbar (Tray + switcher jendela + jam + kalender) dengan kembali一键 ke sistem asli.

4. Manajemen jendela: Snap Layouts, Virtual Desktops, memindahkan jendela antar layar dengan dukungan DPI per layar.

5. Topik/ruang kerja: membuat Topic (aplikasi+file+tautan+perintah), menjalankannya dengan satu perintah atau pintasan, dan impor/ekspor sebagai file yang dapat dibagikan.

6. Cuplikan dan riwayat clipboard: pencarian di riwayat, pin item, cuplikan teks dan ekspansi (Text Expansion) via pintasan.

7. Paket ekstensi: SDK untuk pengembang, runtime terisolasi, instalasi dari file/repositori, galeri internal dengan 25 ekstensi dasar.

8. Distribusi dan kesiapan: versi portable + installer, pembaruan otomatis, auto-start, changelog, dokumentasi Arab/Inggris, kompatibel Windows 10/11.

4) Harga dan Model Keuntungan

• Gratis selamanya (tanpa registrasi): inti, panel, topik, cuplikan, pencarian, tema dasar, dan 25 ekstensi.

• Pro sekali bayar (29$ normal / 19$ peluncuran): sinkronisasi cloud untuk tema dan topik, cadangan, grup tema, alat diagnostik, dan dukungan prioritas.

• Langganan opsional (2.5$/bln): fitur AI (terjemahan/ringkasan) baik di perangkat atau via API key opsional — dan dapat dinonaktifkan sepenuhnya.

• Pasar ekstensi dan tema: komisi 15% untuk pembuat konten.

• Gratis untuk sekolah/nonprofit: lisensi massal murah + versi build dari sumber.

5) Rencana Penyebaran Global Saluran Gratis

• Peluncuran publik gratis: Product Hunt + Hacker News (Show HN) + Reddit (r/windows, r/productivity, r/SaaS) via video pendek yang mengukur "waktu tersimpan" dan cerita penggunaan harian.

• GitHub sebagai model distribusi: inti MIT + SDK + contoh → bintang dan fork diterjemahkan ke adopsi dan kemitraan; template "issue" mudah mendorong kontributor.

• Paket instalasi: winget + Chocolatey + Scoop + MSIX dengan halaman dukungan dan materi promosi untuk setiap saluran.
