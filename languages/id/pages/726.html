Nasaq Code — Rencana Proyek Lengkap

Asisten coding cerdas di editor Anda, memahami proyek dan menjaga privasi Anda.

Rencana proyek digital baru: ide, audiens, produk, pendapatan, peluncuran, risiko; belum dirilis.

1) Audiens

• Freelancer: cepat menyelesaikan tugas klien dan menekan biaya langganan, misalnya 5–10 bug/hari atau prototipe 24–48 jam.

• Tim kecil/startup (3–15 pengembang): alat terpadu untuk mempercepat tinjauan kode dan tes tanpa infrastruktur rumit atau biaya tinggi.

• Mahasiswa ilmu komputer/pembelajar mandiri: penjelasan interaktif kode, contoh praktis, latihan singkat untuk recursion dan API design.

• Tim perusahaan sensitif data: opsi Local LLMs agar kode tetap di jaringan internal, terutama keuangan dan kesehatan.

• Kontributor open source: cepat memahami kode besar (100 ribu+ baris) dan saran sesuai gaya proyek.

2) Keunggulan

• Privasi fleksibel: mode cloud untuk model terhosting dan mode lokal penuh via Ollama atau llama.cpp; tombol alih instan mencegah kode keluar saat mode lokal aktif.

• Konteks: Semantic Indexing file repositori mencari berdasarkan makna, bukan hanya kata; indeks diperbarui otomatis <30 detik setelah file disimpan.

• Agen tugas terkendali: langkah baca, ubah, jalankan perintah memerlukan persetujuan untuk perubahan sensitif; setiap tindakan tercatat untuk audit/rollback.

• Integrasi: dukungan MCP menghubungkan alat eksternal (basis data, sistem tiket, API internal) via satu file JSON.

• Kecepatan: chat samping hemat memori, pintasan keyboard dapat disesuaikan, target respons <2 detik untuk mulai streaming.

3) Cakupan versi pertama (8 tugas)

1. Ekstensi VS Code: chat samping dasar dengan Markdown dan penyorotan kode.

2. Koneksi multi-penyedia: OpenAI-compatible APIs, Ollama, llama.cpp via pengaturan terpadu.

3. Kunci/konfigurasi aman: simpan kunci API lokal dan terenkripsi; opsi menonaktifkan pengiriman cloud.

4. Indeks semantik awal: indeks lokal repositori dengan embeddings; cari potongan paling relevan (hingga 50 ribu file teks).

5. Edit file dengan persetujuan: saran Diff dengan terima/tolak per file sebelum disimpan.

6. Perintah terminal terkendali: jalankan tes/build setelah persetujuan eksplisit; output tampil di panel.

7. Riwayat chat/konteks proyek: simpan sesi lokal, lanjutkan, akses 20 percakapan terakhir.

8. Dukungan awal MCP: koneksi ke minimal satu server MCP; tampilkan dan panggil alat dari percakapan.

4) Harga

• Free individu: chat, edit dengan persetujuan, koneksi ke model pribadi/lokal tanpa batas pesan ketat (batas wajar).

• Pro 8 dolar/bulan: indeks lebih cepat untuk proyek besar, sinkronisasi pengaturan opsional terenkripsi, dukungan prioritas email 48 jam.

• Team 12 dolar/pengguna/bulan: kebijakan privasi bersama, templat perintah tim, laporan penggunaan bulanan tanpa menyimpan konten kode.

• Perusahaan: kontrak tahunan mulai 2.000 dolar/tahun untuk 20 pengguna, termasuk penerapan internal terarah dan dukungan teknis pada jam kerja.

• Prinsip: pendapatan dari fitur organisasi dan dukungan; fungsi inti tetap gratis untuk adopsi dan kepercayaan.

5) Peluncuran via kanal gratis

• Marketplace ekstensi VS Code: halaman produk dengan kata kunci jelas, gambar, video 60–90 detik tentang skenario nyata.

• Repositori open source di GitHub: lisensi jelas, panduan kontribusi, templat Issues; target 500 bintang dalam 3 bulan.

• Konten edukatif: 8 artikel/pelajaran singkat (Arab/Inggris), misalnya "memperbaiki bug dalam 10 menit" atau "memahami repositori baru dalam 15 menit".

• Komunitas pengembang: pembaruan mingguan di Reddit, Hacker News, Discord; fokus transparansi/privasi dan masukan dini.

• Duta mahasiswa: kerja sama 10 klub teknologi universitas untuk lokakarya gratis, paket presentasi siap pakai; target 1.000 pengguna aktif bulanan dalam 6 bulan.

6) Risiko hukum dan teknis

• Privasi/kebocoran data: kode ke penyedia eksternal berisiko; solusi: mode lokal default untuk proyek sensitif dan peringatan sebelum permintaan cloud.

• Akurasi saran: model dapat salah; solusi: wajib persetujuan Diff dan tes otomatis setelah perubahan.

• Lisensi/dependensi pihak ketiga: risiko konflik; solusi: tinjauan lisensi otomatis di CI dan kebijakan lisensi kompatibel (MIT/Apache-2.0).

• Performa perangkat terbatas: indeks/model lokal berat; solusi: atur ukuran indeks dan model ringan (7B atau kurang).

• Perubahan API/protokol: pembaruan API/MCP dapat merusak integrasi; solusi: lapisan abstraksi penyedia dan tes integrasi mingguan dengan versi percobaan.
