Kanvia — полный план проекта

Перемещайте карточки вашей команды от идеи к завершению без хаоса и сложности.

Полный план реализации нового цифрового проекта: идея, аудитория, продукт, бизнес-модель, план распространения и риски. Проект в разработке, ещё не запущен.

1) Целевая аудитория

• Малые команды разработчиков (3–15 человек), использующие GitHub/GitLab и уставшие от тяжести Jira: например, SaaS-компания из 7 человек тратит 4 часа в неделю на обновление тикетов.

• Индивидуальные создатели (indie makers), отслеживающие идеи продукта и ошибки в одном месте: например, одиночный разработчик с 40 идеями в Notion without clear priority.

• Маркетинговые/разработческие агентства, управляющие 5–20 клиентскими проектами: нужна отдельная доска на клиента без сложных прав.

• Нетехнические команды (маркетинг, операции), которым Trello кажется неорганизованным, а Jira — тяжёлым: 2–3 доски и 50 карточек typical.

• Распределённые команды через часовые пояса: 12 участников нуждаются в асинхронных обновлениях и понятной истории изменений.

• Maintainers проектов с открытым исходным кодом: быстрая сортировка issues и feature requests (50+ запросов/неделю).

2) Отличия (почему выбирают наш продукт)

• Единый поток идей и проблем с ящиком сортировки (Inbox): снижает переключение между инструментами (Notion + Trello + GitHub Issues) и экономит ~30% времени на управление.

• «Не сейчас» (Not now) с автоматическим повторным появлением через 14 дней: предотвращает накопление backlog и «гниение» карточек (stale cards).

• Настройка без конфигурации: доска готова за 90 секунд, без обязательных полей и сложных workflows.

• Настоящий free-to-start: неограниченные карточки на одной доске и 5 пользователей; оплата только за несколько досок и автоматизацию.

• Лёгкий PWA (offline-first): работает на телефоне, отклик <100ms, размер бандла <200KB.

• Опция self-host через Docker + экспорт JSON/CSV в один клик: без lock-in, полный контроль над данными.

3) Объём первой версии (не более 8 задач)

1. Модель данных: boards, columns (Inbox/To do/Doing/Done/Not now/Closed), cards, tags, assignments, comments.

2. Аутентификация: magic link по email + passkey, один аккаунт с несколькими пользователями и ролями (owner/member/viewer).

3. Интерфейс Kanban: drag-and-drop между колонками, modal карточки, Markdown, @mentions, вложения (лимит 10MB).

4. Сортировка (Triage): новые элементы попадают в «Inbox»; перемещение одним нажатием на доску или «Not now» с датой повторного появления.

5. Поиск и фильтры: полнотекстовый поиск по карточкам, по tag/assignee/status; сохранённые фильтры и вид «My work».

6. Уведомления: внутри приложения + ежедневный/еженедельный email digest; web push по желанию (VAPID).

7. Экспорт/импорт JSON+CSV + ссылка на доску только для чтения (public read-only) с контролем приватности.

8. Развёртывание Docker + документация + тесты (unit + e2e smoke) + endpoint проверки здоровья (health check).

4) Ценообразование и бизнес-модель

• Free: 1 доска, 5 пользователей, неограниченные карточки, 100MB вложений, 7 дней истории изменений.

• Starter: $6/пользователь/месяц — неограниченные доски, 5GB, автоматизация (rules), интеграции (GitHub, Slack, Zapier), приоритетная поддержка.

• Team: $12/пользователь/месяц — SSO (SAML/OIDC), audit log, расширенные права, 50GB, SLA 99.9%.

• Enterprise: цена по запросу — on-prem, выделенная поддержка, кастомный SLA.

• Self-host: бесплатное сообщество (Docker) + лицензия поддержки $299/год (updates + priority email).

• Бизнес-модель: freemium conversion 3–5%; upsell при 20+ карточках/неделю или второй доске; скидка 20% при годовой оплате. Пример: 10,000 бесплатных workspace → 400 платных → ~$120k MRR (среднее $300/workspace).

5) План глобального распространения бесплатными каналами

• GitHub: core открыт (MIT) + docs + one-click deploy (Docker/Railway/Fly.io); цель 500 star за 30 дней.

• SEO-контент: 2 статьи/неделю (EN + ES) про «simple kanban for small teams», «jira alternative for startups»; case studies 500–800 слов.

• Сообщества: Reddit (r/startups, r/projectmanagement), Hacker News Show HN, IndieHackers; 3 полезных комментария/неделю, без spam.

• Видео: YouTube 1 видео/неделю (60–120s demos) + Shorts/TikTok; встраивание в docs.

• Интеграции: GitHub Actions marketplace, Zapier/Make listing; бесплатный тариф привлекает discovery (цель 1,000 installs/90 дней).

• Локализация: сначала EN, затем ES/PT/FR/AR через community translations (Crowdin); поддержка RTL с начала.
