AriaForge — полный план проекта

Сканируйте сайт, получайте готовые к копированию исправления и отслеживайте соответствие автоматически.

Полный план реализации нового цифрового проекта: идея, аудитория, продукт, модель монетизации, план запуска и риски. Проект в разработке и ещё не запущен.

1) Целевая аудитория

• Основатели SaaS/no-code сайтов (Webflow, Bubble, Framer) с командами 5–50 сотрудников и выручкой 10k–200k$ в месяц; 40% их страниц содержат проблемы доступности.

• Веб-агентства (20–200 сотрудников), которым нужны отчёты о соответствии для клиентов (ADA/WCAG 2.2 AA).

• Менеджеры product/marketing в магазинах Shopify, стремящиеся избежать исков ADA (среднее урегулирование 25k$).

• Независимые разработчики, использующие v0/Bolt/Lovable для создания интерфейсов с помощью ИИ.

• Образовательные и некоммерческие организации, которым нужно соответствие WCAG 2.2 AA на страницах регистрации.

• Дизайнеры Figma, желающие проверять доступность до написания кода.

2) Отличия (почему выбирают наш продукт)

• Готовые к копированию исправления (diff для React/Vue/HTML), а не просто отчёт: время исправления сокращается с 8 часов до 15 минут.

• Сортировка по юридическим рискам + влиянию на пользователя (иски ADA Title III, скринридеры).

• Бесплатный слой: 5 проверок/месяц, по 10 страниц в каждой, без кредитной карты, без водяного знака.

• ИИ, обученный на реальных ошибках WCAG из Common Crawl, точность alt-текста 95%.

• Непрерывный мониторинг через GitHub Action + уведомления в Slack, обнаружение поддельного ARIA в коде ИИ.

• Вариант on-prem/GDPR, без хранения PII, соблюдение robots.txt.

3) Объём первой версии (максимум 8 задач)

1. Движок сканирования URL (Playwright + axe-core) для обнаружения 50+ правил.

2. Генератор исправлений на ИИ (LLM) для alt-текста, labels, контраста, порядка фокуса, имён кнопок.

3. Веб-панель управления со списком проблем в приоритетном порядке + просмотрщик diff.

4. Регистрация free tier + вход через magic link.

5. Тарификация Stripe для Starter/Pro/Team.

6. GitHub Action для проверки в CI.

7. Еженедельный отчёт о мониторинге по email/Slack.

8. Документация + обучающий онбординг (5 шагов).

4) Тарифы и модель доходов

• Free: 5 проверок/месяц, 10 страниц, базовые исправления.

• Starter 19$/мес: 50 проверок, 100 страниц, исправления от ИИ, мониторинг одного сайта.

• Pro 79$/мес: безлимитные проверки, 500 страниц, 5 мест в команде, интеграция CI.

• Team 249$/мес: SSO, on-prem, SLA, выделенная поддержка.

• Enterprise: индивидуальная цена (годовой контракт).

• Доходы: 60% Pro, 25% Team, 15% дополнительные функции (PDF-отчёты аудита по 9$).

• Цель: 1000 free-пользователей → 5% конверсия = 50 платных ≈ 3950$ MRR к 6-му месяцу.

6) Риски (юридические и технические)

• Юридические: иски ADA; отказ от ответственности (инструмент — не юридический сертификат); WCAG не обязателен во всех юрисдикциях; избегать утверждения "compliant".

• Конфиденциальность: сканирование сторонних сайтов может захватывать PII; соблюдение robots.txt, rate limiting, хранение 30 дней.

• Технические: ложные срабатывания ~15% из-за axe-core; исправления ИИ могут сломать UI; обязательный человеческий просмотр + preview.

• Производительность: сканирование больших сайтов затратно; очередь + кэширование + лимит 500 страниц.

• Конкуренция: AudioEye/accessiBe/UserWay; отличие за счёт готовых патчей для разработчиков.

• Дрейф моделей: провайдеры меняются; слой абстракции + fallback.
