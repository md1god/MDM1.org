CritterDock — полный план проекта

Оживите пиксельного спутника на рабочем столе в один клик.

Полный план реализации нового цифрового проекта: идея, аудитория, продукт, бизнес-модель, план распространения и риски. Проект в разработке, ещё не запущен.

1) Целевая аудитория

• Разработчики ПО (18–35 лет), ежедневно использующие ИИ-ассистентов: около 60% из них ищут «периферийную обратную связь» во время сборки/тестирования, например: разработчик Node.js хочет, чтобы питомец прыгал при успешных тестах и спал при неудачах.

• Создатели контента (10k–100k подписчиков): стримеры/ютуберы, которым нужен питомец-оверлей на рабочий стол, реагирующий на донаты чата и вехи подписчиков.

• Коллекционеры пиксель-арта: пользователи, собравшие 50+ питомцев на других платформах и желающие импортировать/экспортировать в едином формате.

• Удалённые работники и студенты: нуждаются в сигналах концентрации (Pomodoro, напоминания пить воду) от ненавязчивого питомца.

• Преподаватели программирования: классные маскоты, взаимодействующие с результатами компиляции, чтобы поощрять учеников.

• Нетехнические пользователи: члены семьи, которым нужна установка в один клик без Terminal или Node.

2) Отличия (почему выбирают наш продукт)

• ИИ-сгенерированные превью анимаций (GIF 3–5 секунд) до установки, что снижает «сожаление об установке» примерно на 40%.

• Изолированная установка (sandbox): каждый питомец в отдельном процессе с manifest прав; никакого случайного кода.

• Мультиплатформенность: Windows/macOS/Linux + VS Code + Terminal (CLI).

• Общественный надзор: голосование + автоматическая проверка безопасности (эвристики + VirusTotal по выбору) + ручная проверка Top 100.

• Оффлайн-первый режим: питомцы работают локально, для бесплатного уровня аккаунт не требуется.

• Удаление/откат в один клик: без остатков в Registry или LaunchAgents.

3) Объём первой версии (не более 8 задач)

1. Оболочка рабочего стола (Tauri 2) с system tray и прозрачным окном always-on-top.

2. Движок питомца: анимация spritesheet + state machine (idle/walk/sleep/react).

3. Веб-галерея + API: просмотр, поиск, фильтрация по тегам.

4. Установка/удаление в один клик с versioning и cache.

5. Генератор превью (clip 4s) из spritesheet через FFmpeg.

6. Сканер безопасности отправок (static analysis + sandbox execution с таймаутом 5s).

7. Аккаунты пользователей + избранное + оценки (1–5).

8. Платежи (Stripe) для premium pets + manba' creators 70/30.

4) Цены и модель прибыли

• Free-to-start: 20 питомцев бесплатно, без аккаунта, без рекламы.

• Пакет Premium $4.99 единоразово: 100+ эксклюзивных питомцев + themes + звук.

• Рынок creators: продажа питомцев $1.99–$9.99, разделение 70/30 (creator/platform).

• Tip jar (Stripe Connect) для поддержки creators (0% комиссии первые 3 месяца).

• Pro subscription $2.99/месяц: cloud sync, конструктор кастомного питомца, analytics.

• Лицензия для школ/классов $49/год (до 30 устройств, поддержка).

5) План глобального распространения по бесплатным каналам

• Запуск Product Hunt + голосование «Pet of the Week» (цель: Top 5 дня).

• Reddit: r/programming, r/PixelArt, r/vscode, r/DesktopToys (3 поста/неделю, value-first).

• GitHub: runtime с открытым кодом (MIT) для привлечения разработчиков; отдельный repo питомцев (CC-BY for art).

• TikTok/YouTube Shorts: 15-секундные демо реакций питомцев, 3/неделю, hashtag challenge.

• Dev.to/Hashnode: «Создай своего настольного питомца за 10 мин» (туториал + ссылка на repo).

• Discord-сообщество + еженедельный showcase + bounties за новых питомцев ($50).

• Hacker News Show HN + посты о вехах на IndieHackers.

6) Риски (юридические и технические)

• Юридические: права на пиксель-арт; процедура DMCA; товарные знаки; ToS отправок (оригинальность + license).

• Технические: потребление CPU/RAM в Electron/Tauri; побег из sandbox; вредоносные payloads; совместимость OS/GPU.

• Приватность: telemetry только opt-in; без записи нажатий клавиш; соответствие GDPR/CCPA.

• Модерация: spam/NSFW; автоматическая + ручная проверка; процесс апелляций.

• Цепочка поставок: CVE в dependencies; SBOM + Dependabot; фиксация версий.
