Вишах — полный план проекта

Синхронизируйте закладки в зашифрованном виде между всеми устройствами, храните их только в вашем личном месте.

Полный план реализации нового цифрового проекта: идея, аудитория, продукт, модель монетизации, план распространения и риски. Проект в разработке и ещё не запущен.

План продукта: синхронизация закладок (Bookmarks) с полной приватностью

Идея: инструмент с открытым исходным кодом для синхронизации закладок между всеми браузерами и устройствами, с хранением в зашифрованном виде в личном облаке пользователя и автоматической очисткой с помощью ИИ. Мы не копируем существующие продукты — мы создаём оригинальное решение с нуля.

1) Целевая аудитория

• Пользователи, заботящиеся о приватности и отказывающиеся привязывать свои данные к аккаунтам браузеров.

• Владельцы self-hosting инсталляций и пользователи Nextcloud/WebDAV.

• Профессионалы, работающие на 3 и более устройствах (работа/дом/телефон).

• Небольшие команды и агентства, делящие общую библиотеку ссылок.

2) Преимущества (почему выбирают нас)

• Сквозное шифрование (E2E) по умолчанию: провайдер не видит ни одной ссылки.

• Свобода хранения: WebDAV / Nextcloud / Google Drive / Dropbox / локальная папка, без ограничений.

• Автоматическая умная организация: классификация, теги и предложения папок через ИИ, которые можно отключить.

• Мгновенный единый поиск на всех устройствах с локально сохранённым текстом страниц.

• Бесплатная модель с самого начала и открытый, проверяемый исходный код.

• Без привязки к вендору (No vendor lock-in): полный экспорт доступен всегда.

3) Объём первой версии (максимум 8 задач)

1. Расширения для Chrome, Firefox и Edge с базовой двусторонней синхронизацией.

2. Подключение личного хранилища (сначала WebDAV и Nextcloud, затем Google Drive).

3. E2E-шифрование с локальным ключом, производным от фразы восстановления.

4. Разрешение конфликтов по чёткой стратегии (самая новая / слияние / сохранённая копия).

5. Автоматическая организация с помощью ИИ (предлагаемые теги и папки с возможностью проверки).

6. Веб-интерфейс/мини-приложение для просмотра ссылок и поиска по ним.

7. Импорт/экспорт в форматах HTML, JSON и CSV + резервное копирование.

8. Простая панель настроек и корректный тест синхронизации.

4) Тарифы и модель доходов

• Бесплатно навсегда (Free): неограниченная синхронизация через хранилище пользователя, два устройства, ограниченный месячный объём ИИ-организации.

• Pro (ежемесячная/годовая подписка): неограниченное число устройств, безлимитная ИИ-организация, журнал конфликтов, приоритетная поддержка.

• Команды (Teams): общие библиотеки, роли и права доступа, панель администрирования.

• Поддержка открытого исходного кода (Sponsorships): спонсорство на GitHub и дополнительная коммерческая лицензия для компаний.

5) План глобального распространения через бесплатные каналы

• Публикация исходного кода с открытой лицензией на GitHub и включение в списки awesome-privacy и awesome-selfhosted.

• Официальные магазины расширений: Chrome Web Store, Mozilla Add-ons и Edge Add-ons.

• Сообщества: Reddit (r/privacy, r/selfhosted, r/firefox), Hacker News, Product Hunt.

• Каталоги альтернатив: AlternativeTo и Slant.

• SEO-контент: руководства «как синхронизировать закладки, не продавая свои данные», нейтральные сравнения.

• YouTube и open-source площадки: обучающие видео по установке с Nextcloud.

• Интеграции и сообщества Nextcloud и Home Assistant.

6) Риски (юридические и технические)

• Юридические: соблюдение GDPR при обработке данных пользователей, политики магазинов расширений, условия использования провайдеров хранения, права на товарный знак названия.

• Технические: изменения интерфейсов браузеров (Manifest), точность разрешения конфликтов при шифровании, лимиты скорости облачных провайдеров, безопасность ключей и синхронизации, стоимость эксплуатации ИИ.

7) Предлагаемое название и рекламный слоган

Предлагаемое название: Вишах
