Spreadly — Полный план проекта

Читайте мангу как настоящую книгу — по две страницы, где угодно, офлайн.

Полный план реализации нового цифрового проекта: идея, аудитория, продукт, бизнес-модель, план распространения и риски. Проект находится в разработке и ещё не запущен.

1) Целевая аудитория

• Читатели манги и комиксов в вебе (16–35 лет), 60% из них на телефонах, которым надоело листать по одной странице.

• Любители разворота (spread), которые хотят ощущение бумажной книги на сайтах-агрегаторах.

• Команды переводчиков (scanlation), которым нужен быстрый визуальный просмотр перед публикацией.

• Пользователи планшетов (iPad/Android tablets), читающие в горизонтальной ориентации.

• Читатели контента RTL/LTR (японский, корейский, китайский, английский), которым нужна плавная смена направления.

• Пользователи с особыми потребностями (увеличение, высокий контраст, навигация с клавиатуры).

2) Ключевые преимущества (почему выбирают наш продукт)

• Умное распознавание разворота (gutter detection) с автокадрированием убирает пустые поля и выравнивает панели.

• Офлайн-первый режим (PWA + IndexedDB) сохраняет 200–500 страниц (~150MB) для чтения без сети.

• Универсальный слой адаптеров (adapters) + плагины для каждого сайта: работает на 5+ крупных сайтах без отдельных форков.

• Производительность: переключение страницы <100ms, предзагрузка двух следующих страниц, виртуализированный список для длинных глав.

• Приватность: без отслеживания, прогресс чтения экспортируется/импортируется как зашифрованный файл (сервер не требуется).

• Доступность: ARIA-ориентиры, фокус клавиатуры, высокий контраст, поддержка скринридеров.

3) Объём первой версии (не более 8 задач)

1. Движок читалки (переключение разворот/одна страница, RTL/LTR, зум, навигация клавиатурой/жестами).

2. Слой адаптеров для 5 сайтов (эвристики + селекторы для каждого сайта).

3. Офлайн-хранилище (Service Worker + IndexedDB) с обработкой квот.

4. Предзагрузка и кэширование (prefetch next 2 pages, виртуализация).

5. Экспорт/импорт прогресса чтения (зашифрованный JSON-файл).

6. Панель настроек + онбординг (3 шага, <60с до первого чтения).

7. Проход по доступности (WCAG AA) + тесты клавиатуры.

8. Закрытая бета (200 пользователей) + исправления + публикация в магазинах расширений.

4) Цены и бизнес-модель

• Free-to-start: базовая читалка (разворот/одна страница, офлайн 50 страниц, 3 сайта) бесплатно навсегда, без рекламы.

• Premium $3/мес или $24/год: офлайн 500 страниц, синхронизация между устройствами, темы, неограниченные сайты, приоритетная поддержка.

• Lifetime $49 единоразово для ранних пользователей (первые 1 000).

• Пожертвования (GitHub Sponsors/Patreon) для переводчиков сообщества.

• Цель: 5% конверсия из 50k MAU → ~$7.5k MRR при среднем $3; безубыточность при ~$1.2k/мес инфраструктуры.

5) Глобальный план распространения через бесплатные каналы

• Релизы GitHub + магазины Chrome/Firefox/Edge (ASO-ключевые слова: manga reader, two-page).

• Ценные посты (not spam) в r/manga, r/manhwa, r/ComicBook (кейсы со скриншотами).

• Discord: outreach к 20 scanlation-группам для бета-теста + отзывы.

• Запуск на Product Hunt с демо-GIF + пост "Show HN".

• YouTube/TikTok: 60-секундные демо от креаторов (бартер: бесплатный премиум за обзор).

• Перевод интерфейса на 6 языков силами сообщества (Crowdin бесплатно для OSS).

6) Риски (юридические и технические)

• Правовые: мы не хостим изображения; только клиентское улучшение. Риск: снятие из магазинов расширений. Митигация: контакт DMCA, без изменений хотлинкинга, соблюдение robots.txt, понятные ToS.

• Технические: изменения DOM ломают адаптеры. Митигация: эвристический фолбэк, еженедельные автоматические smoke-тесты на 5 сайтах, обновления плагинов сообществом в течение 48ч.

• Магазины: отклонения по политике MV3. Митигация: минимальные разрешения, без удалённого кода, задокументированная политика приватности.

• Приватность: синхронизация данных. Митигация: E2E-шифрование, opt-in, local-first по умолчанию.

• Производительность: слабые устройства. Митигация: уровни качества, опция отключения анимаций.

• Конкуренция: нативные приложения. Митигация: web-first zero-install, работает на любом сайте.

7) Предложенное название и маркетинговый слоган

Название: Spreadly
