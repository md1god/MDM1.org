План продукта: платформа планирования маршрутов покрытия для автономной сельхозтехники

Проблема: автономная сельхозтехника (тракторы, комбайны, роботы-опрыскиватели) нуждается в маршрутах по всему полю без повторного перекрытия химикатов и пропусков, с безопасными разворотами и обходом препятствий. Доступные решения — сложные для интеграции библиотеки.

1) Целевая аудитория

1. Начинающие производители сельхозроботов (OEM): строят роботов для уборки/опрыскивания/борьбы с сорняками, нужен готовый планировщик вместо своей разработки, экономия 6–12 мес.

2. Поставщики услуг и кооперативы: парк 3–20 машин, нужно авто-разделение поля, чтобы успеть до смены погоды.

3. Компании опрыскивания БПЛА: маршруты для нерегулярных полей с учётом ёмкости бака и батареи.

4. Исследователи и студенты: бесплатный инструмент для быстрого освоения, полевых экспериментов и публикаций.

5. Технически подкованный фермер: поля 50–500 га с коммерческой навигацией, хочет план, снижающий топливо и избыточные дозы.

2) Преимущества

1. Простота: ядро — пакет Python с REST API и веб-приложением; интеграция за час, запуск из браузера.

2. Разделение парка: авто-разделение поля между машинами с балансом времени (±5%) и точками передачи.

3. 3D-рельеф: данные высот DEM для наклона маршрутов по контурам на склонах, меньше эрозии.

4. Оптимизация по стоимости: снижение евро/га (топливо+время+перекрытие), панель аналитики покрытия, перекрытия, расстояния, времени.

5. Открытая совместимость: экспорт GeoJSON, GPX, KML, ISO 11783 (ISOBUS), ROS 2.

6. Бесплатный старт: ядро Apache-2.0 и бесплатный облачный тариф.

3) Объём первой версии (≤8 задач)

1. Задача 1 — геометрический движок: чтение границ из GeoJSON/KML/Shapefile, WGS84↔UTM с метровой точностью, проверка полигона.

2. Задачи 2–3 — маршруты и кромка: зигзаг (Boustrophedon) с авто-углом, спираль, контуры; кромка Headland с разворотами Omega/полоборот/Fish-tail.

3. Задачи 4–5 — препятствия и порядок: авто-разделение поля вокруг препятствий, соединение зон; упорядочивание маршрутов (прибл. TSP), экспорт GeoJSON/GPX/CSV/ROS 2.

4. Задача 6 — веб-MVP: отрисовка границ на MapLibre, ввод ширины орудия/скорости, генерация, предпросмотр, экспорт, бесплатные расчёты.

5. Задача 7 — аналитика: покрытие (%), перекрытие (%), расстояние (км), время (ч), слои на карте.

6. Задача 8 — документация: руководство «первый план за 10 минут», OpenAPI, 6 примеров (L-поле, 2 внутренних препятствия).

4) Ценообразование и бизнес-модель

1. Ядро Apache-2.0: бесплатно навсегда; доверие, сообщество, бесплатный маркетинг.

2. Free: 3 поля и 20 планов/мес со всеми аналитиками v1.

3. Pro — 19 $/мес: неограниченные поля, разделение парка, 3D, ISOBUS, поддержка за 48 ч.

4. Business — 99 $/мес: REST API (10 тыс. вызовов/мес), 5 пользователей, приоритетная поддержка.

5. Enterprise: on-prem, SLA 99,5%, 3–10 тыс. $/год.

6. Услуги: интеграция OEM-движков и обучение (500–800 $/день) — ранний доход.

5. Послы сообщества: 10 лучших контрибьюторов/мес — бесплатные лицензии, спонсорство.

1. Патенты: паттерны навигации/разворота защищены; чистая реализация по академическим статьям (до 2000 — общественное достояние), проверка патентным консультантом (~5 тыс. $).

2. Лицензии/собственность: только снисходительные зависимости (MIT/Apache/BSD), CLA, проверка вкладов.

3. Конфиденциальность: границы/планы чувствительны; шифрование, европейский хостинг, GDPR.

4. Качество алгоритмов: сложные поля дают пропуски/перекрытия; 50 реальных полей в тестах, свойственные тесты.

5. Масштабируемость: тяжёлые расчёты; асинхронные очереди (Celery+Redis), кэш.
