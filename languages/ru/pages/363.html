Ampora — полный план проекта

Каждый ватт под вашим контролем.

Полный план реализации нового цифрового проекта: идея, аудитория, продукт, бизнес-модель, план распространения и риски. Проект находится в разработке и ещё не запущен.

Продукт с оригинальной концепцией в сфере энергетики и интернета вещей

1) Целевая аудитория

• Частные лица и умные дома: те, кто хочет отслеживать потребление электроэнергии и бытовых приборов, а также снизить счета.

• Управляющие недвижимостью и небольшие организации: клиники, кафе, офисы, склады — нуждаются в учёте энергопотребления по зонам и мгновенных уведомлениях.

• Операторы солнечных панелей и систем хранения: небольшие солнечные фермы и сервисные провайдеры, желающие видеть выработку, потребление и эффективность.

• Производители устройств и интеграторы: хотят шлюз, который быстро подключит их устройства без создания полноценного backend.

• Лаборатории, университеты и государственные инициативы: нуждаются в платформе с открытым исходным кодом для исследований в области энергоэффективности.

2) Преимущества (почему стоит выбрать наш продукт)

• Простое подключение: готовые шаблоны для популярных устройств (MQTT, HTTP, Modbus, BACnet) с автоматическим обнаружением и умным помощником настройки.

• Приоритет энергетики: мгновенные панели учёта потребления, выработки и стоимости, а не универсальная панель управления с добавленной позже энергетикой.

• Механизм правил и мгновенных уведомлений: оповещение при превышении порога, отключении устройства или снижении выработки солнечной энергии — с выбором каналов (email, webhook, push-уведомления).

• Упрощённый искусственный интеллект: прогнозирование потребления, обнаружение аномального поведения и практические рекомендации по экономии.

• Интерфейс с функцией drag-and-drop: пользователь может самостоятельно создать своё приложение (панель управления, отчёт) без написания кода, с возможностью полной кастомизации для продвинутых пользователей.

• Открытый исходный код + управляемый облачный сервис: бесплатный self-hosting или бесплатный облачный аккаунт для старта.

• Конфиденциальность и владение данными: данные пользователя остаются у него, с возможностью экспорта в стандартных форматах (CSV, MQTT, API).

3) Объём первой версии (не более 8 задач)

1. Ядро шлюза (Core Gateway): приём данных по MQTT / HTTP / Modbus со стандартной идентификацией устройства.

2. Механизм событий и правил: условные правила + мгновенные уведомления по email и webhook.

3. Мгновенная энергетическая панель: потребление, выработка, ориентировочная стоимость с динамическим графиком.

4. Конструктор панелей (Dashboard Builder): drag-and-drop компонентов с готовыми шаблонами.

5. Шлюз устройств + аутентификация (device provisioning): ключи, сертификаты и удалённое отключение устройств.

6. Документированное REST API + WebSocket: для разработчиков и мгновенных уведомлений.

7. Учётные записи пользователей и команды: регистрация, роли, одно рабочее пространство с бесплатным тарифом.

8. Публикация приложений (App Publisher): экспорт интерфейса в виде самостоятельного веб-приложения или встраивание.
