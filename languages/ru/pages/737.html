YieldAtlas — Полный план проекта

Находите недооценённую недвижимость в Великобритании, оценивайте прозрачно, начинайте бесплатно.

Полный план реализации нового цифрового проекта: идея, аудитория, продукт, бизнес-модель, план распространения и риски. Проект в разработке, ещё не запущен.

1) Целевая аудитория

• Начинающие инвесторы «покупка для сдачи в аренду» (Buy-to-Let) в городах Midlands/North (Manchester, Leeds, Birmingham, Liverpool): возраст 25-40, бюджет 120k-250k £, цель доходность аренды ≥6%.

• Владельцы портфелей (5-30 объектов), ищущие стабильный поток сделок без комиссий посредников (typically 2-3%).

• Независимые sourcers, которым нужны доказательства (score + comparables) для продажи сделки за комиссию.

• Иностранные инвесторы (Персидский залив/Европа), покупающие удалённо и желающие проверки (due diligence) данных района.

• Инвесторы HMO/turnkey, нуждающиеся в оповещениях по планированию (planning) и лицензированию (licensing) до покупки.

2) Конкурентные преимущества (почему наш продукт)

• Прозрачность: score 0-100 с видимыми весами (скидка от median, yield, days on market, EPC, crime, transport), а не «чёрный ящик».

• Free-to-start: поиск + 3 оповещения/месяц без карты, чтобы снизить трение регистрации.

• Объединение данных: Land Registry + EPC + crime + transport + council tax + planning (где доступно) вместо только listings.

• Настраиваемый порог «below market» (например ≥12% скидка) + median по postcode (LSOA), чтобы избежать искажения outliers.

• Экспорт CSV/PDF + журнал аудита (audit trail) для показа сделки партнёрам/кредиторам.

• Без долгих контрактов: отмена в клик, with pause subscription для seasonal инвесторов.

3) Объём первой версии (максимум 8 задач)

1. Ingest: импорт listings + sold prices (Land Registry/feeds) с ежедневным обновлением и dedup.

2. Postcode analytics: median, yield, discount, trend 12m на postcode/LSOA.

3. Scoring v1: объяснимые факторы + risk flags (flood, crime, EPC low).

4. Web app responsive: filters (price, yield, beds, type), map, deal cards.

5. Alerts: saved searches + email/push + quiet hours.

6. Accounts: saved deals, notes, tags, shared link.

7. Exports: CSV/PDF report with comparables.

8. Admin: data quality dashboard (stale, missing EPC, duplicates).

4) Ценообразование и модель прибыли

• Free: 10 поисков/день, 3 оповещения/месяц, базовый score.

• Starter £19/месяц: безлимитный поиск, 25 оповещений, экспорт.

• Pro £49/месяц: продвинутый scoring, filters HMO/turnkey, bulk export, ограниченный API.

• Team £149/месяц: 5 мест, общие watchlists, audit.

• Скидка за год (2 месяца бесплатно), referral credits, пакеты доп. оповещений (pay-as-you-go).

• Цель: 1,000 free → 8% conversion → ~80 paid × £45 = £3,600/месяц; при 5,000 free → ~£18,000/месяц.

5) План глобального распространения бесплатными каналами

• SEO: страницы «[city] below market property deals» и «average yield [postcode]» с агрегированными данными.

• Reddit/forums (r/UKProperty, r/propertyinvesting): ценные posts (case studies), а не spam.

• YouTube Shorts: walkthrough анализа сделки (screen recording) 60-90 секунд.

• Product Hunt + Indie Hackers: build in public, еженедельные обновления.

• LinkedIn: outreach брокерам ипотеки/бухгалтерам/инвесторам, referral affiliate.

• Партнёрства: местные property meetups, sourcers (referral комиссия).

• Ежемесячный отчёт «UK Below-Market Deal Index» for PR/organic backlinks.

6) Риски (правовые и технические)

• Лицензирование данных: соблюдать terms feeds/APIs; avoid scraping prohibited; хранить provenance.

• GDPR: consent, retention, cookie policy, right to deletion.

• Точность: stale listings/asking vs sold; disclaimers; verify with Land Registry.

• Ложные сигналы: scoring «not investment advice» + risk labels + manual verify.

• Техника: rate limits, geocoding costs, map tiles; caching + queues + monitoring.

• Конкуренция/churn: differentiate via transparency + community; годовые планы + pauses.
