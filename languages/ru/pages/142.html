Maqam Studio — полный план проекта

Разделение вокала и музыки за секунды, бесплатно и на вашем устройстве.

Полный план реализации нового цифрового проекта: идея, аудитория, продукт, модель монетизации, план продвижения и риски. Проект находится в разработке и ещё не запущен.

План продукта: разделение вокала и музыки (полностью новая идея)

1) Целевая аудитория

• Музыкальные продюсеры и звукорежиссёры (Producers/Mixers) — им нужны Stems для создания Remix.

• Ведущие караоке и аранжировщики — им нужна версия без Vocals для тренировки.

• Создатели контента и авторы Reels/TikTok — хотят короткую версию Acapella или Instrumental в высоком качестве.

• Преподаватели и студенты языковых/фонетических направлений — хотят изолировать речь от музыки для прослушивания.

• Исследователи и разработчики приложений — хотят API для интеграции разделения в свои продукты.

2) Ключевые преимущества (почему выбирают наш продукт)

• Обработка в первую очередь локально на устройстве пользователя (полная приватность, без загрузки файлов и без ожидания в облачных очередях).

• Рабочий процесс всего из 3 шагов: загрузка → выбор режима → экспорт.

• Готовые режимы вместо сложных настроек: караоке, Acapella, музыкальная тренировка, разделение на 4 дорожки (Vocals/Drums/Bass/Other).

• Мгновенное A/B-прослушивание с быстрым переключателем для сравнения перед экспортом.

• Работает из браузера (WebGPU/WASM) + лёгкая версия для настольных систем, без сложной установки.

• Бесплатно для старта без ограничения по времени в локальном режиме; оплата только за облако и API.

3) Объём первой версии (не более 8 задач)

1. Импорт аудио- и видеофайлов (MP3/WAV/M4A/MP4) с автоматическим извлечением звука.

2. Движок разделения вокала локально в браузере/на устройстве с обработкой небольшими пакетами (Chunking).

3. Интерфейс всего из 3 шагов с индикатором загрузки и оценкой времени ожидания.

4. A/B-прослушивание с мгновенным переключением между обработанной и оригинальной версией.

5. Готовые режимы: караоке / Acapella / тренировка / разделение на 4 дорожки.

6. Экспорт в WAV и MP3 с контролем качества и сохранением результатов в локальную библиотеку.

7. Очередь для пакетной обработки (Batch) нескольких файлов.

8. Целевая страница + создание бесплатного аккаунта для облака + форма оценки внутри продукта.

4) Ценообразование и модель монетизации

• Бесплатно (Free-to-start): локальная обработка без ограничений, экспорт MP3, два готовых режима.

• Бесплатное облако: 60 минут облачной обработки в месяц (мощное устройство не требуется).

• Pro — 6$/мес.: безлимитное облако, разделение на 4 дорожки, экспорт WAV, приоритет по скорости.

• Studio — 19$/мес.: API-ключи, пакетная обработка, коммерческая лицензия на использование результатов в публикуемом контенте.

• Дополнительные источники дохода: баланс API для разработчиков, план для организаций и страница пожертвований/поддержки для профессиональных пользователей.

5) План глобального продвижения через бесплатные каналы

• YouTube: короткие видео «до/после» (караоке, Acapella) с SEO по фразам вроде remove vocals from song free.

• TikTok/Reels/Shorts: 15-секундные ролики, показывающие результат, со ссылкой на бесплатную версию.

• Reddit: полезные публикации в сообществах музыкальной индустрии и караоке (без прямой рекламы).

• Discord и Facebook Groups: сообщества DJ и создателей караоке, с бесплатными ответами на запросы о разделении.

• Product Hunt + Hacker News: официальный запуск с понятной бесплатной версией.

• Блог/SEO-шаблоны: руководства («Как сделать караоке из любой песни»), привлекающие органический трафик.

• Небольшие партнёрства: каналы обучения музыке и создания контента в обмен на упоминание продукта.

6) Риски (юридические и технические)

• Юридические: разделение вокала может использоваться для повторной публикации защищённой музыки; поэтому мы разъясняем, что использование должно быть только в разрешённых целях, и блокируем загрузку защищённого контента в облачный слой с помощью сопоставления отпечатков (Fingerprinting).

• Лицензирование данных и Models: обучение или использование должно вестись на лицензированных данных, с проверкой лицензий любого используемого компонента на предмет разрешения коммерческого использования.

• Товарный знак: проверка названия и логотипа на целевых рынках перед запуском во избежание конфликтов товарных знаков.

• Технические: на качество разделения влияют плотные миксы; решение: несколько режимов + оптимизация на небольших фрагментах.

• Производительность: память на слабых устройствах; решение: пакетная обработка + резервная облачная версия.
