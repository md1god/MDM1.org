Fennec — полный план проекта

Fennec: тестируйте, документируйте и делитесь APIs без облака, с молниеносной скоростью.

Полный план реализации нового цифрового проекта: идея, аудитория, продукт, бизнес-модель, план распространения и риски. Проект в разработке и ещё не запущен.

1) Целевая аудитория

• Независимые разработчики и небольшие команды (2–10 человек), создающие REST/GraphQL/gRPC APIs; 70% из них ежедневно используют Git и нуждаются в инструменте, который не вынуждает создавать облачный аккаунт или оформлять подписку.

• QA/инженеры по автоматизации в стартапах (50–500 сотрудников), ищущие альтернативу после изменений цен incumbent-инструментов; средняя команда из 4 тестировщиков, нуждающаяся в batch runner для CI.

• Студенты и преподаватели университетов (≈2M студентов CS по всему миру), которым нужен офлайн-инструмент для лабораторий без интернета.

• Мейнтейнеры OSS, желающие хранить коллекции как код в репозитории с возможностью ревью через PR.

• DevOps/SRE для smoke tests в пайплайнах, которым нужен headless CLI runner с exit codes и JUnit report.

2) Отличия (почему выбирают наш продукт)

• Offline-first: работает полностью без аккаунта; данные в локальной папке, без обязательной синхронизации.

• File-based collections: каждый запрос = файл .http/.yaml, diff-friendly, git-native; без проприетарного binary формата.

• Один бинарный файл <80MB, startup <2s (против ~8s у incumbent), память <200MB.

• Встроенный mock server с инъекцией latency/errors для contract testing.

• Опциональный AI (bring your own key) генерирует tests из OpenAPI spec; данные отправляются только с согласия.

• Plugin SDK (JS) для custom auth flows + бесплатный marketplace.

3) Объём первой версии (не более 8 задач)

1. HTTP client engine (methods, headers, body types, SSL, proxy) + response viewer.

2. Модель workspace/collection, хранящаяся как файлы + environment variables с masking секретов.

3. Scripting pre/post на JS sandbox (QuickJS) + assertions (expect).

4. Headless CLI runner для CI (exit codes, JUnit report).

5. Импорт из OpenAPI 3.x и Postman collection v2.1.

6. Режим mock server, обслуживающий примеры collections.

7. Git-aware UI (status badges, diff view) + разрешение конфликтов.

8. Мультиплатформенная упаковка (Windows/macOS/Linux) + подписанный auto-update.

4) Тарифы и модель дохода

• Free forever: неограниченные collections, локальное использование, CLI, mock server, imports.

• Pro $8/пользователь/месяц: опциональный управляемый sync, shared environments, role-based access.

• Enterprise $29/пользователь/месяц (годовая): SSO/SAML, compliance export, выделенная поддержка.

• Цели: 100k free пользователей в год 1, конверсия 3% → 3000 платных → $288k ARR, плюс sponsorships.

5) Глобальный план распространения через бесплатные каналы

• GitHub releases + Homebrew/winget/scoop/apt; landing page, оптимизированная под SEO.

• Контент: уроки на Dev.to/Hashnode/YouTube Shorts; case studies.

• Сообщество: Discord, Reddit (r/programming, r/webdev), Hacker News Show HN.

• Интеграции: расширение VS Code, GitHub Actions marketplace.

• Локализация: i18n для 8 языков; перевод docs силами сообщества.

• Программа для университетов: Pro free для студентов.

6) Риски (юридические и технические)

• Юридические: trademark search перед неймингом; не копировать код из источников; соблюдение licenses (Apache/MIT) библиотек; условия AI features.

• Технические: безопасность QuickJS sandbox; обработка больших ответов (streaming); OS keychain для секретов; подпись auto-update; производительность при 10k+ requests.

• Рынок: lock-in incumbent; нужны migration tools; нагрузка поддержки.

• Соответствие: GDPR для опционального cloud sync; data residency.
