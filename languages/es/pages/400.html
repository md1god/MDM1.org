ContextDock — Plan de proyecto completo

Construye, prueba y publica servidores MCP en minutos — con seguridad y sin complejidad de infraestructura.

Plan de implementación completo para un nuevo proyecto digital: la idea, el público, el producto, el modelo de ingresos, el plan de despliegue y los riesgos. El proyecto está en construcción y aún no se ha lanzado.

Plan de producto: plataforma para construir, probar y publicar servidores MCP

1) Público objetivo

• Ingenieros de IA (AI engineers) que construyen servidores Model Context Protocol para conectar modelos con bases de datos y sistemas internos.

• Empresas SaaS que quieren abrir sus productos a los modelos inteligentes mediante MCP sin un gran equipo de Infra.

• Programadores independientes y comunidades Open Source que publican herramientas MCP y quieren probarlas y compartirlas rápidamente.

• Equipos de DevOps y Security que necesitan supervisar y documentar los servidores MCP internos.

2) Puntos diferenciales (por qué elegir nuestro producto)

• Entorno de pruebas integrado con simulación: simulación de Claude, ChatGPT y el cliente local sin claves API externas, con registro de cada invocación (prompt/tool call) para diagnosticar errores.

• Comprobación automática de seguridad: detección de permisos excesivamente amplios, filtración de datos en la descripción de la herramienta (tool description) y ámbitos de entrada (input) no fiables.

• Plantilla de seguridad lista (Auth Kit): OAuth 2.1 y OIDC y claves de transición listas que se generan con un solo clic dentro de tu proyecto.

• Publicación con un clic: exportación como imagen Docker o despliegue gestionado en una red global con HTTPS y registros de uso.

• Interfaz visual para flujos de trabajo: encadenar varias herramientas en una ruta lógica (orchestration) sin código y luego exportar la ruta como código TypeScript/Python.

• Máxima flexibilidad de ejecución: modo Self-host totalmente gratuito junto a la nube gestionada, a diferencia de quienes solo permiten el despliegue en la nube.

3) Alcance de la primera versión (como máximo 8 tareas)

1. Generador de proyectos (scaffold) para servidores MCP en TypeScript y Python a partir de plantillas listas.

2. Entorno local de ejecución y simulación con interfaz web para probar las herramientas y ver las salidas.

3. Registro de invocaciones en vivo (request/response logs) con filtros y búsqueda.

4. Pruebas automáticas: ejecución de conjuntos de pruebas (test suite) sobre las herramientas y verificación de los esquemas (JSON Schema).

5. Comprobación básica de seguridad + informe exportable.

6. Auth Kit: generación de configuraciones OAuth/API keys con un clic.

7. Publicación con un clic (Docker público + despliegue gestionado sencillo) con subdominio gratuito.

8. Compartir el proyecto mediante un enlace público que muestre la documentación y los estados de las pruebas (galería de despliegues).

4) Precios y modelo de ingresos

• Gratis para empezar: proyectos ilimitados en local, Self-host totalmente abierto y despliegue en subdominio compartido.

• Pro — 19$/mes por desarrollador: subdominio propio, registros más largos, comprobación avanzada de seguridad y despliegue gestionado con límites mensuales razonables.

• Team — 49$/miembro/mes: espacios de trabajo compartidos, roles y permisos, revisión de Pull Request sobre la documentación y la configuración.

• Enterprise: Self-host dentro de la red del cliente, SLA, acuerdos de nivel de servicio y soporte dedicado.

• Fuentes de ingresos adicionales: plantillas profesionales de la comunidad (Marketplace con una comisión del 20%) y servicios de auditoría de seguridad.

5) Plan de despliegue global con canales gratuitos

• GitHub: plantilla MCP de código abierto ligera vinculada a la plataforma, con contribuciones de la comunidad.

• GitHub Topics y Awesome-MCP: inclusión de las plantillas en las listas MCP conocidas.

• X y LinkedIn: serie de vídeos cortos «Construye un servidor MCP en 5 minutos».

• Reddit y Hacker News: publicación de Show HN y compartición de experiencias de DevOps.

• YouTube y Twitch: directos de construcción, prueba y despliegue de un servidor MCP.

• Discord abierto: comunidad para desarrolladores con canales de soporte y de intercambio de plantillas.

• Dev.to, Medium y un blog interno: casos de estudio y comparativas analíticas (errores comunes en servidores MCP).

• Meetups y conferencias de DevOps y AI: presentaciones gratuitas sobre seguridad de herramientas inteligentes (MCP Security).

• Programa de partners: recompensas para consultoras y agencias de desarrollo cuando refieran clientes.
