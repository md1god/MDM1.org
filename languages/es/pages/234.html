SANAD — Plan de proyecto completo

Desde la solicitud de cotización hasta la entrega de un producto trazable, SANAD gestiona toda tu fábrica en una sola base de datos.

Plan de ejecución completo para un nuevo proyecto digital: la idea, el público, el producto, el modelo de ingresos, el plan de difusión y los riesgos. El proyecto está en construcción y aún no se ha lanzado.

Plan de producto: sistema ERP/MES/QMS para manufactura (producto original nuevo)

1) Público objetivo

• Fábricas pequeñas y medianas (SME) y talleres de manufactura que operan bajo el sistema de "fabricación bajo pedido" (Make-to-Order).

• Empresas emergentes en los sectores de dispositivos y materiales, alimentos, preparados, muebles y piezas mecánicas.

• Equipos de calidad y cumplimiento que necesitan trazabilidad de lotes y números de serie, como preparación para obligaciones como ISO 9001, 21 CFR Part 11 y EU MDR.

• Mercados emergentes primero (donde las soluciones actuales son costosas o solo en inglés), luego expansión global.

2) Puntos de distinción (por qué elegir nuestro producto)

• Un solo esquema sobre PostgreSQL: cotización, inventario, planta, calidad y trazabilidad en una sola base, en lugar de conectar 4–5 sistemas.

• Gratis para empezar y autoalojado, sin límites ni tarifas de configuración.

• API primero + servidor MCP integrado para ejecutar agentes inteligentes y automatizar flujos de trabajo.

• Soporte nativo árabe/inglés con interfaz RTL.

• Trazabilidad de lotes y números de serie nativa desde el diseño, no como complemento posterior.

• Funciona en entornos con conectividad débil con sincronización posterior para la planta de la fábrica.

3) Alcance de la primera versión (máximo 8 tareas)

1. Cotización y emisión de ofertas (Quoting).

2. Órdenes de venta y compra y proveedores.

3. Inventario, almacenes y mínimo.

4. Lista de materiales (BOM) y planificación de necesidades simplificada (MRP).

5. Órdenes de trabajo y gestión de la planta de la fábrica.

6. Calidad (QMS): registros de inspección y desviaciones.

7. Trazabilidad de lotes y números de serie (Lot/Serial Traceability).

8. REST API + servidor MCP + autenticación y permisos multirrol.

4) Precios y modelo de ingresos

• Community: autoalojamiento totalmente gratuito (licencia abierta).

• Cloud Free: plan gratuito limitado (un usuario, una fábrica, capacidad de almacenamiento limitada).

• Cloud Pro: suscripción mensual por usuario o según capacidad, con copias de seguridad gestionadas y soporte.

• Ingresos adicionales: implementación y migración, capacitación, integraciones personalizadas, soporte empresarial (SLA), alojamiento privado.

5) Plan de difusión global con canales gratuitos

• GitHub para el repositorio abierto, y Product Hunt y Hacker News para el lanzamiento.

• Contenido SEO y videos educativos en YouTube sobre manufactura digital, trazabilidad y calidad.

• Comunidades de Reddit y Discord especializadas en manufactura y software de código abierto.

• Publicación de plantillas y documentación, traducción al árabe y contribuciones de la comunidad.

• Inclusión gratuita en G2 y Capterra, y alianzas con cámaras de industria y universidades.

6) Riesgos (legales y técnicos)

• Legales: licencia del proyecto y derechos de los contribuyentes; privacidad de datos (GDPR) y datos sensibles de las fábricas; no reclamar certificaciones regulatorias (la certificación es responsabilidad del cliente); responsabilidad de seguridad del producto y la salud.

• Técnicos: complejidad de la sincronización sin conexión y seguridad de los puntos de API y del servidor MCP; multiusuario y aislamiento; rendimiento de PostgreSQL con el crecimiento de datos; migración de datos de clientes desde sistemas antiguos; resistencia a la copia y la suplantación.

7) Nombre propuesto y eslogan
