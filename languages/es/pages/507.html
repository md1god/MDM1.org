Qaid — Plan de proyecto completo

Tu contabilidad en lenguaje de texto simple, totalmente tuya, a la velocidad de la luz.

Plan de ejecución completo para un nuevo proyecto digital: idea, audiencia, producto, modelo de ingresos, plan de difusión y riesgos. El proyecto está en construcción y aún no se ha lanzado.

Plan de producto contable textual de código abierto

1) Público objetivo

• Propietarios de pequeñas y medianas empresas que prefieren transparencia y control total sobre sus datos financieros

• Contadores y autónomos que trabajan con múltiples clientes y necesitan una herramienta ligera y portable

• Desarrolladores y entusiastas de la automatización que quieren integrar la contabilidad en su flujo de trabajo programático

• Equipos remotos que necesitan colaboración simple sin la complejidad de plataformas cloud costosas

2) Puntos diferenciales

• Archivos de texto en bruto: tus datos son totalmente tuyos, legibles con cualquier editor, respaldables con Git

• Motor de consultas potente: lenguaje de consulta integrado para analizar gastos, flujos y presupuestos sin exportar

• Rendimiento instantáneo: procesamiento de archivos con miles de líneas en fracciones de segundo gracias al motor Rust

• Múltiples interfaces: línea de comandos rica, interfaz textual interactiva (TUI) y una interfaz web ligera local

• Plantillas inteligentes: creación instantánea de estructuras de cuentas estandarizadas según tipo de actividad

• Integración fluida: exportación/importación CSV, JSON y Beancount; conectores para vincular con bancos vía OFX/QFX

• Totalmente gratuito: sin suscripciones, sin rastreo, sin límites en número de cuentas o transacciones

3) Alcance de la primera versión (8 tareas)

1. Motor de análisis (parser) robusto para archivos de diario textuales con soporte para directivas y comentarios

2. Lenguaje de consulta integrado para filtrado, agregación e informes financieros básicos

3. Interfaz de línea de comandos (CLI) con comandos: registrar, informes, balance, flujos, convertir formatos

4. Interfaz textual interactiva (TUI) para navegar, buscar y editar transacciones

5. Servidor web local para una interfaz de panel simple (solo lectura)

6. Sistema de plantillas para estructuras de cuentas listas (comercio, servicios, sin ánimo de lucro, personal)

7. Herramientas de importación/exportación: CSV, JSON, Beancount, Ledger CLI

8. Suite de pruebas completa y documentación con ejemplos para principiantes

4) Precios y modelo de ingresos

• Versión base: gratuita y de código abierto (MIT) para siempre

• Complementos opcionales de pago (anuales, por usuario):

• Sincronización cifrada entre dispositivos mediante el proveedor de almacenamiento que elija el usuario

• Informes avanzados programados enviados por correo electrónico

• Integración bancaria automatizada con actualizaciones diarias (donde existan APIs abiertas)

• Servicios profesionales: configuración inicial, formación de equipos, desarrollo personalizado para empresas

5) Plan de difusión global (canales gratuitos)

• Publicación como paquete en los registros de distribución principales: Homebrew, Scoop, Chocolatey, AUR, Nixpkgs, pkgx

• Documentación interactiva y sitio estático en GitHub Pages con ejemplos vivos en el navegador

• Serie de videotutoriales cortos (3-5 minutos) en YouTube y PeerTube cubriendo escenarios reales

• Artículos técnicos en blogs de desarrolladores conocidos (Dev.to, Hashnode, Medium) explicando la filosofía textual

• Participación en comunidades: r/plaintextaccounting, foros de Ledger/Beancount, servidores Discord relevantes

• Paquetes de plantillas para actividades comunes disponibles para descarga con un clic

• Programa de embajadores para contadores y autónomos que obtienen insignia y reconocimiento a cambio de ayuda

• Traducción de la interfaz y documentación al árabe, español, francés, alemán, chino, japonés

6) Riesgos (legales y técnicos)

• Legales: evitar cualquier similitud en marca o interfaz de usuario con herramientas existentes; revisar licencias de librerías usadas (preferir MIT/Apache-2.0)

• Técnicos: complejidad del análisis de textos humanos diversos; manejo de fechas y monedas múltiples; rendimiento de memoria con archivos enormes; compatibilidad de interfaces entre sistemas operativos

• Adopción: resistencia al cambio de hábitos; necesidad de ejemplos convincentes para migrar desde hojas de cálculo o SaaS

• Mantenimiento: carga de soporte para formatos bancarios cambiantes; actualización regular de dependencias de Rust

7) Nombre propuesto y eslogan

Nombre propuesto: Qaid

Eslogan: Tu contabilidad en lenguaje de texto simple, totalmente tuya
