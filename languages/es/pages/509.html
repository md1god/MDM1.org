CalorieLens — Plan de proyecto completo

Toma una foto, conoce las calorías, ajusta y guarda — gratis, con total privacidad, sin apps.

Plan de ejecución completo para un nuevo proyecto digital: la idea, el público, el producto, el modelo de negocio, el plan de difusión y los riesgos. El proyecto está en construcción y aún no se ha lanzado.

1) Público objetivo

• Personas que quieren rastrear calorías sin instalar apps ni crear cuentas

• Practicantes de deporte y dietas temporales (keto, ayuno intermitente)

• Quienes prefieren privacidad y evitar anuncios y rastreo

• Usuarios de escritorio y móvil que buscan una herramienta rápida y compartible

2) Puntos diferenciales (por qué elegir nuestro producto)

• Completamente gratis y sin registro: funciona al abrir el enlace, sin cuentas ni muros de pago

• Funciona solo en el navegador: sin instalación, opera en cualquier dispositivo, soporta PWA para uso offline

• Resultados editables: el usuario corrige la estimación manualmente y el modelo aprende de sus correcciones localmente

• Privacidad absoluta: las fotos no salen del dispositivo, procesamiento local vía WebAssembly/TensorFlow.js

• Compartir fácil: enlace de resultado compartible con nutricionista o entrenador

• Código abierto: total transparencia, la comunidad mejora el modelo

3) Alcance de la primera versión (máx. 8 tareas)

1. Interfaz web simple: subir/tomar foto → mostrar estimación → editar campos → guardar/compartir

2. Modelo de estimación de calorías/macros que funciona localmente (TensorFlow.js + modelo MobileNet entrenado en Food-101)

3. Editor de resultados interactivo: ajustar calorías, proteínas, carbohidratos, grasas, gramos con recálculo instantáneo

4. Almacenamiento local (IndexedDB) para historial diario con exportación CSV/JSON

5. Modo PWA: instalar como app, funciona offline, sincronización opcional después

6. Página de resultados compartible mediante enlace único (sin servidor, vía URL params comprimidos)

7. Soporte RTL completo para árabe, y modo oscuro/claro

8. Tests unitarios y de integración + CI/CD para despliegue automático en Pages/Workers gratuitos

4) Precios y modelo de ingresos

• Versión base: gratis y open source para siempre

• Plan "Pro" opcional (4$/mes o 35$/año): sincronización cloud encriptada, modelos más precisos (mayores), reportes semanales/mensuales PDF, API para desarrolladores, soporte prioritario

• Sin anuncios, sin venta de datos: ingresos solo de suscripciones opcionales

• Licencia MIT: las empresas pueden alojar su propia instancia

5) Plan de difusión global con canales gratuitos

• Reddit: r/nutrition, r/loseit, r/keto, r/intermittentfasting — posts "Show HN" semanales con capturas reales

• GitHub: release open source con README excelente, ejemplos, invitación a contribuciones

• Product Hunt / AlternativeTo / SaaSHub: lanzamiento de la v1 gratis

• Contenido SEO: artículos "cómo calcular calorías de tu comida con una foto", comparativas con apps populares

• Twitter/Threads/Mastodon: hilo diario "comida del día + estimación", retweets de cuentas de fitness

• Discord/Telegram: comunidad pequeña para soporte, peticiones de features, compartir modelos entrenados

• YouTube Shorts/Reels/TikTok: videos de 30 seg: "foto → resultado → ajuste → guardar"

• Micro-alianzas: entrenadores personales, nutricionistas que ofrecen la herramienta a sus clientes gratis

6) Riesgos (legales y técnicos)

• Legales: disclaimer médico claro ("herramienta de estimación, no consejo médico"), cumplimiento GDPR/CCPA (sin datos personales), evitar claims diagnósticos

• Precisión del modelo: estimar comida es difícil (salsas ocultas, aceites de cocción, tamaños de porción) — mitigación: editor manual fácil, aprendizaje de correcciones del usuario localmente

• Rendimiento en navegador: modelos grandes pueden ralentizar móviles básicos — mitigación: modelo ligero por defecto, opción "modelo preciso" para dispositivos potentes

• Soporte de cámara: requieren permisos HTTPS, fallback a subida de archivo — mitigación: PWA con manifest correcto, instrucciones claras

• Mantenimiento: un solo modelo no cubre todas las cocinas — mitigación: arquitectura modular para modelos regionales, comunidad aporta datos anónimos

7) Nombre propuesto y eslogan

Nombre propuesto: CalorieLens

Eslogan: Toma una foto, conoce las calorías, ajusta y guarda — gratis, con total privacidad, sin apps.
