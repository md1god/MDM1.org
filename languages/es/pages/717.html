Fennec — Plan de proyecto completo

Fennec: prueba, documenta y comparte APIs sin nube, a velocidad vertiginosa.

Plan de ejecución completo para un nuevo proyecto digital: idea, audiencia, producto, modelo de ingresos, plan de lanzamiento y riesgos. El proyecto está en construcción y aún no se ha lanzado.

1) Audiencia objetivo

• Desarrolladores independientes y equipos pequeños (2–10 personas) que construyen APIs REST/GraphQL/gRPC, el 70% usa Git a diario y necesita una herramienta que no les obligue a tener cuenta en la nube ni suscripción.

• Ingenieros de QA/automatización en startups (50–500 empleados) que buscan alternativa tras cambios de precios en herramientas incumbent; equipo promedio de 4 testers necesitando batch runner para CI.

• Estudiantes y profesores en universidades (≈2M estudiantes CS a nivel mundial) necesitando herramienta offline para laboratorios sin internet.

• Mantenedores de OSS que quieren colecciones almacenadas como código en el repositorio, revisables mediante PR.

• DevOps/SRE para smoke tests en pipelines, necesitando CLI headless runner con exit codes y reporte JUnit.

2) Puntos distintivos (por qué elegir nuestro producto)

• Offline-first: funciona completamente sin cuenta; los datos en carpeta local, sin sync obligatorio.

• Colecciones basadas en archivos: cada request = archivo .http/.yaml, diff-friendly, git-native; sin formato binary propietario.

• Un solo binary <80MB, startup <2s (frente a ~8s de herramientas incumbent), memoria <200MB.

• Mock server integrado con inyección de latency/errors para contract testing.

• IA opcional (bring your own key) que genera tests desde spec OpenAPI; no envío de datos sin consentimiento.

• Plugin SDK (JS) para custom auth flows + marketplace free.

3) Alcance de la primera versión (máximo 8 tareas)

1. Motor HTTP client (methods, headers, body types, SSL, proxy) + response viewer.

2. Modelo workspace/collection almacenado como archivos + environment variables con masking de secretos.

3. Scripting pre/post con JS sandbox (QuickJS) + assertions (expect).

4. CLI headless runner para CI (exit codes, reporte JUnit).

5. Import desde OpenAPI 3.x y Postman collection v2.1.

6. Modo mock server que sirve ejemplos de collections.

7. UI Git-aware (status badges, diff view) + resolución de conflictos.

8. Empaquetado multiplataforma (Windows/macOS/Linux) + auto-update firmado.

4) Precios y modelo de ingresos

• Gratis para siempre: colecciones ilimitadas, uso local, CLI, mock server, imports.

• Pro $8/usuario/mes: sync gestionado opcional, shared environments, role-based access.

• Enterprise $29/usuario/mes (anual): SSO/SAML, compliance export, soporte dedicado.

• Objetivos: 100k usuarios free en año 1, conversión 3% → 3000 paid → $288k ARR, además de sponsorships.

5) Plan de lanzamiento global por canales gratuitos

• GitHub releases + Homebrew/winget/scoop/apt; landing page optimizada para SEO.

• Contenido: tutoriales en Dev.to/Hashnode/YouTube Shorts; case studies.

• Comunidad: Discord, Reddit (r/programming, r/webdev), Hacker News Show HN.

• Integraciones: VS Code extension, GitHub Actions marketplace.

• Localización: i18n para 8 idiomas; traducción de docs vía comunidad.

• Programa universidades: Pro free para estudiantes.

6) Riesgos (legales y técnicos)

• Legal: trademark search antes de nombrar; no copiar código de fuente; cumplimiento de licenses (Apache/MIT) para librerías; términos de AI features.

• Técnico: seguridad del sandbox QuickJS; manejo de respuestas grandes (streaming); OS keychain para secretos; firma de auto-update; rendimiento con 10k+ requests.

• Mercado: lock-in incumbent; need migration tools; carga de soporte.

• Cumplimiento: GDPR para cloud sync opcional; data residency.

7) Nombre propuesto y eslogan de marketing

Nombre propuesto: Fennec

Eslogan: Fennec: prueba, documenta y comparte APIs sin nube, a velocidad vertiginosa.
