Sinf — Plan completo del proyecto

Descubre lo que hay en tu comida con un solo toque y participa en la construcción de la mayor base de datos alimentaria abierta del mundo árabe.

Plan de implementación completo para un nuevo proyecto digital: la idea, el público objetivo, el producto, el modelo de negocio, el plan de difusión y los riesgos. El proyecto está en construcción y aún no se ha lanzado.

1) Público objetivo

• Consumidores preocupados por la salud: aquellos que leen los ingredientes y desean conocer la cantidad de azúcar, sal, grasas y aditivos antes de comprar.

• Personas con alergias o dietas especiales: personas con diabetes, alergia al gluten, vegetarianos o aquellos que siguen una dieta específica.

• Desarrolladores y equipos de producto: aquellos que crean aplicaciones de fitness, nutrición o comercio electrónico y necesitan datos alimentarios estructurados a través de una API.

• Investigadores y estudiantes de nutrición: necesitan grandes volúmenes de datos que puedan consultarse y analizarse.

• Colaboradores voluntarios: fotógrafos de productos, activistas de datos abiertos y editores de categorías.

2) Puntos diferenciadores (¿por qué elegir nuestro producto?)

• Empezamos por el mundo árabe y la región: cubrimos productos locales (marcas regionales no incluidas anteriormente), con una interfaz y un orden completamente en árabe, para luego expandirnos a nivel mundial.

• Calidad antes que cantidad: un sistema de verificación automático (huella de la imagen del código de barras + detección de conflictos entre ingredientes) asigna a cada ficha una puntuación de confianza visible para el usuario.

• Diseño moderno desde cero: una experiencia de usuario simple y rápida (aplicación web primero, usable sin necesidad de instalación), en lugar de interfaces antiguas y sobrecargadas.

• Datos realmente abiertos: licencia abierta explícita para los datos + API gratuita al inicio, sin restricciones contractuales.

• Contribución en un solo paso: basta con fotografiar un único código de barras para añadir un producto, con recompensas de reputación para los colaboradores.

3) Alcance de la primera versión (máximo 8 tareas)

1. Búsqueda por nombre o código de barras, y una página de producto que muestre los ingredientes y los valores nutricionales.

2. Añadir un producto mediante fotografía (código de barras + imagen del envase + tabla nutricional), con una verificación básica.

3. Clasificación automática del nivel de calidad (azúcar, sal, grasas saturadas, aditivos), con una explicación sencilla.

4. Filtros inteligentes según alergias y dieta (gluten, diabetes, vegetariano, etc.).

5. API pública de lectura (puntos finales para productos y búsquedas), con claves gratuitas.

6. Panel sencillo para colaboradores: mis contribuciones, reputación y tareas de edición pendientes.

7. Soporte para dos idiomas (árabe e inglés), con una estructura preparada para añadir más idiomas.

8. Exportación de datos abiertos (CSV/JSON con un solo clic) y un paquete de datos periódico.

4) Precios y modelo de negocio

• Gratis al inicio: uso para consumidores, colaboradores y API, con un límite generoso (por ejemplo, 1000 solicitudes/día), sin anuncios molestos.

• Plan Pro para desarrolladores: mayor número de solicitudes, datos adicionales (historial de modificaciones, lotes), soporte técnico, mediante una suscripción mensual escalonada.

• Enterprise: licencias de datos personalizadas, SLA, integración con sistemas de minoristas y entidades de salud.

• Financiación comunitaria: donaciones, patrocinadores institucionales para datos abiertos y becas de investigación.

• Servicios de pago: limpieza y normalización de listas de productos de empresas, a cambio de una tarifa (sin ocultar los datos básicos).

5) Plan de difusión global mediante canales gratuitos

• Vídeos cortos: clips con el formato «¿Qué hay en este producto?» en plataformas de vídeo corto, para concienciar a la población.

• Comunidades de datos abiertos: difusión en foros de código abierto, Reddit y grupos de desarrolladores.

• Integraciones gratuitas: plantillas de código abierto que utilicen la API para crear aplicaciones de salud rápidamente.

• Universidades y asociaciones de salud: colaboraciones de investigación y proyectos estudiantiles para verificar los datos.

• Contenido SEO en varios idiomas: páginas de productos indexables que muestren los valores nutricionales en los resultados de búsqueda.

• Campañas de reto de contribución: un reto semanal para fotografiar productos locales, con un ranking de reputación.
