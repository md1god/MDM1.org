Mizan — Plan de proyecto completo

Un único esquema crea un modelo sólido en todas partes.

Plan de ejecución completo para un nuevo proyecto digital: la idea, la audiencia, el producto, el modelo de ingresos, el plan de lanzamiento y los riesgos. El proyecto está en construcción y aún no se ha lanzado.

1) Público objetivo

• Desarrolladores de front-end que construyen formularios de registro, pago, pedidos y configuración dentro de aplicaciones TS/JS.

• Equipos que necesitan un único modelo que sirva a React, Vue, Solid y Angular sin reescribir la lógica.

• Pequeñas y medianas empresas que quieren conectar los formularios a una API con validación unificada entre front-end y servidor.

2) Puntos diferenciadores

• Un único esquema (schema) genera tipos, validación y contrato de API automáticamente, de modo que no hay duplicación entre el front-end y el servidor.

• Bajo coste y alto rendimiento: actualizaciones locales sin volver a renderizar el formulario completo, con validación diferida o inmediata según el campo.

• Editor visual en la nube, gratuito, para construir esquemas y exportarlos como código TypeScript.

• Enfoque offline primero: guardar borradores localmente y sincronizarlos al recuperar la conexión.

• Documentación en árabe e inglés y plantillas listas para casos de uso habituales.

3) Alcance de la primera versión (como máximo 8 tareas)

1. Motor del núcleo para el estado de los formularios: valores, errores, nivel de tacto y dependencias entre campos.

2. Capa de validación extensible con mensajes de error personalizables.

3. Generación automática de tipos a partir del esquema con compatibilidad estricta con TypeScript.

4. Hooks e interfaces de componentes para React, Vue y Solid.

5. Exportación del contrato OpenAPI desde el esquema para usarlo en el servidor.

6. Guardado de borradores localmente y recuperación tras recargar la página.

7. Editor visual de esquemas con exportación directa de código.

8. Documentación + 5 plantillas listas (registro, pago, pedido, configuración, contacto).

4) Precios y modelo de ingresos

• Gratuito para empezar: motor, hooks, plantillas básicas y exportación local sin límites.

• Plan Pro: sincronización en la nube, editor avanzado, analítica de embudos de formularios — suscripción mensual/anual.

• Plan Teams: espacios de trabajo, permisos y contrato de API gestionado — suscripción por usuario.

• Núcleo de código abierto con servicios de alojamiento para empresas.

5) Plan de lanzamiento global con canales gratuitos

• Contenido educativo breve (vídeo + artículo) sobre problemas habituales de formularios y sus soluciones.

• Participación en comunidades de desarrolladores de front-end, foros de preguntas y respuestas, y salas de Discord y Telegram.

• Captura "antes/después" comparando el tiempo de construcción del formulario con y sin el producto.

• Plantillas gratuitas en plantillas de GitHub y en bibliotecas de componentes para atraer a los primeros usuarios.

• Concurso de construcción de formularios con premios simbólicos para impulsar una difusión más amplia.

6) Riesgos (legales y técnicos)

• Legales: riesgos de disputas de marcas — hay que comprobar el registro antes del lanzamiento y respetar una licencia clara de código abierto.

• Legales: protección de los datos de los formularios (privacidad, cumplimiento) al ofrecer la sincronización en la nube.

• Técnicos: dificultad de cubrir varios navegadores y front-ends sin romper los tipos.

• Técnicos: fuerte competencia de empresas y proyectos consolidados en este ámbito, lo que exige una diferenciación rápida y clara.

7) Nombre propuesto y eslogan

Nombre propuesto: Mizan

Eslogan: Un único esquema crea un modelo sólido en todas partes.
