OrbitPost — Complete Project Plan

Schedule once, publish everywhere — by humans or AI agents.

Full execution plan for a new digital project: idea, audience, product, business model, go-to-market, and risks. The project is under construction and not yet launched.

1) Target Audience

Marketing agencies, independent content creators, SaaS founders, and developers building AI agents (n8n/LangChain/custom) needing autonomous publishing. Plus companies wanting self-hosting (on-prem) for compliance and data privacy.

2) Differentiators (Why choose our product)

• API-first for agents: REST + MCP server + webhooks, designed to be called by AI agents (not merely by users).

• Free self-hosting (one-command Docker Compose) + free cloud tier.

• BYO-LLM: use your own key (OpenAI/Anthropic/Ollama local) — no token cost from us.

• Plugin architecture: adding a new platform = adding a package, no core changes.

• Queue engine with retry, timezone scheduling, and anti-duplicate.

• Open-core: Apache-2.0 kernel, enterprise features (SSO/RBAC/audit) paid.

• Local-first: your data, your keys, your schedule — on your machines.

3) First Release Scope (max 8 tasks)

1. Scheduling and queue engine (queue + retry + timezone).

2. OAuth connectors for 5 platforms (X, LinkedIn, Instagram, Facebook, TikTok).

3. AI content generation (BYO key) with templates.

4. Public REST API + webhooks + OpenAPI spec.

5. MCP server (agent tool) + SDK (Python/TS).

6. Dashboard (calendar, drafts, simple analytics).

7. Docker self-host + docs + one-click deploy.

8. Free cloud tier + billing (Stripe).

4) Pricing and Revenue Model

• Self-host: free (Apache-2.0 core), optional paid support.

• Cloud Free: 3 accounts, 10 posts/day, 1 user.

• Pro $19/month: 10 accounts, unlimited, 3 users.

• Team $49/month: 30 accounts, 10 users, advanced analytics.

• Enterprise: custom pricing (SSO, RBAC, audit, SLA, on-prem support).

• Revenue: cloud subscriptions, managed hosting, support/SLA, plugin marketplace (20% rev-share), premium templates.

5) Global Go-to-Market with Free Channels

• Product Hunt launch + Hacker News (Show HN).

• Reddit: r/selfhosted, r/marketing, r/SideProject, r/LocalLLaMA.

• GitHub: excellent README + badges + issue templates + good first issues.

• YouTube: tutorials "self-host in 5 min" + agent automation demos.

• Discord/Slack communities (n8n, LangChain, Indie Hackers).

• MCP registry listing + LangChain tools integration.

• SEO docs + comparison pages ("vs Buffer/Hootsuite").

• Affiliate creators (free tier credits, not cash upfront).

• Open-source contributions to MCP ecosystem.

6) Risks (Legal and Technical)

Legal: social platform terms (automation/auto-publishing) may restrict or ban; OAuth app reviews (delays); trademarks; GDPR/CCPA (user data, right to be forgotten); misuse (spam/bot) → AUP + rate limiting + verification.

Technical: platform API changes (breaking changes); rate limits; queue reliability (idempotency, dedup); scaling (Redis/Postgres); agent key security (encryption at rest, scoped tokens, rotation); cloud hosting cost; vendor lock-in in OAuth apps.

7) Proposed Name and Marketing Slogan

Proposed name: OrbitPost

Marketing slogan: Schedule once, publish everywhere — by humans or AI agents.
