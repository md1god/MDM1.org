Fennec — Complete Project Plan

Fennec: test, document, and share APIs without cloud, at lightning speed.

Complete implementation plan for a new digital project: idea, audience, product, business model, go-to-market plan, and risks. The project is under development and not yet launched.

1) Target Audience

• Independent developers and small teams (2–10 people) building REST/GraphQL/gRPC APIs; 70% use Git daily and need a tool that doesn't force a cloud account or subscription.

• QA/automation engineers at startups (50–500 employees) seeking an alternative after incumbent pricing changes; average team of 4 testers needing a batch runner for CI.

• Students and lecturers at universities (≈2M CS students worldwide) needing an offline tool for labs without internet.

• OSS maintainers wanting collections stored as code in the repository, reviewable via PR.

• DevOps/SRE for smoke tests in pipelines, needing a headless CLI runner with exit codes and JUnit report.

2) Differentiators (Why choose our product)

• Offline-first: works fully without an account; data in a local folder, no mandatory sync.

• File-based collections: each request = a .http/.yaml file, diff-friendly, git-native; no proprietary binary format.

• Single binary <80MB, startup <2s (vs ~8s for incumbent tools), memory <200MB.

• Built-in mock server with latency/error injection for contract testing.

• Optional AI (bring your own key) generates tests from OpenAPI spec; no data sent without consent.

• Plugin SDK (JS) for custom auth flows + free marketplace.

3) First Release Scope (max 8 tasks)

1. HTTP client engine (methods, headers, body types, SSL, proxy) + response viewer.

2. Workspace/collection model stored as files + environment variables with secret masking.

3. Pre/post scripting via JS sandbox (QuickJS) + assertions (expect).

4. Headless CLI runner for CI (exit codes, JUnit report).

5. Import from OpenAPI 3.x and Postman collection v2.1.

6. Mock server mode serving collection examples.

7. Git-aware UI (status badges, diff view) + conflict resolution.

8. Cross-platform packaging (Windows/macOS/Linux) + signed auto-update.

4) Pricing and Business Model

• Free forever: unlimited collections, local use, CLI, mock server, imports.

• Pro $8/user/month: optional managed sync, shared environments, role-based access.

• Enterprise $29/user/month (annual): SSO/SAML, compliance export, dedicated support.

• Goals: 100k free users in year 1, 3% conversion → 3000 paid → $288k ARR, plus sponsorships.

5) Global Launch via Free Channels

• GitHub releases + Homebrew/winget/scoop/apt; SEO-optimized landing page.

• Content: tutorials on Dev.to/Hashnode/YouTube Shorts; case studies.

• Community: Discord, Reddit (r/programming, r/webdev), Hacker News Show HN.

• Integrations: VS Code extension, GitHub Actions marketplace.

• Localization: i18n for 8 languages; community-translated docs.

• University program: Pro free for students.

6) Risks (Legal and Technical)

• Legal: trademark search before naming; no copying code from any source; library license compliance (Apache/MIT); AI feature terms.

• Technical: QuickJS sandbox security; handling large responses (streaming); OS keychain for secrets; auto-update signing; performance with 10k+ requests.

• Market: incumbent lock-in; need migration tools; support burden.

• Compliance: GDPR for optional cloud sync; data residency.

7) Proposed Name and Tagline

Proposed name: Fennec

Tagline: Fennec: test, document, and share APIs without cloud, at lightning speed.
