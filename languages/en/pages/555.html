Athar — Complete Project Plan

A unified memory engine for AI agents that combines meaning, text, and structure in one engine, with a source, trust level, and timestamp for every piece of information.

A complete implementation plan for a new digital project: idea, audience, product, monetization model, go-to-market plan, and risks. The project is under construction and has not yet been launched.

Original product plan: Athar (أثر)

1) Target Audience

• Independent developers and small teams building AI agents or RAG systems who want to run them without managing complex infrastructure.

• Companies and organizations that need agent memory and hybrid search within their own infrastructure, with a commitment to privacy and local data storage.

• Data teams that want to query vectors, text, structured data, and JSON in a single engine instead of connecting multiple systems.

• Multi-tenant SaaS platforms that need isolation between customers, permissions, and audit logs.

• Arab developers and teams building Arabic applications who need high-quality text and semantic search for Arabic.

2) Points of Differentiation (Why Choose Our Product)

• All-in-one embedded engine: runs as a single local file or as a server, with no mandatory external services, a unique visual identity, and a temporal interface to visualize memory.

• True hybrid search: a single query blends vector, BM25, SQL, and JSON paths, with a cost planner that selects the best execution plan.

• Memory with a lifecycle: every piece of information has a source, trust level, timestamp, and expiration date, with duplicate and contradiction detection and suggestions for merging or forgetting.

• Reproducibility: snapshots and audit logs allow replaying an agent's memory state to diagnose errors with precision.

• Instant integration with agents: native MCP server and SDKs for Python and TypeScript, in addition to a CLI and local inspection dashboard.

• Free to start and self-hostable: the core version is fully open source, with no restriction of core features to the cloud.

• Early advantage in Arabic: text normalization, tokenization, and precise Arabic text search from the first release, not as a later addition.

3) Scope of Version 1 (Maximum of 8 Tasks)

1. Build a single-file storage core with collections, namespaces, and flexible schema records.

2. Implement hybrid indexing and retrieval combining vector, BM25, and structured filters in a single query.

3. Build a memory model that includes source, trust, TTL, duplicate detection, and contradiction detection.

4. Add a pluggable embedding pipeline: cloud providers and local models, with caching and retries.

5. Release SDKs for Python and TypeScript and a ready-to-use MCP server.

6. Provide a REST server mode with access tokens, namespaces, and rate limits.

7. Add snapshots, replay, and audit logs for diagnostics.

8. Build a CLI and local dashboard for inspection, with import of CSV/JSON/Parquet and backups.

4) Pricing and Monetization Model

• Community: free forever, self-hostable, all core features included, no local limits.

• Cloud Free: 1 GB storage, 100,000 vectors, 3 namespaces, no credit card required.

• Cloud Pro: $19/month, includes 10 GB, then $0.12 per additional GB per month.

• Team: $49/month per 5 seats, with daily backups and advanced permissions.

• Enterprise: annual pricing including SSO, advanced isolation, extended audit logs, and dedicated support.

• Revenue streams: cloud subscriptions, additional usage, enterprise support and migration. We do not sell customer data.

5) Global Go-to-Market Plan with Free Channels

• Launch the open-source repository under Apache 2.0, with clear documentation, three ready-to-use examples, and a sandbox environment.

• Publish packages to PyPI and npm, register the MCP server in specialized directories, and add integrations with common agent frameworks.

• Simultaneous launch on GitHub, Hacker News, Product Hunt, Reddit, and developer communities, with a short demo.

• Weekly free content: tutorials, practical comparisons, case studies, and short videos in Arabic and English.

• Organize hackathons and university workshops, and support a Discord community with weekly Q&A sessions.

• Optimize for search engines with targeted technical pages, and publish reproducible benchmarks to build trust.

6) Risks (Legal and Technical)

• Legal: compliance with dependency and embedding model licenses, trademark checks before launch, and adherence to GDPR, CCPA, and data storage location requirements.

• Legal: liability for incorrect results or outdated information, clarifying product boundaries and not providing absolute accuracy guarantees.

• Technical: index performance at scale,
