RoundForge — Complete Project Plan

Turn your match files into actionable insights in minutes, for any competitive game.

A complete implementation plan for a new digital project: the idea, the audience, the product, the revenue model, the distribution plan, and the risks. The project is under construction and has not been launched yet.

An original product plan for competitive gaming data analysis

1) Target audience

• Team coaches and performance analysts in esports.

• High-rank players and content creators who explain rounds and comparisons.

• Data researchers and tool builders who want a clean API to build their own apps.

• Amateur teams and academies that do not have the budget for professional tools.

2) Points of distinction (why choose our product)

• Multi-game from the ground up: a plugin architecture that supports more than one competitive game with the same interface.

• From upload to insight in minutes: upload the match file and get a ready visual report without writing a single line of code.

• Cloud interface + local library: the same engine works as a Python library for local use, and as a cloud service for teams.

• Actionable insights: not just raw numbers, but recommendations such as "positioning problems in economy rounds".

• Free to start: the basic tier is open for use to build a community and drive fast adoption.

• Privacy first: local processing is possible so that sensitive team data is not uploaded to our server.

3) Scope of the first version (maximum 8 tasks)

1. A demo parser engine written from scratch in Python.

2. Extracting core events: kills, fights, economy, bombs, rounds.

3. A performance metrics calculator (player rating, aim accuracy, round impact).

4. An interactive 2D map viewer to display positioning and movements.

5. An automatic text/visual report in HTML and PDF format.

6. A simple REST API to upload a match and retrieve the analysis.

7. A simple web interface for drag-and-drop and displaying results.

8. Clear documentation + ready-made examples + basic tests.

4) Pricing and revenue model

• Free: analysis of a limited number of matches per month + the library is open source.

• Pro (monthly subscription): unlimited matches, advanced reports, export, historical comparisons.

• Team (annual subscription): a shared workspace, multiple permissions, integration with Discord/Notion.

• API/Enterprise: paid developer access and a private cloud for professional teams.

• An additional source: sponsorships, community competitions, and paid training courses.

5) Global distribution plan through free channels

• Publish the library on GitHub and PyPI and list it in free esports tool directories.

• Articles and tutorials on Medium, Dev.to, and Reddit (r/esports, r/GlobalOffensive).

• Short videos on YouTube and TikTok that explain analyzing a real match step by step.

• Discord communities for teams and academies, offering a free initial analysis.

• Collaboration with content creators and analysts in exchange for free access.

• Launch a free challenge/hackathon to build plugins for a new game.

6) Risks (legal and technical)

• Legal: respecting the game's terms of use and not reverse engineering its files, complying with data and image licenses and not using protected logos, and protecting player data in accordance with GDPR.

• Technical: match file formats changing with updates, the need for high performance on huge files, the accuracy of the maps, and cloud scaling and its costs.

7) Suggested name and tagline

Suggested name: RoundForge

Tagline: Turn your match files into actionable insights in minutes, for any competitive game.
