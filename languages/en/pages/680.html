New product plan: flat-file content management system

General idea: an easy, fast tool for building websites without databases — content stored as simple text files (Markdown) and rendered through a lightweight template engine, with a web editor and instant publishing. Goal: faster, clearer, and safer than traditional solutions.

1) Target audience

1. Independent developers and freelancers who build small, fast sites for clients with limited budgets, and want to avoid ongoing database maintenance and security updates.

2. Small business owners and shops (cafés, clinics, handmade stores) who need a landing page + blog + static pages, and seek hosting costs under $5/month.

3. Designers and small UI agencies who reuse templates across dozens of clients and want delivery in one or two days instead of weeks.

4. Developers hosting sites on simple servers (small VPS, shared hosting) or exporting static sites to free content delivery networks.

5. Arabic teams and educational institutions needing genuine Arabic support, RTL direction, and built-in Arabic fonts without manual tweaks.

6. Content writers and bloggers who want direct browser-based editing with live preview, without dealing with complex technical tools.

2) Differentiators (why choose our product)

1. No database at all: one folder of files is enough; backup = copy the folder, restore = paste it. This measurably cuts operational errors and allows hosting at $3–5/month.

2. Built-in instant search index: an index built locally from files and reloaded on save, with results in under 50ms for 10,000 pages — no Elasticsearch or external services.

3. Native bidirectional Arabic editor: live preview, switching between Markdown and visual editing, full RTL support, and a default built-in Arabic font — a feature rarely free in the lightweight site category.

4. One-click publishing via three paths: export to static files, upload via SFTP/SSH, or sync with a Git repository. The user picks the path during initial setup in under two minutes.

5. Permissions and edit history without complexity: JSON/TOML user files with roles (owner, editor, reader) and an edit history stored with each page — suitable for small teams without external apps.

6. Measurable performance: target first-load time under 100ms with output caching, and only one config file — no complex PHP extensions or custom server settings.

3) First-release scope (max 8 tasks)

1. Read and render engine: reading files, parsing Markdown, lightweight template engine, and cache invalidated on file change.

2. Two ready default templates: a blog template and a landing-page template, both working in RTL and LTR with automatic font adjustment.

3. Web editor: browser-based editing interface with live preview, saving directly as a text file in the repository.

4. Users and permissions: login, three roles, and edit history per page.

5. Publishing: static site export + SFTP upload, with preview before publishing.

6. Instant search: local index with keyword highlighting and instant results.

7. Multilingual: at least two versions per page with language switching from the menu.

8. Documentation and experience: Arabic/English guide, 10-minute video, and a free trial with no credit card.

4) Pricing and revenue model

1. Free forever (Free-to-start): one project up to 50 pages, one user, search, and static export — enough to fully try the product and launch a real site.

2. Pro at $12/month: 5 projects, 5 users, edit history, SFTP publishing, and weekly automatic backups.

3. Agency at $39/month: 25 projects, white-label dashboard, and unlimited client subdomains.

4. Launch offer: lifetime license at $149 per person (limited to 200 seats) to accelerate cash flow in the first 3 months.

5. Template marketplace: additional revenue from selling templates and add-ons with a 70% designer share — encourages the developer community at no cost to the core product.

6. Optional managed hosting: $5/month per project for those who don't want server setup — high margin relying on existing infrastructure.

5) Global go-to-market via free channels

1. Open core + first 100 users: launch the repository on GitHub with full docs, then contact 100 developers/designers directly via personalized messages (first 100 users = strongest later pricing channel).
