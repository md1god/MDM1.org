Knotiva — Complete Project Plan

Weave your ideas into a network of living nodes, and turn a single number into a 3D model in seconds inside Blender.

Full plan for a new digital project: idea, audience, product, revenue, rollout, risks. Under construction; not launched.

1) Target audience

• Small-studio parametric designers: 2–15-person teams making furniture, facades, consumer products; one dimension change (e.g. height of 40 columns) costs ~45 min of manual rebuild; target 90 s.

• Architects and urban designers: trying 20 facade-shading options; sun angle and grid density must drive instant 3D results without complex coding.

• Technical artists and animators: want time- or audio-driven shapes; spend 3–6 h/day in Blender and need generators that stay in-window.

• Teachers and students: design professors at ~40 universities teaching computational design lack a simple visual example of nodes, inputs, outputs for a 60-min class.

• Budget-limited freelancers: emerging-market designers on 16GB mid-range PCs, no costly CAD; start free, upgrade after first sale.

2) Why choose us

• Nodes read as sentences, not wires: Arabic/English labels, function colors, in-node previews make graphs clear at a glance to newcomers.

• Live edits, no restart: one number refreshes a 50,000-face network in <200 ms; undo/redo as in Blender.

• Shareable text versions: small JSON file in Git, so clients comment "thickness = 12 mm" instead of a vague screenshot.

• Result-first templates: 100 presets (railings, tiles, roof frame, wave, rope, wire mesh); one click yields a result to refine, not a blank page.

• Local-first speed: no cloud; offline base version; a meter shows which node takes 70% of the time.

3) First release (8 tasks max)

• Task 1: Engine core with 30 nodes: point, curve, surface, transform, repeat, merge, trim, label; Python and NumPy in Blender 4.3+.

• Task 2: Node editor inside Blender, hideable side panel, customizable shortcuts, no external window.

• Task 3: Strict types block text-to-geometry links; clear Arabic error names the side to change.

• Task 4: Preview refreshes on drag, capped at 30 fps for mid-range PCs.

• Task 5: JSON save/import, mesh export in Blender, 3 examples working after install.

• Task 6: Pricing page and Arabic/English docs, Discord channel, installer under 8MB.

4) Pricing and revenue

• Free forever: core, 30 nodes, 10 templates, docs, no card; 5,000 active users in 6 months.

• Pro $9/month or $79/year: 120 advanced nodes, cloud copies, unlimited edit history.

• Studio $24/seat/month: up to 10 seats, private templates, 24-hour support, 3-seat min.

• Free education licenses with institutional email; name on the completion certificate.

• Template marketplace 80/20: designers sell at $5–25; 20% only after a new seller's first $1,000 in sales.

• Optional support: $149 for a 90-minute custom setup session.

5) Global outreach, free channels

• Blender add-on store: publish free version first, with animated images of one number changing the shape instantly.

• YouTube and Bilibili shorts: 3/week, 45 s, "From number to curve in 20 seconds", Arabic/English/Chinese subtitles.

• Reddit and Discord: answer 5 questions daily in 3D communities, no direct promotion, docs link in signature only.

• Weekly no-prize challenge: "Redesign a chair with 7 nodes"; featured work in a newsletter to 2,000 subscribers by month four.

• Design-school partnerships: free 60-min workshop for a university using the tool in one course, in return for a partners-page listing.

• Community translation via Git: French, Spanish, Korean files reviewed by volunteers for a "translator" badge.

6) Risks (legal and technical)

• License: as a Blender add-on, code must be GPL-compatible; review each file before release; log component sources separately.

• Trademarks: "for Blender" is descriptive only, no logo or similar name; check the name in 5 markets before launch.

• Blender API changes: a major update may break the UI; test within 72 h on Windows, macOS, Linux; keep a 6-month compatibility branch.

• Mid-range performance: 200 nodes may use 6GB RAM; alert at 80%; compute in 5,000-face batches.

• Numerical drift: 0.01 mm across platforms can ruin a print; golden tests for 25 cases; pin precision in the file.

• Thin free content: few free templates hurt conversion; add 2 free templates weekly for 3 months.

7) Proposed name and tagline

Name: Knotiva

Tagline: Weave your ideas into a network of living nodes, and turn a single number into a 3D model in seconds inside Blender.
