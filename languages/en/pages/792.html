Siraj — Complete Project Plan

Run an AI coding agent on your phone with no root or complex terminal, instant output, and data kept on your device.

A complete execution plan for a new digital project: idea, audience, product, revenue model, launch plan, and risks. The project is under construction and has not been launched yet.

1) Target audience

• Developer without a computer: an engineering student or employee who has an Android phone with 4 GB of memory and version 11 or above, and wants to accomplish 3 tasks daily (write a function, fix a bug, generate a test) while on the move; our goal is first run within 60 seconds.

• Support and hardware technicians: an engineer who needs to read logs from a device connected via USB, run 10 diagnostic commands, and take a screenshot without root permissions; we bring that together in a single dashboard.

• Small business owners: an e-commerce merchant who wants to generate 10 product descriptions or edit their store files within 20 minutes from their phone, without an expensive desktop subscription.

• Teachers and students: a programming instructor who explains 15 examples in a session and needs an environment that remembers the last line written even if the app is suddenly closed.

• Privacy-conscious users: a team working on client code that refuses to upload it to unknown servers; operation is local by default, and only what the user chooses is sent to a service provider.

2) Differentiators (why choose our product)

• Installs like any app: a normal APK file, no bootloader unlocking, no root permissions, and no terminal setup; average from download to first task: 4 taps.

• Lightweight isolation from scratch: our own user-space layer redirects file paths and calls without ptrace interception; target under 3% additional CPU load and under 150 MB memory at idle.

• Instant result streaming: text appears token by token with response time under 200 milliseconds, with a diff view shown before accepting any file modification.

• Built-in bridge connection: connect the target device via USB or Wi-Fi, run 5 common commands (install, logs, screenshot, copy file, reboot) with an audit log.

• Work stays saved: every session is recorded in an encrypted local database with a snapshot every 30 seconds; resume to the last position at 100% in our internal tests.

• A truly free start: 20 tasks per day and 3 parallel sessions with no credit card, and you can enter your own provider key so you pay for token costs, not us.

3) Scope of the first version

• Task 1 — Installation package: a signed APK that works on Android 11–15, with a first-run wizard that installs a minimal Ubuntu environment (90 MB) into the app’s private folder within 45 seconds.

• Task 2 — Isolation layer: implement redirection for /home, /tmp, and /proc in user space, with a compatibility table covering 12 devices across 4 memory classes.

• Task 3 — Agent engine: receive user instructions, split them into 5 visible steps, and stream output token by token with a stop button at any time.

• Task 4 — Interface: Arabic with RTL direction and English with instant switching, an editor with tabs, and a status bar showing processor, memory, and the current session.

• Tasks 5 and 6 — Bridge and saving: device detection and execution of the five commands with confirmation before any install or delete, then an encrypted SQLite database and a snapshot every 30 seconds and compressed session export.

• Tasks 7 and 8 — Account and measurement: optional email sign-up with a quota of 20 tasks per day and an upgrade screen, and anonymous performance metrics (startup time, success rate) that can be disabled with an optional error report. Out of scope: iOS, model training, and sync between devices.

4) Pricing and revenue model

• Free (0$): 20 tasks per day, 3 sessions, projects up to 50 MB, and unlimited local model; no bank card.

• Traveler plan (4.99$/month or 39$/year): 600 tasks per month, 10 sessions, projects 500 MB, and optional encrypted backup.

• Team plan (12$/user/month): shared instruction library, 20 sessions, and an audit log with CSV export; minimum 5 users.

• Pay-as-you-go: optional credit of 10$ consumed for cloud model tokens with only a 10% markup over the provider price, with a detailed invoice for each task.

• Fixed rules: no ads inside the interface, no data selling, and subscription cancellation from the same screen in two taps; the BYOK model eliminates token fees entirely.

5) Global launch plan with free channels

• Open repository: app core under Apache-2.0 with README in Arabic, English, and Indonesian, and a “first run in 5 minutes” guide; goal of 50 contrib
