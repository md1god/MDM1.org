Mehwar — Complete Project Plan

Turn any car model into six precise, print-ready orthographic views in under twenty seconds, with no installation or file uploads.

Plan for a new digital project: idea, audience, product, revenue, distribution, risks. In development; not launched.

1) Target audience

• Simulation car modelers (55%): rebuild models for driving games. A GT-model dev needs matching top/side/front views; now: 6 cameras, hidden wheels/glass, 15–25 min/car.

• Automotive designers/reverse engineering (20%): redesign a classic car; need a 1:10 blueprint on A3 beside the clay model.

• Indie game devs (10%): studios of 2–5 want one "reference sheet" of proportions/angles, not scattered forum images.

• Students/beginners (10%): learning hard-surface modeling; need clean silhouettes, no lighting/camera setup.

• Content creators/print workshops (5%): record lessons or build 1:8 RC bodies; need printable blueprints with a measurement grid.

2) Why our product

• Zero install/upload: all in-browser via WebAssembly and WebGL2; drag file, results in ~20 s. No server storage; unpublished models stay private.

• Smart body isolation: part names/positions detect 4 wheels, glass, cabin; one-click "Body only" (hide 4 wheels + 12 interior parts; restore).

• Measurable accuracy: reads unit and bounding box; 4,512 mm at 1:20 prints "225.6 mm" + scale bar; manual unit fix avoids 100× cm/mm error.

• Work-ready output: transparent PNG to 4096×4096 px, vector SVG, PDF on A4/A3, six numbered pages, free without watermark.

• Shareable presets: angles, margins, line thickness, background color in JSON/link; reuse for dozens of cars.

3) First version (8 tasks max)

• 1 — Local import: WASM from scratch reads OBJ, FBX, GLB/GLTF; 150 MB cap, clear error.

• 2 — 3D viewer: orthographic cameras: top, bottom, front, rear, right, left; 15° check angle.

• 3 — Component detection: wheels/glass/cabin by name/position; checkbox per group.

• 4 — Controls: unit (mm/cm/in), scale (1:1, 1:10, 1:20, 1:43), background color, 10 mm grid, 1–4 px lines.

• 5 — Export: "Export all" to PNG/SVG/PDF; names like mehwarside1-20.png.

• 6 — Presets/experience: localStorage, JSON import, Arabic/English landing page, no sign-up; feedback sends text only, not the model file.

4) Pricing and revenue

• Free forever: import, six views, PNG to 2048 px, SVG; no sign-up/watermark; growth engine; starts in a minute.

• One-time Pro $19: 4096 px, PDF with length/width/height, batches up to 20 models, preset sync; via Lemon Squeezy for VAT simplicity.

• Lifetime $39: same, ongoing updates for subscription-averse; target 30% of buyers.

• Studio team $49/month: 5 seats, shared presets, 24-hour replies, API for model intake.

• Economics: ~$40/month (domain + CDN + analytics); 300 Pro × $19 = $5,700; break-even at 3; >90% margin; 14-day refunds.

5) Free-channel global launch

• Modeling communities (weeks 1–4): posts in r/3Dmodeling, r/Blender, driving-sim mod groups on Reddit/Discord; before/after: 18 min manual vs 20 s; 10 answers/week.

• Short videos (weeks 2–8): 30 clips on YouTube Shorts, TikTok, Reels, "From file to blueprint in 15 seconds", English/Turkish/Spanish subs; 100k views by month 3.

• Product launches (week 6): Show HN, Product Hunt, Indie Hackers same day, no-sign-up trial; 500 visitors, 30 emails in 72 h.

• Open-source tool: small MIT command-line tool for local batch conversion; draws developers, listed in GitHub modeling-tool lists; code from scratch.

• SEO/localization: 12 pages for "how to get orthographic views of a car model" and "1:20 scale blueprint"; 800–1,500 organic visits/month by month 6; translate: Arabic/English, then Turkish, Italian, Portuguese.

6) Risks (legal and technical)

• Model rights (legal): users may lack rights; terms make user responsible, we never receive the file, PDF header says "For personal and educational use".

• Trademarks (legal): no logos/brand names or company-named pages; use generic text like "two-door sports car".

• Library licenses (legal): code from scratch, but UI uses open-source libraries; publish LICENSE and attribution; check MIT/BSD for commercial use regularly.

• Privacy (legal): no accounts cuts GDPR load; anonymous analytics, no ad cookies; one-page policy: file stays on device.

• Performance/dimensions (technical): large FBX may exceed 500 MB RAM; 150 MB cap, batched reading + cancel, show bounding-box dimensions before export, 30-second GLB guide, WebGL2 fallback if WebGPU absent.

7) Name and tagline

Name: Mehwar (مِحور)

Tagline: Turn any car model into six precise, print-ready orthographic views in under twenty seconds, with no installation or file uploads.
