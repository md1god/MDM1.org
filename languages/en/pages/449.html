Kovexa — Complete Project Plan

Launch all your games from one window: real performance measurement, settings tuned to your device, and updates scheduled without hassle.

Complete execution plan for a new digital project: idea, audience, product, revenue model, distribution plan, and risks. The project is under construction and not yet launched.

Product Plan: Integrated game launcher that measures your device and tunes your game

1) Target Audience

• PC gamer for long multiplayer sessions and late-night gaming, FEDERAL; seeks a lighter alternative to the heavy official client.

• Gamer on a modest device (4–8GB RAM / older GPU) wants settings measured on their device, not generic publisher specs.

• Arab and Gulf/Egyptian gamer playing on multiple servers and regions needs clear account and region management without any bypass of restrictions.

• Gamer sitting after a workday (engineer/developer) hates tools that crash, spy, or inject into games.

• Content creator and performance benchmarker needs a tool that produces shareable numbers (frametime, temperature, FPS).

2) Differentiators (Why Choose Our Product)

• Real measurement, not publisher copies: reads user hardware and measures game performance on their machine (frametime/1% low) and suggests settings line by line.

• Ultra-light: Rust core + React UI via Tauri, <100MB RAM consumption and opens in under a second — on Windows, macOS, and Linux from a single core.

• No injection, no conflict with anti-cheat: we never read or write process memory; only system settings and files outside the game path.

• Local-first: no mandatory account, no ads, performance measurement is optional to share.

• Smart update scheduler: determines download speed, pauses on metered networks, resumes, and schedules updates during quiet night hours with time-remaining estimation.

• New Identity Unit: "Quiet Command Deck" design (single top bar, high contrast, full keyboard shortcuts, native RTL support for Arabic) instead of copying store interfaces.

• Open source (open-core): core under MIT — greater trust and faster spread than closed competitors.

3) First Version Scope (8 Tasks)

1. Core and UI: Tauri 2 + Rust + React/TS app, dark/light theme, RTL, keyboard shortcuts, and install/sign on all three platforms.

2. Unified Library: Automatic game discovery via known store paths + manual folders, with tags and local metadata (no network fetching).

3. Settings Launcher: Per-game config file (preferred GPU, process priority, memory limit, disable Overlays/recording, 32-bit mode) via system variables and files outside the game, with backup before any change.

4. Performance Meter and Recommendations: Records frametime/FPS/temperature/usage, "why it stutters" summary, and settings recommendations built on user's device + optional anonymous measurement database.

5. Update Scheduler: Integration with official store updater (runs it under supervision and controls speed, scheduling, and resume) + update size and time-remaining alerts.

6. Account and Region Management: Profile per account (region, language, maintenance window, allowed launch args) + conflict warning + args templates; with explicit rejection of any attempt to bypass region restrictions.

7. Allowed Mods Manager: For titles that officially support mods only — signed download, scoped permissions, safe update and enable/disable, and error log.

8. Diagnostics and Sync: Reads game logs and generates shareable support summary (no sensitive data) + optional cloud sync for profiles with backup and signed self-update with safe rollback.

4) Pricing and Revenue Model

• Free forever (freemium): library, settings, measurement, recommendations, scheduler, diagnostics, and mods — no ads, no mandatory account.

• Pro: $3.99/month or $29/year (or $39 lifetime for founders) for unlimited cloud sync, advanced frametime analysis, automatic backup, generated config files, and priority support.

• Open-core: Core code under MIT for free, closed services (Sync, Pro) paid — balance between trust and profit.

• Additional revenue without breaking user trust: Affiliate commission from store/hardware links (prices unchanged, commission disclosed), sponsors only in settings screen, and selling custom config templates to communities.
