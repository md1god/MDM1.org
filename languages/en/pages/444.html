New project plan: a diagram editor and explainer for instructional topics

1) Target audience

• Teachers and course creators especially (in-person/online): they need companion diagrams and illustrations for explaining in minutes, not a complicated dashboard.

• Students and content creators: they like quick drawing for summaries, flashcards/lewla/memes and simple diagrams.

• Small business owners and stores: posters, price lists, WhatsApp ads, with no design budget.

• Users on low-powered devices/Chromebooks: they need a lightweight app that works without an account and without a GPU.

• Fans of Arabic illustration: a tool that professionally supports Arabic writing (RTL) and fonts.

2) Points of differentiation (why choose our product)

• A drawing engine written from scratch (vector-first): every stroke is stored as an editable path, so it stays sharp at any zoom and exports to SVG with no quality loss (common competitors store raster layers).

• A "topic board" instead of a blank canvas: ready-made templates (circular diagram, timeline, comparison table, a teacher's layout with names) filled in with text, so a beginner reaches an orderly result in under 60 seconds.

• Exceptional performance on low-powered devices: a package under 25MB, boot under 1.5 seconds, a drawing engine core with memory under 150MB, and it works without a GPU.

• An install-free web version (WebAssembly) + desktop binary: the same engine and interface in one version, and sharing via a link shows the diagram instantly.

• First-class Arabic text: correct letter shaping (joining/forming), RTL/LTR support within the same file, and bundled OFL fonts.

• Non-destructive editing: change the color or thickness of any stroke drawn later without redrawing it.

• Explain mode over the screen: screenshot + annotations + arrows in a shortcut, and share as an animated image or a slide.

• Full privacy: no accounts, no tracking, no file uploads; all work stays local, and the browser version works offline.

• Later add-on (Add-on API) with an open architecture that encourages gurus/professionals to build their own tools.

3) Scope of the first version (max 8 tasks)

1. Core drawing engine: brushes (anti-aliasing + pressure), pen, eraser, eyedropper, unlimited undo/redo, shapes (rectangle, circle, line, arrow, triangle).

2. Productivity tools: align, distribute and space, a text tool (Arabic shaping + RTL), a "mark" tool (correct/incorrect), a lasso selection tool for editing.

3. Layers: unlimited layers in Pro, ordering, opacity, masks, merge/flatten, lock.

4. "Diagram topic" templates: 20 starter templates (circular diagram, timeline, comparison, sequence, concept map, title slide) with fillable text fields.

5. Files: open/save in PNG, JPEG, SVG and PDF, import SVG/PDF, crop, and export windows with ready-made sizes (1080×1080 post, 1920×1080 slide, banner, A4).

6. Explain mode: screenshot + annotation tools + arrow + text, with MP4/GIF export or sequential images.

7. Interface: Arabic RTL and English LTR, two themes (light/dark), customizable shortcuts panel, simple bottom toolbar (only 3 tools per screen).

8. Distribution and launch: Rust core + TypeScript/WASM interface + desktop wrapper (Tauri), Linux/Windows/macOS packages, a free web page, a public repository with an MIT license, a layout page and a template system.

4) Pricing and revenue model

• Free forever (free-to-start): all core tools, two layers, PNG/JPEG export, 20 templates, desktop + web, no account and no size limits.

• Pro — one-time payment of $29 (with 12 months of free upgrades): unlimited layers and masks, high-quality SVG/PDF export, Explain mode, the full template library, the Add-on interface, priority support.

• Optional annual subscription at $19/year: encrypted cloud sync, refreshed templates and themes, and team usage limits.

• Template and component store: designed by the community, with the designer taking 70% and the rest for us.

• Educational license: fully free for schools and universities (a simple verification request via an educational email).

• Additional stream: a paid on-demand "diagram printing" service, and a commission for embedded white-label partnerships.
