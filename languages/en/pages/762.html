Rayfilo — Complete Project Plan

A preview link for every change within a minute, automatically stops before it costs you.

Full plan for a new digital project: idea, audience, product, revenue model, rollout, risks. Not yet launched.

1) Target Audience

• Startup teams (5–20 developers): daily updates; designers/PMs want a real preview link before merge, no long release cycles or ops help.

• Internal platform teams (3–8 engineers): 1–3 Kubernetes clusters; unify build/deploy across 10–40 repos, no repeated config.

• Mid-sized companies (50–300 employees): audit needs; deployment record: request → checks → approval → time in production.

• Open-source developers: small teams, 20–200 merge requests/month; preview per request, fewer random comments, feedback on a real build.

• Education/training: bootcamps teaching continuous delivery to 30–120 trainees; safe, quick create/remove environments, no surprise bills.

• Freelancers: one developer, 2–5 side apps, no time for full CI/CD, but wants the same features; free start, no credit card.

2) Why Choose Our Product

• Preview by decision, not setup: connect repository; unique link per change request in ~90 seconds, in a comment with build status, preview link, checks.

• Built-in cost awareness: 30-minute default, 2-hour max, auto-shutdown on request close; estimated hourly cost shown before creation.

• No-code templates: 12 types (React frontend, Vue frontend, Django frontend, Node.js frontend, Go service, Python job...) via dropdown; pipeline is a reviewable file, not a black box.

• Simple conditions engine: readable rules replace scattered logic: "frontend-only → no server rebuild", "dependabot branch → light checks only".

• Technology-neutral: any compatible Kubernetes cluster; local runs via Kind or k3d; engine swappable behind the interface.

• Developer-first: short commands, no meetings; one CLI assistant lists, opens, extends, deletes environments; Slack/Teams alerts on demand.

3) First-Version Scope (max. 8 tasks)

1. Repository connection: GitHub/GitLab sign-in, one repository, auto webhook, permissions preview before approval.

2. Change extraction: read merge request, classify files, pick template, create unique environment ID for later logs.

3. Image build: container image with shared cache, tagged with commit ID, pushed to user's or free built-in registry.

4. Quality checks: static checks, unit tests, known dependency check; results in one comment, not scattered messages.

5. Preview environment: separate namespace, request values, subdomain, expiration in a lightweight database.

6. Lifecycle/deployment: update comment per change, delete on close or timeout; "Deploy to Production" with optional written approval and exportable edit log.

4) Pricing and Revenue

• Starter ($0): one repository, 20 previews/month, 2-hour max lifetime, 7-day logs, all twelve templates; no credit card or time limit.

• Team ($19/month per active developer, min. 3): 10 repositories, 300 previews, lifetime up to 6 hours, 30-day logs, Slack alerts, email support in 1 business day.

• Growth ($79/month): unlimited repositories, parallel environments per request, approval policies, advanced cost dashboard, deployment log backup, live chat.

• Enterprise (volume-based, from $400/month): customer cluster, LDAP/SSO, centralized auditing, 99.9% SLA, annual support contract.

• Fair rules: no ads, no data selling, no surprise fees; overages warn first, then stop creation unless confirmed; data exportable on cancellation.

• Main revenue: monthly team subscriptions, plus limited one-time $199 custom template packages for companies wanting internal templates to their standards.

5) Global Rollout via Free Channels

• Repository channels: lightweight extension in GitHub and GitLab marketplaces, one-step install, local config file, tag updated each release.

• Free content: 12 short Arabic/English articles, "How to add a preview link to a merge request in 5 minutes", 6 90-second recordings, copyable examples.

• Communities: local Kubernetes and CNCF channels, 4 weekly free streaming sessions in the first 8 weeks, searchable recordings.

• Ambassadors: 50 developers worldwide get a badge and early access for an article, video, or template fix; monthly hall of fame instead of cash.

• Small integrations: command in Slack and Microsoft Teams palette, VS Code and JetBrains search showing active environments; free and open.

• Success metrics: 1,000 active users in 6 months, 200 installs/month, 35% 30-day retention, from anonymous events collected weekly, published transparently.
