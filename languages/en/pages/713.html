Khanah — Complete Project Plan

Share your heritage with the world, without limits or complexity.

Complete execution plan for a new digital project: idea, audience, product, revenue model, distribution plan, and risks. The project is under construction and not yet launched.

1) Target Audience

1. Amateur and professional photographers documenting architectural and natural heritage in their countries who need a fast tool to upload hundreds of images at original resolution with rich metadata (GPS, date, categories).

2. Volunteers in free knowledge projects (such as open image encyclopedias) who upload daily batches from "Wiki Loves Monuments" events and local photography contests, and need automatic upload scheduling when Wi‑Fi is available.

3. Researchers and academics collecting field sample images (plants, rocks, artifacts) who want to link each image to an international identifier (DOI/ORCID) and taxonomic classification (Taxonomy) before publishing.

4. Citizen journalists in areas with intermittent connectivity, needing an "offline‑first" mode with smart sync when network returns, and background upload support without keeping the screen on.

5. Teachers and students in school environment documentation projects, needing a simplified interface in multiple languages (Arabic, French, Swahili, Spanish) with ready‑made templates for CC‑BY‑SA 4.0 licensing.

6. Third‑party app developers who want to integrate upload functionality via a lightweight SDK (under 200 KB) inside their own apps (travel apps, tourist guides, citizen science platforms).

2) Unique Selling Points (Why Choose Our Product)

1. Flexible Resumable Uploader engine that splits large files (>100 MB) into 4 MB chunks, automatically resumes after network interruption, and reduces battery consumption by 35% compared to traditional sequential upload.

2. Visual metadata editor enabling drag‑and‑drop of categories from a live taxonomic tree (sourced from Wikidata) with smart tag suggestions powered by on‑device machine vision (TensorFlow Lite, 92% accuracy for famous landmarks).

3. "Field Mission" mode that groups multiple photos into a single project, applies a license template and default location to the whole batch, then exports a CSV report ready for institutional reporting.

4. Two‑way sync with personal cloud (Nextcloud, Google Drive, S3) as an instant backup before upload to the public repository, with client‑side AES‑256 encryption.

5. Multi‑account and identity support (personal, organization, bot accounts) with separate OAuth keys, and instant switching without logout.

6. Open SDK package (MIT License) allowing any Android/iOS/Flutter app to add a "Upload to Commons" button in two lines of code, with unified error handling and response codes.

3) First Version Scope (Maximum 8 Tasks)

1. Clean Architecture + Kotlin Multiplatform sharing 70% of code between Android and iOS, modules: core‑upload, core‑metadata, core‑auth, ui‑components.

2. Unified authentication module supporting OAuth 2.0 (PKCE) for the target repository, encrypted refresh token storage via Android Keystore / iOS Keychain, with silent renewal of expired tokens.

3. Upload Queue Manager supporting priorities (High/Normal/Low), chunk aggregation, pause/resume, progress notifications in system tray, and configurable maximum of 5 concurrent uploads.

4. Interactive metadata editor with fields: Title, Description (Markdown), Location (selection from offline‑first map via MapLibre + MBTiles), Categories (instant search in Wikidata SPARQL), License (SPDX dropdown list).

5. Offline‑first mode with Room/SQLite database storing thumbnails (512 px) and metadata, automatic sync when network returns, encrypted ZIP project export/import.

6. On‑device machine vision module integrating a MobileNetV3 model trained on 10,000 global landmarks, works without internet, shows top 5 suggestions with confidence >0.7, updatable via Firebase Remote Config.

7. Public SDK + Reference App: sample Material 3 / Cupertino app demonstrating all features, automated UI tests (Espresso/XCUITest) covering 85% of critical paths.

8. Full CI/CD pipeline (GitHub Actions + Fastlane) building signed AAB/IPA, publishing daily internal testing builds, and generating automatic release notes from Conventional Commits messages.

4) Pricing & Revenue Model

1. Completely free for end users (no ads, no tracking, no in‑app purchases), open source under Apache 2.0 license.

2. Commercial SDK license (B2B) for companies embedding upload in proprietary apps: $499/year per app (unlimited uploads), includes email support with 48‑hour SLA.
