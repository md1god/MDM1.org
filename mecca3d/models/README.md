ضع هنا ملف سيارة ثلاثية الأبعاد باسم car.glb (صيغة glTF Binary) فتحلّ تلقائياً محل السيارة المكعّبة.
اختياري: car.json مثل {"rotY":180,"length":4.7,"y":0} لتدوير النموذج إن كان وجهه معكوساً أو لضبط الطول.
من Unity: صدّر النموذج إلى GLB (مثلاً بإضافة UnityGLTF) أو من Blender: File > Export > glTF 2.0 (.glb).
تنبيه: شروط متجر Unity تمنع غالباً نشر ملفات الأصل الخام علناً؛ راجع ترخيص الأصل قبل رفعه إلى مستودع عام.
