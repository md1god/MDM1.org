Rabet — Full Project Plan

Your relationship with every customer starts here.

Full execution plan for a new digital project: the idea, audience, product, revenue model, rollout plan, and risks. The project is under construction and has not launched yet.

New Open Source CRM Product Plan

1) Target Audience

• Small and medium businesses (10–200 employees) in emerging markets

• Sales and receivables (SaaS) teams and digital agencies

• Users who moved away from expensive traditional CRM systems and want full control over their data

• Developers who want to build custom CRM applications with ease

2) Differentiators

• Arabic-first: fully bilingual (Arabic/English) design with full RTL support, not an afterthought translation

• Modern modular architecture: every module (contacts, deals, support tickets) can be enabled or disabled with one click, and custom fields can be added without touching the code

• Lighter performance: lean principles, no heavy dependencies, simple to run on a single server or Docker

• Direct integration with Arabic communication tools: WhatsApp Business, email, and SMS via ready-to-use APIs

• Built-in smart dashboards: simplified predictive reports computed locally, with no need for external analytics subscriptions

3) First Release Scope (8 Tasks)

1. Authentication, roles, and permissions management

2. Contact and customer management with a unified activity log

3. Deals pipeline with drag-and-drop and close-date prediction

4. Support ticket module linked to customers

5. Visual form and custom fields builder

6. Email integration (SMTP/IMAP) with automatic correspondence logging

7. Fully documented REST API with access keys

8. Docker package, one-step install script, and full RTL support

4) Pricing and Revenue Model

• Completely free: self-hosted, with no limits on users or records

• Managed cloud plan: from $9/month per company (hosting, backups, updates)

• Paid add-ons: advanced integrations, automation bots, advanced reports (from $5/month per add-on)

• Consulting and implementation: custom services for large enterprises

5) Global Rollout Plan Using Free Channels

• Publish the project on GitHub with complete Arabic/English documentation

• Long-form content blog: comparisons, tutorials, ready-made CRM templates (SEO)

• Presence in Open Source communities and participation in Arabic tech conferences

• YouTube and X channels covering setup and automation

• Developer referral program: rewards for contributed templates or integrations

• Free hosted trials to attract non-technical users

6) Risks

• Legal: securing the project license (MIT/Apache) and protecting the trademark; complying with local data protection laws (such as GDPR or Arabic data protection regulations) when allowing cloud hosting

• Technical: maintaining integrations with constantly changing external services; needing comprehensive security testing to prevent CSRF/XSS vulnerabilities in an open source system; managing dependency vulnerabilities

• Business: sustainable funding for open source development; competing with major players that have massive marketing resources

7) Proposed Name and Tagline

Proposed name: Rabet

Tagline: Your relationship with every customer starts here.
