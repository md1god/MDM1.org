2) Differentiators (Why Choose Our Product)

1. Open Data Provenance: Every number shows which query, which engine, which date, and which snapshot produced it — reproducible and auditable, unlike closed dashboards that cannot be verified.

2. Gap Matrix: We compare your answers with competitors' answers question by question, and show questions where they are mentioned and you are not — the most actionable signal.

3. Fix Queue: Every gap translates into a specific recommendation (page/document/FAQ/schema.org) ranked by impact × effort, with estimated LLM call cost.

4. Answer Source Map: Which pages are quoted across each engine — reveals "newsrooms and comparison sites" that dominate answers, the core of [hidden source].

5. Metrics Translated for Non-Technical: "Your share of answers" instead of overlapping SoV/citation-share jargon.

6. Citable-by-design: Public report copyable by hash + read API + CSV/JSON export, with MCP-compatible endpoint to feed AI agents.

7. Deployment Flexibility: SaaS or self-host (Docker) for agencies and governance.

8. Free Research Hub No Signup + Public Sector Index = Free Growth Engine Without Ad Spend.

3) v1 Scope (8 Tasks Max)

1. Query Dashboard Setup: Define brand (name + synonyms), competitors (up to 3), custom questions and ready-made question library per sector and market/language (Arabic/English), and frequency selector (weekly by default).

2. Collection Engine: Run queries on ChatGPT, Gemini, Perplexity, Google AI Overviews, Claude, and Microsoft Copilot via official APIs where possible + limited fallback layer, with raw snapshot storage (hash + timestamp + model version).

3. Extraction Pipeline: Detect brand mention (entity matching + synonyms + negative lists), extract quoted links with URL normalization and tracking removal, and sentiment classification (positive/neutral/negative) via rules then LLM when needed.

4. Metrics Engine: Presence rate per query, Answer Share, Citation Share, sentiment trend, aggregation by engine/market/section, with statistical significance thresholds (minimum n and exclusion of small differences).

5. Gap & Competition Matrix: Per query: who mentions, who doesn't, gap size, and "quick-win questions" ranked by impact.

6. Recommendations Queue: Generate recommendations from gaps (update pages, FAQ, Schema.org, reviews, PR) with each linked to a specific URL and impact estimate.

7. Dashboard + Report: Charts (presence over time, answer source map, gap matrix, competitor comparison), weekly email report, public readable report link no signup, and CSV/JSON export.

8. Public Index + API: Public page per sector/city/country showing presence ranking free (without exposing client data), and read API with free key + OpenAPI docs + MCP example.

Out of scope now: Autonomous agents executing recommendations on-site, multi-tenant for enterprises, predictive models, non-Arabic/English language support, embedded chat platforms (Slack/WhatsApp) — for phase two.

Proposed Technologies (Written from Scratch): Python/FastAPI for backend + PostgreSQL + Redis/Celery for scheduled tasks + TypeScript/Next.js for frontend with Tailwind RTL, and mention detection engine built on embeddings + rules (spaCy/Nltk + synonym bridge) without relying on external model per query.
