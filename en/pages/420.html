LingoLayer — Full Project Plan

Read any site in your language, keep the original above it.

Full plan for a new digital project: idea, audience, product, revenue model, launch plan, and risks. The project is being built and has not launched yet.

Product plan: adding side-by-side original translation and in-page translation

1) Target audience

• Readers who follow foreign sites daily (news, tech, software docs) and want the text translated without leaving the page.

• Learners and language students comparing the original with the translation to improve their language.

• Users in the Arab world, China, and Europe who hit pages in a language they don't master.

• Writers and researchers who copy translated passages for their work.

2) Differentiators (why choose our product)

• Sentence- and paragraph-level translation that preserves page formatting (headings, links, tables) instead of breaking the layout.

• Hide/show the translation with one click, plus a side-by-side mode for long reading.

• Free choice of translation engine (free cloud engines + a local model option for privacy).

• Automatic saving of your own terms (personal dictionary), applied to every page.

• Low memory use and faster opening than heavy solutions, with an offline mode using local engines.

• All modern browsers supported through one unified interface.

3) First version scope (max 8 tasks)

1. Build the extension with TypeScript + WXT (or plain Manifest V3), supporting Chrome, Firefox, and Edge.

2. Extract page text (DOM traversal), marking paragraphs and headings while ignoring scripts and ads.

3. Insert the translation below/beside the original text with customizable CSS formatting.

4. Connect several engines (DeepL/Google/LibreTranslate) behind a single abstraction layer with API key management.

5. Fixed toolbar: on/off, direction toggle, hide translation, auto-translate switch.

6. Context menu alternative for manual translation of a selected part of the page.

7. Settings page: source/target language, display mode, local term storage (localStorage/IndexedDB).

8. Publish free in the official stores + a userscript via Greasy Fork + a simple landing page.

4) Pricing and revenue model

• Fully free to start: all core features and the local LibreTranslate engine, without limits.

• Optional paid (Freemium): a Pro plan for a small monthly fee, for professional API keys via our proxy, PDF file translation, and syncing the personal dictionary across devices.

• Limited, clean sponsorship (one non-intrusive ad slot) in the free version when the user opts in.

• Open source for the core to build trust, while advanced features stay commercial.

5) Global launch plan with free channels

1. Official stores (Chrome Web Store, Firefox AMO, Edge Add-ons) and Greasy Fork — the biggest source of organic downloads.

2. Reddit, Hacker News, V2EX: an explanatory post with a short video showing translation on a complex page.

3. X, Telegram, YouTube: 60-second tutorials in target languages (Arabic, English, Chinese).

4. An open usage guide and comparison on GitHub Pages to capture long-tail search keywords (SEO).

5. Partnerships with language-education content creators and tech channels (barter, not paid).

6. Discourse and Discord user communities, plus an Early Explorers program with free perks.

6) Risks (legal and technical)

• Legal: commercial translation API terms may ban proxying — fix: the user enters their key locally, open engines by default.

• Legal: copyright-protected pages — keep translation local, never store user texts on our servers.

• Technical: websites keep changing structure and break extraction — ship per-site detection templates + fast updates.

• Technical: rate limits on free engines — caching layer and automatic routing between engines.

• Store: rejection over ad or content policies — follow store policies from day one.

• Competition: fast competitor clones — defend with speed, privacy, and the personal dictionary.

7) Proposed name and tagline

Proposed name: LingoLayer

Tagline: Read any site in your language, keep the original above it.
