Namq — Complete Project Plan

Make coding agents build interfaces that feel human, not templates.

Complete plan for a new digital project: idea, audience, product, revenue, distribution, and risks. The project is under construction, not yet launched.

1) Audience

• Frontend developers using Claude Code, Cursor, or Codex to generate quick landing pages who need automatic design quality checks.

• Small teams and startups building a distinctive visual identity without a full design team.

• Design/dev agencies delivering client sites who want to avoid "AI-generated" output.

• QA and DevOps engineers who want design checks in CI before deployment.

• Technical educators and creators interested in web interface quality.

2) Differentiators

• Deterministic, explainable assessment: each violation tied to a clear rule and visual evidence, not opinion.

• Identity, not general taste: a custom "design contract" per brand (colors, fonts, spacing, visual tone).

• Works with any coding agent: skill package + standalone CLI, no vendor lock-in.

• Checks the visual result: analyzes DOM, CSS, and screenshots, not just code.

• Fixes, not just criticism: actionable suggestions with code examples.

• Free and open source from day one: lowers adoption barriers and builds community trust.

• No "generator fingerprint": rules from scratch, with independent product identity and design language.

3) First Version Scope (max 8 tasks)

1. Open-source CLI named after the product, run via npx, with an installable skill for Claude Code, Cursor, and Codex.

2. Deterministic YAML/JSON engine with 60 rules in 6 categories: layout, typography, color, spacing, components, motion.

3. Detects common repeated patterns: default purple gradients, excessive rounded corners, inflated shadows, overused icons, generic copy.

4. Playwright analyzer measuring contrast, visual hierarchy, grid, fonts, and actual spacing.

5. 0–100 score report with visual evidence (screenshot + element coordinates) and copyable fixes.

6. CI/GitHub Action fails the build above a quality threshold, with a concise PR report.

7. Custom design contract per project: Design Tokens, allowed exceptions, one config file.

8. Before/after comparison and local browser preview to show fix impact.

4) Pricing & Revenue

• Free forever: CLI + skill + 60 rules + unlimited local use. Open source under Apache 2.0.

• Pro — $12/month: cloud reports, historical comparisons, private rule packs, multi-project scans.

• Team — $29/seat/month: shared design contracts, CI history, permissions, Slack integration.

• Enterprise — custom: on-prem, SSO, auditing, priority support.

• Extra revenue: marketplace for paid design rule packs, extra CI minutes, design audit consulting.

5) Global Distribution (Free Channels)

• GitHub + npm: open-source repo, regular releases, README showing before/after transformation.

• Agent skill marketplaces: publish the skill in Claude Code, Cursor, and Codex communities.

• Product Hunt and Hacker News: launch with a striking visual comparison of an "AI slop" page vs. a polished page.

• Short YouTube, X, and TikTok content: 30-second before/after videos with the score.

• SEO articles: "How to stop AI interfaces from looking generic" and practical guides.

• Discord, Reddit, dev.to: developer and design communities, with free copies for open-source teams.

• Template and UI library partnerships: ready rule packs per framework and a "checked" badge.

6) Risks (Legal & Technical)

Legal:

• Name/trademark risk: check the trademark before launch and reserve domain and accounts.

• Copying rules/text from existing products: build taxonomy and wording from scratch; document sources.

• Library, font, and image licenses: review terms; use only commercially permitted components.

• Screenshot privacy: don't send screenshots to the cloud by default; require explicit consent.

• Coding agent terms: comply with integration policies; don't impersonate official status.

Technical:

• False positives weaken trust: calibrate rules, allow exceptions, explain results.

• Browser/font rendering differences: pin the scan environment; document accuracy limits.

• "AI slop" style evolution: update rules regularly through an open community.

• Large-project performance: selective scanning and caching.

• Easy bypass: combine visual checks with structural rules, not code alone.

• External agent dependence: keep a standalone CLI that works without any agent.

7) Name and Tagline

Proposed name: Namq

Tagline: Make coding agents build interfaces that feel human, not templates.
