Rawaq — Full Project Plan

Your entire library in one place — from your server to any screen.

A complete implementation plan for a new digital project: the idea, the audience, the product, the revenue model, the rollout plan, and the risks. The project is under construction and has not launched yet.

1) Target Audience

• The organized individual user: someone who owns thousands of files (PDF, CBZ/CBR, EPUB, images) across their devices and wants a tidy, fast library.

• Families and small groups: 2–10 people who want to share their own library securely and for free.

• Creators and legal content providers: a small publishing house, writers, and teachers who want to present their work to a limited audience.

• Educational communities and clubs: small digital libraries inside schools and reading clubs.

• A currently underserved Arabic-speaking audience: readers who need an authentic Arabic (RTL) interface and full-text search inside scanned files.

2) Differentiators (Why Choose Our Product)

1. Arabic first: an authentic RTL interface, right-to-left page order, and full support for the Arabic cover and metadata — not a late-stage translation.

2. Local intelligence with no cloud: content recommendations, genre classification, and cover generation all run on-device, with no data sent outward.

3. Search inside images: optional Arabic/English OCR for scanned files, with lightweight text indexing.

4. A reading experience first: night mode, page splitting, horizontal/vertical scrolling, and offline reading with automatic progress sync.

5. Single-tier operation: one Docker package or a built-in desktop app that works as both server and interface — no complex network settings.

6. Privacy by design: sharing via temporary, revocable invite links, with fine-grained permissions per user.

7. Truly lightweight: sub-second open time even with libraries exceeding 100,000 items (progressive background indexing).

8. Price: a genuinely free edition sufficient for personal and family use, not just a temporary trial.

3) First Release Scope (At Most 8 Tasks)

1. Import a library from a unified folder supporting PDF, CBZ/CBR, EPUB, PNG/JPG.

2. Automatic indexing that extracts the title, author, and pages from the file itself (without relying on the internet).

3. Built-in reader: horizontal/vertical scrolling, night mode, two-page split, and saved reading position.

4. Share the library via an invite link with permissions (read-only / read + organize).

5. Reading progress sync across two or more devices via direct differential sync.

6. Ship as one Docker package + a single desktop app (Windows/macOS/Linux).

7. Full Arabic (RTL) interface with English support and a mobile-first design.

8. Full-text search inside files, with an optional OCR toggle to build the index.

4) Pricing and Revenue Model

• Free forever (Free-to-start): one server, up to 3 users, 5,000 items, all core reading features.

• Pro — $4/month or $36/year: unlimited sharing, OCR, cloud backup, and custom interfaces.

• Home Lab — $79 one-time: a perpetual license for one device with all Pro features.

• Team/Enterprise — $12/user/month: advanced permissions, activity logs, and a private domain.

• Supporting revenue sources: optional managed hosting for those who don't want to run a server, + donations via GitHub Sponsors.

• Principle: the core function is never locked — payment buys convenience and capacity, not the right to read.
