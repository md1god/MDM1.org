Sijil — Complete Project Plan

Topic-organized conversations with automatically documented decisions — nothing gets lost in groups.

Complete implementation plan for a new digital project: idea, audience, product, business model, go-to-market plan, and risks. The project is under construction and not yet launched.

New product plan: Topic- and decision-organized conversation

1) Target Audience

• Distributed technical and engineering teams (5–200 people): Developers, platform engineers, DevOps teams — working on multiple projects and losing context in public channels.

• Product and operations units in mid-sized companies: Teams working per client/release, needing a searchable decision record instead of relying on memory.

• Non-profits, academic institutions, and agencies needing a transparent archive of meetings and projects (decision log auditable later).

• Digital product users who moved from chat groups and complain about "lost voice" — search yields no answers, notifications are meaningless.

• Decision makers: CTO/Operations Manager who pays for other tools; we start from zero then expand.

2) Differentiators (Why Choose Our Product)

1. The thread is the atomic unit, not the channel: Every discussion lives in a path with a title and lifecycle (Active ← Paused ← Archived ← Merged). No single "chat room" growing without bounds.

2. Automatic outcome documentation: The system extracts decisions and action items (who, when) from the conversation and turns them into a trackable list linked to code — instead of manually copying into a ticket.

3. Async rhythm by design: No "typing now" indicator, no instant notifications on every reply. User chooses a batching window (instant/hourly/daily) → reduces notification fatigue and restores productivity.

4. Semantic search respecting permissions: Answers "When did we agree to use Redis cache?" with context, highlighting the source and hiding what the user lacks permission to see.

5. Full export and data ownership: Markdown/JSON/CSV export for every space and path, with a "fingerprint" for changes → no vendor lock-in, differentiating from closed tools.

6. Optional and separate AI: Integration via user's key (BYOK) or local model on-prem, with ability to disable any feature by policy, and no training on customer data.

7. Open-core: High-quality self-hosted Docker core, cloud edition as an add-on → free start with no credit card, natural upgrade path to enterprise.

3) MVP Scope (Max 8 Tasks)

1. Workspaces and users: Create workspaces, members, roles (Owner/Admin/Member), invites, email + Google + GitHub login, and SSO (SAML) on paid plan.

2. Paths and topics: Create path/topic within workspace, smart auto-naming on first 3 messages, promote to standalone path, merge two paths, archive and restore, pin messages and tag labels.

3. Chat and threading: Real-time messages (WebSocket) + threaded replies + reply to message + attachments (images/files ≤ 100MB) + simplified rich editor + delayed messages (reply after hours) coherently enter the path.

4. Notification basics: Channels (email, browser push, outgoing webhooks) with configurable batching windows + "My Daily Digest" + Do Not Disturb.

5. Commitment and decision extraction: Automatic message classification (Decision/Task/Question/Update), tracking card per task (Owner, Due, Status), "Matters to Me Now" board + reminders + task export.

6. Semantic search within space: Indexing respecting permissions, full-text + semantic search with source highlighting and context snippets, filter by time and type.

7. AI: Per-path summary (3 sizes: Short/Detailed/Decisions), weekly workspace summary, Q&A with message citations, with BYOK/local model and disable policy + audit log.

8. Integrations and deployment: Outgoing/incoming webhooks + GitHub (comments/tasks/PR) + Jira/Trello + SMTP for email; responsive web app (PWA) + CLI and public API (OpenAPI) + self-hosted Docker Compose + status page/docs/licensing.

4) Pricing and Business Model

• Free forever (start without card): One workspace, unlimited members, 90-day archive, 1GB storage, full-text search, GitHub integration, limited AI summaries (10 topics/day). Goal: near-zero acquisition cost.

• Pro — $6/user/mo (annual $5): Unlimited archive, 25GB storage, semantic search, unlimited summaries, commitment extraction, SSO, advanced export, 24/48hr support, 99.9% SLA.

• Business/Enterprise — $12+ or proprietary on-prem: Full audit log, configurable retention, data residency (EU/US), SCIM, dedicated account manager, DPA and NDA + guaranteed SLA.
