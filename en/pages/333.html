ForgeLayer — Full Project Plan

Design in 3D with parameters, and run it with code from anywhere.

Full implementation plan for a new digital project: the idea, the audience, the product, the revenue model, the rollout plan, and the risks. The project is under construction and has not launched yet.

A new product plan in the field of architectural 3D design (CAD)

1) Target Audience

• Architects and small-scale makers (Makers) who need designs that can be modified quickly.

• Students and universities in engineering, industrial design, and architecture, looking for a free tool that runs on multiple platforms.

• Small digital publishing and game companies that need programmable 3D models.

• Developers who want to generate designs automatically through API and MCP without opening a desktop application.

2) Differentiators (why choose our product)

• A lightweight, open-source geometric kernel written in Rust — fast and memory-efficient.

• Full parametric design: changing a single parameter updates the entire model.

• Runs in the browser with no installation, plus an optional desktop version.

• A first-class automation interface (MCP + REST) to generate and manage designs with code.

• Open export with no lock-in: STL, STEP, glTF, SVG.

• Free to start and works offline.

3) Scope of the First Version (8 tasks maximum)

1. A rigid 2D/3D geometric engine with parameter support.

2. A 3D editor in the browser (WebGL) with pan, rotate, and measure.

3. A shareable parameter library inside the browser.

4. An embedded code window (Script Console) to generate shapes programmatically.

5. Export to STL, glTF, and SVG.

6. A simple MCP server for commands: create, edit, export.

7. Local save + optional cloud sync.

8. Developer documentation with ready-to-integrate examples.

4) Pricing and Revenue Model

• Free: all core features, unlimited export for personal use.

• Pro — 12$ per month: cloud sync, version history, STEP export, priority processing.

• Teams/Enterprises — 49$ per user per month: shared workspaces, permission controls, private hosting.

• Consulting and customization services + sponsorship of open-source projects as an additional source of revenue.

5) Global Rollout Plan Using Free Channels

1. GitHub/MakerWorld platform and publishing an open-source repository to attract developers.

2. SEO articles in (English, Arabic, German, Japanese) about architectural design.

3. Short-form content on YouTube/TikTok/LinkedIn (60-second walkthroughs of a full project).

4. Participation in Reddit, Discord, and forum communities for engineers and makers.

5. An innovator stars program that grants top users free subscriptions.

6. Product Hunt and Hacker News campaigns at the launch of the trial version.

7. Partnerships with universities and technical schools for free educational editions.

8. A weekly newsletter sharing free templates and examples.

6) Risks (legal and technical)

• Legal: avoid any reliance on restrictive licenses or proprietary designs; choose MIT/Apache licenses and verify libraries are free of patents.

• Legal: compliance with data protection laws when cloud syncing (GDPR).

• Technical: consistency of results between the browser and the desktop version (different graphics libraries) — addressed via reference tests.

• Technical: performance of large models — handled by chunking and on-demand computation.

• Technical: leaks or file loss — handled with automatic backups and file integrity checks.

7) Proposed Name and Tagline

Proposed name: ForgeLayer

Tagline: Design in 3D with parameters, and run it with code from anywhere.
