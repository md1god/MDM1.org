Mizan Studio — Complete Project Plan

Edit your photos losslessly, at local speed with full privacy, and start for free.

A complete implementation plan for a new digital project: the idea, audience, product, revenue model, launch plan, and risks. The project is under construction and has not been launched yet.

Product plan: an original non-destructive photo editor

1) Target audience

• Amateur and professional photographers who work with RAW formats and want high-quality results without expensive subscriptions.

• Field photographers, journalists, and travelers who need to work offline.

• Content creators and site managers who value speed and privacy.

• Privacy-conscious users and institutions that do not allow uploading images to the cloud.

• Users on Linux and mid-spec machines neglected by commercial software.

2) Points of distinction (why choose our product)

• Fully non-destructive: every edit is stored as a reversible, copyable history/patch stack.

• High performance: local processing with GPU acceleration via WebGPU/wgpu.

• Privacy by default: no image uploads; all processing on the device.

• Local AI: background removal, denoising, upscaling — all working offline.

• Cross-platform: Windows / macOS / Linux / a lightweight Web version.

• An open project format that can be shared and integrated, instead of closed formats.

• Open source and extensible with plugins whose revenue the community shares.

• Always free to start, with no watermark.

3) Scope of the first release (8 tasks maximum)

1. Import an image library (RAW/JPEG/PNG) with metadata and basic tagging.

2. A non-destructive editing engine with undo and copy (history/patch stack).

3. Basic tools: exposure, contrast, highlights/shadows, white balance, saturation.

4. Curves and color (Curves + HSL).

5. Crop, rotate, and horizontal tilt correction.

6. Basic masks/layers with brush and linear gradient support.

7. Multi-format and multi-size export with fast preview.

8. Save/import a project file in an open format for sharing and backup.

4) Pricing and revenue model

• Free to start: all basic tools + high-quality export for personal use.

• Pro (annual license or one-time payment): batch processing, device sync, advanced AI plugins, templates.

• Commercial/team license: support and a license for institutional use.

• Plugin marketplace: the community shares in the revenue from paid tools and recipes.

• Donations and sponsors from the open-source ecosystem.

5) Global launch plan with free channels

• Launch the open repository with clear documentation and a contribution guide.

• Product Hunt, Hacker News, and Reddit (r/photography, r/FOSS, r/rust).

• Tutorials on YouTube and a free worksheet series.

• A community gallery and shareable recipes that attract photographers.

• Integration via plugins and connections with other software at no cost.

• Collaboration with open photography communities and hackathons.

6) Risks (legal and technical)

• Legal: compliance with RAW format library licenses and some algorithm patents, trademark clearance, choosing a clear project license, and ensuring the code is written from scratch without copying.

• Technical: RAW decoding performance on weak devices, color management and consistency across platforms, varied GPU support, and lightweight AI models, in addition to scope size and validity.

7) Proposed name and marketing tagline

Proposed name: Mizan Studio

Marketing tagline: Edit your photos losslessly, at local speed with full privacy, and start for free.
