Qimam — Complete Project Plan

An open SEO platform that works with AI agents and gives you full visibility into your site in search and AI, starting free.

Execution plan: idea, audience, product, revenue model, launch, risks. Not yet launched.

1) Target Audience

• Developers/engineering teams: SEO in dev/CI-CD, no heavy tools.

• Small agencies/freelancers paying for separate tools; need resellable reports.

• Startups/content teams: keywords, competitor analysis, AI visibility on a limited budget.

• Small sites, blogs, stores unable to afford enterprise prices.

• Coding-agent users (Cursor, Claude Code, VS Code with MCP) wanting SEO in the dev environment.

• Arab market first as underserved; global from day one.

2) Differentiators

Problem: paid SEO tools are costly, closed, GUI-only, ignore AI visibility, monopolize data/methodology.

• Agent-first, MCP-native: all functions as standard agent tools; CLI, API, clear JSON Schema.

• Local-first, self-host: core runs locally/on user's server; BYO API keys.

• Unified view: keywords, backlinks, technical audit, rank tracking, competitors.

• AI visibility: brand mentions and source citations in ChatGPT, Gemini, Perplexity, Copilot.

• Verifiable transparency: open methodology, confidence scores, reproducible reports.

• Cost from zero: free self-hosting, free cloud plan, low-cost subscriptions.

• Privacy/compliance: no data selling; regional retention, deletion.

• Distinct design: Arabic-first RTL, light/fast, TUI mode, editorial reports.

• Integrations: GitHub Actions, WordPress, Next.js, Shopify, Ghost, Webhooks.

3) First-version scope (maximum 8 tasks)

1. Crawler/audit: 10,000 pages; broken links, titles, descriptions, canonical, hreflang, sitemap, robots.txt; CSV/JSON.

2. Keyword discovery/clustering: seeds + suggestions + public data + optional SERP; clusters by intent/language.

3. Rank tracking: daily/weekly, desktop/mobile, geo scope, history, alerts.

4. Backlink explorer: Common Crawl + user crawl + optional provider; referring domains, anchors, risk, Disavow.

5. Competitive gap: 2+ domains, content gaps, keyword overlap, Share of Voice.

6. AI visibility: question sets, mentions, citations, sentiment, periodic report.

7. MCP Server + CLI: unified tools, local auth, agent examples, documented I/O schemas.

8. Reports/alerts: scheduled PDF/CSV, Email/Slack/Webhook alerts, white-label template.

Out of scope: proprietary global index, mobile app, enterprise SSO, ranking/SEO guarantees.

4) Pricing and revenue model

Revenue model:

• Subscriptions: monthly/annual.

• Extra crawl/AI credits.

• Enterprise support/deployment/onboarding.

• Paid add-on/integration marketplace later.

• No data selling, ads, or API-key monopoly.

5) Global go-to-market plan with free channels

• GitHub: open repo, strong README, clear releases, beginner Issues, contributor license.

• MCP registries: MCP directories, awesome-mcp-servers, agent platforms.

• Packages: npm, PyPI, Docker Hub, Homebrew.

• Launch: Product Hunt, Show HN, Reddit (r/SEO, r/TechSEO, r/webdev, r/mcp), Indie Hackers.

• Education: YouTube shorts, Dev.to/Hashnode, Arabic/English guides.

• Practical SEO: optimize its own site; free public analyses.

• Free integrations: GitHub Action, WordPress, Shopify, Next.js.

• Communities: meetups, universities, hackathons, newsletters.

• Middle East first: Arabic content for neglected teams, then global.

• Referral program: credits for users/agencies bringing projects.

6) Risks (legal and technical)

Legal:

• Crawling search results may violate ToS; official APIs/user keys, respect robots.txt, no bypassing.

• Privacy/GDPR/CCPA; processing agreements, minimal collection, deletion, regional residency.

• Library/Common Crawl licenses; audit, source docs, MIT/Apache core, DCO.

• Name/trademark similarity; check before launch.

• AI provider terms; no violating output resale; clear attribution.

• Recommendation liability; disclaimer: measurement tool, no ranking guarantees.

Technical:

• Rate limits, blocking, CAPTCHA; swappable providers, cache, retries.
