Miqyas — Complete Project Plan

One trusted metric reaching every dashboard and every AI agent.

Complete implementation plan for a new digital project: the idea, audience, product, revenue model, go-to-market plan, and risks. The project is under construction and has not launched yet.

1) Target Audience

• Data and analytics teams at startups and mid-sized companies using one or more data warehouses.

• Data engineers and BI analysts suffering from duplicate metric definitions and conflicting numbers across dashboards and reports.

• Product and AI teams building LLM agents or embedded analytics and needing a reliable semantic layer.

• Application developers who want to embed analytics without rebuilding duplicate business logic.

2) Differentiators (Why choose our product)

• AI-first: a semantic layer delivered to agents via MCP and API interfaces, not just a traditional BI layer.

• Fast start: define metrics in minutes via YAML or a visual interface, without rebuilding models.

• Single source of truth: one metric definition used in dashboards, reports, and AI agents, with versioning and tracking.

• Practical governance: fine-grained permissions, audit log, and clear lineage.

• Warehouse-neutral: works on top of PostgreSQL, BigQuery, Snowflake, and DuckDB without lock-in.

• Free to start: open-source core and self-hosting, with an optional cloud layer.

3) Scope of the First Version (maximum 8 tasks)

1. Metrics and dimensions definition engine in YAML with versioning and safe changes.

2. Initial read connectors: PostgreSQL, BigQuery, Snowflake, DuckDB.

3. Unified query interface: REST + GraphQL + SQL endpoint + MCP server for agents.

4. Search and automatic documentation catalog for metrics with lineage tracking.

5. Metric- and column-level permissions and audit log.

6. Safe SQL generator with caching and simple pre-aggregations.

7. Lightweight dashboard embedding and JavaScript SDK.

8. Free demo environment with sample data and a step-by-step guided setup.

4) Pricing and Profit Model

• Free forever: open-source core for self-hosting, with no limit on the number of metrics.

• Cloud Free: one project, 3 users, a generous monthly query limit, for trial and adoption.

• Pro: monthly per-user subscription with advanced permissions, backups, and support.

• Scale: usage-based pricing for queries and embedding, with SLA and a private deployment option.

• Enterprise: annual contracts including SSO, advanced auditing, network isolation, and dedicated support.

• Core profit from cloud subscriptions and usage, not from selling data.

5) Global Go-to-Market Plan with Free Channels

• Publish the core on GitHub with open documentation and a clear license, and build a contributor community.

• Search engine optimization through technical guides, practical comparisons, and use cases.

• List the MCP server in open AI tool directories and technical communities.

• Short video content on YouTube and developer platforms explaining the solution to the conflicting metrics problem.

• Participate in dbt, Slack, and specialized Reddit communities through helpful answers, not ads.

• Ambassador program and contributor rewards, and free virtual hackathons.

• Parallel Arabic and English content to attract MENA markets, then expand globally.

6) Risks (Legal and Technical)

• Legal: respect open-source licenses, do not copy code or trademarks, and review intellectual property before launch.

• Legal: comply with GDPR and CCPA, data processing agreements, and manage warehouse connection secrets.

• Legal: terms of use of cloud and AI platform providers, and clarify that AI outputs are not financial or legal advice.

• Technical: SQL dialect differences across warehouses, addressed by a translation layer and contract tests.

• Technical: large query performance, addressed by caching, pre-aggregations, and clear limits.

• Technical: metric definition drift, addressed by versioning, review, and alerts.

• Technical: agent security and prompt injection prevention, through read-only permissions, query filtering, and full auditing.

7) Proposed Name and Tagline

Proposed name: Miqyas

Tagline: One trusted metric reaching every dashboard and every AI agent.
