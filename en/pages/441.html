Zuhhal — Complete Project Plan

Ask the sky, get its data in seconds.

A complete implementation plan for a new digital project: idea, audience, product, business model, distribution plan, and risks. The project is under construction and has not yet been launched.

Product Plan: Search and download space data from a single source

1) Target Audience

• Researchers and graduate students in astronomy: need quick access to multiple archives without writing new connectors each time.

• Amateur astronomers: capture images with home telescopes and want to compare them with space observation data.

• Science teachers and students: need ready examples and data for lessons and labs.

• Space journalists and content creators: need reliable figures and images with citable sources.

• Developers of lightweight scientific apps: want a single API instead of integrating dozens of services.

2) Key Differentiators (Why choose our product)

• Single entry point: unified search across multiple public data sources (images, spectra, tables) instead of navigating scattered sites.

• Natural language in Arabic and English: “Show me the spectrum of star X for 2019” instead of learning technical search parameters.

• No-code from day one: interactive web interface, plus CLI and lightweight Python library for automation.

• Automatic format conversion: from raw scientific formats to PNG/CSV/JPEG ready for display and publication.

• Preview before download: thumbnail preview, column descriptions for tables, and field descriptions before downloading files.

• Shareable queries: every result produces a permanent link and ready-to-copy code snippet for research papers.

• Data economy with transparent limits: clear counter for queries and storage with alerts before hitting free limits.

3) First Version Scope (Max 8 Tasks)

1. Free registration and a single dashboard showing queries, downloads, and storage consumed.

2. Unified search across 3 public data sources (images, spectra, tables) via a single custom-built connector interface.

3. Natural language search in Arabic and English with automatic source suggestions.

4. Instant result preview: thumbnail image, spectral plot, or table with columns.

5. Download as a single file + automatic conversion from scientific format to PNG/CSV.

6. Simple CLI and lightweight Python library with one-step installation.

7. Permanent share link for each result + export query as a ready-to-copy code snippet.

8. Pricing page and accounts + email support within 48 hours.

4) Pricing and Business Model

· Plan · Price · What you get ·

· Free · 0 · 50 queries/month, 5 GB downloads, 3 sources, share links ·

· Pro · $9/month · Relatively unlimited queries, 100 GB, scheduled tasks, full API ·

· Team · $29/month · 5 members, shared storage, permissions, unified billing ·

· Academic/Amateur · 50% discount · Student ID or astronomy club membership ·

Revenue sources: subscriptions, API packages for developers, lightweight ads only in free mode, and sponsorships for educational source pages. Completely free to start with no credit card required.

5) Global Distribution Plan via Free Channels

1. Multi-language SEO: dedicated page for each data type and each language (Arabic, English, Spanish, Portuguese, Indonesian, Turkish, French, German, Hindi, Russian).

2. Short educational content on YouTube and TikTok: “How to get a galaxy image in 20 seconds”.

3. Communities: posts in amateur astronomy forums, Discord, and specialized Reddit groups, with no paid ads.

4. Launch on free product directories: Product Hunt page + AI tools and education directories.

5. Answers on Stack Overflow and Science.SE with practical examples using the interface.

6. Ready open notebooks and templates: copyable analysis templates that drive traffic from search engines.

7. Weekly newsletter featuring eye-catching space data + direct links to ready results.

8. Partnerships with university astronomy clubs and schools to use the tool in classes.

6) Risks (Legal and Technical)

Legal

• Space observation data is often public, but must credit the original source in every download and provide a permanent link to the source.

• Must not resell raw data or include it in a commercial data warehouse without a license.

• Comply with usage limits (rate limits) and terms of service for each connected source.

• User data protection (GDPR): encryption, right to deletion, no data selling.

• Secure name and trademark before launch and document them.

Technical

• External source APIs may change or go down temporarily ⇒
