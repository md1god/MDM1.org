قَبْس · Qabs — Full Project Plan

Launch, pilot, and guard every autonomous vehicle from a single screen.

Full implementation plan for a new digital project: the idea, the audience, the product, the revenue model, the rollout plan, and the risks. The project is under construction and has not yet launched.

Product plan: an operations and maintenance platform for autonomous vehicles

1) Target audience

• Delivery and aerial survey companies that manage fleets of small aircraft (drones) and ground vehicles.

• Farms and industrial facilities that use transport robots and patrol Rovers.

• University research teams and small marine robotics companies (Sub/ROV).

• Developers and hobbyists who build autonomous driving systems (autopilot) on a limited budget.

2) Differentiators (why our product is chosen)

• Full setup through the browser with no software installation, with a setup wizard that guides the user question by question.

• Standalone in-browser simulator to test the mission before sending it to the actual vehicle.

• Smart automatic calibration of control values (parameter tuning) based on logs from previous flights.

• Works with several hardware sets (flight controllers / sensors) through unified gateways, so there is no lock-in to a single company.

• Unified fleet dashboard: several vehicles and different types on one screen with safety alerts.

• A model that starts free and unlocks advanced features only when needed.

3) Scope of the first version (8 tasks at most)

1. Lightweight agent that connects the vehicle to the platform via Serial/MQTT and streams the measurements.

2. Interactive setup wizard (setup wizard) to automatically generate the configuration file.

3. Point-based mission editor on the map (waypoints) with altitude limits and restricted zones.

4. In-browser 2D/3D simulator to run the mission before execution.

5. Live dashboard for telemetry and logs of errors and warnings.

6. Automatic calibration that suggests values computed from previous flight logs.

7. Accounts, teams, and permissions plus a permanently free plan.

8. Interface programming (REST API) and mission file import/export.

4) Pricing and revenue model

• Free: one vehicle, simulator, 10 missions per month, community support.

• Pro: 29$/month per user — fleet of up to 10 vehicles, smart calibration, unlimited logs.

• Enterprise: 499$/month — unlimited fleet, SSO, private hosting, service level agreement (SLA).

• Additional revenue: certified training and integration consulting for companies.

5) Global rollout plan using free channels

1. Open source repository for the agent and the SDK to attract developers.

2. Articles and short explainer clips (YouTube/Bilibili) solving common setup and calibration problems.

3. Participation in robotics and drone communities and HN/Reddit forums.

4. Ambassador program and project competitions for students.

5. Weekly newsletter with use cases and operating tips.

6. Presence at free local events (hackerspaces, university labs).

6) Risks (legal and technical)

• Legal: export control restrictions on navigation/control systems and the civil aviation regulations of each country; it must be documented that the product is software belonging to the end user.

• Legal: liability for damages resulting from wrong commands — terms of use that prohibit use in manned or emergency missions.

• Technical: message compatibility with multiple hardware versions (breaking changes); handled with a compatibility layer and automated tests.

• Technical: security of the telemetry channel and prevention of command tampering — encryption and message signing.

• Operational: automatic calibration complexity may produce unsafe values — they are only adopted after passing simulation.

7) Proposed name and tagline

Proposed name: قَبْس · Qabs

Tagline: Launch, pilot, and guard every autonomous vehicle from a single screen.
