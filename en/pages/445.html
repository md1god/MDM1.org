NAQSH — Complete Project Plan

Draw your vectors once and get print-, cut-, and embroidery-ready files, free and open source.

Complete execution plan for a new digital project: idea, audience, product, business model, distribution plan, and risks. The project is under construction and not yet launched.

Product Plan: NAQSH — Manufacturing-Ready Vector Drawing Studio

The idea: A free, open-source vector illustration editor that runs locally on desktop and in the browser, combining professional editor precision with outputs ready for printing, cutting, and upholstery, plus a programmable API allowing AI to control design.

1) Target Audience

• Makers and printers (core segment): Those producing stickers, decals, vinyl, T-shirt templates, screen printing, stone engraving, and CNC/laser embroidery.

• Independent designers and icon creators: Racing for clean, editable vector art and lightweight SVG files.

• Arab content creators, educators, and students: Need proper Arabic support (diacritics, right-to-left direction, letter spacing) in posters, headings, and educational printouts.

• Small studios and design agencies: Teams of 2–6 needing real collaboration without subscriptions.

• AI agent developers: Want a programmable drawing interface instead of generating non-editable images.

2) Differentiators (Why Choose Our Product)

• Manufacturing outputs, not just images: Cut path layer with kerf compensation, registration marks, spot colors, and export to DXF and DST (embroidery) and PDF for printing — which most drawing tools neglect.

• Arabic-first: Arabic diacritics, bidirectional writing, kashida, and Arabic/Latin mixing exported correctly in SVG and PDF — a common, recurring problem in other tools.

• Programmable from the ground up: MCP server + JSON control channel + headless CLI, so the smart agent draws, modifies, and exports itself. Every action in the UI is programmatically callable.

• Local-first and free collaboration: Documents on your device, optional shared sync via CRDT with free share links — no subscription, no proprietary lock-in.

• Documented, open file format: JSON for everything with version upgrades and full recovery of layers, fonts, and effects.

• High performance: 60 fps at 50,000 shapes, and a single web build loading in seconds (same Rust core via WASM).

• Mac/Windows/Linux and browser from a single core with a shared TypeScript UI instead of heavy native GUI.

3) Version 1 Scope (Max 8 Tasks)

1. Document core and geometry: JSON document structure, pen and Bézier tools with handles, shapes, layers, precise Boolean ops (union/subtract/intersect/divide), fills, strokes, gradients, lossless import/export to/from SVG.

2. User interface: Toolbar, panels (layers/appearance/colors), select/move/scale, zoom/pan canvas, full shortcuts, light/dark themes, Arabic and English menu support.

3. Two apps from one core: Desktop app (Rust + Tauri) and browser app (Rust→WASM + TypeScript UI) with same code and look.

4. Agent API: MCP server, JSON control channel, CLI for headless operation (generate, modify, batch export).

5. Manufacturing and print export: Print-ready PDF (bleed margins, crop marks, spot colors), SVG with cut layer, DXF for embroidery, kerf compensation options.

6. Arabic bidirectional typesetting: Diacritics and letter joining, RTL paragraphs, kashida, embedded fonts and conversion to paths.

7. Local-first collaboration: CRDT sync, presence indicators, comments, share links with limits on free tier, and version history.

8. Quality gate and launch: Geometric tests (property-based) for operation stability and file round-trips, automated screenshots, signed builds for Windows/macOS/Linux/WASM, Arabic/English docs, performance counter in CI.

4) Pricing and Business Model

Freemium model: Core fully open source, pay only for cloud services.

• Community (free forever): Full editor, unlimited local files, SVG/PDF, share links (3), community support.

• Creator (free during beta, then $0 for students): Unlimited cloud sync, collaboration for under 10 people, DXF/DST export, brand kits.

• Studio ($12/mo or $96/yr): Team workspace, full year version history, managed MCP server, batch processing via API, bracket expansion.

• Self-Hosted ($2,000/yr): Internal enterprise build, SSO auth, guaranteed support.

• Additional revenue: Template and asset marketplace (30% cut), print shop referral commissions, optional "cloud" subscription for AI later.
