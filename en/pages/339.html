Mihrab Engineering — Complete Project Plan

Design your next part from the browser in minutes.

Full implementation plan for a new digital project: the idea, the audience, the product, the revenue model, the rollout plan, and the risks. The project is under construction and has not launched yet.

1) Target audience

• Mechanical engineers and small-scale manufacturers (prototyping) who need quick design without installing heavy software.

• Engineering students and technical institutes in developing countries (low-end devices + limited internet).

• Maker communities and hobbyists who 3D-print and want to edit simple STL/STEP files.

• Startup product teams that need cloud-shared prototypes.

2) Differentiators (why choose our product)

• Runs entirely in the browser with no installation, with offline support via Service Worker and local storage in IndexedDB.

• A lightweight Parametric editing engine written in Rust, compiled to WebAssembly for near-desktop performance.

• Real-time collaborative editing mode among multiple editors (like a shared document) using CRDT.

• Guided import/export workflow: STEP, STL, OBJ, SVG with instant preview.

• Full Arabic (RTL) interface with support for other languages — a clear gap in the market.

• A truly free version with no time limit, not a limited trial.

3) Scope of the first version (8 tasks maximum)

1. Basic 3D viewer in the browser (rotate, zoom, clip, measure).

2. 2D sketching tools: line, circle, rectangle, cut to form a revolve profile (Revolve) and pull (Extrude).

3. Rust → WebAssembly engine for core geometric computations.

4. Import and export STL and OBJ with preliminary conversion to STEP.

5. Save projects locally and retrieve them, exporting them as a single project file.

6. Arabic RTL + English interface with a language switcher.

7. Read-only preview sharing via a link (URL + WebRTC).

8. Landing page + comparison of ready-to-download sample prototypes.

4) Pricing and revenue model

• Free to start: two projects, unlimited core features, Merge up to 5 parts, export up to 10 times per month.

• Pro — $12/month: unlimited projects, real-time collaborative editing, STEP import/export, Loft, version history.

• Team — $8/user/month: shared workspaces, permissions, API integration.

• Additional revenue: a paid template store and parts libraries (20% commission), plus discounted university educational licenses.

5) Global rollout plan using free channels

1. YouTube / Bilibili: short "Design a part in 5 minutes" tutorials with Arabic and English text.

2. X (Twitter) and Threads: a Build in Public series and before/after design GIF clips.

3. Reddit and forums r/CAD, r/3Dprinting: a free trial version + feedback surveys.

4. Arabic Maker communities: Telegram and Discord groups (progress updates, an Arabic publishing group, and a monthly challenge with a symbolic prize).

5. GitHub Pages / open libraries: release part of the SDK as open source to attract developers.

6. SEO: browser-based alternative comparison articles for queries like "free online CAD program".

7. Educational partnerships: free tools for technical training academies in exchange for a reference logo.

6) Risks (legal and technical)

• Legal: avoid infringing patents on parametric engineering algorithms; evaluate open-source library licenses before adoption, and clarify ownership of files used for model training. Depending on user files may require a GDPR-compliant privacy policy.

• Technical: browser memory limits with large models → chunking and lazy loading. WebAssembly stability across browsers → test matrix. Loss of work if local storage fails → optional cloud sync.

• Other: competition from companies with complete tool suites; we mitigate this by focusing on speed, price, and the Arabic language.

7) Proposed name and marketing tagline

Proposed name: Mihrab Engineering (Mihrab CAD)

Marketing tagline: Design your next part from the browser in minutes.
