CubeHarbor — Full Project Plan

Your all-in-one gateway to the world of your cubes — all versions, packs, and high performance in one place, with the click of a button.

A complete implementation plan for a new digital project: the idea, target audience, product, revenue model, distribution plan, and risks. The project is under construction and has not yet been launched.

Product Plan: A native Minecraft launcher

1) Target Audience

• Beginner players: Want to play the game instantly without needing to understand Java settings or runtime variables.

• Modpack players: Install complex collections of mods and need dependency resolution and conflict detection.

• Multi-version players: Switch between older and newer versions, as well as private servers.

• Multi-platform players: Use Windows, macOS, and Linux and want a unified experience.

• Content creators and community members: Need to export packs, share them, and easily link to servers.

2) Key Selling Points (Why Choose Our Product)

• True cross-platform support: Built natively with Rust + Tauri to run on all three systems with identical behavior, not a fork or wrapper.

• Smart dependency resolution: Automatically reads description files, installs requirements, and detects mod conflicts before launch, while suggesting solutions.

• Performance and runtime optimization: Automatically adjusts Java memory and runtime arguments based on the device's specifications, and runs thumbnail loading and updates in parallel.

• Privacy by design: No mandatory account, no remote telemetry, and everything runs locally by default.

• Extensibility: A clear plugin system that allows the community to add features without modifying the core.

• Modern interface: Clean design, dark mode support, full Arabic and RTL support.

3) Scope for the First Release (Maximum of 8 Tasks)

1. Manage MC accounts (official/demo) and launch the game with a specific version.

2. Download, manage, install, and verify the integrity (checksums) of official game versions.

3. Automatically install popular mod loaders (Forge, Fabric, and Quilt).

4. Import and run modpacks from local files with dependency resolution.

5. Multi-profile manager with independent memory and JVM arguments for each profile.

6. Conflict and missing dependency detector that displays a clear report before launch.

7. Automatic runtime resource optimization and parallel downloads.

8. Fully bilingual interface (Arabic and English) with RTL support and dark mode.

4) Pricing and Revenue Model

• Free to start: All launch, version management, and pack management features are completely free with no limitations.

• Optional supporter plan: Cloud sync for profiles and settings, backups for packs, and silent background updates.

• Cosmetic store: Themes, icons, and fonts — these do not affect functionality or provide any gameplay advantage.

• Sponsorships and partnerships: Integration with communities, servers, and support for content creators through reliable and non-intrusive links.

• Core principle: No data selling, no intrusive ads, and no essential features locked behind a paywall.

5) Global Distribution Plan Through Free Channels

• Open-source release: Publish the source code on code hosting platforms to attract contributors and build trust.

• Gaming communities: Technical showcases within gaming communities, forums, and specialized subreddits on Reddit.

• Visual content: Create comparison videos showcasing installation speed and conflict resolution on YouTube and TikTok in Arabic and English.

• System stores: Make downloads available through packages and free stores (e.g., Flatpak and AUR).

• Community building: Official Discord server + plugin system to give contributors recognition and badges.

• Early multilingual support: Community-driven translations to attract users outside of the English-speaking audience.

6) Risks (Legal and Technical)

• Trademark compliance: Adhere to the game's trademark usage policy and avoid using any protected game assets; name, icons, and design must be entirely original.

• Third-party packs: Respect the licenses of mods and modpacks, do not redistribute assets without permission, and rely on original source links.

• Accounts: Do not store user credentials; rely on official browser-based login (OAuth).

• Dependency resolution complexity: Variations in description file formats and versions may break installations; mitigate with automated tests and clear failure reports.
