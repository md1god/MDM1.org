Nasaq — Full Project Plan

Simple content management for your static sites, straight from your repository.

A complete implementation plan for a new digital project: the idea, the audience, the product, the revenue model, the launch plan, and the risks. The project is under construction and has not been launched yet.

1) Target Audience

• Static site developers: those who use Git as their source of content and want to simplify editing it.

• Content teams: such as marketing or writing teams that want to update content without deep programming expertise.

• Small projects: non-profit organizations, schools, and early-stage products that need cheap and fast content management.

2) Differentiators (Why Choose Our Product)

• Extremely simple: a clear interface designed specifically for non-developers with the fewest possible steps.

• Secure and Git-based: every edit is saved directly to the repository, with every change easy to review.

• Works from anywhere: support for self-hosted deployment in addition to a lightweight SaaS version, with a focus on user freedom.

• Broadly compatible: supports the most popular static site generators, with easy addition of new generators.

• Lightweight and fast: a streamlined design focused on fast performance even with large repositories.

3) Scope of the First Release (At Most 8 Tasks)

1. Authentication: secure connection with trusted Git providers.

2. Content browsing: navigating site files and organizing them by folders.

3. Smart editor: a simple Markdown editor with custom fields support and live preview.

4. Media management: uploading images and files and organizing them inside the repository.

5. Safe saving: automatically creating a merge request for every edit to preserve the review mechanism.

6. Simple permissions: clear access levels (administrator, editor, reader).

7. Basic support: covering three of the most popular static site generators.

8. Ready deployment: a single configuration file and a Docker package for easy running.

4) Pricing and Revenue Model

• Free to start: the self-hosted version is completely free, and a usage-limited SaaS version is free as well.

• Freemium model: monthly subscriptions for the SaaS version for teams that need greater storage capacity, a larger number of users, or additional collaboration features.

• Value-focused: revenue comes only from the hosted service, while keeping the self-hosted version entirely free.

5) Global Distribution Plan Using Free Channels

• Comprehensive documentation: creating a usage guide in Arabic and English and publishing it for free.

• Educational content: writing short articles explaining how to manage a static site's content without a technical background.

• Developer communities: participating in static site generator communities, Reddit, and Dev.to.

• Short social media: publishing short tutorial videos on YouTube Shorts, TikTok, and LinkedIn.

• Open-source templates: collaborating with developers to publish templates that use the product to increase exposure organically.

6) Risks (Legal and Technical)

• Legal: full compliance with the licenses of any libraries used, respecting user privacy, and ensuring no unnecessary data is collected.

• Technical: securing access keys, protecting file uploads, handling edit conflicts, ensuring compatibility with Git provider changes, and maintaining suitable performance with large repositories.

7) Proposed Name and Tagline

Proposed name: Nasaq

Tagline: Simple content management for your static sites, straight from your repository.
