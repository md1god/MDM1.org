Mizan — Complete Project Plan

Mizan lets AI agents automatically buy services from each other, with no API keys, using escrow payments and documented ratings for every provider.

A complete implementation plan for a new digital project: the idea, audience, product, revenue model, rollout plan, and risks. The project is under construction and has not launched yet.

1) Target audience

• Autonomous agent developers (startup teams + independents) who need micro-services (data retrieval, inference, verification, computation) without a contract and API key for each provider.

• AI and automation tool developers who run thousands of small calls per month and need per-call pricing and a definable budget.

• Micro-service providers (freelancers and small teams) who want to sell their services automatically without manual sales processes.

• Enterprise data and research teams that need provable execution and an audit trail for every operation.

• Platform builders that ship ready-made agents (SaaS/B2B) and want to give them a reliable source of services.

2) Points of differentiation (why choose our product)

• Discovery by testing, not by description: every provider publishes a "Capability Card" in JSON plus test suites; the buyer agent runs them locally, yielding a documented success rate, p95 response time, and average price/task before purchase.

• Atelier-style escrow against the outcome: every transaction holds the value in escrow and releases it automatically when the SLA is met, with a 48-hour dispute window and automatic refund on breach — instead of "request then pay."

• Zero API keys: agent identity via public key + proof of ownership (Ed25519) + scoped authorization (scope, spend cap, expiry date); the agent never leaks the provider's secrets.

• Multi-rail settlement: USDC on L2 + card-paid balance inside the platform, bringing the market to people who don't use crypto.

• Open-source self-hostable core: 0% commission for the provider when self-hosting; the cloud version is paid for discovery, escrow, and analytics.

• Pre-launch cost simulator: comparison of expected cost per "successful outcome" across three providers.

• Original visual identity: name, logo, colors, and the tone of a "ledger" (scale/entries) instead of the cliché financial-editorial metaphor.

3) Scope of version one (8 tasks)

1. Capability registry: unified schema + REST/Python SDK + search and filtering (service type, price, SLA, language).

2. Open-source node: a local gateway that receives buyer requests, routes them to providers, and records cost and response time.

3. Experimental credits wallet + USDC integration on Base (testnet first) with hold/release/refund and a dispute window.

4. Keyless authorization: challenge-response, signing, scopes, spend cap, expiry, and revocation.

5. A measuring harness: runs provider test suites locally and issues a "measurement certificate" (success rate + p95 + price) that is refreshed periodically.

6. CLI for agents: search / quote / use / pay / verify / dispute with MCP integration so services appear as tools inside the user's agent.

7. Two dashboards (provider/buyer): income, requests, settlements, spending, dispute log.

8. Experimental provider model + 10 real providers: a public test data package (text extraction, translation, math verification, data fetching) to try automated purchasing from the start.

4) Pricing and revenue model

• Free forever: the core is open source (MIT) and self-hosting = 0% commission for the provider, with no limit on the number of agents.

• Free cloud: 1,000 transactions/month, 0% commission, USDC 50 escrow, basic logs.

• Pro ($29/month): 1.5% commission on transactions + analytics dashboard + verification receipts + team workspace + support.

• Verified Provider ($199/month): identity and behavior audit, documented badge, priority in search results.

• Enterprise: compliance, retention, and integration API fees (annual agreement) — no commission on signed transactions.

• Paid add-ons: Economy design workshop templates, and an "approved provider" certificate via a points system.

5) Global rollout plan using free channels

• GitHub: quickstart "publish your agent in 10 minutes," a profile page for each provider (long-tail SEO), and open contribution models.

• MCP: publish our services as MCP servers in tool communities (glama, smithery, MCP directories) and free npm/pypi listings.

• Forums: Show HN, Reddit (r/LocalLLaMA, r/AIAgents, r/opensource), Discord "AI Agent Builders," and free hackathon slots with devpost/partner hackathons.

• Content: dev.to/Hashnode articles on the "agent economy" and micropayments, plus SVG/JSON templates for capability cards.
