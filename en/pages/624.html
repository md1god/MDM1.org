Vaultcade — Complete Project Plan

Your game saves kept forever: encrypted local backups, one-click restore, on any device.

Execution plan for a new digital project: idea, audience, product, revenue model, distribution, and risks. Not yet launched.

1) Target Audience

Problem: Game saves are lost through OS reinstalls, sync conflicts, corruption, or device changes. Existing solutions are tied to one platform, a closed cloud, or complex manual setup.

• PC players with large libraries moving between devices.

• Steam Deck, Linux, and Proton users with varying save paths.

• Modders and speedrunners needing multiple recoverable versions.

• Players outside major stores, retro games, and emulators.

• Privacy-conscious users avoiding third-party clouds.

• Families and friends sharing devices.

2) Differentiators

• Local-first, free to start: no account or internet needed.

• User's cloud, not forced: sync with WebDAV, S3, or own storage; no lock-in or big hosting cost.

• End-to-end encryption: keys stay on-device; providers cannot see content.

• Transparent detection: auto save paths for popular stores, heuristics for unlisted games, editable rules.

• Safe timeline: game-version-tied versions, preview before restore, automatic safety copy.

• Smart conflicts: file- and game-level comparison, not "last write wins."

• Lightweight: native app (Rust + Tauri) with CLI on Windows, Linux, Steam Deck; no process injection or background services.

• Full transparency: no ads, no data selling, optional telemetry.

3) First Version Scope (max 8 tasks)

Desktop app + CLI, Arabic and English interfaces, code from scratch.

1. Auto-detect libraries and save paths for Steam, Epic, GOG, itch, Wine/Proton.

2. Add games or folders manually; simple rules editor with import/export.

3. Backup engine: compression, deduplication, verification fingerprints, atomic writes.

4. One-click restore with preview and automatic safety copy.

5. Version timeline with game-version tags and adjustable retention.

6. Play monitoring, post-session auto-backup, locked-file handling.

7. Encrypted transfer bundle export/import with key management and recovery.

8. Encrypted sync to user storage (WebDAV/S3), device management, conflict resolution.

Out of scope: managed cloud, mobile apps, macOS.

4) Pricing and Revenue Model

• Free: unlimited local backups, detection, restore, export/import, two-device sync via user storage, 30-day history.

• Pro: $2.99/month or $24.99/year: unlimited devices and history, advanced conflicts, scheduled backups, family sharing for five devices.

• Founder license: $59 one-time, limited, lifetime Pro features.

• Managed storage later: $1.99/month per 50GB.

• Regional pricing, 30-day refunds, no ads or data selling.

5) Distribution Plan with Free Channels

• GitHub: open repo for detection rules and CLI, attracting contributions and trust.

• Technical communities: PCGamingWiki, ProtonDB, Lutris, Bottles, Steam Deck groups on Reddit and Discord.

• Distribution: Flathub, AUR, winget, Scoop, Chocolatey, itch.io; Steam page if allowed.

• Content: short YouTube, TikTok, Shorts tutorials on lost-save recovery, multilingual SEO.

• Launch: Product Hunt, Hacker News (Show HN), AlternativeTo, Awesome lists.

• Modding: Nexus Mods, ModDB, modder channels, value offers before promotion.

• Growth: free creator keys, referral month of Pro, Crowdin translation.

• Partnerships: speedrunning and digital preservation.

6) Risks (Legal and Technical)

Legal:

• Trademark: freedom-to-operate search and name registration before launch.

• Privacy: GDPR/CCPA, end-to-end encryption, clear deletion policy.

• IP: no game or protected-file distribution, no breaking protection, only copying user files.

• Cloud: bring-your-own-storage avoids provider API changes.

• Data loss: clear disclaimer, safety copies, integrity checks, insurance as it grows.

• Licensing: SBOM and open-source license compliance.

Technical:

• False paths: dry run and user confirmation before deletion or restore.

• Locked files: VSS on Windows, retries, incremental copying.

• Sync conflicts: content fingerprints and logical clocks, not device time.

• Performance: compression, deduplication, incremental copying for large files.

• Anti-cheat: no process injection; file-system monitoring only.

• Save changes: versioned rules, raw fallback backups if parsing fails.

• Security: AEAD encryption, secure key recovery, lost-device revocation.

• Updates: staged rollout with rollback.

7) Name and Tagline

Proposed name: Vaultcade

Tagline: Your game saves kept forever: encrypted local backups, one-click restore, on any device.
