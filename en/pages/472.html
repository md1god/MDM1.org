Darq — Complete Project Plan

Discover MCP servers, understand their risks, and install them with confidence.

A complete implementation plan for a new digital project: idea, audience, product, revenue model, distribution plan, and risks. The project is under development and has not yet been launched.

1) Target Audience

• Individual developers and AI agent engineers who use clients like Claude, Cursor, and VS Code and want to discover and install MCP servers quickly and securely.

• Small and medium-sized teams that need permission governance, audit logs, and unified policies before allowing their members to use external servers.

• Security and platform teams responsible for reviewing the supply chain, dependencies, vulnerabilities, and tool behavior before adoption.

• MCP server creators who want fair distribution, a verification page, usage data, and a support channel without paying for ranking.

• Regulated organizations that need compliance reports and approval logs before deploying MCP tools internally.

Primary focus: individual developers and small teams, then expand to security teams and enterprises.

2) Differentiators (Why Choose Our Product)

• Interpretable security score, not an opaque number: each score is built on visible evidence such as required permissions, dependencies, known vulnerabilities, package source, signature, maintenance recency, and server behavior in an isolated environment.

• Continuous monitoring instead of one-time checks: periodic re-scans, alerts on new vulnerabilities, ownership or permission changes, and automatic revocation of trust badges when warranted.

• Safe global installer: generate ready-to-use configurations for multiple clients, with version pinning, backups, one-click rollback, and clear explanations of permissions before installation.

• Organic marketplace with no paid ranking: sponsorships and partnerships are clearly labeled, and payment cannot improve the score or buy a higher position.

• Full transparency: the evaluation methodology is published, open to objections and reviews, with a change log for each server.

• Privacy-first: local scanning is available, telemetry is only optional, and secrets are sanitized from configuration files.

• Comparison experience: server pages compare by client, permissions, license, compatibility, and risks, with reliable alternatives.

• New visual identity: a design based on the "open shield" and network of dots concept, conveying protection and transparency rather than security complexity.

3) Scope of the First Version (Max 8 Tasks)

1. Initial index: collect 300–500 MCP servers from public sources, remove duplicates, and unify metadata.

2. Semantic search and filters: search by description and function, filter results by client, transport, authentication, permissions, license, and language.

3. Security evaluation engine v0: automated checks for dependencies, vulnerabilities, permissions, and source, with methodology and limitations clearly published.

4. Server pages: documentation, versions, compatibility, installation commands, warnings, and change logs.

5. Installer/config generator for five clients: Claude, Cursor, VS Code, Cline, and Continue, with version pinning, backups, and rollback.

6. Continuous monitoring: periodic re-scans, email or in-app alerts, and a path to revoke trust badges in the event of incidents.

7. Server ownership claim: maintainer verification, new server submission, and a basic control panel.

8. Admin dashboard: review reports, manage objections, and basic usage metrics without personal tracking.

4) Pricing and Revenue Model

• Free to start: search, basic evaluation, server pages, installation, and basic alerts.

• Pro for individuals: ~$9/month for deeper scans, longer history, instant alerts, and saved comparisons.

• Team for teams: ~$25 per user/month with a minimum of five seats, for private lists, permission policies, audit logs, and approvals.

• Enterprise: custom annual pricing for SSO, compliance reports, SLA, internal deployment, and priority support.

• Support for maintainers: optional user subscriptions, with 80% to the creator and 20% to the platform, clearly separated from evaluation.

• Paid services: clearly labeled sponsored listings and deployment consulting, with no impact on score or ranking.

• Core rule: no selling of scores, no paid ranking, no fees for free installation.
