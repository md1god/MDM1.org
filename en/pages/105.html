Naseej Maps — Complete Project Plan

Interactive maps woven from your data, with no restrictions and no monopoly.

A complete implementation plan for a new digital project: the idea, audience, product, revenue model, rollout plan, and risks. The project is under construction and has not launched yet.

Product plan: a next-generation interactive web mapping library

1) Target audience

• Web and front-end developers who need interactive maps without being tied to a single provider.

• GIS and geospatial teams in companies, government entities, and non-profit organizations.

• Startups in logistics, real estate, transport, and mobility that build custom maps.

• Newsrooms and research institutions that need rich geospatial data visualization.

• Arab developers looking for native Arabic and RTL support in maps.

2) Points of distinction (why choose our product)

• Written from scratch in TypeScript with a modern, type-safe development experience.

• A rendering engine via WebGL/WebGPU that displays millions of features smoothly.

• Web Components that work with React, Vue, Svelte, and plain JavaScript with no framework dependency.

• A simple declarative interface with advanced hooks when needed.

• Native support for Arabic and RTL, label direction, and an excellent mobile experience.

• No monopoly: works with any tile source or vector data and any geographic projection.

• A fully free open-source core, with a plugin system and free deployment to get started.

3) Scope of the first version (maximum 8 tasks)

1. A WebGL rendering core built from scratch for raster and vector data layers.

2. A projections and coordinates system with support for Web Mercator and custom projections.

3. A vector layer with styles for points, lines, and polygons and click and hover interactions.

4. Ready Web Components with official bindings for the most popular frameworks.

5. A documented package with a declarative interface, interactive documentation, and live examples.

6. Support for multiple sources (XYZ, WMS, WMTS, and GeoJSON) and layer management.

7. Arabic and RTL support, label direction, and mobile performance optimization.

8. A free visual style editor and limited free cloud deployment to get started.

4) Pricing and revenue model

• Free for projects: the full library open source under a permissive license, the basic style editor, and a free monthly cloud usage limit.

• Starter/Pro plan: tile hosting, map analytics, team authentication (SSO), and technical support via monthly subscription.

• Enterprise plan: annual contract, service level agreement (SLA), private deployment, and training.

• Plugin marketplace: a commission on paid plugins and themes published by developers.

5) Global rollout plan through free channels

• Publish the repository on GitHub and distribute it via npm and free CDN networks.

• Continuous educational content: articles, videos, and copyable interactive examples.

• Build a community via Discord, Stack Overflow, Reddit, GIS forums, and developer platforms.

• Participate in hackathons, universities, and open-source programs such as autumn contributions.

• List the product in awesome lists and tech product communities.

• Integrations with open data tools and open-source maps to broaden reach.

6) Risks (legal and technical)

• Legal: ensuring all code, design, and branding are written from scratch, verifying the licenses of tile and data sources, respecting third-party terms of use, protecting user privacy, and complying with regulations such as GDPR.

• Technical: WebGPU performance on older devices, browser compatibility differences, maintenance of geospatial databases, competition from established libraries, plugin security, and accuracy of conversion between projections.

7) Proposed name and marketing tagline

Proposed name: Naseej Maps

Marketing tagline: Interactive maps woven from your data, with no restrictions and no monopoly.
