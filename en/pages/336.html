Mi'yar — Full Project Plan

Design in 3D in Arabic, start free in seconds.

Full execution plan for a new digital project: idea, audience, product, revenue model, rollout plan, and risks. The project is under construction and has not launched yet.

1) Target Audience

• Beginners in 3D design: students, 3D printing enthusiasts, and makers who need a free program that is easy to learn.

• Engineers and independent designers: those working on parts, spare parts, and small molds who want parametric design without fees.

• Non-programmers: install the program and start within minutes, with no complicated setup.

• Universities and technical schools: looking for a free educational tool that runs on Windows, macOS, and Linux.

2) Differentiators (why choose our product)

• Arabic-first interface with full language and right-to-left direction support, plus English.

• Lightweight cloud parametric engine: the browser runs the design instantly with no heavy loading, with an option to install a desktop version for large projects.

• AI-powered learning: an assistant that explains commands and suggests next steps while designing, and converts a text description into an editable base model.

• Ready-made part library for collaboration: users create reusable parts and share them under a free license.

• Direct integration with 3D printing: wall thickness checking and splitting large parts across the print bed from inside the program.

• Lighter performance: smooth on mid-range and older devices thanks to WebGL and WASM.

3) Scope of the First Release (8 tasks maximum)

1. A web application running in the browser to draw 2D shapes (lines, circles, arcs) with design constraints.

2. Converting a 2D shape into a solid using extrude and revolve.

3. Boolean operations: union, intersection, and subtraction of bodies.

4. An editable feature tree at any stage, with automatic recalculation.

5. A simplified units screen (distance, angle, thickness) with a unified measurement system.

6. Export to STL / STEP / 3MF, and section cuts of a ready shape.

7. Saving projects in the cloud, sharing a link for viewing and collaborative editing, and version history.

8. Assistant layer: a text assistant that suggests commands and explains the steps, with a fully Arabic interface.

4) Pricing and Revenue Model

• Free to start: a free version covering all drawing, solid modeling, and basic export tools, with unlimited projects.

• Pro plan — $12 per month: the advanced smart assistant, industrial-grade export, and a professional part library.

• Teams plan — $25 per user per month: real-time collaboration, permissions, and larger storage.

• Education plan — free for schools and universities, with a paid plan for advanced labs.

• Other revenue sources: a marketplace for parts and drawings (15% commission on paid drawings), sponsorship for 3D printing tools, and an API for manufacturers.

5) Global Rollout Plan Using Free Channels

1. YouTube and Twitch: short tutorials in multiple languages (Arabic, English, Spanish, Hindi) building two projects in 10 minutes.

2. TikTok and Instagram Reels: before/after clips of designing a part and 3D printing it.

3. Reddit and Discord: a users community, a support channel, and weekly design challenges with symbolic prizes.

4. GitHub Pages and an SEO blog: simple tool comparisons and articles solving common problems.

5. Educational communities: partnerships with technical schools and makers clubs, and free workshops via Zoom.

6. Product Hunt and Hacker News: launching a beta version with an awareness campaign.

7. Community translation: open localization on Transifex or Weblate to speed entry into new markets.

6) Risks (legal and technical)

• Legal: avoid copying any code or protected interfaces; rely only on openly licensed libraries (MIT / LGPL / Apache) and document the licenses inside the project. Protect the name and logo with trademarks, and register the idea and designs officially.

• Technical: the accuracy of engineering operations (smoothing, booleans) requires comparative testing against industrial standards; support for large files may be delayed; WebGL may fail on some old graphics cards, so the desktop option remains.

• Operational: server costs for free accounts may rise, so a storage limit applies to free projects and a full local version is added.

• Competitive: established free tools already exist; differentiation comes through Arabic, speed, and the smart assistant.

7) Proposed Name and Tagline

Proposed name: Mi'yar (Meyar)

Tagline: Design in 3D in Arabic, start free in seconds.
