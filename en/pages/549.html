NebulaRoute — Complete Project Plan

Intelligent control of AI models, with complete privacy and free of charge.

A complete implementation plan for a new digital project: the idea, audience, product, revenue model, distribution plan, and risks. The project is under construction and has not been launched yet.

1) Target Audience

• Independent developers: looking for a fast tool to test and compare models before integrating them into their projects.

• Privacy-focused users: want to keep their conversations on their devices without storing them on external servers.

• Students and researchers: have limited budgets and need to use open-weight models for free.

• Emerging tech teams: looking for a way to choose the most suitable models at the lowest possible cost.

2) Differentiators (Why choose our product)

• Privacy by default: runs locally as much as possible, without forcing the user to create an account.

• Smart task routing: suggests the most suitable model based on the nature of the task, not just the most popular one.

• "Free-first" focus: all core features work without payment or a credit card.

• Automatic device capability detection: recommends models that can actually run, preventing crashes or freezes.

• Simple and lightweight: an interface designed for speed, free of ads and complexity.

3) Scope of the First Version (maximum 8 tasks)

1. [ ] Basic chat interface: create a clean and fast chat screen.

2. [ ] Local execution: support integration with Ollama for full on-device operation.

3. [ ] Browser execution: support WebLLM with WebGPU when available.

4. [ ] Side-by-side comparison: display two models' responses to the same question for immediate comparison.

5. [ ] Smart routing system: suggest a model based on the question type and device capabilities.

6. [ ] Estimator calculator: estimate token usage before enabling any optional cloud usage.

7. [ ] Local key management: store API keys on the device only when needed, and in an isolated way.

8. [ ] Quick templates: add a small set of templates for the most frequent tasks.

4) Pricing and Revenue Model

• Core: completely free, and runs locally without restrictions.

• Optional in the future: an optional enterprise package that provides team settings, while all privacy features remain free.

• Fixed principle: no selling of user data, and no converting core features into paid ones.

5) Global Distribution Plan with Free Channels

• One descriptive page: a lightweight page targeting the term "running models locally" in the most widely used languages.

• Free tool directories: add it to relevant free technical tool directories for developers.

• Short educational content: publish a short explanation showing how it works without registration, with a focus on the privacy feature.

• Participation in open communities: contribute usefully to technical developer communities, without paid ads.

• Discoverability optimization: use an accurate technical description for the tool page to increase organic visibility.

6) Risks (Legal and Technical)

· Type · Risk · Mitigation ·

· Legal · Differences in open-weight model licenses · Show each model's license only when it is selected, and do not redistribute it within the tool. ·

· Legal · Optional use of cloud services via user keys · Make it entirely optional, with a clear notice that keys do not pass through the tool's servers. ·

· Technical · Weak WebGPU support on some devices · Detect support automatically, and rely on local Ollama as an immediate fallback. ·

· Technical · High memory and battery consumption · Filter models according to device capabilities, and limit the size of suggested models. ·

· Technical · Instability of some model versions · Rely on public model lists, without forcing any model to be pinned. ·

7) Proposed Name and Marketing Tagline

Proposed name: NebulaRoute

Marketing tagline: Intelligent control of AI models, with complete privacy and free of charge.
