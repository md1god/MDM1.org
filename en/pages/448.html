Zaytoon — Complete Project Plan

One panel for Windows: open any app, file, or work set in one click, without replacing the shell

A complete implementation plan for a new digital project: the idea, audience, product, revenue model, distribution plan, and risks. The project is under construction and has not been launched yet.

1) Target audience

• Power Windows users: developers, system administrators, and users with many windows (Multi-Monitor) who want a lighter alternative to the existing shells layer.

• Remote workers and students: they need a stable "work kit" (apps + files + folders + links) that opens with one click instead of manually setting up the session.

• Customization and luxury lovers: they follow Keyboards, Wallpapers, and Dotfiles, and love modifying the interface and importing add-ons.

• Developers and add-on creators: a second segment that creates content, expands the system, and brings it to a new audience.

• Non-English markets: Arabic, Turkish, Spanish, Portuguese, and Indonesian users who suffer from interfaces without native RTL.

2) Points of differentiation (why we choose our product)

• Native and lightweight: a kernel written from scratch (Rust + DirectWrite) with boot time < 120ms and usage < 60MB, without Electron and without WebView2.

• One panel instead of the taskbar and Start menu: apps + files + settings + calculator + web search + snippets + clipboard history in one place, while keeping the original Windows system recoverable with one press.

• "Topics": every work kit (apps/files/links/workflows) is saved and launched with a single command, and shared as a single file — the key differentiator versus any traditional app launcher.

• Add-on system with a safe sandbox: Sandbox (WASM/JS with limited permissions) + open SDK + themes and add-ons gallery, with a publishing script and signing.

• Local-first and no tracking: indexing and search on the device, zero analytics, fully offline operation.

• RTL support and native Arabic: layout, fonts, IME input, and full interface translation from day one.

• Open source (MIT) for the kernel: builds trust, attracts contributors and makers, and expands distribution for free.

3) Scope of the first version (max 8 tasks)

1. The Quick Launcher: Global Hotkey + instant fuzzy search across apps, files, folders, and settings + calculator/web search/quick conversions.

2. The customizable panel: layouts and snapping, colors and side panels, a theme editor with live preview, and full RTL support.

3. Shell replacement mode: an alternative to the Start menu and taskbar (Tray + window switcher + clock + calendar) with one-click return to the original system.

4. Window management: Snap Layouts, virtual desktops, moving windows between screens with per-screen DPI support.

5. Topics/Spaces: create a Topic (apps+files+links+commands), launch it with one command or shortcut, and import/export it as a shareable file.

6. Snippets and clipboard history: search the history, pin items, text snippets, and Text Expansion via shortcuts.

7. Add-on kit: an SDK for developers, a sandboxed execution environment, install from file/repository, and a built-in gallery with 25 core add-ons.

8. Distribution and readiness: portable version + installer, auto-update, auto-start, changelog, Arabic/English documentation, and Windows 10/11 compatibility.

4) Pricing and revenue model

• Free forever (no sign-up): the kernel, the panel, topics, snippets, search, basic themes, and 25 add-ons.

• One-time Pro (29$ regular / 19$ launch): cloud sync for themes and topics, backup, theme packs, diagnostic tools, and priority support.

• Optional subscription (2.5$/month): AI features (translation/summarization) either on-device or via an optional API key — and it can be fully disabled.

• Add-ons and themes market: 15% commission for content creators.

• Free for schools/nonprofits: discounted bulk copies + a source-built version.

5) Global distribution plan through free channels

• Free public launch: Product Hunt + Hacker News (Show HN) + Reddit (r/windows, r/productivity, r/SaaS) via a short video measuring "time saved" and a daily use story.

• GitHub as a distribution model: MIT kernel + SDK + examples → stars and forks translate into adoption and partnerships; easy "issue" templates encourage contributors.

• Installation packages: winget + Chocolatey + Scoop + MSIX with a support page and promotional material for each channel.

• YouTube: a "shortcuts" channel — one video per feature/30 seconds (recordable without heavy production) + collaborations with Productivity and Keyboards channels.

• Technical articles on dev.to
