CalorieLens — Plano de Projeto Completo

Tire uma foto, descubra as calorias, ajuste e salve — grátis, com privacidade total, sem apps.

Plano de execução completo para um novo projeto digital: ideia, público, produto, modelo de receita, plano de divulgação e riscos. O projeto está em construção e ainda não foi lançado.

1) Público-alvo

• Pessoas que querem rastrear calorias sem instalar apps ou criar contas

• Praticantes de esportes e dietas temporárias (keto, jejum intermitente)

• Quem valoriza privacidade e evita anúncios e rastreamento

• Usuários de desktop e celular que querem ferramenta rápida e compartilhável

2) Diferenciais (por que escolher nosso produto)

• Totalmente grátis e sem cadastro: funciona ao abrir o link, sem contas nem paywalls

• Roda só no navegador: sem instalação, funciona em qualquer dispositivo, suporta PWA para uso offline

• Resultados ajustáveis: usuário corrige a estimativa manualmente e o modelo aprende com as correções localmente

• Privacidade absoluta: imagens não saem do dispositivo, processamento local via WebAssembly/TensorFlow.js

• Compartilhamento fácil: link de resultado compartilhável com nutricionista ou treinador

• Código aberto: transparência total, comunidade desenvolve o modelo

3) Escopo da v1 (máx. 8 tarefas)

1. Interface web simples: upload/captura de foto → exibir estimativa → editar campos → salvar/compartilhar

2. Modelo de estimativa de calorias/macros rodando localmente (TensorFlow.js + modelo MobileNet treinado no Food-101)

3. Editor de resultados interativo: ajustar calorias, proteína, carboidratos, gordura, gramas com recálculo instantâneo

4. Armazenamento local (IndexedDB) para histórico diário com exportação CSV/JSON

5. Modo PWA: instalar como app, funciona offline, sincronização opcional depois

6. Página de resultado compartilhável via link único (sem servidor, via URL params comprimidos)

7. Suporte RTL completo para árabe, modo escuro/claro

8. Testes unitários e de integração + CI/CD para deploy automático em Pages/Workers gratuitas

4) Precificação e modelo de receita

• Versão base: grátis e open source para sempre

• Plano "Pro" opcional (4$/mês ou 35$/ano): sincronização na nuvem criptografada, modelos mais precisos (maiores), relatórios semanais/mensais PDF, API para devs, suporte prioritário

• Sem anúncios, sem venda de dados: receita só de assinaturas opcionais

• Licença MIT: empresas podem hospedar sua própria instância

5) Plano de divulgação global com canais gratuitos

• Reddit: r/nutrition, r/loseit, r/keto, r/intermittentfasting — posts "Show HN" semanais com screenshots reais

• GitHub: lançamento open source com README excelente, exemplos, convite a contribuições

• Product Hunt / AlternativeTo / SaaSHub: lançamento da v1 grátis

• Conteúdo SEO: artigos "como calcular calorias da refeição com uma foto", comparação com apps famosos

• Twitter/Threads/Mastodon: série diária "refeição do dia + estimativa", retweets de contas de fitness

• Discord/Telegram: comunidade pequena para suporte, pedidos de features, compartilhamento de modelos treinados

• YouTube Shorts/Reels/TikTok: vídeos de 30s: "foto → resultado → ajuste → salvar"

• Microparcerias: personal trainers, nutricionistas oferecem a ferramenta aos clientes grátis

6) Riscos (legais e técnicos)

• Legais: disclaimer médico claro ("ferramenta de estimativa, não aconselhamento médico"), conformidade GDPR/CCPA (sem dados pessoais), evitar alegações diagnósticas

• Precisão do modelo: estimar comida é difícil (molhos escondidos, óleos de cozimento, tamanhos de porção) — mitigação: editor manual fácil, aprendizado com correções do usuário localmente

• Performance no navegador: modelos grandes podem travar celulares fracos — mitigação: modelo leve padrão, opção "modelo preciso" para dispositivos potentes

• Suporte à câmera: permissões HTTPS obrigatórias, fallback de upload de arquivo — mitigação: PWA com manifest correto, instruções claras

• Manutenção: um modelo não cobre todas as culinárias — mitigação: arquitetura plugável para modelos regionais, comunidade contribui com dados anônimos

7) Nome proposto e slogan

Nome proposto: CalorieLens

Slogan: Tire uma foto, descubra as calorias, ajuste e salve — grátis, com privacidade total, sem apps.
