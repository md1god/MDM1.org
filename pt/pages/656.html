OrbitPost — Plano de projeto completo

Agende uma vez, publique em todo lugar — por humanos ou agentes de IA.

Plano de execução completo para um novo projeto digital: ideia, público, produto, modelo de receita, plano de lançamento e riscos. O projeto está em construção e ainda não foi lançado.

1) Público-alvo

Agências de marketing, criadores de conteúdo independentes, fundadores de SaaS e desenvolvedores que constroem agentes de IA (n8n/LangChain/custom) que precisam de publicação autônoma. Além de empresas que querem hospedagem própria (on-prem) para conformidade e privacidade de dados.

2) Diferenciais (por que escolher nosso produto)

• API-first para agentes: REST + MCP server + webhooks, projetado para ser chamado por agentes de IA (e não merely para usuários).

• Gratuito para auto-hospedagem (Docker Compose com um comando) + camada gratuita na nuvem.

• BYO-LLM: use sua chave (OpenAI/Anthropic/Ollama local) — sem custo de tokens de nossa parte.

• Arquitetura de plugins: adicionar uma nova plataforma = adicionar um pacote, sem modificar o core.

• Motor de fila com retry, agendamento por fuso horário e anti-duplicação.

• Open-core: kernel Apache-2.0, recursos enterprise (SSO/RBAC/audit) pagos.

• Local-first: seus dados, suas chaves, seu cronograma — em suas máquinas.

3) Escopo da primeira versão (máximo 8 tarefas)

1. Motor de agendamento e fila (queue + retry + timezone).

2. Conectores OAuth para 5 plataformas (X, LinkedIn, Instagram, Facebook, TikTok).

3. Geração de conteúdo com IA (chave BYO) com templates.

4. API REST pública + webhooks + spec OpenAPI.

5. MCP server (ferramenta de agente) + SDK (Python/TS).

6. Painel (calendário, rascunhos, analytics simples).

7. Auto-hospedagem Docker + documentação + deploy com um clique.

8. Camada gratuita na nuvem + billing (Stripe).

4) Precificação e modelo de receita

• Auto-hospedagem: gratuito (core Apache-2.0), suporte pago opcional.

• Cloud Free: 3 contas, 10 posts/dia, 1 usuário.

• Pro $19/mês: 10 contas, ilimitado, 3 usuários.

• Team $49/mês: 30 contas, 10 usuários, analytics avançado.

• Enterprise: preço sob consulta (SSO, RBAC, audit, SLA, suporte on-prem).

• Receitas: assinaturas na nuvem, hospedagem gerenciada, suporte/SLA, marketplace de plugins (rev-share 20%), templates premium.

5) Plano de lançamento global com canais gratuitos

• Lançamento no Product Hunt + Hacker News (Show HN).

• Reddit: r/selfhosted, r/marketing, r/SideProject, r/LocalLLaMA.

• GitHub: README excelente + badges + issue templates + good first issues.

• YouTube: tutoriais "self-host em 5 min" + demos de automação de agentes.

• Comunidades Discord/Slack (n8n, LangChain, Indie Hackers).

• Listagem no registro MCP + integração com ferramentas LangChain.

• Docs SEO + páginas de comparação ("vs Buffer/Hootsuite").

• Criadores afiliados (créditos do tier gratuito, sem dinheiro adiantado).

• Contribuições open-source para o ecossistema MCP.

6) Riscos (legais e técnicos)

Legais: termos das plataformas de redes sociais (automação/publicação automática) podem restringir ou proibir; revisão de apps OAuth (atrasos); marcas registradas; GDPR/CCPA (dados de usuários, direito ao esquecimento); abuso (spam/bot) → AUP + rate limiting + verificação.

Técnicos: mudanças nas APIs das plataformas (breaking changes); rate limits; confiabilidade da fila (idempotência, dedup); escalabilidade (Redis/Postgres); segurança de chaves de agentes (criptografia em repouso, tokens com escopo, rotação); custo de hospedagem na nuvem; vendor lock-in em apps OAuth.

7) Nome sugerido e slogan

Nome sugerido: OrbitPost
