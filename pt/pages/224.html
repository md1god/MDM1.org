صِنف — Plano completo do projeto

Saiba o que há na sua comida com um toque e ajude a construir o maior banco de dados alimentar aberto do mundo árabe.

Plano de execução completo para um novo projeto digital: ideia, público-alvo, produto, modelo de negócio, plano de divulgação e riscos. O projeto está em construção e ainda não foi lançado.

1) Público-alvo

• Consumidores conscientes da saúde: aqueles que leem os ingredientes e querem saber sobre açúcar, sal, gorduras e aditivos antes da compra.

• Pessoas com alergias e dietas específicas: diabéticos, celíacos, vegetarianos, veganos ou aqueles que seguem uma dieta específica.

• Desenvolvedores e equipes de produtos: que constroem aplicativos de fitness, nutrição ou comércio eletrônico e precisam de dados alimentares estruturados via API.

• Pesquisadores e estudantes de nutrição: que precisam de grandes volumes de dados que possam ser consultados e analisados.

• Colaboradores voluntários: fotógrafos de produtos, ativistas de dados abertos, editores de categorias.

2) Diferenciais (por que escolher nosso produto)

• Começamos pelo árabe e pela região primeiro: dados de produtos locais (marcas regionais não cobertas), com interface e experiência em árabe nativo, para depois expandir globalmente.

• Qualidade antes da quantidade: sistema de verificação automática (impressão digital da imagem do código de barras + verificação de conflitos entre ingredientes) que atribui a cada ficha um grau de confiança visível ao usuário.

• Design moderno do zero: experiência de uso simples e rápida (aplicativo web primeiro, sem necessidade de instalação), ao invés de interfaces antigas e sobrecarregadas.

• Dados verdadeiramente abertos: licença aberta explícita para os dados + API gratuita no início, sem restrições contratuais.

• Contribuição em um único passo: fotografar um código de barras já é suficiente para adicionar um produto, com recompensas de reputação para os colaboradores.

3) Escopo da primeira versão (máximo 8 tarefas)

1. Busca por nome ou código de barras e página do produto exibindo ingredientes e valores nutricionais.

2. Adição de produto por foto (código de barras + foto da embalagem frontal + tabela nutricional) com verificação básica.

3. Classificação automática do nível de qualidade (açúcar, sal, gorduras saturadas, aditivos) com explicação simplificada.

4. Filtros inteligentes por alergia e dieta (glúten, diabético, vegetariano...).

5. API pública para leitura (endpoints de produtos e busca) com chaves gratuitas.

6. Painel simples para colaboradores: minhas contribuições, reputação, tarefas de edição pendentes.

7. Suporte a dois idiomas (árabe e inglês) com estrutura para adicionar outros idiomas.

8. Exportação de dados abertos (CSV/JSON com um clique) e pacote de dados periódico.

4) Preços e modelo de negócio

• Gratuito no início: uso pelo consumidor, contribuições e API, com limite generoso (por exemplo, 1000 requisições por dia) — sem anúncios irritantes.

• Plano Pro para desenvolvedores: maior número de requisições, dados adicionais (histórico de alterações, lotes), suporte — com assinatura mensal escalonada.

• Enterprise: licenças de dados personalizadas, SLA, integração com sistemas de varejo e saúde.

• Financiamento comunitário: doações, patrocinadores institucionais para dados abertos, bolsas de pesquisa.

• Serviços pagos: limpeza e padronização de listas de produtos de empresas, mediante taxa (sem bloquear o acesso aos dados básicos).

5) Plano de divulgação global com canais gratuitos

• Conteúdo em vídeo curto: vídeos com o formato "O que tem neste produto?" em plataformas de vídeos curtos para fins educativos.

• Comunidades de dados abertos: publicação em fóruns de código aberto, Reddit e grupos de desenvolvedores.

• Integrações gratuitas: templates open source que suportam a API para criar aplicativos de saúde rapidamente.

• Universidades e associações de saúde: parcerias de pesquisa e projetos estudantis para verificação de dados.

• Conteúdo SEO em vários idiomas: páginas de produtos indexáveis que exibem os valores nutricionais nos resultados de busca.

• Campanhas de desafio de contribuição: desafio semanal para fotografar produtos locais, com ranking de reputação.

6) Riscos (legais e técnicos)

• Legais: licenças, imagens de produtos e marcas registradas — serão resolvidos com dados abertos explícitos, revisão dos direitos de imagem e respeito às marcas, sem reivindicar propriedade.

• Privacidade: dados dos colaboradores — aplicaremos coleta mínima de dados e política de exclusão clara (em conformidade com GDPR).
